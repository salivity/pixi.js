Pass a 2D Matrix Uniform in PixiJS Shaders

Passing a 2D matrix uniform into a custom vertex shader in Pixi.js involves declaring the matrix in GLSL, converting your 2D transformation data into a WebGL-compatible flat array, and attaching it to a PIXI.Shader or PIXI.Filter uniform group. This guide demonstrates how to define a 3x3 matrix (mat3) in a custom vertex shader and pass transformation data using Pixi's native Matrix class or a custom Float32Array.

1. The Vertex Shader

In 2D graphics, affine transformations (translation, rotation, scale, and skew) require a 3x3 matrix (mat3) to support homogeneous coordinates. Define your uniform in the vertex shader:

attribute vec2 aVertexPosition;

uniform mat3 projectionMatrix;
uniform mat3 translationMatrix;
uniform mat3 uCustomMatrix; // Your 2D matrix uniform

varying vec2 vTextureCoord;

void main(void) {
    // Apply the custom 2D matrix to the vertex position
    vec3 position = uCustomMatrix * vec3(aVertexPosition, 1.0);

    // Complete the standard PixiJS projection chain
    gl_Position = vec4((projectionMatrix * translationMatrix * position).xy, 0.0, 1.0);
}

2. Preparing the Matrix Data

WebGL expects matrices to be supplied in column-major order. A 2D affine transformation in Pixi.js uses the components [a, b, c, d, tx, ty], which maps to a 3x3 matrix:

\[\begin{bmatrix} a & c & tx \\ b & d & ty \\ 0 & 0 & 1 \end{bmatrix}\]

In a flat array (column-major order), this translates to: [a, b, 0, c, d, 0, tx, ty, 1]

You can generate this array manually using a Float32Array or by using Pixi's built-in PIXI.Matrix:

import * as PIXI from 'pixi.js';

// Using PIXI.Matrix
const pixiMatrix = new PIXI.Matrix();
pixiMatrix.scale(1.5, 1.5);
pixiMatrix.translate(50, 100);

// Convert to a 9-element column-major array
const matrixData = pixiMatrix.toArray(false);

3. Creating the Shader and Passing the Uniform

Pass the matrix uniform as part of the shader configuration:

import * as PIXI from 'pixi.js';

const vertexSrc = `...`; // Vertex shader source code from step 1
const fragmentSrc = `
    varying vec2 vTextureCoord;
    void main(void) {
        gl_FragColor = vec4(1.0, 0.0, 0.0, 1.0);
    }
`;

// Define uniforms
const uniforms = {
    uCustomMatrix: matrixData
};

// Create the shader
const customShader = PIXI.Shader.from(vertexSrc, fragmentSrc, uniforms);

// Apply shader to a Mesh or Geometry
const geometry = new PIXI.Geometry()
    .addAttribute('aVertexPosition', [-50, -50, 50, -50, 50, 50, -50, 50], 2)
    .addIndex([0, 1, 2, 0, 2, 3]);

const mesh = new PIXI.Mesh(geometry, customShader);
app.stage.addChild(mesh);

4. Updating the Uniform Dynamically

To update the matrix inside your animation loop, update the existing array reference or reassign the uniform:

app.ticker.add(() => {
    pixiMatrix.rotate(0.01);
    
    // Update the uniform buffer directly
    customShader.uniforms.uCustomMatrix = pixiMatrix.toArray(false);
});
