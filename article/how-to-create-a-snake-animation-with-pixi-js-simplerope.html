How to Create a Snake Animation with Pixi.js SimpleRope

This article demonstrates how to build a dynamic worm or snake animation in Pixi.js using the SimpleRope mesh object. By chaining an array of control points to a continuous texture and updating those points sequentially toward a target, you can simulate realistic, flexible skeletal motion. The following guide covers texture preparation, point array configuration, and the mathematical logic needed to create smooth, undulating movement in your render loop.

Understanding SimpleRope

The PIXI.SimpleRope class renders a strip of textured triangles across a defined array of PIXI.Point instances. Instead of rotating individual rigid sprites to form segments, SimpleRope deforms and bends a single texture smoothly along the curve defined by these points.

1. Initialize Points and the SimpleRope Mesh

To create a snake, you need a collection of equidistant points representing the spine, along with a texture. The texture should typically be a horizontal strip representing the snake from head to tail.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Configuration
const ropeLength = 40; // Total number of segments
const segmentLength = 15; // Distance between each point
const points = [];

// Initialize points in a straight line
for (let i = 0; i < ropeLength; i++) {
    points.push(new PIXI.Point(i * segmentLength, 0));
}

// Create the rope
const snakeTexture = PIXI.Texture.from('snake_body.png');
const snakeRope = new PIXI.SimpleRope(snakeTexture, points);
app.stage.addChild(snakeRope);

2. Tracking Movement and Simulating the Body

A natural snake or worm body animation requires two distinct behaviors:

  1. Target Following (Inverse Kinematics): The head leads, and each following point maintains a fixed distance from the point ahead of it.
  2. Undulation: A sine wave offset is added perpendicular to the direction of travel to simulate slithering.
let count = 0;
const mousePosition = new PIXI.Point(app.screen.width / 2, app.screen.height / 2);

// Update mouse target position on interaction
app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;
app.stage.on('pointermove', (event) => {
    mousePosition.copyFrom(event.global);
});

app.ticker.add(() => {
    count += 0.1;

    // 1. Move the head toward the target with ease
    const head = points[0];
    head.x += (mousePosition.x - head.x) * 0.1;
    head.y += (mousePosition.y - head.y) * 0.1;

    // 2. Make each subsequent segment follow the one ahead of it
    for (let i = 1; i < points.length; i++) {
        const current = points[i];
        const leader = points[i - 1];

        // Calculate angle and distance to the leading segment
        const dx = leader.x - current.x;
        const dy = leader.y - current.y;
        const angle = Math.atan2(dy, dx);

        // Constrain segment length
        current.x = leader.x - Math.cos(angle) * segmentLength;
        current.y = leader.y - Math.sin(angle) * segmentLength;

        // 3. Add perpendicular wave motion for slithering
        // Skip the head and tail extremities to keep them stable
        if (i > 1 && i < points.length - 2) {
            const wave = Math.sin(count + i * 0.3) * 2;
            const perpAngle = angle + Math.PI / 2;
            current.x += Math.cos(perpAngle) * wave;
            current.y += Math.sin(perpAngle) * wave;
        }
    }
});

3. Tuning the Behavior

  • Number of Points: More points yield smoother bends, but require more CPU updates. A range between 20 and 50 points provides optimal balance between fluidity and performance.
  • Segment Length: Lower segmentLength values create a tighter, denser body, while higher values create a looser chain. Ensure the total length (ropeLength * segmentLength) matches the aspect ratio of your texture to avoid distortion.
  • Slither Intensity: Adjust the frequency (count += rate) to change slither speed, and scale the wave multiplier to change the amplitude of the slither.
