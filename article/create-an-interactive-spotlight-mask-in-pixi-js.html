Create an Interactive Spotlight Mask in Pixi.js

This article demonstrates how to build an interactive spotlight effect in Pixi.js that dynamically illuminates dark regions of a scene based on pointer movement. By combining layered display objects with Pixi.js masking and event listeners, you will learn the exact steps required to render a darkened ambient scene and smoothly reveal bright underlying details using a circular mask attached to the mouse or touch input.

The Layering Concept

The most efficient way to achieve a spotlight effect in Pixi.js is by using two visual layers:

  1. The Ambient Layer: A darkened, low-brightness version of your scene (or the base scene covered by a semi-transparent black overlay).
  2. The Illuminated Layer: A fully lit, vibrant duplicate of the scene placed directly above the dark layer.
  3. The Mask: A circular PIXI.Graphics object applied exclusively to the illuminated layer. When this circle moves, it exposes only the bright pixels directly beneath it, simulating a flashlight or spotlight.

Step-by-Step Implementation

1. Initialize the Application and Assets

Set up your Pixi application and load your background image or sprites.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

// Load the texture to reveal
const texture = await PIXI.Assets.load('path/to/scene.jpg');

2. Create the Dark and Bright Layers

Instantiate two sprites using the same texture and place them on top of one another.

// Layer 1: The Dark Background
const darkScene = new PIXI.Sprite(texture);
darkScene.width = app.screen.width;
darkScene.height = app.screen.height;
// Tint the sprite dark to represent lack of light
darkScene.tint = 0x222222;
app.stage.addChild(darkScene);

// Layer 2: The Fully Lit Foreground
const brightScene = new PIXI.Sprite(texture);
brightScene.width = app.screen.width;
brightScene.height = app.screen.height;
app.stage.addChild(brightScene);

3. Create and Assign the Spotlight Mask

Generate a circle using PIXI.Graphics to serve as the spotlight cone, and set it as the mask for the brightScene.

const radius = 120;

const spotlight = new PIXI.Graphics()
    .circle(0, 0, radius)
    .fill({ color: 0xffffff });

// Position the spotlight initially off-screen or in the center
spotlight.x = app.screen.width / 2;
spotlight.y = app.screen.height / 2;

// Add to the stage and apply as mask
app.stage.addChild(spotlight);
brightScene.mask = spotlight;

4. Add Interactive Pointer Tracking

Enable interactivity on the stage to update the spotlight’s coordinates on every pointer move.

app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;

app.stage.on('pointermove', (event) => {
    spotlight.x = event.global.x;
    spotlight.y = event.global.y;
});

Softening the Edges

Standard masks produce sharp, hard edges. To create a realistic, feathered light beam, apply a BlurFilter to the mask graphic:

const blurFilter = new PIXI.BlurFilter({
    strength: 15,
    quality: 4
});

spotlight.filters = [blurFilter];

This creates a smooth radial falloff around the illuminated area, delivering an atmospheric, interactive spotlight reveal.
