Adjust Pitch and Playback Rate with @pixi/sound

This guide explains how to dynamically adjust the playback rate and pitch of audio clips in PixiJS using the @pixi/sound library. You will learn how the library controls audio speed, how changing playback speed inherently alters audio pitch via the Web Audio API, and how to manipulate these properties dynamically on both global audio assets and active sound instances.

Understanding Speed and Pitch in @pixi/sound

Under the hood, @pixi/sound relies on the Web Audio API's AudioBufferSourceNode. In standard Web Audio implementations, the playback rate and pitch are directly linked through the playbackRate parameter. When you increase the playback speed, the pitch shifts higher (chipmunk effect); when you decrease the speed, the pitch drops lower.

In @pixi/sound, this behavior is controlled using the speed property.

Installation and Setup

First, ensure @pixi/sound is installed in your PixiJS project:

npm install @pixi/sound pixi.js

Import and register your audio file:

import { Sound } from '@pixi/sound';

const sound = Sound.from({
    url: 'path/to/audio.mp3',
    preload: true
});

Adjusting Speed Globally on the Sound Object

You can set the speed property directly on the Sound instance. Any instances played after updating this value will inherit the new playback rate and pitch:

// Set playback rate to 1.5x (higher speed and higher pitch)
sound.speed = 1.5;

// Set playback rate to 0.75x (lower speed and lower pitch)
sound.speed = 0.75;

// Play the sound with the current speed configuration
sound.play();

Modifying Playback Rate Dynamically During Playback

To change the pitch and rate while an audio clip is actively playing, modify the speed property of the IMediaInstance returned by the play() method.

// Start playback and keep reference to the instance
const instance = sound.play();

// Update speed dynamically (e.g., in a ticker or user event)
function setDynamicPitch(rate) {
    if (instance) {
        instance.speed = rate;
    }
}

Practical Example: Real-Time Modulation

Here is an implementation showing how to modulate audio pitch and speed over time using a PixiJS ticker or an input value:

import { Application } from 'pixi.js';
import { Sound } from '@pixi/sound';

const app = new Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

const engineSound = Sound.from({
    url: 'assets/engine_loop.mp3',
    loop: true,
    preload: true
});

engineSound.play().then(instance => {
    let elapsed = 0;

    app.ticker.add((ticker) => {
        elapsed += ticker.deltaTime * 0.02;

        // Oscillate speed between 0.5 and 1.5
        const targetRate = 1.0 + Math.sin(elapsed) * 0.5;

        // Apply dynamically to the playing instance
        instance.speed = targetRate;
    });
});

Controlling Speed at the Global Sound Manager Level

If you need to adjust the speed and pitch across all currently playing sounds simultaneously (such as a slow-motion gameplay mechanic), use the global sound library instance:

import { sound } from '@pixi/sound';

// Slow down all audio in the game to half-speed and drop pitch
sound.speedAll = 0.5;

// Return all audio to normal speed and pitch
sound.speedAll = 1.0;
