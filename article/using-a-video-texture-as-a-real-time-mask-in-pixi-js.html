Using a Video Texture as a Real-Time Mask in PixiJS

Yes, you can use a video texture as a real-time mask on any display object in PixiJS. By converting an HTML5 video element into a dynamic PixiJS texture and assigning it to a sprite, that sprite can be applied directly to another display object's mask property. This article covers how this mechanism works, how to implement it with standard PixiJS methods, and the technical requirements needed to ensure smooth playback and proper rendering.

How It Works

PixiJS renders scenes using WebGL. When an HTML5 <video> element is wrapped in a PIXI.Texture, the engine uploads the current video frame to the GPU as a WebGL texture on every animation frame. Because a PIXI.Sprite using this video texture updates continuously, assigning that sprite as a mask allows the alpha channel (or geometry) of the playing video to mask any target container, graphic, or sprite in real time.

Implementation Steps

1. Prepare the HTML5 Video Element

Browsers enforce strict autoplay policies. The video element must be set to muted and include playsinline if you want it to play automatically without user interaction.

const video = document.createElement('video');
video.src = 'path/to/mask-video.mp4';
video.crossOrigin = 'anonymous';
video.loop = true;
video.muted = true;
video.playsInline = true;
video.play();

2. Create the Video Texture and Mask Sprite

Generate a texture from the video source using PIXI.Texture.from(). Then, create a sprite using that texture.

// Create a texture from the video element
const videoTexture = PIXI.Texture.from(video);

// Create the mask sprite
const maskSprite = new PIXI.Sprite(videoTexture);

// Position or scale the mask sprite to match your layout
maskSprite.width = 800;
maskSprite.height = 600;

3. Assign the Mask to the Target Object

Add both the target display object and the mask sprite to the display list, then assign the mask sprite to the target's mask property.

// The object you want to reveal through the video mask
const content = PIXI.Sprite.from('path/to/background.jpg');
app.stage.addChild(content);

// The mask must be added to the stage or container hierarchy
app.stage.addChild(maskSprite);

// Apply the mask
content.mask = maskSprite;

Alpha Masking vs. Stencil Masking

When using a sprite as a mask in PixiJS:

  • Alpha Channel: PixiJS automatically applies a SpriteMaskFilter internally when a sprite is used as a mask. This means the masking effect is driven by the alpha channel of the video texture.
  • Color Channels: Standard WebGL sprite masking relies on the mask's alpha channel, not its luminance (black and white values). If your video uses black-and-white visuals to define transparency, you must either encode the video with an actual alpha channel (such as WebM with VP8/VP9 or ProRes 4444) or apply a custom fragment shader filter that maps luminance to alpha.

Performance and Best Practices

  • Texture Upload Cost: Uploading high-resolution video frames to the GPU every frame is resource-intensive. Keep mask video resolutions as low as possible (e.g., 720p or lower) to maintain high frame rates on mobile devices.
  • Power-of-Two Dimensions: While modern WebGL handles non-power-of-two textures, using standard video aspect ratios (like 16:9) is fully supported. Ensure the video format is widely compatible, such as MP4 (H.264) for maximum browser coverage.
  • Garbage Collection: When removing the mask, pause and unload the underlying HTML5 video element and call destroy(true) on the texture to release GPU memory.
