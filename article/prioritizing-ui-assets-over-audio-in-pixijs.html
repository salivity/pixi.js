Prioritizing UI Assets Over Audio in PixiJS

Optimizing the initial load time of a PixiJS application requires prioritizing essential visual elements over heavy media files. By deferring non-essential assets such as background music (BGM), you ensure that the user interface renders immediately, improving the First Contentful Paint (FCP) and user experience. This guide explains how to split your loading pipeline using PixiJS's modern Assets manager to load critical UI textures first and stream or load audio in the background.

1. Separate Assets Using Bundles

The most effective way to control loading priority in PixiJS (v7 and v8) is by defining asset bundles. Instead of loading your entire manifest simultaneously, split assets into critical UI elements and non-critical audio.

import { Assets } from 'pixi.js';

// Define manifests into distinct bundles
Assets.addBundle('critical-ui', {
    button: 'assets/ui/button.png',
    panel: 'assets/ui/panel.png',
    font: 'assets/ui/font.fnt'
});

Assets.addBundle('background-audio', {
    bgm: 'assets/audio/ambient-music.mp3'
});

2. Implement a Two-Stage Loading Sequence

Execute loading sequentially by awaiting the critical bundle before initializing the scene, then loading the background music asynchronously without blocking the user interface.

async function initGame() {
    // Stage 1: Load critical UI
    const uiAssets = await Assets.loadBundle('critical-ui', (progress) => {
        console.log(`UI Loading: ${Math.round(progress * 100)}%`);
    });

    // Render the UI immediately
    createInterface(uiAssets);

    // Stage 2: Load audio in the background (fire-and-forget)
    loadBackgroundMusic();
}

function loadBackgroundMusic() {
    Assets.loadBundle('background-audio')
        .then((audioAssets) => {
            playMusic(audioAssets.bgm);
        })
        .catch((error) => {
            console.error('Failed to load background music:', error);
        });
}

3. Handle Audio Streaming with Pixi Sound

If you are using the @pixi/sound package, full file downloads are not always necessary before playback. Configure your background music to stream or preload only metadata, which frees network bandwidth for texture uploads.

import { sound } from '@pixi/sound';

// Stream audio instead of preloading the entire array buffer
sound.add('bgm', {
    url: 'assets/audio/ambient-music.mp3',
    preload: false,
    stream: true,
    loaded: (err, soundInstance) => {
        if (!err) {
            soundInstance.play({ loop: true });
        }
    }
});

4. Adjust Concurrency Limits

The PixiJS loader handles multiple network requests concurrently. If you choose to load UI and audio in a single manifest, large audio files can saturate available HTTP/2 streams or HTTP connections. Avoid this by setting strict load phases rather than relying on automated prioritization algorithms, ensuring zero network competition between heavy audio buffers and visual UI components.
