Create a Retro Pixelation Filter in Pixi.js

This article explains how to build a custom retro pixelation post-processing filter in Pixi.js with fully adjustable pixel block dimensions. By leveraging a custom fragment shader through the Pixi.js Filter class, you can control horizontal and vertical pixelation independently in real time to achieve classic 8-bit, 16-bit, or stylized mosaic effects.

The Pixelation Logic

A pixelation effect works by dividing the screen into a discrete grid of rectangular blocks. Instead of sampling the texture at every individual fragment coordinate, the shader rounds each coordinate down to the nearest multiple of the specified block size. Sampling the original texture only at these quantized positions produces the blocky, retro aesthetic.

1. Define the Custom Fragment Shader

Pixi.js provides standard uniforms like uSampler for the input texture and uInputSize for texture dimensions (where xy represents width and height, and zw represents the inverse width and height).

precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;
uniform vec4 uInputSize;
uniform vec2 uBlockSize;

void main(void) {
    // Convert normalized UV coordinates (0.0 to 1.0) into pixel coordinates
    vec2 pixelCoord = vTextureCoord * uInputSize.xy;
    
    // Snap pixel coordinates to the nearest block size
    vec2 roundedCoord = floor(pixelCoord / uBlockSize) * uBlockSize;
    
    // Convert snapped pixel coordinates back to normalized UV coordinates
    vec2 sampleCoord = roundedCoord * uInputSize.zw;
    
    // Output the sampled color
    gl_FragColor = texture2D(uSampler, sampleCoord);
}

2. Instantiate the Filter in JavaScript

To use the shader, create a custom subclass or instance of PIXI.Filter. Pass the fragment shader code and define default uniform values for uBlockSize.

import * as PIXI from 'pixi.js';

const fragmentShader = `
precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;
uniform vec4 uInputSize;
uniform vec2 uBlockSize;

void main(void) {
    vec2 pixelCoord = vTextureCoord * uInputSize.xy;
    vec2 roundedCoord = floor(pixelCoord / uBlockSize) * uBlockSize;
    vec2 sampleCoord = roundedCoord * uInputSize.zw;
    gl_FragColor = texture2D(uSampler, sampleCoord);
}
`;

class RetroPixelFilter extends PIXI.Filter {
    constructor(blockWidth = 8, blockHeight = 8) {
        super(undefined, fragmentShader, {
            uBlockSize: new Float32Array([blockWidth, blockHeight])
        });
    }

    get size() {
        return this.uniforms.uBlockSize;
    }

    set size(value) {
        if (typeof value === 'number') {
            this.uniforms.uBlockSize[0] = value;
            this.uniforms.uBlockSize[1] = value;
        } else if (Array.isArray(value)) {
            this.uniforms.uBlockSize[0] = value[0];
            this.uniforms.uBlockSize[1] = value[1];
        }
    }
}

3. Apply and Adjust the Filter

Assign the filter to any Pixi.js display object (such as a Sprite, Container, or the root stage) via its filters array. You can dynamically adjust the dimensions to animate the pixelation or create transition effects.

// Initialize Pixi application
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Create a target sprite
const sprite = PIXI.Sprite.from('path/to/game-scene.png');
app.stage.addChild(sprite);

// Create and apply the retro pixel filter
const pixelFilter = new RetroPixelFilter(12, 12);
app.stage.filters = [pixelFilter];

// Dynamically change block dimensions
function setPixelSize(width, height) {
    pixelFilter.uniforms.uBlockSize[0] = Math.max(1, width);
    pixelFilter.uniforms.uBlockSize[1] = Math.max(1, height);
}

// Example: Animate pixelation over time
let elapsed = 0;
app.ticker.add((delta) => {
    elapsed += delta * 0.05;
    const dynamicSize = Math.floor(Math.sin(elapsed) * 16 + 18);
    setPixelSize(dynamicSize, dynamicSize);
});

Using a value of 1.0 for both dimensions renders the scene normally, while higher values intensify the retro, low-resolution effect.
