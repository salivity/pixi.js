Pixi.js Texture orig and trim Rectangles Explained

In Pixi.js, the orig and trim properties on a Texture define how a sprite's visual data relates to its original, uncropped dimensions. When creating texture atlases or sprite sheets, packing tools often trim away empty transparent pixels to save GPU memory and texture space. The orig and trim rectangles allow Pixi.js to reconstruct the appearance and behavior of the untrimmed asset, ensuring proper positioning, scaling, and anchor-point calculations without rendering invisible pixels.

The Purpose of Trimming in Sprite Sheets

When generating a texture atlas using tools like TexturePacker, transparency around the edges of an image is typically stripped away. While this reduces the overall footprint on the sprite sheet, it creates a discrepancy: the texture stored in memory is smaller than the original asset, and its visual center may have shifted. Without metadata tracking the original dimensions, animations would wobble and anchors would become misaligned. Pixi.js solves this using the orig, trim, and frame rectangles.

The orig Rectangle

The orig (original) rectangle holds the full, uncropped dimensions of the asset as it was originally designed.

  • Type: PIXI.Rectangle
  • Purpose: Stores the width and height of the raw source image prior to trimming.
  • Function in Rendering: Pixi.js uses orig to determine the conceptual size of a Sprite. When you read or set dimensions, calculate bounds, or apply an anchor (such as anchor.set(0.5) to center the sprite), the math is calculated against the orig rectangle rather than the physically trimmed pixel bounds. This ensures that the anchor remains exactly where the artist intended, even if the visible content is off-center.

The trim Rectangle

The trim rectangle represents the offset and dimensions of the non-transparent content relative to the orig boundary.

  • Type: PIXI.Rectangle
  • Purpose: Defines the positional offset (x, y) where the visible pixels begin inside the original frame, as well as the trimmed width and height.
  • Function in Rendering: When drawing the sprite, the renderer applies the trim.x and trim.y values as an internal offset. This shifts the trimmed texture into its correct relative position inside the space defined by orig.

How They Work Together

To render a trimmed texture correctly, Pixi.js references three core properties:

  1. frame: Points to the exact pixel coordinates of the visible graphic within the larger base texture sheet.
  2. trim: Places that visible graphic at the correct offset relative to the original asset's origin (0, 0).
  3. orig: Defines the complete bounding box of the asset, ensuring standard transform properties—such as hit areas, anchors, and pivots—operate as if the transparent pixels were never removed.

If an asset has not been trimmed, trim is typically null, and orig simply matches the dimensions of frame.
