Render Transparent WebM Video in Pixi.js

Rendering an alpha-channel transparent WebM video over a 2D scene in Pixi.js allows you to incorporate complex pre-rendered animations with low performance overhead. This guide explains how to properly encode your media, load an HTML5 video element into a Pixi.js texture, and ensure the alpha channel renders cleanly over existing display objects without visual artifacts.

1. Video Encoding Requirements

For transparency to work, your WebM file must be encoded using a codec that supports an alpha channel, such as VP8 or VP9 with a pixel format like yuva420p. Using FFmpeg, you can generate an alpha WebM with a command like:

ffmpeg -i input.mov -c:v libvpx-vp9 -pix_fmt yuva420p output.webm

Note that while Chromium-based browsers and Firefox natively support transparent WebM, Apple devices (Safari/iOS) generally do not support VP8/VP9 alpha channels and require HEVC (H.265) with alpha in an MP4 or MOV container instead.

2. Creating the HTML5 Video Element

Pixi.js renders video textures by sourcing frames from an underlying HTML <video> element. To ensure smooth playback and avoid autoplay restrictions, configure the video element with muted, playsInline, and crossOrigin attributes before feeding it to Pixi.js.

const video = document.createElement('video');
video.src = 'path/to/transparent-video.webm';
video.crossOrigin = 'anonymous';
video.loop = true;
video.muted = true;
video.playsInline = true;
video.setAttribute('playsinline', '');

// Wait for video metadata to avoid size mismatch
video.addEventListener('loadedmetadata', () => {
    video.play();
});

3. Binding to a Pixi.js Texture and Sprite

Once the video element is initialized, convert it into a Pixi.js texture using PIXI.Texture.from() and attach it to a PIXI.Sprite.

import * as PIXI from 'pixi.js';

// Initialize your application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1a1a1a
});
document.body.appendChild(app.view);

// Add your background or other 2D game scene elements
const background = PIXI.Sprite.from('path/to/background.jpg');
app.stage.addChild(background);

// Create the video texture
const videoTexture = PIXI.Texture.from(video);

// Create the video sprite
const videoSprite = new PIXI.Sprite(videoTexture);
videoSprite.width = 400;
videoSprite.height = 400;
videoSprite.position.set(200, 100);

// Add the video sprite on top of the scene
app.stage.addChild(videoSprite);

4. Handling Texture Settings and Alpha Blending

WebGL decodes video frames directly into GPU textures. By default, Pixi.js handles alpha channel blending using standard premultiplied alpha modes. However, depending on how your video was exported, you may see dark edges (fringing) around transparent areas.

To resolve fringing, adjust the base texture's alpha mode settings:

// Ensure Pixi treats the texture's alpha correctly
videoTexture.baseTexture.alphaMode = PIXI.ALPHA_MODES.PREMULTIPLY_ON_UPLOAD;

// Set standard blending mode on the sprite
videoSprite.blendMode = PIXI.BLEND_MODES.NORMAL;

If your source video already has straight (unmultiplied) alpha, you can switch the alphaMode to PIXI.ALPHA_MODES.UNPACK:

videoTexture.baseTexture.alphaMode = PIXI.ALPHA_MODES.UNPACK;

5. Managing Lifecycle and Playback

Because video frames update independently of the Pixi.js ticker, ensure that you clean up both the video element and the GPU texture when the video is removed from the stage to prevent memory leaks:

function destroyVideo() {
    video.pause();
    video.removeAttribute('src');
    video.load();
    videoTexture.destroy(true);
    videoSprite.destroy();
}
