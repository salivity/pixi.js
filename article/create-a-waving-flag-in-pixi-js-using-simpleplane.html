Create a Waving Flag in Pixi.js Using SimplePlane

Animating a realistic waving flag in Pixi.js can be achieved efficiently using the SimplePlane mesh class. This article covers how to project a 2D texture onto a customizable vertex grid and manipulate those vertex points in real time using a sine wave function inside the Pixi.js ticker loop.

Understanding the SimplePlane

A standard Sprite in Pixi.js consists of only four vertices (two triangles), making local deformation impossible. The SimplePlane class solves this by subdividing a texture into a customizable grid of rows and columns. By altering the positions of these grid vertices on every frame, you can bend, ripple, and distort the texture to simulate cloth waving in the wind.

1. Initializing the SimplePlane

To start, load your flag texture and instantiate a SimplePlane. Define the horizontal and vertical resolution by specifying the number of vertices along the X and Y axes. A higher number of vertices provides smoother waves at the expense of slight computational overhead.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

const flagTexture = PIXI.Texture.from('path/to/flag.png');

// Create a plane with 20 vertices horizontally and 10 vertically
const verticesX = 20;
const verticesY = 10;
const flag = new PIXI.SimplePlane(flagTexture, verticesX, verticesY);

flag.x = 100;
flag.y = 100;
app.stage.addChild(flag);

2. Accessing the Vertex Buffer

The vertices of a SimplePlane are stored in a flat array within its geometry attributes. In Pixi.js, you access this buffer using geometry.getBuffer('aVertexPosition'). The array holds alternating pairs of coordinates: [x0, y0, x1, y1, ...].

To animate the flag correctly:

  1. Cache the original Y-coordinates to avoid compounding displacement errors.
  2. Iterate through the vertices.
  3. Apply a displacement formula based on time and the vertex's X position.

3. Implementing the Wave Animation Loop

Using a sine function, displace the Y-coordinates relative to their distance from the flagpole (the left side). Multiplying the amplitude by the horizontal progress ensures the left edge remains pinned while the right edge flaps freely.

// Access and clone original positions
const positionBuffer = flag.geometry.getBuffer('aVertexPosition');
const originalPositions = new Float32Array(positionBuffer.data);

let timer = 0;

app.ticker.add((delta) => {
    timer += 0.1 * delta;
    
    // Total points along grid
    for (let i = 0; i < positionBuffer.data.length; i += 2) {
        // Retrieve original grid coordinates
        const origX = originalPositions[i];
        const origY = originalPositions[i + 1];

        // Normalize X from 0 (pole) to 1 (outer edge)
        const progressX = origX / flagTexture.width;

        // Wave parameters
        const frequency = 5;
        const speed = timer;
        const wave = Math.sin(progressX * frequency - speed);

        // Amplitude increases further away from the pole
        const amplitude = 25 * progressX;

        // Update Y position
        positionBuffer.data[i + 1] = origY + wave * amplitude;
    }

    // Flag buffer as updated for the GPU
    positionBuffer.update();
});

Tuning Wave Dynamics

  • Wind Speed: Modify the multiplier added to timer inside the loop to make the flag flap faster or slower.
  • Wave Density (Frequency): Adjust the multiplier applied to progressX inside the Math.sin() function to increase or decrease the number of ripples across the cloth.
  • Wind Strength (Amplitude): Alter the maximum amplitude value to make ripples shallower or deeper. Adding a secondary, smaller sine wave with a different frequency can also introduce natural turbulence to the cloth motion.
