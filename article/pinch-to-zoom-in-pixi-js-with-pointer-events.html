Pinch to Zoom in Pixi.js with Pointer Events

This article explains how to implement multi-finger pinch-to-zoom gestures in Pixi.js using modern Pointer Events. By tracking multiple active pointers via their unique identifiers, calculating the Euclidean distance between touch points, and applying the resulting scale delta to a Pixi.js Container, you can create smooth, responsive touch-based zoom interactions for mobile and touch-enabled devices.

1. Pointer Tracking Concept

Pixi.js normalizes mouse and touch inputs into Pointer Events (pointerdown, pointermove, pointerup, pointerupoutside, and pointercancel). Unlike native touch lists, pointer events fire individually for each contact point.

To handle a pinch gesture:

  1. Store active pointers in a JavaScript Map using event.pointerId as the key.
  2. When the map contains two active pointers, calculate the distance between them.
  3. As pointers move, compare the new distance to the previous distance to derive a scale multiplier.
  4. Apply this multiplier to the target container's scale.

2. Distance Calculation

The distance between two pointers is calculated using the Pythagorean theorem:

function getDistance(p1, p2) {
    const dx = p1.x - p2.x;
    const dy = p1.y - p2.y;
    return Math.hypot(dx, dy);
}

function getMidpoint(p1, p2) {
    return {
        x: (p1.x + p2.x) / 2,
        y: (p1.y + p2.y) / 2
    };
}

3. Implementation

The following example attaches pointer listeners to the Pixi.js stage (or an interactive background) to scale a target worldContainer.

import * as PIXI from 'pixi.js';

// Setup Application
const app = new PIXI.Application({
    width: window.innerWidth,
    height: window.innerHeight,
    antialias: true,
});
document.body.appendChild(app.view);

// Setup Containers
const worldContainer = new PIXI.Container();
app.stage.addChild(worldContainer);

// Make the stage interactive to capture global touches
app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;

// State tracking
const activePointers = new Map();
let lastDistance = 0;

app.stage.on('pointerdown', (event) => {
    activePointers.set(event.pointerId, { x: event.global.x, y: event.global.y });

    if (activePointers.size === 2) {
        const [p1, p2] = Array.from(activePointers.values());
        lastDistance = getDistance(p1, p2);
    }
});

app.stage.on('pointermove', (event) => {
    if (!activePointers.has(event.pointerId)) return;

    // Update the position of the moved pointer
    activePointers.set(event.pointerId, { x: event.global.x, y: event.global.y });

    if (activePointers.size === 2) {
        const [p1, p2] = Array.from(activePointers.values());
        const currentDistance = getDistance(p1, p2);

        if (lastDistance > 0) {
            const factor = currentDistance / lastDistance;
            
            // Constrain zoom boundaries
            const newScaleX = Math.min(Math.max(worldContainer.scale.x * factor, 0.5), 5);
            const newScaleY = Math.min(Math.max(worldContainer.scale.y * factor, 0.5), 5);

            // Optional: Zoom toward the midpoint between the two fingers
            const mid = getMidpoint(p1, p2);
            const localPos = worldContainer.toLocal(mid);

            worldContainer.scale.set(newScaleX, newScaleY);

            // Adjust position so zoom centers on pinch midpoint
            worldContainer.position.x = mid.x - localPos.x * worldContainer.scale.x;
            worldContainer.position.y = mid.y - localPos.y * worldContainer.scale.y;
        }

        lastDistance = currentDistance;
    }
});

function removePointer(event) {
    activePointers.delete(event.pointerId);
    if (activePointers.size < 2) {
        lastDistance = 0;
    }
}

app.stage.on('pointerup', removePointer);
app.stage.on('pointerupoutside', removePointer);
app.stage.on('pointercancel', removePointer);

4. Key Considerations

  • eventMode / interactive: In Pixi.js v7+, use eventMode = 'static' or 'dynamic'. In Pixi.js v6 and older, set interactive = true.
  • Hit Area: Ensure the listening object covers the entire screen area by assigning a hitArea matching app.screen, otherwise events will stop firing when fingers move over empty canvas regions.
  • Touch Action CSS: Apply touch-action: none; to the canvas element in CSS. This prevents the browser from intercepting pinch gestures for native page zooming.
