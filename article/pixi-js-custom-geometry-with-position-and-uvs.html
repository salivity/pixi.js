Pixi.js Custom Geometry with Position and UVs

Creating custom geometry in Pixi.js allows developers to build arbitrary 2D meshes, render complex polygonal shapes, and map textures precisely using low-level vertex attributes. This article explains how to instantiate a custom Geometry instance, configure vertex position and UV coordinate buffers, and assemble them into a renderable mesh.

1. Define the Vertex and UV Data

Custom geometry in Pixi.js requires raw numeric data typically provided via Float32Array. For a 2D surface, position data requires two components per vertex (\(x, y\)), while UV mapping coordinates also require two normalized values per vertex (\(u, v\), ranging from 0.0 to 1.0).

// Define a simple quad (two triangles sharing vertices)
const positions = new Float32Array([
    0, 0,     // Vertex 0 (Top-Left)
    100, 0,   // Vertex 1 (Top-Right)
    100, 100, // Vertex 2 (Bottom-Right)
    0, 100    // Vertex 3 (Bottom-Left)
]);

const uvs = new Float32Array([
    0, 0, // UV for Vertex 0
    1, 0, // UV for Vertex 1
    1, 1, // UV for Vertex 2
    0, 1  // UV for Vertex 3
]);

const indices = new Uint16Array([
    0, 1, 2, // First Triangle
    0, 2, 3  // Second Triangle
]);

2. Instantiate and Configure the Geometry Object

Instantiate PIXI.Geometry and register your data arrays using the addAttribute method. Standard shaders in Pixi.js expect specific attribute names: aVertexPosition for positions and aTextureCoord for UVs.

import * as PIXI from 'pixi.js';

// Create a new Geometry instance
const geometry = new PIXI.Geometry();

// Add position attribute: (attributeName, bufferData, size)
geometry.addAttribute('aVertexPosition', positions, 2);

// Add UV attribute
geometry.addAttribute('aTextureCoord', uvs, 2);

// Add index buffer to define the triangle topology
geometry.addIndex(indices);

The addAttribute function accepts the following parameters:

  • id (string): The attribute variable name expected in the vertex shader (e.g., aVertexPosition, aTextureCoord).
  • buffer (PIXI.Buffer | Float32Array | number[]): The array containing the attribute data.
  • size (number, optional): The number of elements per vertex. Defaults to 2 for 2D positions and standard UV coordinates.
  • normalized (boolean, optional): Whether data should be normalized. Defaults to false.
  • type (number, optional): The data type. Defaults to PIXI.TYPES.FLOAT.

3. Render the Geometry with a Mesh

To display the geometry, pair it with a shader or material within a PIXI.Mesh. When using default shaders, assign a PIXI.Shader.from() or PIXI.MeshMaterial.

// Load a texture and create a basic mesh material
const texture = PIXI.Texture.from('path/to/texture.png');
const shader = PIXI.Shader.from(null, null, { uTexture: texture });

// Create the Mesh using the custom geometry and shader
const mesh = new PIXI.Mesh(geometry, shader);

// Add the mesh to the Pixi application stage
app.stage.addChild(mesh);

4. Updating Buffer Data Dynamically

If vertex positions or UV coordinates change at runtime, update the underlying buffer directly and mark it for a GPU upload:

// Modify the positions array
positions[0] = 10;
positions[1] = 10;

// Notify Pixi.js that the buffer needs to be re-uploaded to the GPU
geometry.getAttribute('aVertexPosition').buffer.update();
