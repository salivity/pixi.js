Create Mesh Vertex Color Gradients in Pixi.js

This guide explains how to generate multi-colored gradients across a 2D mesh in Pixi.js using custom vertex colors. By configuring a custom Geometry with vertex positions and color attributes, and pairing it with a simple WebGL shader, you can leverage the GPU's native attribute interpolation to blend colors seamlessly across polygonal surfaces without relying on static gradient textures.

1. Understanding Vertex Colors in Pixi.js

When rendering geometry in WebGL, assigning distinct color values to individual vertices causes the GPU rasterizer to interpolate those values smoothly across the faces of triangles. In Pixi.js, you implement this by constructing a Geometry containing position and color buffers, then rendering it with a Mesh powered by a custom Shader.

2. Defining the Shaders

To pass colors from individual vertices to the rendered pixels, you need a minimal vertex and fragment shader pair:

const vertexShader = `
    precision mediump float;
    attribute vec2 aVertexPosition;
    attribute vec4 aColor;

    uniform mat3 translationMatrix;
    uniform mat3 projectionMatrix;

    varying vec4 vColor;

    void main() {
        vColor = aColor;
        gl_Position = vec4((projectionMatrix * translationMatrix * vec3(aVertexPosition, 1.0)).xy, 0.0, 1.0);
    }
`;

const fragmentShader = `
    precision mediump float;
    varying vec4 vColor;

    void main() {
        gl_FragColor = vColor;
    }
`;

3. Setting Up Geometry Buffers

Define the geometry for a simple quad using four vertices and two triangles. Assign an independent RGBA color to each corner to create a multi-stop gradient:

// 1. Define 2D vertex positions (X, Y) for a rectangle
const positions = new Float32Array([
    0,   0,     // Vertex 0: Top-Left
    200, 0,     // Vertex 1: Top-Right
    200, 200,   // Vertex 2: Bottom-Right
    0,   200    // Vertex 3: Bottom-Left
]);

// 2. Define RGBA color channels (0.0 to 1.0) for each vertex
const colors = new Float32Array([
    1.0, 0.0, 0.0, 1.0, // Red    (Top-Left)
    0.0, 1.0, 0.0, 1.0, // Green  (Top-Right)
    0.0, 0.0, 1.0, 1.0, // Blue   (Bottom-Right)
    1.0, 1.0, 0.0, 1.0  // Yellow (Bottom-Left)
]);

// 3. Define triangle indices
const indices = new Uint16Array([
    0, 1, 2, // First triangle
    0, 2, 3  // Second triangle
]);

4. Creating and Attaching the Mesh

Create a Geometry instance, register the attributes, compile the Shader, and instantiate the Mesh:

// Create geometry and add attributes
const geometry = new PIXI.Geometry()
    .addAttribute('aVertexPosition', positions, 2)
    .addAttribute('aColor', colors, 4)
    .addIndex(indices);

// Create the shader program
const shader = PIXI.Shader.from(vertexShader, fragmentShader);

// Combine geometry and shader into a Mesh
const gradientMesh = new PIXI.Mesh(geometry, shader);

// Position and add the mesh to the Pixi stage
gradientMesh.position.set(100, 100);
app.stage.addChild(gradientMesh);

5. Dynamic Gradient Manipulation

Because the color data resides in a standard typed array, you can alter the gradient dynamically during the render loop. If you update the values inside the colors array at runtime, notify Pixi.js that the buffer has changed by updating its flag:

// Update a vertex color dynamically
colors[0] = 0.5; // Change red channel of Vertex 0

// Flag the color buffer for a GPU upload
geometry.getAttribute('aColor').update();
