Define Custom Texture Sub-Regions in Pixi.js

This guide explains how to crop and define custom sub-region frames from a larger master texture in Pixi.js. By using the Rectangle geometry class alongside the core Texture and BaseTexture classes, you can extract and display specific visual segments from a single spritesheet or image asset. This approach optimizes memory usage and draw calls by referencing one master asset across multiple sprites.

Understanding the Components

To define a custom sub-region, Pixi.js relies on three core components:

  • BaseTexture (or TextureSource in v8): The underlying raw image data loaded into WebGL/WebGPU memory.
  • Rectangle (PIXI.Rectangle): A mathematical bounding box specifying the x, y, width, and height of the region you want to cut out.
  • Texture (PIXI.Texture): The wrapper that pairs the base image data with the defined rectangle frame, which is then applied to a renderable Sprite.

Step-by-Step Implementation

1. Define the Frame Geometry

Create an instance of PIXI.Rectangle with the exact pixel coordinates and dimensions of the sub-region relative to the master texture.

const x = 32;      // Horizontal offset from the top-left corner
const y = 64;      // Vertical offset from the top-left corner
const width = 64;  // Width of the sub-region
const height = 64; // Height of the sub-region

const frame = new PIXI.Rectangle(x, y, width, height);

2. Create the Sub-Texture from a Base Texture

Pass the master image's base texture and the rectangle frame into a new PIXI.Texture constructor.

// Load or reference your base texture
const baseTexture = PIXI.BaseTexture.from('path/to/master-spritesheet.png');

// Create the sub-region texture
const subTexture = new PIXI.Texture(baseTexture, frame);

If you already have a loaded master PIXI.Texture, you can derive the sub-region by referencing its .baseTexture property:

const masterTexture = PIXI.Texture.from('path/to/master-spritesheet.png');
const subTexture = new PIXI.Texture(masterTexture.baseTexture, frame);

3. Assign the Texture to a Sprite

Attach the newly created texture to a PIXI.Sprite to display it on your canvas:

const characterSprite = new PIXI.Sprite(subTexture);
characterSprite.position.set(100, 100);
app.stage.addChild(characterSprite);

Dynamically Updating an Existing Sub-Region

If you need to change the sub-region of an existing texture at runtime (for example, to cycle through animation frames manually), update the .frame property directly:

// Re-assign the frame with new dimensions or coordinates
sprite.texture.frame = new PIXI.Rectangle(96, 64, 64, 64);

// Notify Pixi.js to recalculate texture UVs if automatic updates are disabled
sprite.texture.updateUvs();

This method eliminates the overhead of creating new PIXI.Texture objects continuously during frame-by-frame animations.
