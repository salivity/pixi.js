Efficient Pixi.js Typewriter Effect Implementation

Creating a smooth typewriter effect in Pixi.js requires revealing text character-by-character without triggering heavy CPU-to-GPU texture re-uploads on every frame. This article demonstrates how to build an efficient, frame-rate independent typewriter text component in Pixi.js using delta-time updates, explains why naive text updates degrade performance, and outlines how using PIXI.BitmapText maintains optimal rendering speeds.

The Performance Pitfall of PIXI.Text

The most common mistake when implementing a typewriter effect in Pixi.js is repeatedly updating the text property of a standard PIXI.Text instance:

// Inefficient approach
ticker.add(() => {
    myText.text = fullString.substring(0, currentIndex++);
});

PIXI.Text generates an offscreen HTML5 <canvas>, renders the glyphs using the browser's 2D canvas API, and uploads the entire canvas as a GPU texture. Updating the string every few frames causes continuous canvas clears, font re-rasterizations, and GPU texture re-allocations, leading to garbage collection spikes and frame drops.

The Efficient Solution: PIXI.BitmapText

To make a typewriter effect efficient, use PIXI.BitmapText. Bitmap fonts rely on a pre-rendered texture atlas containing all font glyphs. When you update the string of a PIXI.BitmapText object, Pixi.js simply recalculates quad coordinates on existing GPU geometry instead of generating and uploading a new texture.

Step-by-Step Implementation

The following implementation handles typing speed independently of the monitor refresh rate using PIXI.Ticker delta time, allows custom typing speeds, and fires a completion callback.

import * as PIXI from 'pixi.js';

class TypewriterText extends PIXI.Container {
    constructor(fullText, style, charactersPerSecond = 30) {
        super();

        this.fullText = fullText;
        this.charactersPerSecond = charactersPerSecond;
        this.charInterval = 1000 / charactersPerSecond; // Milliseconds per character
        
        this.currentIndex = 0;
        this.elapsedTime = 0;
        this.isComplete = false;

        // Use BitmapText for GPU-accelerated glyph rendering
        this.textField = new PIXI.BitmapText('', style);
        this.addChild(this.textField);

        this.onComplete = null;
    }

    start() {
        this.currentIndex = 0;
        this.elapsedTime = 0;
        this.isComplete = false;
        this.textField.text = '';

        PIXI.Ticker.shared.add(this.update, this);
    }

    update(ticker) {
        if (this.isComplete) return;

        // Convert ticker delta to elapsed milliseconds
        this.elapsedTime += ticker.deltaMS;

        // Determine how many characters should be visible based on elapsed time
        const targetIndex = Math.min(
            Math.floor(this.elapsedTime / this.charInterval),
            this.fullText.length
        );

        if (targetIndex !== this.currentIndex) {
            this.currentIndex = targetIndex;
            this.textField.text = this.fullText.slice(0, this.currentIndex);

            if (this.currentIndex >= this.fullText.length) {
                this.finish();
            }
        }
    }

    finish() {
        this.isComplete = true;
        this.textField.text = this.fullText;
        PIXI.Ticker.shared.remove(this.update, this);

        if (typeof this.onComplete === 'function') {
            this.onComplete();
        }
    }

    destroy(options) {
        PIXI.Ticker.shared.remove(this.update, this);
        super.destroy(options);
    }
}

Usage Example

// Initialize Pixi application
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Ensure the bitmap font is loaded beforehand
const message = "All systems operational. Commencing initialization sequence...";

const typewriter = new TypewriterText(
    message,
    { fontName: 'Desyrel', fontSize: 32 },
    25 // Types 25 characters per second
);

typewriter.position.set(50, 50);
typewriter.onComplete = () => console.log('Typing animation finished.');

app.stage.addChild(typewriter);
typewriter.start();

Handling Layout Shifting and Word Wrap

When building dialogue boxes with automatic word wrapping, partial words at the end of a line can temporarily wrap down before jumping back up as the word completes. To prevent this layout jitter:

  1. Pre-wrap with Invisible Characters: Pre-calculate line breaks by breaking the full text string with explicit newline (\n) characters based on the container width prior to running the typewriter.
  2. Alpha-Masking Approach: Render the full text upfront using a single PIXI.BitmapText or standard PIXI.Text, and animate an invisible mask (PIXI.Graphics) over each line sequentially. This approach ensures zero text reflow and preserves exact line breaks.
