PixiJS Distance Between Objects in Different Containers

Calculating the distance between two DisplayObject instances residing in different containers in Pixi.js requires converting their local coordinates into a shared coordinate space. Because an object’s x and y properties are relative to its immediate parent container, you cannot calculate the Euclidean distance directly from these values. By using Pixi.js's built-in coordinate transformation methods—specifically toGlobal() or getGlobalPosition()—you can project both objects into global screen space and compute the true distance between them.

The Coordinate Space Problem

When an object is nested inside a PIXI.Container, its position properties (position.x, position.y) exist in the local space of that container. If Container A is shifted to (100, 100) and contains Sprite A at (10, 10), Sprite A's global position is (110, 110). Attempting to measure the distance between Sprite A and Sprite B using their local coordinates will yield incorrect results whenever their parent containers have different positions, scales, or rotations.

Step 1: Convert Local Positions to Global Coordinates

Pixi.js provides two primary methods on DisplayObject to find screen-space coordinates:

  1. toGlobal(): Transforms a point within the local space of the display object to global screen coordinates. Passing new PIXI.Point(0, 0) returns the object's origin in the global space.
  2. getGlobalPosition(): A convenient helper method that calculates and returns the global position of the object's origin.
// Using getGlobalPosition()
const globalPosA = objectA.getGlobalPosition();
const globalPosB = objectB.getGlobalPosition();

Alternatively, to avoid memory allocation from creating new Point objects inside a render loop, reuse an existing PIXI.Point:

const pointZero = new PIXI.Point(0, 0);
const globalPosA = objectA.toGlobal(pointZero);
const globalPosB = objectB.toGlobal(pointZero);

Step 2: Compute the Euclidean Distance

Once both positions are in the same coordinate space, use the standard Euclidean distance formula (\(d = \sqrt{\Delta x^2 + \Delta y^2}\)) or Math.hypot():

const dx = globalPosA.x - globalPosB.x;
const dy = globalPosA.y - globalPosB.y;

const distance = Math.hypot(dx, dy);

Complete Code Example

import * as PIXI from 'pixi.js';

// Setup containers and objects
const containerA = new PIXI.Container();
containerA.position.set(50, 100);

const containerB = new PIXI.Container();
containerB.position.set(300, 400);

const spriteA = new PIXI.Sprite(PIXI.Texture.WHITE);
spriteA.position.set(20, 20);
containerA.addChild(spriteA);

const spriteB = new PIXI.Sprite(PIXI.Texture.WHITE);
spriteB.position.set(10, 10);
containerB.addChild(spriteB);

// Helper function to calculate distance
function getDistanceBetween(objA, objB) {
    const posA = objA.getGlobalPosition();
    const posB = objB.getGlobalPosition();

    return Math.hypot(posA.x - posB.x, posA.y - posB.y);
}

const distance = getDistanceBetween(spriteA, spriteB);
console.log(`Distance: ${distance}px`);

Alternative: Using toLocal()

Instead of converting both objects to global coordinates, you can transform the position of one object directly into the local coordinate space of the other using toLocal():

// Converts objectB's origin directly into objectA's local space
const localPos = objectA.toLocal(new PIXI.Point(0, 0), objectB);

// The distance from objectA's origin (0, 0) to localPos
const distance = Math.hypot(localPos.x, localPos.y);

This approach eliminates the need to calculate two separate global vectors, directly yielding the relative offset between the two objects.
