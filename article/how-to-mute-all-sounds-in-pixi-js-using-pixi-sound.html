How to Mute All Sounds in Pixi.js Using @pixi/sound

This article provides a quick guide on how to globally silence audio when pausing a game in Pixi.js using the @pixi/sound library. You will learn the core global methods required to mute and unmute all active audio channels, understand the difference between muting and pausing audio streams, and see a practical implementation example you can drop directly into your game state logic.

Installing and Importing @pixi/sound

To manage global audio, ensure @pixi/sound is installed in your project:

npm install @pixi/sound

Import the sound singleton instance into your game state or scene manager:

import { sound } from '@pixi/sound';

Muting All Sounds Globally

The @pixi/sound library exposes a global sound controller that manages all loaded audio assets. To silence everything instantly when a game enters a paused state, call sound.muteAll():

function onGamePause() {
    // Mute all playing sounds and music globally
    sound.muteAll();
}

When resuming the game, restore the previous volume levels by calling sound.unmuteAll():

function onGameResume() {
    // Restore sound volume to previous levels
    sound.unmuteAll();
}

muteAll() vs. pauseAll()

Depending on how you handle your game loop, you may want playback position to freeze rather than continue playing silently:

  • sound.muteAll(): Audio keeps playing in the background at zero volume. Use this if background music or ambient loops should not lose their playback synchronization while menus are open.
  • sound.pauseAll(): Freezes all active audio playback at the current timestamp. Call sound.resumeAll() to continue playback exactly where it stopped.

You can combine both if you want absolute silence and frozen playback tracks:

function pauseGame() {
    isPaused = true;
    sound.pauseAll();
    sound.muteAll();
}

function resumeGame() {
    isPaused = false;
    sound.unmuteAll();
    sound.resumeAll();
}

Complete Implementation Example

Here is an implementation showing an event-driven pause toggle within a Pixi.js game:

import { Application } from 'pixi.js';
import { sound } from '@pixi/sound';

const app = new Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Load an asset
sound.add('bgm', 'assets/music/theme.mp3');
sound.play('bgm', { loop: true });

let isGamePaused = false;

function togglePause() {
    isGamePaused = !isGamePaused;

    if (isGamePaused) {
        sound.muteAll();
        // Additional pause logic (freeze ticker, show menu)
        app.ticker.stop();
    } else {
        sound.unmuteAll();
        // Resume game loop
        app.ticker.start();
    }
}

// Listen for a pause key (e.g., 'Escape' or 'P')
window.addEventListener('keydown', (e) => {
    if (e.key === 'p' || e.key === 'Escape') {
        togglePause();
    }
});
