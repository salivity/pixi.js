Water Ripple Effects with Pixi.js SimplePlane

Simulating water ripples in Pixi.js can be achieved efficiently without writing complex GLSL shaders by utilizing the SimplePlane class. This guide explains how to generate realistic ripple dynamics by creating a subdivided vertex grid and dynamically manipulating vertex positions using wave algorithms within the Pixi.js animation loop.

Understanding Pixi.js SimplePlane

The SimplePlane class allows you to draw a textured mesh defined by a grid of vertices. Unlike a standard Sprite, which uses only four vertices (one for each corner), a SimplePlane divides a rectangular texture into multiple rows and columns. By shifting these individual vertex points over time, you can distort the surface texture to mimic ripples, waves, or flag waving effects.

Setting Up the Plane

To achieve smooth deformation, the plane requires an adequate resolution of vertices. High segment counts provide smoother wave curves at the cost of slight performance overhead, while low segment counts can make ripples appear jagged.

import * as PIXI from 'pixi.js';

// Initialize the Pixi Application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1099bb
});
document.body.appendChild(app.view);

// Load the water texture
const texture = PIXI.Texture.from('path/to/water-texture.jpg');

// Define grid density: 30 columns and 30 rows
const verticesX = 30;
const verticesY = 30;

// Create the plane
const plane = new PIXI.SimplePlane(texture, verticesX, verticesY);
app.stage.addChild(plane);

Storing Original Vertex Positions

To apply wave equations without drifting away from the original layout, you must maintain a reference copy of the unmodified vertex coordinates.

// Get access to the vertex buffer array
const buffer = plane.geometry.getBuffer('aVertexPosition');
const originalVertices = new Float32Array(buffer.data);

Calculating Wave Mechanics

A realistic ripple expands outward from an epicenter. The displacement of each vertex is calculated using a damped sine wave formula based on its distance from the ripple center and the elapsed time:

\[\text{Displacement} = \sin(\text{distance} \times \text{frequency} - \text{time} \times \text{speed}) \times \text{amplitude} \times \text{decay}\]

Implementing the Animation Loop

Add an update loop using Pixi's ticker to calculate and apply displacements to the vertex buffer on every frame.

let timer = 0;
const rippleOrigin = { x: 400, y: 300 }; // Center of the ripple
const waveLength = 0.05;
const waveSpeed = 4.0;
const waveAmplitude = 10;
const maxRadius = 300;

app.ticker.add((delta) => {
    timer += delta * 0.05;
    const vertexData = buffer.data;

    for (let i = 0; i < vertexData.length; i += 2) {
        const origX = originalVertices[i];
        const origY = originalVertices[i + 1];

        // Compute distance from the ripple center
        const dx = origX - rippleOrigin.x;
        const dy = origY - rippleOrigin.y;
        const distance = Math.sqrt(dx * dx + dy * dy);

        // Apply deformation within maximum radius
        if (distance < maxRadius && distance > 0) {
            // Decay amplitude toward the edges of the ripple
            const decay = (1 - distance / maxRadius);
            
            // Calculate ripple offset using a sine function
            const wave = Math.sin(distance * waveLength - timer * waveSpeed);
            const offset = wave * waveAmplitude * decay;

            // Shift vertices along their vector from the center
            const dirX = dx / distance;
            const dirY = dy / distance;

            vertexData[i] = origX + dirX * offset;
            vertexData[i + 1] = origY + dirY * offset;
        } else {
            vertexData[i] = origX;
            vertexData[i + 1] = origY;
        }
    }

    // Flag the buffer for a GPU upload
    buffer.update();
});

Dynamic Interaction

To make the effect interactive, attach pointer event listeners to update the ripple center coordinates dynamically:

plane.eventMode = 'static';
plane.on('pointerdown', (event) => {
    const localPosition = event.getLocalPosition(plane);
    rippleOrigin.x = localPosition.x;
    rippleOrigin.y = localPosition.y;
    timer = 0; // Reset ripple cycle
});

Performance Considerations

  1. Vertex Count: Keep the segment count within 20 to 50 divisions. Going beyond 100 divisions increases the CPU load because all vertex calculations run on the main JavaScript thread.
  2. Multiple Waves: To simulate multiple ripples simultaneously, iterate through an array of active ripple sources per vertex, combining their displacement values before updating the buffer.
  3. Dirty Flag: Ensure buffer.update() is called only when changes are made, allowing WebGL to synchronize the modified geometry with the GPU.
