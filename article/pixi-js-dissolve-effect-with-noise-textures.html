Pixi.js Dissolve Effect with Noise Textures

This article explains how to build a custom dissolve and burn-away visual effect in Pixi.js using a custom GLSL fragment shader and a noise texture. You will learn the mechanics behind noise-based thresholding, how to write the fragment shader with an illuminated burn edge, how to wrap it inside a Pixi.js Filter, and how to animate the progress uniform to produce a transition.

The Core Concept

A dissolve or burn effect works by comparing values from a grayscale noise texture (such as Perlin or Simplex noise) against a progress value that increases from 0.0 to 1.0.

  1. For each pixel, the shader samples the luminance value of the noise texture at the corresponding UV coordinates.
  2. If the noise value is lower than the current progress value, the pixel is discarded (or its alpha is set to 0).
  3. If the noise value falls within a narrow boundary just above the progress value, the pixel is tinted with a glowing burn color (e.g., orange or red) to simulate burning embers.
  4. Pixels with noise values well above the threshold render normally.

Writing the Custom Fragment Shader

Pixi.js allows you to supply custom GLSL code to a PIXI.Filter. The fragment shader requires the base texture sampler, a secondary noise texture sampler, and uniforms to control progress, edge width, and edge color.

precision mediump float;

varying vec2 vTextureCoord;

uniform sampler2D uSampler;
uniform sampler2D uNoiseSampler;
uniform float uProgress;
uniform float uEdgeWidth;
uniform vec3 uEdgeColor;

void main(void) {
    vec4 baseColor = texture2D(uSampler, vTextureCoord);
    float noise = texture2D(uNoiseSampler, vTextureCoord).r;

    // Discard pixel if noise value is below the progress threshold
    if (noise < uProgress) {
        discard;
    }

    // Add glowing burn edge
    if (noise < uProgress + uEdgeWidth) {
        float edgeFactor = (noise - uProgress) / uEdgeWidth;
        vec3 finalEdge = mix(uEdgeColor * 2.0, baseColor.rgb, edgeFactor);
        baseColor.rgb = finalEdge;
    }

    gl_FragColor = baseColor;
}

Implementing the Filter in Pixi.js

To apply this shader, load both the target sprite image and the noise texture, then wrap the shader in a PIXI.Filter.

import * as PIXI from 'pixi.js';

// Initialize the Pixi application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1a1a1a,
});
document.body.appendChild(app.view);

// Assets
const spriteTexture = PIXI.Texture.from('path/to/character.png');
const noiseTexture = PIXI.Texture.from('path/to/noise.png');

// Ensure noise texture repeats if textures have mismatched sizes
noiseTexture.baseTexture.wrapMode = PIXI.WRAP_MODES.REPEAT;

const sprite = new PIXI.Sprite(spriteTexture);
sprite.anchor.set(0.5);
sprite.position.set(app.screen.width / 2, app.screen.height / 2);
app.stage.addChild(sprite);

// Define uniforms
const uniforms = {
    uNoiseSampler: noiseTexture,
    uProgress: 0.0,
    uEdgeWidth: 0.05,
    uEdgeColor: [1.0, 0.3, 0.0], // RGB for fiery orange
};

// Create the custom filter
const dissolveFilter = new PIXI.Filter(null, fragmentShaderSource, uniforms);
sprite.filters = [dissolveFilter];

Animating the Dissolution

Animate the effect by updating the uProgress uniform inside Pixi's ticker or with an animation library like GSAP.

let progress = 0.0;
const dissolveSpeed = 0.005;

app.ticker.add((delta) => {
    if (progress < 1.0) {
        progress += dissolveSpeed * delta;
        dissolveFilter.uniforms.uProgress = Math.min(progress, 1.0);
    }
});

To reverse the transition and make the sprite materialize instead of disappear, set progress to 1.0 initially and decrement the uniform down to 0.0. You can also change the character of the burn by swapping the noise asset; low-frequency noise generates large burning holes, while high-frequency noise creates a fine, ash-like disintegration.
