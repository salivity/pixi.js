Multi-Layer Parallax Scrolling in Pixi.js

Implementing multi-layer parallax scrolling in Pixi.js creates an illusion of depth in 2D environments by moving background layers at different speeds relative to a camera's movement. This guide explains how to establish a virtual camera coordinate system, organize layers with distinct scroll factors, and update positions or tile offsets inside Pixi.js's main render loop for smooth, depth-rich visuals.

1. Understanding Parallax Factors

Parallax depth relies on multiplying the camera's position by a unique factor for each layer:

  • Distant Background (e.g., Sky, Mountains): Lowest scroll factor (e.g., 0.1 to 0.2), moving minimally as the camera traverses the world.
  • Midground (e.g., Trees, Buildings): Moderate scroll factor (e.g., 0.5).
  • Foreground/Gameplay Layer: Standard factor of 1.0, moving at the exact speed of the camera.
  • Near Foreground (e.g., Overhead foliage): Higher factor (e.g., 1.2), moving faster than the camera to appear closest to the viewer.

2. Choosing Containers vs. TilingSprites

  • Use PIXI.TilingSprite for infinite or repeating backgrounds. Instead of shifting the sprite’s position.x, you shift its tilePosition.x.
  • Use PIXI.Container or standard PIXI.Sprite for fixed-size, distinct scenes where elements are placed at absolute world coordinates.

3. Implementation

The following example demonstrates setting up a virtual camera and updating multiple TilingSprite layers in Pixi.js.

import * as PIXI from 'pixi.js';

// 1. Initialize the Pixi Application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1099bb,
});
document.body.appendChild(app.view);

// 2. Define the Virtual Camera
const camera = {
    x: 0,
    y: 0,
    targetX: 0,
    targetY: 0,
    ease: 0.1,
    update() {
        // Smoothly interpolate towards the target position
        this.x += (this.targetX - this.x) * this.ease;
        this.y += (this.targetY - this.y) * this.ease;
    }
};

// 3. Define Layers with Parallax Factors
const layerData = [
    { texture: 'sky.png', factorX: 0.1, factorY: 0.05 },
    { texture: 'mountains.png', factorX: 0.3, factorY: 0.1 },
    { texture: 'forest.png', factorX: 0.6, factorY: 0.2 },
];

const parallaxLayers = layerData.map((data) => {
    const texture = PIXI.Texture.from(data.texture);
    const tilingSprite = new PIXI.TilingSprite(texture, app.screen.width, app.screen.height);
    
    app.stage.addChild(tilingSprite);
    
    return {
        sprite: tilingSprite,
        factorX: data.factorX,
        factorY: data.factorY,
    };
});

// 4. Update Loop
app.ticker.add(() => {
    // Advance camera toward target
    camera.update();

    // Offset the tile position based on camera position and layer factor
    parallaxLayers.forEach((layer) => {
        layer.sprite.tilePosition.x = -camera.x * layer.factorX;
        layer.sprite.tilePosition.y = -camera.y * layer.factorY;
    });
});

// Example control: Move camera target with mouse/pointer movement
app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;
app.stage.on('pointermove', (event) => {
    camera.targetX = event.global.x * 2;
    camera.targetY = event.global.y;
});

4. Handling Clamped World Boundaries

If using bounded levels rather than infinite repeating patterns, replace tilePosition manipulation with container offsets clamped to the world boundaries:

parallaxLayers.forEach((layer) => {
    // Center viewport on camera position scaled by factor
    layer.container.position.x = (app.screen.width / 2) - (camera.x * layer.factorX);
    layer.container.position.y = (app.screen.height / 2) - (camera.y * layer.factorY);
});

Binding the parallax layers directly to a single camera abstraction ensures accurate synchronization across all viewport transformations, including zoom and screen resize events.
