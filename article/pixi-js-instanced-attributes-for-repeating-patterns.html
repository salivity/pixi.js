Pixi.js Instanced Attributes for Repeating Patterns

Rendering thousands of repeating geometric patterns efficiently in Pixi.js requires instanced rendering to minimize draw calls. By attaching instanced buffer attributes to a custom Geometry object, you can pass unique transformation and styling data—such as positions, rotations, or colors—for each repeated element while reusing a single base shape. This guide explains how to define instanced attributes using Pixi.js's Geometry, Buffer, and Shader APIs to achieve high-performance rendering of repetitive graphics.

Understanding Instancing in Pixi.js

Standard rendering requires either issuing a draw call per object or combining all vertices into a massive CPU-bound buffer. Instancing allows WebGL to render multiple copies of a base geometry in a single draw call. The base geometry defines the local shape (such as a triangle, quad, or hexagon), while instanced attributes provide per-instance offsets, scales, or tint data.

Step 1: Define the Base Geometry

First, define the static vertices and indices for a single unit of your repeating pattern. For a standard quad or polygon, create standard non-instanced attributes:

import * as PIXI from 'pixi.js';

// Base quad vertices (local space: -0.5 to 0.5)
const baseVertices = new Float32Array([
    -10, -10,
     10, -10,
     10,  10,
    -10,  10
]);

const indices = new Uint16Array([
    0, 1, 2,
    0, 2, 3
]);

const geometry = new PIXI.Geometry();
geometry.addAttribute('aVertexPosition', baseVertices, 2);
geometry.addIndex(indices);

Step 2: Define Instanced Attributes

To define instanced data, populate a typed array containing the specific data for each repeated instance (such as X/Y offsets and RGB color values) and attach it using addAttribute. The eighth parameter of geometry.addAttribute is a boolean flag indicating whether the attribute is instanced (true).

const instanceCount = 5000;
const offsets = new Float32Array(instanceCount * 2);
const colors = new Float32Array(instanceCount * 3);

// Generate repeating grid pattern data
const columns = 100;
const spacing = 25;

for (let i = 0; i < instanceCount; i++) {
    const x = (i % columns) * spacing;
    const y = Math.floor(i / columns) * spacing;

    offsets[i * 2] = x;
    offsets[i * 2 + 1] = y;

    colors[i * 3] = (i % columns) / columns;       // Red
    colors[i * 3 + 1] = 0.5;                       // Green
    colors[i * 3 + 2] = (i / instanceCount);       // Blue
}

// Create buffers
const offsetBuffer = new PIXI.Buffer(offsets);
const colorBuffer = new PIXI.Buffer(colors);

// addAttribute signature:
// (id, buffer, size, normalized, type, stride, start, instance)
geometry.addAttribute('aOffset', offsetBuffer, 2, false, PIXI.TYPES.FLOAT, 0, 0, true);
geometry.addAttribute('aColor', colorBuffer, 3, false, PIXI.TYPES.FLOAT, 0, 0, true);

// Explicitly set the number of instances
geometry.instanceCount = instanceCount;

Step 3: Create the Shaders

Write a custom vertex shader that reads both standard attributes (aVertexPosition) and instanced attributes (aOffset, aColor). Pixi.js automatically injects standard uniform matrices like translationMatrix and projectionMatrix.

const vertexShader = `
precision mediump float;

attribute vec2 aVertexPosition;
attribute vec2 aOffset;
attribute vec3 aColor;

uniform mat3 translationMatrix;
uniform mat3 projectionMatrix;

varying vec3 vColor;

void main() {
    vColor = aColor;
    vec3 position = translationMatrix * vec3(aVertexPosition + aOffset, 1.0);
    gl_Position = vec4((projectionMatrix * position).xy, 0.0, 1.0);
}
`;

const fragmentShader = `
precision mediump float;

varying vec3 vColor;

void main() {
    gl_FragColor = vec4(vColor, 1.0);
}
`;

const shader = PIXI.Shader.from(vertexShader, fragmentShader);

Step 4: Render Using PIXI.Mesh

Combine the geometry and shader into a PIXI.Mesh and add it to the display tree. Pixi.js detects the instanced attributes and executes gl.drawElementsInstanced under the hood.

const instancedMesh = new PIXI.Mesh(geometry, shader);
app.stage.addChild(instancedMesh);

Updating Instanced Attributes

If your repeating pattern needs dynamic updates (such as pulsing waves, animation, or interactive positioning), modify the underlying typed array and notify Pixi.js that the buffer needs synchronization:

function updatePositions() {
    const bufferData = offsetBuffer.data;
    for (let i = 0; i < instanceCount; i++) {
        bufferData[i * 2 + 1] += Math.sin(Date.now() * 0.005 + i) * 0.5;
    }
    offsetBuffer.update();
}

app.ticker.add(updatePositions);

Setting instanced: true on attribute declarations decouples memory scaling from draw calls, providing the most efficient pipeline for rendering dense geometric arrangements in Pixi.js.
