Volume Fading and Crossfades with @pixi/sound in PixiJS

Managing smooth audio transitions in PixiJS games is essential for maintaining immersion, and the @pixi/sound package provides the tools necessary to control volume programmatically. While the library handles Web Audio API node creation and playback management internally, executing seamless volume fades and scene crossfades relies on manipulating sound instance properties in combination with PixiJS's ticker or a tweening library. This article covers how @pixi/sound structures audio volume, how to implement basic volume fading, and how to execute robust crossfades during scene transitions.

Audio Architecture and Volume Hierarchy

The @pixi/sound library organizes volume control across three distinct tiers:

  1. Global Volume: Controlled via sound.volume, adjusting this value scales the output of all sounds globally.
  2. Sound Object Volume: Defined directly on an individual loaded sound (e.g., sound.find('bgm').volume), affecting all instances created from that asset.
  3. Sound Instance Volume: Created when calling .play(), a SoundInstance represents an active audio playback node with its own localized volume property.

For fading and crossfading, adjustments should almost always target the individual SoundInstance. Modifying the sound asset or global volume directly can inadvertently alter unintended sound effects or create abrupt state bugs when an asset is replayed later.

Implementing Volume Fades

Because @pixi/sound does not include an internal animation engine, gradual volume adjustments are executed using an external update loop, such as the PIXI.Ticker or an animation library like GSAP.

A standard fade involves stepping the volume property of an active SoundInstance over time:

import { sound } from '@pixi/sound';
import * as PIXI from 'pixi.js';

function fadeSound(instance, targetVolume, duration, onComplete) {
    const startVolume = instance.volume;
    const diff = targetVolume - startVolume;
    let elapsed = 0;

    const tickerCallback = (ticker) => {
        elapsed += ticker.deltaMS;
        const progress = Math.min(elapsed / duration, 1);
        
        instance.volume = startVolume + diff * progress;

        if (progress >= 1) {
            PIXI.Ticker.shared.remove(tickerCallback);
            if (onComplete) onComplete();
        }
    };

    PIXI.Ticker.shared.add(tickerCallback);
}

When fading out an audio track entirely, always call instance.stop() once the target volume of 0 is reached. Stopping the instance detaches the underlying Web Audio source node, preventing memory leaks and preserving processing headroom.

Executing Scene Crossfades

A crossfade transitions audio smoothly by fading out the current scene's music while simultaneously fading in the incoming scene's music. This avoids jarring cuts and disguises asset loading periods.

To execute a crossfade between two scenes:

  1. Instantiate and play the incoming scene's audio track with an initial volume of 0.
  2. Concurrently interpolate the outgoing track's volume to 0 and the incoming track's volume to its target level (typically 1).
  3. Terminate playback on the outgoing track once the transition completes.

Here is a practical crossfade implementation:

import { sound } from '@pixi/sound';

class AudioManager {
    constructor() {
        this.currentMusic = null;
    }

    crossfade(newSoundAlias, duration = 1000) {
        // Start the incoming sound at 0 volume
        const nextMusic = sound.find(newSoundAlias).play({
            volume: 0,
            loop: true
        });

        // Fade in new music
        fadeSound(nextMusic, 1, duration);

        // Fade out and stop existing music
        if (this.currentMusic) {
            const outgoingMusic = this.currentMusic;
            fadeSound(outgoingMusic, 0, duration, () => {
                outgoingMusic.stop();
            });
        }

        this.currentMusic = nextMusic;
    }
}

Best Practices for Clean Audio Transitions

  • Equal-Power Fades vs. Linear Fades: Linear volume transitions can cause a noticeable perceived dip in overall sound level at the midpoint of a crossfade. If using a tweening library, apply an exponential or sine curve (equal-power curve) to maintain a consistent perceived loudness throughout the transition.
  • Handle Rapid Scene Changes: If a player skips through menus or transitions scenes faster than the fade duration, ensure any active fade tickers are canceled immediately to avoid conflicting volume writes to the same SoundInstance.
  • Sound Destruction Lifecycle: When unloading a scene, ensure references to SoundInstance objects are cleared and active tweens are stopped to ensure the browser garbage collects the discarded Web Audio resources cleanly.
