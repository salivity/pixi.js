Create a Pixi.js Audio Visualizer with AnalyserNode

This guide demonstrates how to capture real-time audio frequency data using the Web Audio API's AnalyserNode and render dynamic visual graphics with Pixi.js. By connecting an audio source to an analyzer and feeding its output buffer into a Pixi.js render loop, you can map frequencies directly to graphical properties like height, scale, and color.

1. Initialize the Web Audio API and AnalyserNode

To inspect audio data, instantiate an AudioContext and an AnalyserNode. The AnalyserNode handles the Fast Fourier Transform (FFT) to convert time-domain signals into frequency data.

const audioContext = new (window.AudioContext || window.webkitAudioContext)();
const analyser = audioContext.createAnalyser();

// fftSize must be a power of 2 (e.g., 64, 128, 256, 512, 1024, 2048)
analyser.fftSize = 128; 

// The number of data points is half the FFT size
const bufferLength = analyser.frequencyBinCount; 
const dataArray = new Uint8Array(bufferLength);

2. Connect the Audio Source

Connect an <audio> element or media stream to the analyser, and route the analyser to the destination speakers so the audio remains audible.

const audioElement = document.querySelector('audio');
const track = audioContext.createMediaElementSource(audioElement);

track.connect(analyser);
analyser.connect(audioContext.destination);

// Browser autoplay policies require resuming context on user interaction
window.addEventListener('click', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
});

3. Set Up the Pixi.js Application

Initialize the Pixi.js application and generate visual elements for each frequency bin. A common approach is creating vertical bars using PIXI.Graphics.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({
  width: 800,
  height: 400,
  backgroundColor: 0x101010,
});
document.body.appendChild(app.view);

const bars = [];
const barWidth = app.screen.width / bufferLength;

for (let i = 0; i < bufferLength; i++) {
  const bar = new PIXI.Graphics();
  bar.beginFill(0x00ffcc);
  bar.drawRect(0, 0, barWidth - 2, 1);
  bar.endFill();
  
  bar.x = i * barWidth;
  bar.y = app.screen.height;
  bar.pivot.y = 1; // Anchor to the bottom

  app.stage.addChild(bar);
  bars.push(bar);
}

4. Extract Data and Animate in the Ticker

Use analyser.getByteFrequencyData(dataArray) inside Pixi’s ticker loop. This function updates the dataArray with integers between 0 and 255 representing the amplitude of each frequency band.

app.ticker.add(() => {
  // Populate the array with current frequency values
  analyser.getByteFrequencyData(dataArray);

  for (let i = 0; i < bufferLength; i++) {
    const value = dataArray[i]; // Value ranges from 0 to 255
    const bar = bars[i];

    // Scale the bar's height according to the frequency intensity
    const targetScaleY = (value / 255) * (app.screen.height - 50);
    bar.scale.y = Math.max(1, targetScaleY);
  }
});

Fine-Tuning Performance and Visuals

  • Smoothing: Adjust analyser.smoothingTimeConstant (between 0 and 1) to determine how quickly values transition between frames. A default of 0.8 provides a balanced transition, while lower values offer a snappier response.
  • Frequency Resolution: Adjust analyser.fftSize to balance visual detail with performance. A higher fftSize generates more bars across finer frequency bands, while a lower fftSize requires fewer WebGL draw calls.
