How Pixi.js SimpleRope Creates Flexible Curved Shapes

The SimpleRope class in Pixi.js renders flexible, dynamic, and curved textures mapped along a continuous sequence of points. By using the provided points as a central skeletal spine, SimpleRope dynamically calculates and constructs a 2D triangle mesh that bends along the path. This article explains the underlying mechanics of SimpleRope, covering its triangle strip generation, perpendicular offset calculations, UV coordinate mapping, and runtime deformation for smooth animations.

Triangle Mesh Generation

SimpleRope extends the base PIXI.Mesh class. Instead of drawing a standard rectangular quad, it divides a texture into a series of connected rectangular segments, each composed of two triangles (a triangle strip).

The number of segments corresponds directly to the number of control points provided in the points array. For an array of \(N\) points, the mesh constructs \(N - 1\) segments. Each point corresponds to a pair of vertices on the outer boundaries of the rope, creating a connected ribbon of geometry.

Tangent and Normal Vector Calculation

To produce a shape with physical thickness along a curved path, Pixi.js determines where to place the vertices relative to the central points:

  1. Tangent Calculation: For each point in the array, the engine determines the direction of the path by computing the vector between the current point and the adjacent points.
  2. Normal (Perpendicular) Vector: The engine calculates a perpendicular vector (the normal) to this tangent line.
  3. Vertex Offset: Two vertices are generated for each point by projecting outward in opposite directions along the normal vector. The distance of this offset is determined by half of the texture's cross-sectional dimension (typically half the height of the texture).

Because these normal vectors continuously pivot according to the angle between successive points, the generated strip stays uniform in width even as the path curves sharply.

UV Coordinate Mapping

Once the vertex positions are calculated, SimpleRope maps the source texture to the mesh using UV coordinates:

  • Along the Length: The U-coordinates (horizontal axis of the texture) run progressively from 0.0 at the first point to 1.0 at the final point. Each intermediate point receives a proportional UV coordinate based on its index or its cumulative distance along the curve.
  • Across the Width: The V-coordinates (vertical axis of the texture) alternate between 0.0 for the top vertex and 1.0 for the bottom vertex along the normal offset.

This mapping stretches and conforms the texture seamlessly around curves, keeping the visual graphic locked to the underlying skeletal path.

Real-Time Deformation

SimpleRope achieves fluid, performant animation because the topology of the mesh (the total number of vertices and triangle indices) remains constant after instantiation.

When you mutate the x and y properties of any PIXI.Point in the path:

  1. The underlying vertex buffer is marked as dirty.
  2. During the render pass, Pixi.js recalculates the normals and vertex positions for only the affected coordinates.
  3. The updated buffer is uploaded directly to the GPU.

Because the underlying vertex arrays are modified in-place without garbage collection overhead, SimpleRope can animate complex physics, undulating ribbons, swinging ropes, or slithering creatures at 60 frames per second.
