How to Zoom Pixi.js Camera to Mouse Position

Zooming a canvas towards the mouse pointer rather than the top-left origin requires shifting the world container to compensate for the change in scale. This guide explains the coordinate math behind mouse-centered zooming in Pixi.js and provides a complete, copy-pasteable implementation using Pixi's built-in transformation methods.

The Underlying Concept

By default, scaling a PIXI.Container scales relative to its origin (0, 0). When zooming toward the cursor, the point in the world directly beneath the mouse must remain in that exact screen position after the scale is applied.

The formula involves three steps:

  1. Find the mouse position in local container coordinates before scaling.
  2. Apply the new scale factor to the container.
  3. Reposition the container so that the local point aligns with the global cursor position: \[\text{container.x} = \text{cursor.x} - (\text{localPoint.x} \times \text{container.scale.x})\] \[\text{container.y} = \text{cursor.y} - (\text{localPoint.y} \times \text{container.scale.y})\]

Implementation

Attach an event listener to the native wheel event on the canvas or use Pixi's interaction events. Pixi's toLocal() method handles the inverted transformation matrix automatically.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application();
await app.init({ width: 800, height: 600, backgroundColor: 0x1099bb });
document.body.appendChild(app.canvas);

// Create a main container that acts as the camera/world
const world = new PIXI.Container();
app.stage.addChild(world);

// Add sample content to visualize the zoom
const graphics = new PIXI.Graphics();
graphics.rect(100, 100, 200, 200).fill(0xff1010);
graphics.circle(400, 300, 50).fill(0xffff00);
world.addChild(graphics);

// Zoom configuration
const ZOOM_SPEED = 0.1;
const MIN_ZOOM = 0.2;
const MAX_ZOOM = 5.0;

// Listen for mouse wheel events on the view canvas
app.canvas.addEventListener('wheel', (event) => {
    event.preventDefault();

    // 1. Get the current cursor position relative to the canvas
    const rect = app.canvas.getBoundingClientRect();
    const cursorGlobal = {
        x: event.clientX - rect.left,
        y: event.clientY - rect.top
    };

    // 2. Convert cursor coordinates to the world container's local space
    const cursorLocal = world.toLocal(cursorGlobal);

    // 3. Determine zoom direction and calculate target scale
    const direction = event.deltaY < 0 ? 1 : -1;
    const factor = 1 + direction * ZOOM_SPEED;
    const newScale = Math.min(Math.max(world.scale.x * factor, MIN_ZOOM), MAX_ZOOM);

    // 4. Apply scale
    world.scale.set(newScale);

    // 5. Reposition container so local point stays under the cursor
    world.x = cursorGlobal.x - cursorLocal.x * world.scale.x;
    world.y = cursorGlobal.y - cursorLocal.y * world.scale.y;
});

Key Considerations

  • toLocal() vs Manual Math: Using world.toLocal(cursorGlobal) accounts for any existing translation, scale, or rotation on the container without requiring manual matrix math.
  • Scale Clamping: Always clamp the new scale value using Math.min and Math.max before assigning it to prevent users from inverting the view or zooming infinitely.
  • Canvas Offsets: Calculate global cursor coordinates by subtracting getBoundingClientRect() values from clientX/clientY to ensure accuracy if the canvas is styled, centered, or padded in the DOM.
