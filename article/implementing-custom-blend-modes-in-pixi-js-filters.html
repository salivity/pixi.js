Implementing Custom Blend Modes in Pixi.js Filters

This article explains how to build and integrate custom blend modes into Pixi.js using custom fragment shaders and the PIXI.Filter class. While Pixi.js includes several standard WebGL blend modes out of the box, complex or non-standard blend operations—such as Overlay, Soft Light, or custom artistic equations—require fragment-level color manipulation. By passing source and backdrop textures into a custom shader, you can implement any mathematical blending equation with high performance.

1. Understanding Blend Math in Shaders

A blend mode combines a source color (the foreground object) with a backdrop color (the background scene). Standard WebGL blending operates via hardware state changes (gl.blendFunc), which are limited to fixed linear equations.

To perform arbitrary or non-linear blending (like Photoshop-style blend modes), the logic must happen inside a fragment shader where you can access both color inputs per pixel:

  • Base/Backdrop Color (\(C_b\)): The underlying pixel color.
  • Blend/Source Color (\(C_s\)): The color of the object being drawn.

2. Writing the Fragment Shader

In GLSL, you can write mathematical helper functions for different blend modes. Below is an example shader implementing an Overlay blend mode:

varying vec2 vTextureCoord;
uniform sampler2D uSampler;       // Source texture (foreground)
uniform sampler2D uBackdrop;      // Target texture (background)
uniform float uAlpha;

// Overlay blend formula for a single channel
float blendOverlay(float base, float blend) {
    return base < 0.5 ? (2.0 * base * blend) : (1.0 - 2.0 * (1.0 - base) * (1.0 - blend));
}

// Vectorized Overlay blend for RGB
vec3 blendOverlay(vec3 base, vec3 blend) {
    return vec3(
        blendOverlay(base.r, blend.r),
        blendOverlay(base.g, blend.g),
        blendOverlay(base.b, blend.b)
    );
}

void main(void) {
    vec4 source = texture2D(uSampler, vTextureCoord);
    vec4 backdrop = texture2D(uBackdrop, vTextureCoord);

    // Perform blend on RGB channels
    vec3 blendedRGB = blendOverlay(backdrop.rgb, source.rgb);

    // Account for alpha compositing
    vec3 finalRGB = mix(backdrop.rgb, blendedRGB, source.a * uAlpha);
    float finalAlpha = max(source.a * uAlpha, backdrop.a);

    gl_FragColor = vec4(finalRGB, finalAlpha);
}

3. Creating the Custom Filter Class

Extend PIXI.Filter in JavaScript to encapsulate the shader and manage uniforms:

import * as PIXI from 'pixi.js';

const fragmentSrc = `...`; // Insert the GLSL shader code from above

export class CustomBlendFilter extends PIXI.Filter {
    constructor(backdropTexture) {
        // Pass null for vertex shader to use Pixi's default
        super(null, fragmentSrc, {
            uBackdrop: backdropTexture,
            uAlpha: 1.0,
        });
    }

    get alpha() {
        return this.uniforms.uAlpha;
    }

    set alpha(value) {
        this.uniforms.uAlpha = value;
    }

    set backdrop(texture) {
        this.uniforms.uBackdrop = texture;
    }
}

4. Applying the Filter to Display Objects

To supply the backdrop texture to your custom blend filter, render the underlying content to a PIXI.RenderTexture before applying the filter to the foreground object:

// Setup textures and sprites
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

const backgroundContainer = new PIXI.Container();
const foregroundSprite = PIXI.Sprite.from('foreground.png');

// Create a render texture to capture the background
const backdropRenderTexture = PIXI.RenderTexture.create({
    width: app.screen.width,
    height: app.screen.height,
});

// Instantiate the custom filter
const blendFilter = new CustomBlendFilter(backdropRenderTexture);
foregroundSprite.filters = [blendFilter];

app.stage.addChild(backgroundContainer);
app.stage.addChild(foregroundSprite);

// Render loop: update backdrop texture before drawing
app.ticker.add(() => {
    // Temporarily hide foreground to capture only background layers
    foregroundSprite.visible = false;
    app.renderer.render(backgroundContainer, { renderTexture: backdropRenderTexture });
    foregroundSprite.visible = true;
});

5. Alternative Formula Reference

Replace the blendOverlay function in the fragment shader to achieve different visual results:

  • Multiply: 
    vec3 blendMultiply(vec3 base, vec3 blend) {
    return base * blend;
}
  • Screen: 
    vec3 blendScreen(vec3 base, vec3 blend) {
    return 1.0 - ((1.0 - base) * (1.0 - blend));
}
  • Hard Light: 
    vec3 blendHardLight(vec3 base, vec3 blend) {
    return blendOverlay(blend, base);
}
  • Color Dodge: 
    vec3 blendColorDodge(vec3 base, vec3 blend) {
    return base / (1.0 - blend);
}
