Simulate Film Grain and Scratches in Pixi.js

This guide demonstrates how to simulate vintage film grain, noise, and scratch-like scanlines in Pixi.js using the FilmFilter from the PixiJS community filters collection. You will learn how to install the filter, configure its noise and scanline properties, and animate the seed inside the render loop to produce a continuous, flickering retro film aesthetic.

1. Install the Film Filter

The FilmFilter is not bundled into the core Pixi.js library by default. It is maintained in the pixi-filters package. You can install either the full filters suite or the individual filter package via npm:

npm install @pixi/filter-film

If you are using a CDN via a script tag, include the pixi-filters bundle after loading the primary Pixi.js script:

<script src="https://pixijs.download/v7.x/pixi.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/pixi-filters@latest/dist/pixi-filters.js"></script>

2. Configure the FilmFilter

The FilmFilter accepts options or parameters that govern noise intensity, scanlines, and the random seed. In standard usage, the parameters correspond to:

  • noise: The amount of grain/noise applied to the display object.
  • noiseIntensity: How visibly intense the noise particles appear.
  • scanlines: Whether horizontal/vertical line artifacts are enabled.
  • scanlineIntensity: The opacity and visibility of the lines.
  • seed: A numeric value that drives the random distribution pattern of the grain.

Here is how to instantiate and attach the filter to a container or the entire stage:

import * as PIXI from 'pixi.js';
import { FilmFilter } from '@pixi/filter-film';

// Create a Pixi Application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1099bb,
});
document.body.appendChild(app.view);

// Initialize the FilmFilter
// Parameters: FilmFilter(options) or FilmFilter(noise, scanlines) depending on version
const filmFilter = new FilmFilter({
    noise: 0.5,             // Grain amount
    noiseIntensity: 0.7,    // Grain contrast
    scanlines: true,        // Enable scanline artifacts
    scanlineIntensity: 0.2, // Keep subtle to mimic aged film lines
    seed: 0
});

// Apply the filter to the stage
app.stage.filters = [filmFilter];

3. Animate Grain and Scratches

Film grain and dust scratches change continuously on physical film stock. If the filter's seed remains constant, the grain will appear frozen over the image like a static texture.

To achieve an authentic jitter, update the filter's seed inside the application ticker loop:

app.ticker.add((delta) => {
    // Update the seed randomly on each frame to make the grain flicker
    filmFilter.seed = Math.random();
});

To emulate irregular scratches rather than a consistent digital pattern, periodically spike the noise and scanline intensities on random frames:

app.ticker.add((delta) => {
    filmFilter.seed = Math.random();

    // Randomly spike values to simulate intermittent physical scratches and dirt
    if (Math.random() < 0.05) {
        filmFilter.noise = 0.8;
        filmFilter.scanlineIntensity = 0.5;
    } else {
        filmFilter.noise = 0.35;
        filmFilter.scanlineIntensity = 0.15;
    }
});

4. Layering for an Authentic Old-Film Look

The FilmFilter operates purely on noise and line artifacts. To produce a complete old projector effect, combine it with a ColorMatrixFilter to desaturate the image or apply a sepia tint:

const sepiaFilter = new PIXI.ColorMatrixFilter();
sepiaFilter.sepia(false);

// Apply both filters in sequence
app.stage.filters = [sepiaFilter, filmFilter];

The rendering order processes the color grading first, followed by the film grain and line distortion across the final output.
