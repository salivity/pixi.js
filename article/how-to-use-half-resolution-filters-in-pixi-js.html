How to Use Half Resolution Filters in Pixi.js

Rendering filter passes at half-resolution is an effective optimization technique in Pixi.js to improve rendering speed, especially on mobile devices or hardware-constrained environments. Pixi.js provides built-in support for downscaling filter passes via the resolution property on any Filter instance. By setting this property to 0.5, the internal render target texture is created at half the width and height of the filtered display object, cutting the total pixel processing load by 75% and significantly boosting frame rates.

Implementing Half-Resolution Filters

Every filter in Pixi.js inherits from the base Filter class, which exposes a resolution property. By default, this value is set to PIXI.settings.FILTER_RESOLUTION (or 1), matching the renderer's standard scale.

To run a filter at half-resolution, modify the resolution property directly on the filter instance:

import * as PIXI from 'pixi.js';

// Create your filter (e.g., a BlurFilter)
const blurFilter = new PIXI.BlurFilter();

// Set the resolution to half
blurFilter.resolution = 0.5;

// Apply the filter to a container or sprite
container.filters = [blurFilter];

Why It Improves Performance

Filters in WebGL work by rendering a display object into an offscreen framebuffer (render texture) and then executing a fragment shader on that texture before drawing it to the screen.

Fragment shaders—particularly multi-pass shaders like blurs, glows, or depth-of-field effects—are heavily fill-rate limited. By reducing the resolution factor to 0.5:

  • The width and height of the temporary framebuffer are halved.
  • The GPU has to compute fragment shader calculations for only a quarter of the original pixel count.
  • Memory bandwidth requirements and GPU fill-rate pressure are drastically reduced.

When to Use Half-Resolution

Half-resolution rendering is ideal for soft visual effects where precision is not critical. Common use cases include:

  • Blur and Glow Effects: High-frequency edge details are naturally softened by blur algorithms, making the loss of native resolution nearly imperceptible to the human eye.
  • Full-Screen Post-Processing: Effects like bloom, heat distortion, or vignette can run at lower resolutions with minimal noticeable quality degradation.
  • Mobile Optimization: Mobile GPUs suffer the most from fill-rate bottlenecks; dropping resolution on heavy filters ensures stable 60 FPS performance.

Visual Trade-offs

Downscaling a filter pass introduces bilinear interpolation when the texture is scaled back up to fit the screen. For sharp or edge-sensitive effects—such as outlines, displacement maps, or color adjustments—a half-resolution pass can result in noticeable pixelation or aliasing. For these use cases, maintain a resolution of 1 or use intermediate values (like 0.75) to balance visual quality with performance.
