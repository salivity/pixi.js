Pixel-Perfect Hit Testing for PNGs in Pixi.js

This article explains how to implement pixel-perfect hit testing on irregular, transparent PNG sprites in Pixi.js. By default, Pixi.js evaluates interactions using rectangular bounding boxes, which mistakenly triggers pointer events on transparent sections of an image. You will learn how to bypass the standard bounding box check by implementing a custom hitArea that reads texture pixel data to ensure clicks and taps only register on visible pixels.

The Limitation of Standard Hit Areas

Pixi.js handles pointer interaction through axis-aligned bounding boxes or predefined geometric shapes (such as PIXI.Rectangle, PIXI.Polygon, or PIXI.Circle). For irregular PNG graphics containing transparent regions, this default behavior detects clicks in empty spaces around the visible artwork. To solve this, you must inspect the alpha channel of the underlying pixel at the pointer's coordinates before confirming an interaction.

Implementing a Custom hitArea with containsPoint

In Pixi.js, any object assigned to a display object’s hitArea property only needs to implement a containsPoint(x, y) method returning a boolean.

To achieve pixel-perfect detection without causing severe GPU readback bottlenecks, read the pixel data from an HTML Canvas element created alongside or extracted from the sprite's texture.

Step 1: Cache the Texture's Pixel Data

Extracting pixels from the GPU dynamically during mouse movement causes performance drops. Instead, draw the image to an offscreen 2D canvas once when the asset loads, then access the raw ImageData array:

function createPixelHitMap(imageElement) {
    const canvas = document.createElement('canvas');
    canvas.width = imageElement.width;
    canvas.height = imageElement.height;

    const ctx = canvas.getContext('2d', { willReadFrequently: true });
    ctx.drawImage(imageElement, 0, 0);

    const imgData = ctx.getImageData(0, 0, canvas.width, canvas.height);
    return {
        width: canvas.width,
        height: canvas.height,
        data: imgData.data // Uint8ClampedArray containing RGBA values
    };
}

Step 2: Define the Pixel-Perfect Hit Area

Construct a custom hit area class that checks the alpha value of the coordinates against an alpha threshold:

class PixelPerfectHitArea {
    constructor(pixelMap, alphaThreshold = 0) {
        this.pixelMap = pixelMap;
        this.alphaThreshold = alphaThreshold; // 0 to 255
    }

    containsPoint(x, y) {
        // Round coordinates to nearest integer pixel
        const px = Math.floor(x);
        const py = Math.floor(y);

        // Reject coordinates outside image dimensions
        if (px < 0 || px >= this.pixelMap.width || py < 0 || py >= this.pixelMap.height) {
            return false;
        }

        // Calculate the index for the Alpha channel (RGBA format)
        const alphaIndex = (py * this.pixelMap.width + px) * 4 + 3;
        const alpha = this.pixelMap.data[alphaIndex];

        return alpha > this.alphaThreshold;
    }
}

Step 3: Assign to the Sprite

Instantiate the sprite, generate the pixel map from the base image, and attach the custom hit area:

const texture = PIXI.Texture.from('character.png');
const sprite = new PIXI.Sprite(texture);

// Ensure the source image has loaded before generating data
const imageSource = texture.baseTexture.resource.source;

const pixelMap = createPixelHitMap(imageSource);
sprite.hitArea = new PixelPerfectHitArea(pixelMap, 20); // 20 allows slight semi-transparency tolerance

sprite.eventMode = 'static';
sprite.cursor = 'pointer';

sprite.on('pointerdown', () => {
    console.log('Clicked visible area of irregular PNG!');
});

app.stage.addChild(sprite);

Performance Best Practices

  1. Avoid GPU Readbacks: Do not use app.renderer.extract.pixels() inside pointer event loops. Reading synchronously from the WebGL context stalls the rendering pipeline. Always sample an offscreen CPU-side canvas or typed array.
  2. Use Binary Bitmasks for Memory Optimization: For large scenes with many sprites, storing a complete 4-byte RGBA buffer per sprite wastes RAM. Store only the alpha channel as a 1-bit boolean array (1 bit per pixel) to cut memory usage by over 95%.
  3. Downsample Complex Hit Maps: If absolute single-pixel precision is unnecessary, downscale the offscreen canvas to 50% or 25% of the original size when building the hit map, adjusting coordinate calculations accordingly.
