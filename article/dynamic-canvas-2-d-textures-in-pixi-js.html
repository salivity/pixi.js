Dynamic Canvas 2D Textures in Pixi.js

Creating dynamic procedural textures in Pixi.js using the HTML5 Canvas 2D context allows developers to leverage familiar 2D drawing methods to generate graphics on the fly. This article explains how to initialize an offscreen canvas, wrap it in a Pixi.js texture, manipulate the canvas context procedurally, and notify Pixi.js when changes occur so they reflect on the GPU immediately.

1. Create the Offscreen Canvas

First, instantiate a standard HTML5 <canvas> element in JavaScript without attaching it to the DOM. Acquire its 2D rendering context to draw procedural graphics.

const canvasWidth = 256;
const canvasHeight = 256;

const canvas = document.createElement('canvas');
canvas.width = canvasWidth;
canvas.height = canvasHeight;
const ctx = canvas.getContext('2d');

2. Wrap the Canvas into a Pixi.js Texture

Pixi.js can construct textures directly from a canvas reference via PIXI.Texture.from(). Once created, assign the texture to a PIXI.Sprite and add it to the Pixi stage.

// Generate the Pixi texture using the canvas
const dynamicTexture = PIXI.Texture.from(canvas);

// Create a sprite that displays the dynamic texture
const sprite = new PIXI.Sprite(dynamicTexture);
app.stage.addChild(sprite);

3. Draw and Update the Texture Dynamically

Whenever you update the 2D context, Pixi.js must be informed to re-upload the canvas bitmap to the GPU. Call dynamicTexture.update() (or dynamicTexture.baseTexture.update() in older versions) after performing your procedural drawing operations.

let frame = 0;

function drawProceduralGraphics() {
    // Clear previous frame
    ctx.clearRect(0, 0, canvasWidth, canvasHeight);

    // Procedural drawing: animated concentric circles
    frame += 0.05;
    const radius = Math.abs(Math.sin(frame)) * (canvasWidth / 2);

    ctx.fillStyle = '#1e1e1e';
    ctx.fillRect(0, 0, canvasWidth, canvasHeight);

    ctx.beginPath();
    ctx.arc(canvasWidth / 2, canvasHeight / 2, radius, 0, Math.PI * 2);
    ctx.fillStyle = '#ff0055';
    ctx.fill();

    // Signal Pixi.js to re-upload the canvas to WebGL/GPU
    dynamicTexture.update();
}

// Hook into Pixi's animation loop
app.ticker.add(() => {
    drawProceduralGraphics();
});

4. Performance Considerations

  • Canvas Dimensions: Uploading canvas data to the GPU requires transferring pixel buffers via WebGL. Keep the canvas dimensions as small as possible to minimize overhead.
  • Conditional Updates: Avoid calling dynamicTexture.update() on frames where the 2D canvas content has not changed. Only trigger the update method when a redraw actually occurs.
