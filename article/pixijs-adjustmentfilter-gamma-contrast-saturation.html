PixiJS AdjustmentFilter: Gamma, Contrast, Saturation

The AdjustmentFilter in PixiJS provides a lightweight, all-in-one post-processing solution to modify the color balance, tonal distribution, and luminance of display objects. Instead of chaining multiple individual filters, it allows developers to adjust gamma, saturation, contrast, brightness, and color channels within a single GPU fragment shader pass. This article explains how the filter works, details how to manipulate gamma, saturation, and contrast values, and demonstrates its practical implementation.

Understanding the AdjustmentFilter

Provided via the external pixi-filters collection (under the @pixi/filter-adjustment package), AdjustmentFilter is designed for fast, real-time photographic color corrections. Applying multiple distinct filters (such as separate blur, color-matrix, and brightness shaders) increases draw calls and impacts frame rates. AdjustmentFilter consolidates key color-grading operations into a single shader pass, making it highly performant for games, interactive visualizers, and canvas-based applications.

Fine-Tuning Gamma

The gamma property modulates the non-linear luminance of midtones without clipping pure blacks (0.0) or pure whites (1.0).

  • Default value: 1.0 (standard linear representation).
  • Values below 1.0 (e.g., 0.5): Compresses midtones downward, making shadows richer and the overall image darker while preserving the brightest highlights.
  • Values above 1.0 (e.g., 1.5 to 2.2): Lifts the midtones, recovering detail in dark areas and simulating exposure increases.

In the shader, the input color is raised to the power of 1.0 / gamma. This non-linear mapping makes it ideal for correcting textures rendered in different color spaces or adapting a scene's mood to day/night cycles.

Fine-Tuning Saturation

The saturation property controls the intensity and purity of the colors across the targeted display object.

  • Default value: 1.0 (unaltered original colors).
  • Value of 0.0: Completely removes color information, producing a clean grayscale image by weighting the red, green, and blue channels according to standard luminance coefficients.
  • Values between 0.0 and 1.0: Produces muted, desaturated tones useful for damaged states, pause screens, or atmospheric fog.
  • Values above 1.0 (e.g., 1.5 to 3.0): Amplifies color vibrancy, pushing muted tones into vivid, stylized territory.

Fine-Tuning Contrast

The contrast property adjusts the separation between the darkest and lightest areas of the image by scaling color values relative to a mid-gray pivot (0.5).

  • Default value: 1.0 (original contrast).
  • Values below 1.0 (e.g., 0.5): Pulls highlights down and shadows up toward neutral gray, producing a flat, washed-out visual effect.
  • Values above 1.0 (e.g., 1.5 to 2.0): Pushes highlights closer to pure white and shadows closer to pure black, yielding a sharper, more dramatic visual dynamic.

Implementation Example

To use AdjustmentFilter, install @pixi/filter-adjustment and attach the filter instance to any PixiJS Container, Sprite, or the root stage.

import { Application, Sprite } from 'pixi.js';
import { AdjustmentFilter } from '@pixi/filter-adjustment';

const app = new Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

const sprite = Sprite.from('path/to/texture.png');
app.stage.addChild(sprite);

// Instantiate the AdjustmentFilter with custom settings
const adjustment = new AdjustmentFilter({
    gamma: 1.2,       // Lift midtones slightly
    contrast: 1.15,   // Increase punchiness between darks and lights
    saturation: 1.4,  // Make colors more vibrant
    brightness: 1.0,  // Keep baseline brightness unchanged
    alpha: 1.0        // Maintain full opacity
});

// Apply the filter to the target
sprite.filters = [adjustment];

// Values can be modified dynamically in a render loop
app.ticker.add((delta) => {
    // Example: gently oscillate saturation over time
    adjustment.saturation = 1.0 + Math.sin(Date.now() * 0.002) * 0.5;
});

By altering these properties dynamically on a single filter instance, you achieve flexible color grading without incurring the rendering overhead of multi-pass filter pipelines.
