Calculate Vertex Bounding Boxes in Pixi.js

Calculating vertex bounding boxes for custom geometries in Pixi.js is essential for accurate frustum culling, interaction hit-testing, and container size calculations. This guide explains how Pixi.js processes vertex positions to generate bounds automatically, how to structure your custom geometry buffers to leverage built-in boundary updates, and how to handle dynamic vertex changes.

How Pixi.js Calculates Geometry Bounds

In Pixi.js, a Mesh delegates its spatial measurement to the underlying Geometry. When Pixi requests bounds (for instance, via mesh.getBounds()), the geometry calculates its local axis-aligned bounding box (AABB) by iterating over the coordinates stored in its position buffer.

By default, the internal calculateBounds() method of PIXI.Geometry searches for an attribute named aVertexPosition. It reads the buffer values in pairs (X and Y coordinates) to find the minimum and maximum coordinates, which are then assigned to geometry.bounds.

Configuring Custom Geometry for Automatic Bounds

For Pixi.js to calculate bounds automatically without manual intervention, you must register your vertex coordinates under the default position attribute name or explicitly assign the position attribute to the geometry.

import * as PIXI from 'pixi.js';

// Define flat vertex array (x, y pairs)
const vertices = new Float32Array([
    -50, -50,
     50, -50,
     50,  50,
    -50,  50
]);

const uvs = new Float32Array([
    0, 0,
    1, 0,
    1, 1,
    0, 1
]);

const indices = new Uint16Array([0, 1, 2, 0, 2, 3]);

// Create geometry and add attributes
const customGeometry = new PIXI.Geometry()
    .addAttribute('aVertexPosition', vertices, 2)
    .addAttribute('aTextureCoord', uvs, 2)
    .addIndex(indices);

// Create mesh
const shader = PIXI.Shader.from(vertexShaderSource, fragmentShaderSource);
const customMesh = new PIXI.Mesh(customGeometry, shader);

// The bounds are automatically computed when queried
const bounds = customMesh.getBounds();
console.log(bounds.minX, bounds.minY, bounds.maxX, bounds.maxY);

As long as the vertex attribute is named 'aVertexPosition' and has a size of 2, the geometry will automatically identify the buffer and compute min/max bounds whenever getBounds() is invoked.

Interleaved Buffers and Custom Attribute Names

If your custom pipeline uses an interleaved buffer (where positions, UVs, and colors are packed into a single array) or non-standard attribute names, the default calculateBounds() might fail to recognize the position data automatically.

In this scenario, override the calculateBounds method on your custom geometry instance to parse the specific strides and offsets:

customGeometry.calculateBounds = function () {
    const positionAttribute = this.getAttribute('aCustomPosition');
    if (!positionAttribute) return;

    const buffer = positionAttribute.buffer;
    const data = buffer.data;
    const stride = positionAttribute.stride || 2;
    const start = positionAttribute.start || 0;

    let minX = Infinity;
    let minY = Infinity;
    let maxX = -Infinity;
    let maxY = -Infinity;

    for (let i = start; i < data.length; i += stride) {
        const x = data[i];
        const y = data[i + 1];

        if (x < minX) minX = x;
        if (y < minY) minY = y;
        if (x > maxX) maxX = x;
        if (y > maxY) maxY = y;
    }

    this.bounds.minX = minX;
    this.bounds.minY = minY;
    this.bounds.maxX = maxX;
    this.bounds.maxY = maxY;
};

Handling Dynamic Geometries

When vertex positions change at runtime (such as procedural animations, mesh deforming, or particle simulations), the bounding box becomes invalid. Pixi.js caches bounds to avoid recalculating vertices every frame.

To force Pixi.js to recalculate the bounding box automatically after updating values:

  1. Update the typed array data.
  2. Flag the position buffer with update() to push the changes to the GPU.
  3. Invalidate the geometry bounds using invalidate().
// Modify vertices
vertices[0] = -100;
vertices[1] = -100;

// Notify the buffer of updates
customGeometry.getBuffer('aVertexPosition').update();

// Force the geometry and the parent mesh to recalculate bounds on the next query
customGeometry.invalidate();

Calling customGeometry.invalidate() clears the cached boundary values. The next time the render pipeline evaluates the mesh or a hit test executes, the vertex bounding box will be updated against the latest vertex positions.
