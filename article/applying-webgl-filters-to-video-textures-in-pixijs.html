Applying WebGL Filters to Video Textures in PixiJS

Yes, PixiJS fully supports applying WebGL filters like blur, color matrices, and custom fragment shaders to a playing video texture. Because PixiJS treats a video texture as a dynamic GPU texture wrapped inside a standard sprite or mesh, you can apply any built-in or custom filter to the .filters array of the host display object. This enables real-time visual effects—such as desaturation, hue shifts, blurs, and displacement maps—to render directly on top of dynamic HTML5 video content at standard display refresh rates.

Creating and Playing the Video Texture

To process video frames through WebGL shaders, PixiJS must first bind an HTML5 <video> element to a PIXI.Texture. You can supply either an existing DOM video element or a direct URL to a video file.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

// Create texture directly from video source
const videoTexture = PIXI.Texture.from('path/to/video.mp4');

// Create a sprite to display the video texture
const videoSprite = new PIXI.Sprite(videoTexture);
videoSprite.width = app.screen.width;
videoSprite.height = app.screen.height;

app.stage.addChild(videoSprite);

PixiJS automatically detects HTMLVideoElement sources and updates the underlying WebGL texture each time a new video frame is ready.

Applying Filters

Filters in PixiJS are applied to the filters property of the PIXI.Sprite containing the video texture.

1. ColorMatrixFilter

The ColorMatrixFilter allows for color grading, brightness/contrast adjustments, saturation controls, and tinting in real time.

const colorMatrix = new PIXI.ColorMatrixFilter();
videoSprite.filters = [colorMatrix];

// Apply built-in effects
colorMatrix.desaturate(); 
// Other options include: colorMatrix.sepia(), colorMatrix.negative(), colorMatrix.hue(180)

2. BlurFilter

The BlurFilter applies a Gaussian blur across the video frames.

const blurFilter = new PIXI.BlurFilter();
blurFilter.strength = 8;
blurFilter.quality = 4;

videoSprite.filters = [blurFilter];

3. Chaining Multiple Filters

You can apply multiple filters simultaneously by passing them within the array. PixiJS processes them sequentially using framebuffers:

const blur = new PIXI.BlurFilter(4);
const colorMatrix = new PIXI.ColorMatrixFilter();
colorMatrix.night(0.5);

videoSprite.filters = [blur, colorMatrix];

Animating Filter Properties

Filter uniforms can be updated dynamically inside the PixiJS ticker to create animated visual effects synchronized with the video playback:

let count = 0;
app.ticker.add(() => {
    count += 0.05;
    blur.strength = Math.sin(count) * 10;
});

Performance Considerations

  • Texture Upload Overhead: Playing videos continuously upload new pixel data from the CPU/RAM to the GPU on every frame update. Keep video resolutions optimized to match the target display dimensions to avoid memory bandwidth bottlenecks.
  • Framebuffer Passes: Each filter (and each blur pass) creates an intermediate render target (FBO). Excessive chaining of complex filters on large video resolutions can lower framerates on lower-end devices.
  • Autoplay Policies: Ensure standard HTML5 video flags like muted and playsinline are active on the video element if you encounter playback or permission issues on modern browsers.
