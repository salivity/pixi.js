Passing Float Uniform Arrays in PixiJS

Passing floating-point arrays as uniform arrays in PixiJS allows developers to stream complex numerical datasets—such as point coordinates, weight tables, or color palettes—directly into custom vertex and fragment shaders. This article covers the end-to-end process of declaring uniform arrays in GLSL, structuring the underlying data with JavaScript typed arrays, binding them to PixiJS shader objects, and updating their values efficiently during runtime.

1. Declare the Uniform Array in the GLSL Shader

In your custom fragment or vertex shader, define the array with an explicit constant size. GLSL requires fixed dimensions for uniform arrays at compile time.

precision mediump float;

// Declare a uniform array of 4 floats
uniform float uValues[4];

// Or declare an array of multi-component vectors
uniform vec2 uPoints[2];

varying vec2 vTextureCoord;

void main(void) {
    // Example access:
    float offset = uValues[0];
    gl_FragColor = vec4(offset, uValues[1], uValues[2], uValues[3]);
}

2. Prepare the Data Using a Float32Array

While standard JavaScript arrays work in certain versions of PixiJS, using a typed Float32Array is the recommended standard. It maps directly to WebGL memory buffers, avoiding internal conversion overhead and ensuring correct data alignment.

  • For simple float arrays, match the length of the array to the uniform size:

    const floatData = new Float32Array([0.2, 0.4, 0.6, 1.0]);

  • For vector arrays (like vec2, vec3, or vec4), flatten the values sequentially into the Float32Array:

    // Flattened data for uniform vec2 uPoints[2];
const pointData = new Float32Array([
    10.0, 20.0, // Point 0 (x, y)
    30.0, 40.0  // Point 1 (x, y)
]);

3. Bind the Array to the PixiJS Shader or Filter

Attach your uniform data to the PIXI.Filter or PIXI.Shader definition. PixiJS automatically inspects the uniform types and maps the typed array to the corresponding WebGL gl.uniform1fv or gl.uniform2fv calls under the hood.

import * as PIXI from 'pixi.js';

const uniforms = {
    uValues: floatData,
    uPoints: pointData
};

const customFilter = new PIXI.Filter(undefined, fragmentShaderCode, uniforms);

// Apply to a PixiJS display object
sprite.filters = [customFilter];

4. Updating Uniform Data at Runtime

To modify the array values inside the render loop without allocating new memory, mutate the existing typed array in place:

app.ticker.add(() => {
    // Mutate the array directly
    floatData[0] = Math.sin(Date.now() * 0.001);
    floatData[1] = 0.5;

    // Optional depending on PixiJS version: 
    // If auto-detection does not pick up internal mutations, reassign the reference
    customFilter.uniforms.uValues = floatData;
});

Modifying the buffer directly minimizes garbage collection spikes, ensuring consistent rendering performance across frames.
