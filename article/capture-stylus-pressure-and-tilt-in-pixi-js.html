Capture Stylus Pressure and Tilt in Pixi.js

Modern tablets and digital styluses can transmit pressure, tilt, and twist data directly into Pixi.js applications. By leveraging the browser's native W3C Pointer Events API, Pixi.js exposes hardware-level stylus properties through its modern event system. Developers can access this data to build pressure-sensitive drawing canvases, interactive brush engines, and dynamic UI elements without relying on external plugins or native wrappers.

How Pixi.js Handles Stylus Inputs

Pixi.js features an integrated event management architecture called the EventSystem. This system processes browser events and normalizes them into FederatedPointerEvent instances.

Because modern browsers on iPadOS, Android, and Windows map stylus hardware input to the Pointer Events standard, Pixi.js receives this rich input data automatically whenever a user interacts with a canvas using an Apple Pencil, S-Pen, or Surface Pen.

Essential Stylus Properties

When a stylus interacts with an interactive Pixi.js object, the resulting event object contains specific properties detailing physical manipulation:

  • pointerType: Identifies the input device. It returns 'pen' for a stylus, 'touch' for fingers, and 'mouse' for a cursor.
  • pressure: A normalized float from 0.0 (no pressure) to 1.0 (maximum pressure). When a device does not detect hardware pressure, it typically defaults to 0.5 on contact.
  • tiltX: The angle in degrees between the Y-Z plane of the stylus and the screen surface, ranging from -90 to 90.
  • tiltY: The angle in degrees between the X-Z plane of the stylus and the screen surface, ranging from -90 to 90.
  • twist: The clockwise rotation of the stylus barrel around its major axis, measured in degrees from 0 to 359.

Accessing Data via the Event System

To receive these inputs, ensure your target object is interactive and listen for standard pointer events such as pointermove or pointerdown.

import { Application, Graphics } from 'pixi.js';

const app = new Application();
await app.init({ width: 800, height: 600, backgroundColor: 0xffffff });
document.body.appendChild(app.canvas);

const drawingArea = new Graphics();
drawingArea.rect(0, 0, 800, 600).fill({ color: 0xffffff, alpha: 0.001 }); // Hit area
drawingArea.eventMode = 'static';

drawingArea.on('pointermove', (event) => {
    // Verify the input is from a pen/stylus
    if (event.pointerType === 'pen') {
        const pressure = event.pressure;
        const tiltX = event.tiltX;
        const tiltY = event.tiltY;
        
        // Use the native event as a fallback if necessary
        const native = event.nativeEvent;
        const twist = native.twist || 0;

        console.log(`Pressure: ${pressure}, Tilt: (${tiltX}, ${tiltY}), Twist: ${twist}`);
    }
});

app.stage.addChild(drawingArea);

While Pixi.js normalizes most attributes into the FederatedPointerEvent, accessing event.nativeEvent provides a direct reference to the underlying browser PointerEvent. This fallback ensures access to newer or vendor-specific properties like tangentialPressure.

Necessary Browser and CSS Configurations

For stylus tracking to function smoothly without browser-level gesture conflicts, apply the following setup:

  1. Disable Default Touch Actions: Modern mobile browsers default to gestures like pinch-to-zoom or page scrolling. Prevent this by applying touch-action: none; to the canvas element via CSS: 
    canvas {
    touch-action: none;
}
  2. Prevent Palm Rejection Collisions: By verifying event.pointerType === 'pen', your application can ignore accidental palm contacts (pointerType === 'touch'), ensuring smooth drawing and input tracking.
