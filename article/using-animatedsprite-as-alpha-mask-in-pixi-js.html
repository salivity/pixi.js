Using AnimatedSprite as Alpha Mask in Pixi.js

Pixi.js allows you to use an AnimatedSprite as a dynamic, moving alpha mask. By assigning an active AnimatedSprite to the mask property of any display object or container, Pixi.js continuously samples the alpha channel of the current animation frame during the render pass. This enables complex, dynamic reveals, looping transitions, and moving matte effects directly on the GPU without manual per-frame mask reassignments.

How Pixi.js Handles Sprite Masks

In Pixi.js, when you assign a sprite-based object to a target's mask property, the WebGL renderer applies a dedicated mask shader (internally managed via SpriteMaskFilter). Unlike graphic/vector stencil masks, sprite masks utilize the texture's alpha channel. Because an AnimatedSprite inherits directly from PIXI.Sprite, it fulfills all criteria required by the masking pipeline while updating its active texture on every tick.

Step-by-Step Implementation

To set up an animated alpha mask, follow these steps:

  1. Prepare Textures: Load an array of textures or a spritesheet where the transparent/opaque regions define the mask shape.
  2. Instantiate the AnimatedSprite: Create the PIXI.AnimatedSprite instance using the texture array.
  3. Add the Mask to the Stage: The masking sprite must exist within the display tree (or be manually updated) so its transform and animation ticker are evaluated.
  4. Assign the Mask: Set targetObject.mask = animatedMaskSprite.
  5. Play the Animation: Call .play() on the AnimatedSprite.
import * as PIXI from 'pixi.js';

// 1. Create textures for the mask
const maskTextures = [
    PIXI.Texture.from('mask_frame_1.png'),
    PIXI.Texture.from('mask_frame_2.png'),
    PIXI.Texture.from('mask_frame_3.png')
];

// 2. Create the AnimatedSprite
const animatedMask = new PIXI.AnimatedSprite(maskTextures);
animatedMask.animationSpeed = 0.2;
animatedMask.loop = true;
animatedMask.play();

// 3. Position the mask and add it to the scene
animatedMask.position.set(100, 100);
app.stage.addChild(animatedMask);

// 4. Create the target object
const content = PIXI.Sprite.from('background.jpg');
app.stage.addChild(content);

// 5. Apply the animated sprite as the alpha mask
content.mask = animatedMask;

Important Considerations

  • Coordinate Space: The position, scale, and rotation of the AnimatedSprite directly affect the masked region. Ensure that positioning accounts for the parent container's local transform.
  • Display Tree Requirement: Always add the AnimatedSprite to the stage. If it is omitted from the display hierarchy, Pixi.js may not update its world transform correctly, leading to misplaced or frozen masks.
  • Performance: Sprite masking requires rendering to intermediate framebuffers and executing custom mask shaders. While performant for typical use cases, avoid nesting multiple dynamic sprite masks within each other to prevent unnecessary GPU draw-call overhead.
