Pixi.js TiltShiftFilter Depth of Field Guide

This guide explains how to create depth-of-field and miniature "diorama" visual effects using the TiltShiftFilter in Pixi.js. You will learn how to set up the filter, apply it to display containers, and fine-tune focal points, blur intensity, and orientation to simulate optical camera lenses directly in WebGL.

Installing and Importing the Filter

The TiltShiftFilter is part of the community-maintained pixi-filters collection rather than Pixi.js core. You can install it individually or via the full bundle:

npm install @pixi/filter-tilt-shift

Import the filter alongside your standard Pixi.js modules:

import { Application, Sprite, Container } from 'pixi.js';
import { TiltShiftFilter } from '@pixi/filter-tilt-shift';

Basic Implementation

To apply the effect, instantiate the filter and assign it to the filters array of any Container, Sprite, or the main stage:

const app = new Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

const scene = new Container();
app.stage.addChild(scene);

// Create the filter instance
const tiltShift = new TiltShiftFilter();

// Apply the filter to the container
scene.filters = [tiltShift];

Configuring Key Properties

The TiltShiftFilter relies on several parameters that govern the position and transition of the out-of-focus areas:

  • blur: Determines the maximum radius of the blur applied to out-of-focus regions. Higher values create a stronger depth-of-field separation.
  • gradientBlur: Defines the transition distance between the sharp focal band and the fully blurred areas. Higher values create a softer, more gradual transition.
  • start: A Point object representing the beginning of the focal axis in pixel coordinates.
  • end: A Point object representing the end of the focal axis in pixel coordinates.
tiltShift.blur = 20;
tiltShift.gradientBlur = 600;

// Set a horizontal focal band across the center of an 800x600 canvas
tiltShift.start.set(0, 300);
tiltShift.end.set(800, 300);

Orienting the Focal Plane

The orientation of the focal area is defined by the line between the start and end vectors:

  • Horizontal Depth of Field: Keep the Y values identical on both points (start.set(0, 300), end.set(800, 300)). The area along this horizontal line remains in focus, while regions above and below blur out.
  • Vertical Depth of Field: Keep the X values identical (start.set(400, 0), end.set(400, 600)). The focus band runs top-to-bottom, blurring the left and right edges.
  • Angled Depth of Field: Use diagonal coordinates (start.set(0, 100), end.set(800, 500)) to simulate non-parallel lens angles or isometric game perspectives.

Dynamic and Interactive Adjustments

You can animate the focal plane dynamically to follow a player character or the user's cursor:

app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;

app.stage.on('pointermove', (event) => {
    const { y } = event.global;
    
    // Shift the focus plane vertically with the mouse
    tiltShift.start.y = y;
    tiltShift.end.y = y;
});

Performance Considerations

The TiltShiftFilter runs multiple blur passes on the GPU. To maintain 60 FPS:

  1. Keep blur values moderate; excessively high radii increase sampling overhead.
  2. Apply the filter to a single parent container rather than multiple individual child sprites.
  3. If the background image is static, render the tilt-shift effect once into a RenderTexture rather than recalculating the filter every frame.
