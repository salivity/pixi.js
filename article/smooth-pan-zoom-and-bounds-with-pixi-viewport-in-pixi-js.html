Smooth Pan, Zoom, and Bounds with Pixi-Viewport in Pixi.js

Implementing a responsive 2D camera in Pixi.js is most efficiently achieved using the pixi-viewport library. This article provides a direct guide to configuring a camera system that supports smooth user panning, mouse-wheel and pinch zooming, momentum-based deceleration, and strict boundary clamping to keep the viewport contained within your game world.

1. Installation

Install both pixi.js and pixi-viewport via your package manager:

npm install pixi.js pixi-viewport

2. Viewport Initialization

pixi-viewport extends PIXI.Container, acting as the parent container for all scene objects. You define both the screen dimensions (the visible canvas area) and the world dimensions (the total navigable area).

import * as PIXI from 'pixi.js';
import { Viewport } from 'pixi-viewport';

const app = new PIXI.Application();
await app.init({ width: 800, height: 600, backgroundColor: 0x1099bb });
document.body.appendChild(app.canvas);

// Create the viewport
const viewport = new Viewport({
    screenWidth: app.screen.width,
    screenHeight: app.screen.height,
    worldWidth: 2000,
    worldHeight: 2000,
    events: app.renderer.events // Required for Pixi v7/v8 event handling
});

// Add the viewport to the stage
app.stage.addChild(viewport);

3. Configuring Pan, Zoom, and Momentum

pixi-viewport utilizes a chainable plugin architecture. To enable interaction, chain the core navigation plugins:

viewport
    .drag()        // Enables click/touch-and-drag panning
    .pinch()       // Enables two-finger pinch zooming on touch devices
    .wheel()       // Enables mouse wheel zooming
    .decelerate({  // Adds smooth inertia/momentum after releasing a drag
        friction: 0.88,
        minSpeed: 0.01
    });

The .decelerate() plugin handles physics smoothing. Adjusting friction (typically between 0.8 and 0.95) controls how long the camera glides after the user finishes dragging.

4. Setting World and Zoom Bounds

To prevent players from panning off the map or zooming infinitely, apply clamping plugins:

viewport
    .clamp({
        direction: 'all', // Restricts movement along both 'x' and 'y'
        underflow: 'center' // Centers world if screen is larger than world
    })
    .clampZoom({
        minScale: 0.5, // Maximum zoom-out level
        maxScale: 3.0  // Maximum zoom-in level
    });
  • clamp(): Restricts the viewport coordinates so the visible screen area cannot move past the configured worldWidth and worldHeight.
  • clampZoom(): Caps the minimum and maximum scale factors to keep visual elements at readable sizes.

5. Complete Implementation Example

import * as PIXI from 'pixi.js';
import { Viewport } from 'pixi-viewport';

async function initScene() {
    const app = new PIXI.Application();
    await app.init({ resizeTo: window, backgroundColor: 0x2c3e50 });
    document.body.appendChild(app.canvas);

    const worldWidth = 3000;
    const worldHeight = 3000;

    const viewport = new Viewport({
        screenWidth: window.innerWidth,
        screenHeight: window.innerHeight,
        worldWidth: worldWidth,
        worldHeight: worldHeight,
        events: app.renderer.events
    });

    app.stage.addChild(viewport);

    viewport
        .drag()
        .pinch()
        .wheel({ smooth: 5 }) // Smooth mouse-wheel interpolation
        .decelerate({ friction: 0.9 })
        .clamp({ direction: 'all' })
        .clampZoom({ minScale: 0.25, maxScale: 2.5 });

    // Populate the world with content
    const graphics = new PIXI.Graphics();
    graphics.rect(0, 0, worldWidth, worldHeight).stroke({ width: 8, color: 0xe74c3c });
    viewport.addChild(graphics);

    // Center camera on load
    viewport.moveCenter(worldWidth / 2, worldHeight / 2);

    // Update screen size on window resize
    window.addEventListener('resize', () => {
        app.renderer.resize(window.innerWidth, window.innerHeight);
        viewport.resize(window.innerWidth, window.innerHeight, worldWidth, worldHeight);
    });
}

initScene();

This configuration creates a fully contained, inertia-driven 2D camera system ready for games, data visualizations, or map-based user interfaces.
