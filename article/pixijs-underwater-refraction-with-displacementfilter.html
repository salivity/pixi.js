PixiJS Underwater Refraction with DisplacementFilter

Simulating an underwater refraction effect in PixiJS is achieved by using a DisplacementFilter paired with an animated displacement map. This article explains how the filter works, how to configure a repeating noise texture, apply the filter to your visual elements, and animate the map continuously to create realistic aquatic distortion.

How Underwater Refraction Works

Refraction occurs when light bends as it passes through water, visually distorting objects beneath the surface. In PixiJS, a DisplacementFilter reads the color values of a secondary texture—called a displacement map—to offset the pixels of your target display object. The red channel shifts pixels horizontally (X-axis), while the green channel shifts pixels vertically (Y-axis). By translating a seamless water or Perlin noise texture across the screen, the static image beneath appears to ripple and wave.

Step 1: Initialize the Application and Assets

Set up your PixiJS application and load two primary assets: the underwater scene (or background image) and a seamless, high-contrast ripple/noise map.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x001e3d
});
document.body.appendChild(app.view);

// Create the background scene
const background = PIXI.Sprite.from('path/to/underwater-scene.jpg');
background.width = app.screen.width;
background.height = app.screen.height;
app.stage.addChild(background);

Step 2: Configure the Displacement Map

The displacement texture must be configured to tile infinitely so it does not clip or reveal hard edges while moving. Set its wrap mode to REPEAT.

// Load the displacement map texture
const displacementSprite = PIXI.Sprite.from('path/to/water-displacement-map.jpg');

// Ensure the texture wraps continuously
displacementSprite.texture.baseTexture.wrapMode = PIXI.WRAP_MODES.REPEAT;

// Add the sprite to the stage so it renders in the filter coordinate space
app.stage.addChild(displacementSprite);

Step 3: Create and Apply the Filter

Instantiate the PIXI.DisplacementFilter, passing the displacement sprite as its argument. Use the scale property to determine the strength of the refraction.

const displacementFilter = new PIXI.DisplacementFilter(displacementSprite);

// Adjust refraction strength (higher values yield stronger distortion)
displacementFilter.scale.x = 25;
displacementFilter.scale.y = 20;

// Apply the filter to the target container or background
background.filters = [displacementFilter];

Step 4: Animate the Refraction

To create continuous water motion, update the displacement sprite’s position inside PixiJS's render ticker.

app.ticker.add((delta) => {
    // Increment position to simulate flowing water
    displacementSprite.x += 1 * delta;
    displacementSprite.y += 0.75 * delta;
});

Complete Implementation Example

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({
    width: 800,
    height: 600,
    resizeTo: window
});
document.body.appendChild(app.view);

// 1. Target Container
const sceneContainer = new PIXI.Container();
app.stage.addChild(sceneContainer);

const background = PIXI.Sprite.from('assets/underwater_scene.jpg');
background.width = app.screen.width;
background.height = app.screen.height;
sceneContainer.addChild(background);

// 2. Displacement Map
const displacementSprite = PIXI.Sprite.from('assets/water_ripples.jpg');
displacementSprite.texture.baseTexture.wrapMode = PIXI.WRAP_MODES.REPEAT;
app.stage.addChild(displacementSprite);

// 3. Filter Configuration
const displacementFilter = new PIXI.DisplacementFilter(displacementSprite);
displacementFilter.scale.x = 30;
displacementFilter.scale.y = 30;
sceneContainer.filters = [displacementFilter];

// 4. Animation Loop
app.ticker.add((delta) => {
    displacementSprite.x += 1.2 * delta;
    displacementSprite.y += 0.8 * delta;
});

Tips for Best Results

  • Seamless Textures: Ensure your displacement map is seamlessly tileable to prevent sudden visible seams when scrolling.
  • Scale Tuning: Keep the displacementFilter.scale between 10 and 40 for subtle water currents. Higher values produce severe distortions better suited for turbulent surfaces or whirlpools.
  • Aspect Ratio: Sticking to square, power-of-two textures (e.g., 512x512) for displacement maps ensures compatibility and optimal WebGL performance.
