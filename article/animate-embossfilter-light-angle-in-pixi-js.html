Animate EmbossFilter Light Angle in Pixi.js

Animating the light source angle in Pixi.js allows you to create realistic, dynamic 3D surface shading effects across your sprites. While the default EmbossFilter provided by the @pixi/filter-emboss package only exposes a static diagonal light direction via its strength property, you can achieve full directional control by supplying dynamic trigonometric offsets through a custom shader or custom uniform matrix updated inside the Pixi.js Ticker loop.

Understanding the Default EmbossFilter

The default EmbossFilter in the Pixi.js ecosystem uses a fixed 45-degree convolution kernel. It shifts samples evenly across the X and Y axes using a single scalar (strength):

// Native implementation samples fixed diagonal offsets:
vec2 onePixel = vec2(strength / uSamplerSize.x, strength / uSamplerSize.y);

Because the directional vector is hardcoded into the kernel calculation, modifying the light angle requires replacing or customizing the fragment shader to accept an explicit angle or directional vector (uLightDirection).

Creating a Directional Emboss Filter

To animate the angle, create a custom Filter that accepts both light strength and an angle in radians.

import * as PIXI from 'pixi.js';

const vertex = `
    attribute vec2 aVertexPosition;
    attribute vec2 aTextureCoord;
    uniform mat3 projectionMatrix;
    varying vec2 vTextureCoord;

    void main(void) {
        gl_Position = vec4((projectionMatrix * vec3(aVertexPosition, 1.0)).xy, 0.0, 1.0);
        vTextureCoord = aTextureCoord;
    }
`;

const fragment = `
    precision mediump float;

    varying vec2 vTextureCoord;
    uniform sampler2D uSampler;
    uniform vec2 uLightDir;
    uniform float uStrength;

    void main(void) {
        vec4 original = texture2D(uSampler, vTextureCoord);
        
        // Sample in the direction of the light and the opposite side
        vec4 c1 = texture2D(uSampler, vTextureCoord - uLightDir * uStrength);
        vec4 c2 = texture2D(uSampler, vTextureCoord + uLightDir * uStrength);
        
        // Compute difference and add a neutral gray baseline (0.5)
        vec3 diff = (c1.rgb - c2.rgb) * 2.0;
        vec3 gray = vec3(0.5, 0.5, 0.5);
        
        gl_FragColor = vec4(gray + diff, original.a);
    }
`;

export class DirectionalEmbossFilter extends PIXI.Filter {
    constructor(strength = 2.0, angle = 0) {
        super(vertex, fragment, {
            uLightDir: new Float32Array([Math.cos(angle), Math.sin(angle)]),
            uStrength: strength * 0.001,
        });
        this.angle = angle;
    }

    setAngle(radians) {
        this.angle = radians;
        this.uniforms.uLightDir[0] = Math.cos(radians);
        this.uniforms.uLightDir[1] = Math.sin(radians);
    }
}

Animating the Light Angle Dynamically

Attach the filter to any display object (such as a PIXI.Sprite or PIXI.Container) and increment the angle inside the PIXI.Ticker update loop.

// Initialize Pixi application
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Create a sprite to apply the filter to
const sprite = PIXI.Sprite.from('path/to/texture.png');
sprite.anchor.set(0.5);
sprite.position.set(app.screen.width / 2, app.screen.height / 2);
app.stage.addChild(sprite);

// Instantiate and apply the custom filter
const embossFilter = new DirectionalEmbossFilter(3.0, 0);
sprite.filters = [embossFilter];

// Animate the light angle inside the ticker
let currentAngle = 0;
const rotationSpeed = 0.02; // Radians per frame

app.ticker.add((delta) => {
    currentAngle += rotationSpeed * delta;
    embossFilter.setAngle(currentAngle);
});

Modifying Existing EmbossFilter Instances

If you prefer modifying an existing @pixi/filter-emboss instance without writing a full shader from scratch, override its uniform values directly on the filter instance:

  1. Update the shader program uniforms using filter.uniforms.uSamplerSize.
  2. Compute dynamic X and Y coordinates: 
    const xOffset = Math.cos(currentAngle) * strength;
const yOffset = Math.sin(currentAngle) * strength;
  3. Pass the resulting normalized coordinates directly to the uniform payload each frame.
