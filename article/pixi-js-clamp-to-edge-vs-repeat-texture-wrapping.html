Pixi.js CLAMP_TO_EDGE vs REPEAT Texture Wrapping

Texture wrapping modes in Pixi.js determine how UV coordinates outside the standard 0.0 to 1.0 range are sampled, which is essential when rendering repeating patterns or preventing visual artifacts. This guide covers the functional differences between CLAMP_TO_EDGE and REPEAT, demonstrates how to configure them on your textures, and highlights the technical requirements for WebGL compatibility.

Understanding the Wrap Modes

  • CLAMP_TO_EDGE (Default): Coordinates outside the 0.0 to 1.0 range are clamped to the nearest edge pixel. When geometry requests pixels beyond the texture boundaries, Pixi.js stretches the outermost edge pixels across the remaining space. This mode prevents edge-bleeding artifacts in spritesheets.
  • REPEAT: The integer part of UV coordinates is discarded, causing the texture to tile continuously. This is ideal for scrolling backgrounds, terrain, and pattern fills.

Configuring Wrap Modes in Code

Wrap modes are applied directly to the underlying source or base texture rather than the sprite itself.

Pixi.js v7 and Below

In Pixi.js v7, assign the desired constant from PIXI.WRAP_MODES to the texture's baseTexture:

import * as PIXI from 'pixi.js';

// Load or create a texture
const texture = PIXI.Texture.from('path/to/pattern.png');

// Set to REPEAT
texture.baseTexture.wrapMode = PIXI.WRAP_MODES.REPEAT;

// Or set to CLAMP_TO_EDGE
texture.baseTexture.wrapMode = PIXI.WRAP_MODES.CLAMP;

// Apply update
texture.baseTexture.update();

Pixi.js v8

Pixi.js v8 introduced WebGPU-aligned naming conventions, switching from wrapMode to addressMode:

import { Assets } from 'pixi.js';

const texture = await Assets.load('path/to/pattern.png');

// Set to repeat
texture.source.addressMode = 'repeat';

// Set to clamp
texture.source.addressMode = 'clamp-to-edge';

// Update the source to apply changes
texture.source.update();

Implementing with TilingSprite

To see repeating textures in action, pair the REPEAT mode with a TilingSprite:

const texture = PIXI.Texture.from('path/to/tile.png');
texture.baseTexture.wrapMode = PIXI.WRAP_MODES.REPEAT;

// Create a tiling sprite of a specific display size
const tilingSprite = new PIXI.TilingSprite(texture, 800, 600);

// Move the texture coordinates over time to animate
app.ticker.add(() => {
    tilingSprite.tilePosition.x += 1;
    tilingSprite.tilePosition.y += 1;
});

app.stage.addChild(tilingSprite);

Key Considerations

  1. Power-of-Two (POT) Dimensions: When targeting WebGL 1 contexts, textures configured with REPEAT must have dimensions that are powers of two (e.g., 128x128, 256x512). Non-power-of-two (NPOT) textures will fail or trigger console warnings unless running in WebGL 2 or WebGPU environments.
  2. Spritesheets: Avoid setting REPEAT on individual frames within a spritesheet. Texture wrapping operates on the entire base image, which will cause adjacent sprites in the atlas to bleed into the repeat pattern instead of tiling only the targeted frame.
