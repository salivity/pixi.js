PixiJS Double and Triple Click Detection

While PixiJS provides a robust event system for handling standard pointer interactions, it lacks built-in listeners for multi-click interactions such as double-clicks and triple-clicks. This article demonstrates how to cleanly implement reliable double-click and triple-click event detection on any PixiJS display object using a reusable helper function that tracks click intervals and counts.

The Detection Logic

Detecting multi-clicks requires measuring the elapsed time between successive pointer interactions. If the interval between taps falls within a defined threshold (typically 250 to 300 milliseconds), the click count increments. If the threshold elapses without another tap, the counter resets.

Depending on your requirements, multi-click handling falls into two categories:

  1. Immediate Execution: The single-click handler fires on every tap, and the multi-click handlers trigger immediately when the count is reached.
  2. Mutually Exclusive Execution: Single-clicks wait for the threshold duration before firing, ensuring only one specific action (single, double, or triple) executes.

Clean Implementation: Mutually Exclusive Clicks

The following implementation wraps PixiJS pointer events to support single, double, and triple clicks exclusively:

function registerMultiClickHandler(displayObject, callbacks, delay = 250) {
    displayObject.eventMode = 'static';
    
    let clickCount = 0;
    let clickTimeout = null;

    displayObject.on('pointertap', (event) => {
        clickCount++;

        if (clickCount === 1) {
            clickTimeout = setTimeout(() => {
                if (callbacks.onSingleClick) {
                    callbacks.onSingleClick(event);
                }
                clickCount = 0;
            }, delay);
        } else if (clickCount === 2) {
            clearTimeout(clickTimeout);
            clickTimeout = setTimeout(() => {
                if (callbacks.onDoubleClick) {
                    callbacks.onDoubleClick(event);
                }
                clickCount = 0;
            }, delay);
        } else if (clickCount === 3) {
            clearTimeout(clickTimeout);
            if (callbacks.onTripleClick) {
                callbacks.onTripleClick(event);
            }
            clickCount = 0;
        }
    });
}

Usage Example

Attach the handler to any PIXI.Container, PIXI.Sprite, or PIXI.Graphics instance:

import * as PIXI from 'pixi.js';

const app = new PIXI.Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

const box = new PIXI.Graphics()
    .rect(0, 0, 150, 150)
    .fill(0x3498db);

box.position.set(100, 100);
app.stage.addChild(box);

registerMultiClickHandler(box, {
    onSingleClick: (e) => {
        console.log('Single click detected');
        box.tint = 0x3498db;
    },
    onDoubleClick: (e) => {
        console.log('Double click detected');
        box.tint = 0xe74c3c;
    },
    onTripleClick: (e) => {
        console.log('Triple click detected');
        box.tint = 0x2ecc71;
    }
}, 300);

Immediate (Eager) Multi-Click Implementation

If your user interface does not require single-clicks to wait for potential multi-clicks, tracking the timestamp difference between clicks avoids setTimeout latency:

function registerImmediateMultiClick(displayObject, callbacks, threshold = 300) {
    displayObject.eventMode = 'static';

    let lastClickTime = 0;
    let clickCount = 0;

    displayObject.on('pointertap', (event) => {
        const currentTime = performance.now();
        const timeDiff = currentTime - lastClickTime;

        if (timeDiff <= threshold) {
            clickCount++;
        } else {
            clickCount = 1;
        }

        lastClickTime = currentTime;

        if (callbacks.onSingleClick) {
            callbacks.onSingleClick(event);
        }

        if (clickCount === 2 && callbacks.onDoubleClick) {
            callbacks.onDoubleClick(event);
        } else if (clickCount === 3 && callbacks.onTripleClick) {
            callbacks.onTripleClick(event);
            clickCount = 0;
        }
    });
}

Best Practices

  • Pointer Events: Use pointertap rather than click to guarantee uniform input handling across desktop mice, touchscreens, and stylus devices.
  • Threshold Adjustment: Keep the delay between 250ms and 350ms. Values below 200ms can make triple-clicking too difficult for average users, while values above 400ms introduce noticeable input latency in mutually exclusive setups.
  • Memory Cleanup: If you destroy display objects dynamically, remove event listeners using displayObject.off('pointertap') and clear any active setTimeout references to prevent memory leaks.
