Render Tiled JSON Tilemaps in Pixi.js

Rendering Tiled maps in Pixi.js involves exporting your project as a JSON file, loading the map data and tileset images via the Pixi.js asset loader, and mapping individual tile IDs to textures. This guide covers the complete process of reading layer data, slicing tileset textures using coordinate math, and drawing the final 2D grid efficiently on screen.

1. Exporting the Map from Tiled

  1. In Tiled, open your map and ensure your tileset is embedded or uses relative paths for external images.
  2. Go to File > Export As...
  3. Select JSON map files (*.json) as the output format.
  4. Keep the output JSON file and your tileset image files in your web project's public assets directory.

2. Understanding the Tiled JSON Structure

The exported JSON file contains key properties required for rendering:

  • tilewidth and tileheight: The dimensions of an individual tile in pixels.
  • width and height: The dimensions of the map measured in tile counts.
  • tilesets: An array containing tileset metadata, including firstgid (the starting Global Tile ID), image source path, imagewidth, and imageheight.
  • layers: An array containing layer objects. A tile layer contains a data array representing the grid, where each number corresponds to a Global Tile ID (GID). A value of 0 denotes an empty tile.

3. Slicing the Tileset into Textures

Tiled uses 1-based GIDs, while 0 represents empty space. To retrieve a tile texture from the tileset image:

  1. Subtract firstgid from the tile's GID to get the local tile index.
  2. Calculate the column and row of the tile within the tileset image:
    • col = localIndex % (tilesetWidth / tileWidth)
    • row = Math.floor(localIndex / (tilesetWidth / tileWidth))
  3. Create a PIXI.Rectangle frame for that region and create a sub-texture.

4. Implementation Example

The following implementation uses modern Pixi.js (PIXI.Assets) to load resources, parse layer data, and assemble the map into a PIXI.Container.

import * as PIXI from 'pixi.js';

async function loadAndRenderMap(app, mapUrl) {
    // 1. Fetch map JSON data
    const mapData = await PIXI.Assets.load(mapUrl);

    // 2. Load the tileset image
    // Assumes single tileset; adjust path resolution as necessary
    const tilesetInfo = mapData.tilesets[0];
    const tilesetTexture = await PIXI.Assets.load(tilesetInfo.image);

    const tileWidth = mapData.tilewidth;
    const tileHeight = mapData.tileheight;
    const tilesPerRow = Math.floor(tilesetInfo.imagewidth / tileWidth);

    // Container to hold the entire map
    const mapContainer = new PIXI.Container();

    // Cache generated sub-textures to avoid recreating identical textures
    const textureCache = new Map();

    function getTileTexture(gid) {
        if (textureCache.has(gid)) {
            return textureCache.get(gid);
        }

        const localId = gid - tilesetInfo.firstgid;
        const col = localId % tilesPerRow;
        const row = Math.floor(localId / tilesPerRow);

        const frame = new PIXI.Rectangle(
            col * tileWidth,
            row * tileHeight,
            tileWidth,
            tileHeight
        );

        const texture = new PIXI.Texture({
            source: tilesetTexture.source,
            frame: frame
        });

        textureCache.set(gid, texture);
        return texture;
    }

    // 3. Iterate through map layers
    mapData.layers.forEach((layer) => {
        if (layer.type !== 'tilelayer' || !layer.visible) return;

        const layerContainer = new PIXI.Container();
        layerContainer.alpha = layer.opacity;

        layer.data.forEach((gid, index) => {
            // Skip empty tiles
            if (gid === 0) return;

            const tileTexture = getTileTexture(gid);
            const sprite = new PIXI.Sprite(tileTexture);

            // Calculate grid position
            const x = (index % layer.width) * tileWidth;
            const y = Math.floor(index / layer.width) * tileHeight;

            sprite.position.set(x, y);
            layerContainer.addChild(sprite);
        });

        mapContainer.addChild(layerContainer);
    });

    app.stage.addChild(mapContainer);
}

5. Performance Optimization for Large Maps

Standard PIXI.Sprite instances work well for small or medium maps. For larger maps with thousands of tiles:

  • Use @pixi/tilemap: This official Pixi extension batches entire tilemaps into dedicated vertex buffers, eliminating performance overhead caused by thousands of individual sprite objects.
  • Culling: Render only the tiles visible inside the current camera viewport by comparing tile positions against app.screen boundaries.
  • Chunking: Divide the map into larger grid sections (chunks) and cache static chunks onto single textures using app.renderer.extract or render textures.
