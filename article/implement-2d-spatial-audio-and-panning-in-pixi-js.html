Implement 2D Spatial Audio and Panning in Pixi.js

This article demonstrates how to implement realistic 2D spatial audio in Pixi.js by integrating the native Web Audio API with sprite coordinates. You will learn how to calculate the distance and horizontal offset between an audio listener sprite and an emitter sprite, then use those calculations to dynamically update stereo panning and volume attenuation inside the Pixi.js render loop.

Core Concepts of 2D Spatial Audio

Pixi.js is strictly a rendering engine and does not handle audio natively. To achieve spatial sound, you pair Pixi.js with the browser's Web Audio API using two nodes:

  1. StereoPannerNode: Controls the left-to-right stereo balance (pan value from -1.0 to 1.0).
  2. GainNode: Controls the audio level (gain value from 0.0 to 1.0) based on the distance between the listener and emitter.

Spatial positioning relies on two continuous calculations:

  • Distance: The Euclidean distance between the listener and emitter determines volume attenuation. As distance increases toward a designated maximum, volume scales down to zero.
  • Pan Angle: The relative X-axis offset determines the pan balance. If the sound source is to the left of the listener, the pan leans toward -1; if to the right, toward 1.

Step 1: Initialize Web Audio Nodes

Create the audio context and connect the audio element through a StereoPannerNode and a GainNode before routing to the output destination.

const audioContext = new (window.AudioContext || window.webkitAudioContext)();

// Load your audio element
const audioElement = new Audio('sound-effect.mp3');
audioElement.loop = true;

// Create source and processing nodes
const track = audioContext.createMediaElementSource(audioElement);
const pannerNode = audioContext.createStereoPanner();
const gainNode = audioContext.createGain();

// Connect: Source -> Panner -> Gain -> Speakers
track.connect(pannerNode);
pannerNode.connect(gainNode);
gainNode.connect(audioContext.destination);

Step 2: Set Up Pixi.js Sprites

Define two sprites: one representing the player (the listener) and one representing the sound source (the emitter).

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Listener sprite (e.g., player character)
const listener = new PIXI.Sprite(PIXI.Texture.WHITE);
listener.width = 32;
listener.height = 32;
listener.tint = 0x00ff00;
listener.position.set(400, 300);
app.stage.addChild(listener);

// Emitter sprite (e.g., campfire, machine)
const emitter = new PIXI.Sprite(PIXI.Texture.WHITE);
emitter.width = 32;
emitter.height = 32;
emitter.tint = 0xff0000;
emitter.position.set(100, 300);
app.stage.addChild(emitter);

Step 3: Implement the Distance and Pan Calculation Loop

Use app.ticker to update the audio nodes on every frame. Define a maxDistance parameter that represents the threshold beyond which the sound is inaudible.

const maxDistance = 400; // Maximum hearing range in pixels
const panRange = 300;    // Horizontal distance for full left/right panning

app.ticker.add(() => {
  // 1. Calculate delta positions
  const dx = emitter.x - listener.x;
  const dy = emitter.y - listener.y;

  // 2. Calculate Euclidean distance
  const distance = Math.hypot(dx, dy);

  // 3. Compute volume attenuation (linear falloff)
  let volume = 1 - (distance / maxDistance);
  volume = Math.max(0, Math.min(1, volume)); // Clamp between 0 and 1
  gainNode.gain.setValueAtTime(volume, audioContext.currentTime);

  // 4. Compute horizontal stereo panning
  let pan = dx / panRange;
  pan = Math.max(-1, Math.min(1, pan)); // Clamp between -1 (full left) and 1 (full right)
  pannerNode.pan.setValueAtTime(pan, audioContext.currentTime);
});

Step 4: Handle Autoplay Policies

Modern browsers suspend an AudioContext until the user interacts with the document. Resume the context inside a user-driven event (such as a pointer tap or key press) to start playback:

window.addEventListener('pointerdown', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
  audioElement.play();
}, { once: true });

Optimization and Refinements

  • Exponential Rolloff: For a more natural audio decay, replace the linear volume calculation with an exponential or inverse-distance equation: 
    const volume = Math.min(1, 1 / (1 + (distance / 100)));
  • Listener Orientation: If your game supports player rotation, transform the delta coordinates (dx, dy) using the listener's rotation angle before computing the pan and attenuation values.
  • Culling Updates: If distance > maxDistance, set the gain immediately to 0 and skip the stereo pan calculation to conserve CPU cycles in scenes with numerous audio emitters.
