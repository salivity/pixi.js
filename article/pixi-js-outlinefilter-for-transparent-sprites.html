Pixi.js OutlineFilter for Transparent Sprites

This guide explains how to add a clean, dynamic outline around a transparent sprite using Pixi.js and the pixi-filters library. You will learn how to install the required filter package, instantiate the OutlineFilter, assign it to a sprite, and adjust settings like stroke thickness, color, and padding to prevent visual clipping around transparent edges.

1. Install the Outline Filter

The OutlineFilter is not bundled with the core Pixi.js library. It is part of the external PixiJS filters repository. Install it via npm:

npm install @pixi/filter-outline

Alternatively, if you are using a CDN or bundle:

<script src="https://cdn.jsdelivr.net/npm/pixi.js@7/dist/pixi.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@pixi/filter-outline@5/dist/filter-outline.min.js"></script>

2. Basic Implementation

To apply the outline, load a transparent PNG or WebP image into a PIXI.Sprite, instantiate the OutlineFilter, and add it to the sprite's filters array.

import * as PIXI from 'pixi.js';
import { OutlineFilter } from '@pixi/filter-outline';

// Initialize the Pixi application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1e1e1e
});
document.body.appendChild(app.view);

// Create the transparent sprite
const sprite = PIXI.Sprite.from('character.png');
sprite.anchor.set(0.5);
sprite.x = app.screen.width / 2;
sprite.y = app.screen.height / 2;
app.stage.addChild(sprite);

// Create the outline filter: OutlineFilter(thickness, color, quality)
const outlineFilter = new OutlineFilter(4, 0xffffff, 0.5);

// Apply the filter to the sprite
sprite.filters = [outlineFilter];

3. Configuring Filter Properties

The OutlineFilter constructor accepts three main parameters, which can also be modified dynamically at runtime:

  • Thickness (thickness): The width of the outline in pixels. Defaults to 1.
  • Color (color): The color of the outline represented as a hexadecimal number (e.g., 0xff0000 for red). Defaults to 0x000000.
  • Quality (quality): A value between 0 and 1 controlling sampling density. Lower values improve performance, while higher values produce smoother curves around corners. Defaults to 0.1.
  • Alpha (alpha): Controls the opacity of the stroke, ranging from 0 (completely transparent) to 1 (fully opaque).
// Dynamic configuration example
outlineFilter.thickness = 6;
outlineFilter.color = 0x00ffcc;
outlineFilter.quality = 0.8;
outlineFilter.alpha = 0.9;

4. Preventing Edge Clipping with Padding

When an outline expands beyond the original texture dimensions, the filter may cut off at the texture boundary. To fix this, increase the padding property of the filter to allocate extra rendering space around the sprite:

// Set padding equal to or greater than the stroke thickness
outlineFilter.padding = 10;

This ensures the outline renders cleanly around transparent pixels without clipping against the sprite's original bounding box.
