Get Global Rotation of Nested Child in Pixi.js

Extracting the global (world) rotation of a nested child object in Pixi.js requires reading the object's transformation matrix rather than its local rotation property. Because Pixi.js calculates rendering coordinates through a hierarchical matrix system, the rotation property on a display object only represents its orientation relative to its immediate parent. This guide demonstrates how to compute the absolute world rotation angle in radians and degrees using the object's worldTransform matrix.

Why Local Rotation Is Insufficient

When a display object (such as a Sprite or Container) is placed inside one or more parent containers, setting or reading child.rotation only provides the offset relative to its immediate parent. If the parent container is rotated by \(45^\circ\) and the child is rotated by \(10^\circ\), child.rotation will return \(10^\circ\), even though its actual orientation on the screen is \(55^\circ\).

Extracting Global Rotation from worldTransform

Pixi.js tracks the combined position, scale, skew, and rotation of an object via its 2D affine transformation matrix: worldTransform.

The matrix elements represent the following components:

  • a: Scale X combined with cosine of rotation (\(\cos(\theta) \cdot \text{scaleX}\))
  • b: Skew Y combined with sine of rotation (\(\sin(\theta) \cdot \text{scaleX}\))
  • c: Skew X combined with negative sine of rotation (\(-\sin(\theta) \cdot \text{scaleY}\))
  • d: Scale Y combined with cosine of rotation (\(\cos(\theta) \cdot \text{scaleY}\))

To extract the global rotation angle in radians, calculate the arctangent of the vertical and horizontal components of the X-axis basis vector using Math.atan2(b, a).

function getGlobalRotation(displayObject) {
    // Ensure the scene graph transforms are up to date
    displayObject.updateTransform();

    const wt = displayObject.worldTransform;

    // Calculate rotation in radians
    return Math.atan2(wt.b, wt.a);
}

Converting to Degrees

If your application works with degrees instead of radians, convert the result using standard radian-to-degree math:

function getGlobalRotationDegrees(displayObject) {
    const radians = getGlobalRotation(displayObject);
    let degrees = radians * (180 / Math.PI);

    // Normalize to a 0-360 range
    if (degrees < 0) {
        degrees += 360;
    }

    return degrees;
}

Important Considerations

  1. Ensuring Updated Transforms: Pixi.js lazily calculates worldTransform right before rendering. If you alter parent or child positions/rotations within the current tick and inspect worldTransform before the next render pass, the matrix may be stale. Calling displayObject.updateTransform() ensures all parent transformations up the chain are recalculated before the angle is determined.
  2. Negative Scaling (Flipping): If a parent container has negative scaling (for example, scale.x = -1), the sign of the rotation will reflect the reflection across that axis. If your scene uses negative scale to flip assets, ensure you account for inverted axes when computing absolute angles.
