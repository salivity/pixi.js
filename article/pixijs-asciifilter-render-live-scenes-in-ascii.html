PixiJS AsciiFilter: Render Live Scenes in ASCII

This article demonstrates how to transform a real-time PixiJS scene into dynamic ASCII text art using the AsciiFilter from the pixi-filters collection. You will learn how to install the necessary dependencies, configure a PixiJS application, and apply the filter to a live scene containing moving elements or video feeds so that the output continuously renders as alphanumeric characters.

Prerequisites and Installation

To use the ASCII filter, install both pixi.js and the community filters package. You can install the complete pixi-filters package or just the standalone ASCII filter package via npm:

npm install pixi.js pixi-filters

Alternatively, if you only need the ASCII filter to keep bundle sizes small:

npm install pixi.js @pixi/filter-ascii

Implementing the AsciiFilter

The AsciiFilter works by dividing the screen into a grid of character blocks and replacing pixels within each block with a typographic character representing that area's average brightness.

Here is a complete implementation that sets up an animated scene and applies the filter:

import * as PIXI from 'pixi.js';
import { AsciiFilter } from 'pixi-filters';

// 1. Initialize the PixiJS Application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x000000,
});
document.body.appendChild(app.view);

// 2. Create a container for your scene
const sceneContainer = new PIXI.Container();
app.stage.addChild(sceneContainer);

// 3. Add visual content (e.g., rotating shapes or sprites)
const graphic = new PIXI.Graphics();
graphic.beginFill(0xff3366);
graphic.drawRect(-50, -50, 100, 100);
graphic.endFill();

graphic.beginFill(0x33ccff);
graphic.drawCircle(60, 0, 40);
graphic.endFill();

graphic.x = app.screen.width / 2;
graphic.y = app.screen.height / 2;
sceneContainer.addChild(graphic);

// 4. Instantiate and configure the AsciiFilter
// The constructor accepts a single number representing character size in pixels (default is 8)
const asciiFilter = new AsciiFilter(10);

// 5. Apply the filter to the container or stage
sceneContainer.filters = [asciiFilter];

// 6. Animate the scene to verify real-time processing
app.ticker.add((delta) => {
    graphic.rotation += 0.02 * delta;
});

Configuring Filter Properties

The AsciiFilter provides one primary property:

  • size: Controls the pixel size of the individual ASCII characters.
    • Smaller values (e.g., 4 to 6) yield higher visual resolution and greater detail, but create smaller text that may be harder to distinguish as individual characters.
    • Larger values (e.g., 12 to 20) make the ASCII letters prominent and stylized, but reduce the overall clarity of the underlying image.

You can adjust this value at runtime based on performance or aesthetic preference:

// Change character size dynamically
asciiFilter.size = 14;

Applying to Live Video and Textures

Because AsciiFilter operates on the WebGL render pipeline, it is not limited to static shapes. You can apply it to HTML5 <video> textures, animated spritesheets, or dynamic particle systems by adding those elements to the filtered container:

// Example: Using a video texture
const videoTexture = PIXI.Texture.from('path/to/video.mp4');
const videoSprite = new PIXI.Sprite(videoTexture);
videoSprite.width = app.screen.width;
videoSprite.height = app.screen.height;

sceneContainer.addChild(videoSprite);

As the video plays, PixiJS re-renders the frames through the fragment shader on every tick, creating a live ASCII video effect with minimal performance overhead.
