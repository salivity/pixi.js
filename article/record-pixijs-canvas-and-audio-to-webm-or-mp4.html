Record PixiJS Canvas and Audio to WebM or MP4

You can record PixiJS canvas output alongside an audio stream directly to an MP4 or WebM video file using standard modern browser APIs. PixiJS renders its graphics onto an HTML <canvas> element, which can be captured as a video stream using HTMLCanvasElement.captureStream(). By merging this video track with an audio track from the Web Audio API or an audio element, the MediaRecorder API can multiplex and encode the combined stream into a downloadable WebM or MP4 file.

1. Capture the PixiJS Canvas Stream

PixiJS renders to a canvas accessible via app.canvas (in PixiJS v8) or app.view (in PixiJS v7 and earlier). You capture the video track directly from this canvas by specifying your target frames per second (FPS).

const canvas = app.canvas || app.view;
const fps = 60;
const canvasStream = canvas.captureStream(fps);
const videoTrack = canvasStream.getVideoTracks()[0];

2. Capture the Audio Stream

To include sound, you must obtain a MediaStreamTrack for your audio.

If you are using the Web Audio API or libraries like @pixi/sound:

  1. Create a MediaStreamAudioDestinationNode using your AudioContext.
  2. Connect your sound source to this destination node as well as the main audio output (audioContext.destination).
  3. Extract the audio track from the node's stream.
const audioContext = new (window.AudioContext || window.webkitAudioContext)();
const audioDestination = audioContext.createMediaStreamDestination();

// Connect your sound source (e.g., an oscillator, buffer source, or element node)
sourceNode.connect(audioContext.destination); // For playback
sourceNode.connect(audioDestination);        // For recording

const audioTrack = audioDestination.stream.getAudioTracks()[0];

If you are playing sound through an HTML <audio> tag, you can capture it directly:

const audioElement = document.querySelector('audio');
const audioStream = audioElement.captureStream ? audioElement.captureStream() : audioElement.mozCaptureStream();
const audioTrack = audioStream.getAudioTracks()[0];

3. Combine Streams and Initialize MediaRecorder

Create a new MediaStream combining both tracks, then instantiate the MediaRecorder. Check for format support to decide between WebM and MP4.

const combinedStream = new MediaStream([videoTrack, audioTrack]);

// Determine supported format
let mimeType = 'video/webm; codecs=vp9,opus';
if (MediaRecorder.isTypeSupported('video/mp4; codecs=avc1,mp4a.40.2')) {
    mimeType = 'video/mp4; codecs=avc1,mp4a.40.2';
} else if (!MediaRecorder.isTypeSupported(mimeType)) {
    mimeType = 'video/webm';
}

const recorder = new MediaRecorder(combinedStream, {
    mimeType: mimeType,
    videoBitsPerSecond: 5000000 // 5 Mbps
});

const recordedChunks = [];

recorder.ondataavailable = (event) => {
    if (event.data.size > 0) {
        recordedChunks.push(event.data);
    }
};

recorder.onstop = () => {
    const blob = new Blob(recordedChunks, { type: mimeType });
    const url = URL.createObjectURL(blob);
    
    // Download the video file
    const a = document.createElement('a');
    a.href = url;
    a.download = mimeType.includes('mp4') ? 'pixi-recording.mp4' : 'pixi-recording.webm';
    a.click();
    URL.revokeObjectURL(url);
};

4. Control the Recording

Start and stop the process using the standard control methods:

// Start recording
recorder.start();

// Stop recording after a specific duration or event
setTimeout(() => {
    recorder.stop();
}, 5000);

Format and Browser Compatibility Considerations

  • WebM (video/webm): Universally supported across Chromium-based browsers and Firefox. It typically pairs VP8/VP9 video with Opus audio.
  • MP4 (video/mp4): Supported natively in Safari and recent versions of Google Chrome and Microsoft Edge (typically using H.264 video and AAC audio). Always use MediaRecorder.isTypeSupported() before specifying MP4 containers to avoid runtime initialization errors.
  • Web Audio State: Ensure the AudioContext is in the "running" state. Browsers require a user interaction (like a click) before an AudioContext can process and output sound to the destination stream.
