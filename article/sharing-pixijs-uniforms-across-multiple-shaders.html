Sharing PixiJS Uniforms Across Multiple Shaders

In Pixi.js, sharing uniform values across multiple distinct shader instances is primarily achieved using uniform groups (UniformGroup) and Uniform Buffer Objects (UBOs). By decoupling the uniform storage from individual shader programs, Pixi.js allows multiple shaders to reference the same data source. When the values in this shared group are modified, the changes instantly apply to every shader referencing that group, eliminating redundant CPU-to-GPU memory transfers and keeping uniform state synchronized across different render objects.

The Role of UniformGroup

By default, standard uniform definitions in a Pixi.js Shader or Filter are tied directly to that specific shader program. To share values, Pixi.js provides the UniformGroup class.

A UniformGroup encapsulates an object of uniform key-value pairs. Instead of defining raw uniform objects inside each shader's configuration, you pass a single UniformGroup instance into the uniform definitions of each shader.

import { Shader, UniformGroup, Program } from 'pixi.js';

// Define the shared uniform group
const sharedGroup = new UniformGroup({
    uSharedTime: 0.0,
    uSharedColor: [1.0, 0.5, 0.0]
});

// Pass the shared group to distinct shader instances
const shaderA = new Shader(programA, {
    sharedData: sharedGroup,
    uLocalValueA: 1.0
});

const shaderB = new Shader(programB, {
    sharedData: sharedGroup,
    uLocalValueB: 42.0
});

Because both shaderA and shaderB point to sharedGroup, updating sharedGroup.uniforms.uSharedTime = performance.now() updates the uniform value for both shaders during their respective render passes.

Hardware Acceleration via Uniform Buffer Objects (UBOs)

When running on WebGL 2 or WebGPU, Pixi.js can bind a UniformGroup as a Uniform Buffer Object (UBO). Instead of uploading individual uniforms through separate driver calls for each shader, a UBO uploads the uniform block directly to dedicated GPU memory once per frame.

To enable this behavior, the UniformGroup can be configured as a buffer group:

const sharedBufferGroup = new UniformGroup({
    uLightPosition: [0.0, 10.0, 5.0],
    uIntensity: 1.5
}, { isStatic: false, ubo: true });

In the shader code, the group is declared inside a uniform block matching the group's structure:

layout (std140) uniform sharedData {
    vec3 uLightPosition;
    float uIntensity;
};

When rendering, the Pixi.js state system checks the dirty flag of the UniformGroup. If the values have changed, the data buffer is updated on the GPU once. Distinct shaders that bind this block automatically read from the identical buffer binding point without re-uploading the data.

Internal Engine Usage

Pixi.js relies on this same pattern internally for rendering operations. The renderer manages a global uniform system (renderer.globalUniforms) containing matrices, resolution metrics, and projection data. Rather than recalculating and rebinding these system-level uniforms for every draw call or custom filter, Pixi.js passes its global UniformGroup across all pipeline shaders, ensuring consistent global context with minimal overhead.
