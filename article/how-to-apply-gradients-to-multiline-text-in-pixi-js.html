How to Apply Gradients to Multiline Text in Pixi.js

Applying gradient fills across multiline text strings in Pixi.js can be achieved either by using the built-in gradient options in PIXI.TextStyle or by applying a custom gradient sprite masked by the text object. This guide covers how to configure native multiline text styles to stretch a gradient across all lines, as well as an alternative masking approach for custom angles and advanced styling.

Method 1: Using Built-in TextStyle Gradients

Pixi.js generates text using an off-screen HTML5 canvas. When you define an array of colors in the fill property along with a gradient type, Pixi.js draws the gradient across the entire bounding box of that canvas, naturally spanning all lines when wordWrap or newline characters (\n) are present.

Here is how to configure a vertical gradient spanning multiple lines:

import * as PIXI from 'pixi.js';

// Initialize your Pixi Application
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Define the multiline style with gradient properties
const style = new PIXI.TextStyle({
    fontFamily: 'Arial',
    fontSize: 36,
    fontWeight: 'bold',
    // Supply two or more colors for the gradient
    fill: ['#ff9900', '#ff0055', '#330033'],
    // 0 = Linear Vertical, 1 = Linear Horizontal
    fillGradientType: PIXI.TEXT_GRADIENT.LINEAR_VERTICAL,
    // Optional: define stop ratios between 0 and 1
    fillGradientStops: [0, 0.5, 1],
    wordWrap: true,
    wordWrapWidth: 400,
    align: 'center'
});

const multilineText = new PIXI.Text(
    'This is a multiline\nPixi.js text string\nwith a vertical gradient.',
    style
);

multilineText.x = 50;
multilineText.y = 50;

app.stage.addChild(multilineText);

Key Properties to Note:

  • fill: An array of hex color strings or numbers (e.g., ['#ffffff', '#000000']).
  • fillGradientType: Accepts PIXI.TEXT_GRADIENT.LINEAR_VERTICAL (default) or PIXI.TEXT_GRADIENT.LINEAR_HORIZONTAL. A vertical gradient spans smoothly from the top of the first line to the bottom of the last line.
  • fillGradientStops: Defines where each color transition occurs along the vector from 0 (start) to 1 (end).

Method 2: Masking a Gradient Sprite with Text

If you need an angled linear gradient (such as a 45-degree angle) or a radial gradient across your multiline text, Pixi's built-in TextStyle options are limited to strictly horizontal or vertical axes. In this scenario, create a gradient on a separate canvas or sprite, and use the multiline PIXI.Text as a mask.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// 1. Create the Multiline Text object to serve as the mask
const textMask = new PIXI.Text(
    'Angled gradients\nacross multiple lines\nusing masking.',
    {
        fontFamily: 'Arial',
        fontSize: 40,
        fontWeight: 'bold',
        wordWrap: true,
        wordWrapWidth: 500,
        fill: 0xffffff // Must be solid to define mask opacity
    }
);

// 2. Create a Canvas with your custom gradient
const canvas = document.createElement('canvas');
canvas.width = 500;
canvas.height = 200;
const ctx = canvas.getContext('2d');

// Define an angled linear gradient
const gradient = ctx.createLinearGradient(0, 0, canvas.width, canvas.height);
gradient.addColorStop(0, '#00c6ff');
gradient.addColorStop(1, '#0072ff');

ctx.fillStyle = gradient;
ctx.fillRect(0, 0, canvas.width, canvas.height);

// 3. Convert Canvas to a Pixi Sprite
const gradientTexture = PIXI.Texture.from(canvas);
const gradientSprite = new PIXI.Sprite(gradientTexture);

// 4. Position and assign mask
gradientSprite.x = 50;
gradientSprite.y = 50;
textMask.x = 50;
textMask.y = 50;

gradientSprite.mask = textMask;

// Add both the sprite and mask to the stage
app.stage.addChild(gradientSprite);
app.stage.addChild(textMask);

Using native TextStyle gradients is the most performant approach for standard vertical or horizontal text flows. Opt for the masking approach whenever your design requires non-orthogonal angles, radial shapes, or complex texture fills across multiple lines of text.
