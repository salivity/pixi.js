Skew Transformations Along X and Y in Pixi.js

Skewing an object in Pixi.js allows you to slant its shape along the horizontal or vertical axes to create pseudo-3D effects, depth, or stylized distortions. This article explains how to use Pixi.js's built-in skew property on display objects, work with radian measurements, and use the set method for streamlined transformations.

Understanding the Skew Property

Every standard display object in Pixi.js—such as a Sprite, Container, or Graphics object—has an observable point property named skew. The skew property contains two components:

  • skew.x: The slant angle along the X-axis (horizontal shear).
  • skew.y: The slant angle along the Y-axis (vertical shear).

Unlike transformations in CSS or some design software that rely on degrees, Pixi.js calculates skew angles in radians.

Setting Skew Values

To apply skew, assign radian values directly to the x and y properties, or use the set() helper function.

Setting Values Directly

const sprite = PIXI.Sprite.from('path/to/image.png');

// Skew 0.2 radians along the X-axis
sprite.skew.x = 0.2;

// Skew 0.4 radians along the Y-axis
sprite.skew.y = 0.4;

Using the set() Method

You can define both axes simultaneously using the set() method:

// Applies 0.2 rad to the X-axis and 0.4 rad to the Y-axis
sprite.skew.set(0.2, 0.4);

// If only one argument is provided, it applies to both axes
sprite.skew.set(0.3);

Converting Degrees to Radians

If you prefer thinking in degrees, multiply the degree value by Math.PI / 180:

const degreesToRadians = (deg) => deg * (Math.PI / 180);

// Skew 15 degrees horizontally and 10 degrees vertically
sprite.skew.x = degreesToRadians(15);
sprite.skew.y = degreesToRadians(10);

Anchor and Pivot Considerations

A skew transformation is calculated relative to the object's origin.

  • For a Sprite, the origin is defined by the anchor property. Setting sprite.anchor.set(0.5) skews the sprite from its center point rather than its top-left corner.
  • For a Container or Graphics object, use the pivot property to adjust the origin point around which the skew occurs.
