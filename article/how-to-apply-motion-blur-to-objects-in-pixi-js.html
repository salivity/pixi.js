How to Apply Motion Blur to Objects in Pixi.js

Applying a motion blur effect to fast-moving objects in Pixi.js enhances visual realism and prevents visual stuttering during high-speed animations. This guide covers how to set up the necessary Pixi.js filter extension, attach the motion blur filter to a display object, and dynamically update the blur's direction and intensity in your render loop based on the object's real-time velocity.

1. Install the Pixi Filters Package

Pixi.js core does not bundle advanced motion blur by default. You need the official community filter package, @pixi/filter-motion-blur, or the complete pixi-filters bundle.

Install it via npm:

npm install @pixi/filter-motion-blur

Or load it via a CDN script tag in your HTML:

<script src="https://cdn.jsdelivr.net/npm/pixi-filters@latest/dist/browser/pixi-filters.js"></script>

2. Instantiate the MotionBlurFilter

Import the filter and instantiate it. The MotionBlurFilter constructor accepts three main arguments:

  • velocity ([x, y] or PIXI.ObservablePoint): The direction and magnitude of the blur.
  • kernelSize (number): The quality of the blur (must be an odd number, typically between 5 and 15). Higher numbers look smoother but cost more GPU performance.
  • offset (number): The offset along the velocity vector (default is 0).
import * as PIXI from 'pixi.js';
import { MotionBlurFilter } from '@pixi/filter-motion-blur';

// Create the filter with an initial velocity of zero
const motionBlur = new MotionBlurFilter([0, 0], 9, 0);

// Assign the filter to your sprite or container
const sprite = PIXI.Sprite.from('path/to/asset.png');
sprite.filters = [motionBlur];
app.stage.addChild(sprite);

3. Update the Blur Dynamically in the Render Loop

Motion blur must adapt to the speed and angle of the moving object. Calculate the object's displacement each frame, scale it appropriately, and pass it directly to motionBlur.velocity.

let prevX = sprite.x;
let prevY = sprite.y;

// Intensity multiplier to amplify or soften the blur effect
const blurIntensity = 0.5;

app.ticker.add(() => {
  // Move your object (e.g., standard physics or path movement)
  sprite.x += 12;
  sprite.y += 6;

  // Calculate velocity for this frame
  const vx = (sprite.x - prevX) * blurIntensity;
  const vy = (sprite.y - prevY) * blurIntensity;

  // Apply the velocity to the filter
  motionBlur.velocity.x = vx;
  motionBlur.velocity.y = vy;

  // Cache current position for the next frame
  prevX = sprite.x;
  prevY = sprite.y;
});

4. Optimize Performance

When the object slows down or stops, disable or clear the filter to preserve GPU performance:

  • Check velocity thresholds: If Math.hypot(vx, vy) < 0.1, set motionBlur.enabled = false or set sprite.filters = [].
  • Re-enable on movement: When speed crosses the threshold again, re-enable the filter: motionBlur.enabled = true.
  • Adjust kernelSize: Keep kernelSize around 5 to 9 for mobile devices to maintain a steady frame rate.
