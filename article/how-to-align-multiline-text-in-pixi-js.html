How to Align Multiline Text in Pixi.js

Aligning multiline text in Pixi.js is handled directly through the PIXI.TextStyle configuration object using the align property. This guide explains how to properly configure text alignment for 'left', 'center', 'right', and 'justify' modes, as well as how to avoid common pitfalls regarding text wrapping and object positioning.

Prerequisites for Multiline Text

For text alignment to take effect, your text must span multiple lines. This can occur in two ways:

  1. Manual line breaks: Including explicit newline characters (\n) inside your string.
  2. Automatic word wrapping: Enabling wordWrap: true and defining a wordWrapWidth in the style settings.

Without multiple lines of text, the align property will have no visible effect within the text bounding box.

The align Property

Pixi.js provides four values for the align property inside PIXI.TextStyle:

  • 'left' (default): Aligns lines along the left margin.
  • 'center': Centers each line horizontally relative to the longest line.
  • 'right': Aligns lines along the right margin.
  • 'justify': Expands spacing between words so each line fills the entire wordWrapWidth (available in modern Pixi.js versions).

Code Example: Configuring Text Alignment

Below is an implementation showing how to define alignment for both manual line breaks and automatically wrapped text.

import * as PIXI from 'pixi.js';

// 1. Center-aligned text with manual line breaks
const centerStyle = new PIXI.TextStyle({
    fontFamily: 'Arial',
    fontSize: 24,
    fill: 0xffffff,
    align: 'center' // Options: 'left', 'center', 'right', 'justify'
});

const centerText = new PIXI.Text({
    text: 'First Line\nSecond Longer Line\nThird Line',
    style: centerStyle
});
centerText.position.set(50, 50);

// 2. Justified text using automatic word wrapping
const justifyStyle = new PIXI.TextStyle({
    fontFamily: 'Arial',
    fontSize: 18,
    fill: 0xffffff,
    wordWrap: true,
    wordWrapWidth: 300,
    align: 'justify'
});

const justifiedText = new PIXI.Text({
    text: 'Pixi.js automatically distributes spacing between words when align is set to justify across a defined wordWrapWidth.',
    style: justifyStyle
});
justifiedText.position.set(50, 200);

align vs. anchor

A frequent source of confusion in Pixi.js is the difference between align and anchor:

  • align (Internal): Affects only how individual lines of text align relative to one another within the text object's bounding box.
  • anchor (External): Affects the origin point of the text object itself relative to its (x, y) position on the stage.

If you set align: 'center' but want the entire text block centered at a specific stage coordinate, you must also set the anchor:

// Center the lines within the box AND center the box at the coordinate
text.style.align = 'center';
text.anchor.set(0.5, 0); // Centers horizontally around text.x
