Build Interactive Sliders with @pixi/ui in Pixi.js

This guide demonstrates how to construct interactive, draggable sliders in Pixi.js using the @pixi/ui component library. You will learn how to set up the necessary dependencies, generate graphical components for the slider's track and thumb, instantiate the Slider class, and listen to value changes to control interactive visual elements.

1. Install Dependencies

To get started, ensure you have both pixi.js and @pixi/ui installed in your project:

npm install pixi.js @pixi/ui

2. Prepare Slider Graphics

The Slider component in @pixi/ui requires display objects for its visual parts: a background track (bg), an optional progress track (fill), and a draggable handle (slider). You can create these dynamically using PIXI.Graphics.

import * as PIXI from 'pixi.js';
import { Slider } from '@pixi/ui';

// Initialize Pixi application
const app = new PIXI.Application({ width: 800, height: 600, backgroundColor: 0x1e1e24 });
document.body.appendChild(app.view);

// 1. Create the background track
const bg = new PIXI.Graphics()
    .beginFill(0x3a3a45)
    .drawRoundedRect(0, 0, 300, 12, 6)
    .endFill();

// 2. Create the fill track (progress bar)
const fill = new PIXI.Graphics()
    .beginFill(0x4caf50)
    .drawRoundedRect(0, 0, 300, 12, 6)
    .endFill();

// 3. Create the draggable handle
const sliderHandle = new PIXI.Graphics()
    .beginFill(0xffffff)
    .drawCircle(0, 6, 12)
    .endFill();

3. Instantiate the Slider Component

Pass the graphics components and configuration settings into the Slider constructor:

const slider = new Slider({
    bg: bg,
    slider: sliderHandle,
    fill: fill,
    min: 0,
    max: 100,
    value: 50, // Initial starting value
});

// Position the slider on the stage
slider.x = (app.screen.width - 300) / 2;
slider.y = (app.screen.height - 12) / 2;

app.stage.addChild(slider);

4. Handling Value Changes

The @pixi/ui Slider class provides an onUpdate signal that emits the updated value whenever the user clicks or drags the handle:

slider.onUpdate.connect((val) => {
    console.log(`Current Slider Value: ${Math.round(val)}`);
});

You can use this callback to update other game or UI properties, such as audio volume, particle counts, or object dimensions.

5. Customization Options

  • Orientation: Sliders are horizontal by default. To make a vertical slider, set slider.orientation = 'vertical' and draw your assets with corresponding vertical dimensions.
  • Step Size: Restrict values to discrete increments by setting the step property on initialization or directly on the instance: slider.step = 5.
  • Interactivity State: Enable or disable user interaction dynamically via slider.enabled = false.
