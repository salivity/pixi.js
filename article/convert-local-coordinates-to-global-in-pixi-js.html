Convert Local Coordinates to Global in Pixi.js

Converting coordinates between nested display hierarchies and the global screen space is a fundamental task in Pixi.js development. This article explains how to use Pixi.js's built-in toGlobal() method to translate a local coordinate inside any container into absolute stage or screen coordinates, detailing the syntax, practical implementation, and performance considerations.

Using the toGlobal() Method

Every DisplayObject and Container in Pixi.js provides a built-in method called toGlobal(). This method calculates the world transform of the target object and translates a point from its local coordinate system into the global stage coordinate system.

Basic Syntax

const globalPoint = displayObject.toGlobal(position, point, skipUpdate);

Parameters

  • position (IPointData): The local coordinate pair { x, y } within the object's coordinate space that you want to convert. Passing { x: 0, y: 0 } will find the global origin of the object.
  • point (optional, Point): An optional target Point object to store the result. Supplying an existing point avoids instantiating a new object, which reduces garbage collection overhead.
  • skipUpdate (optional, boolean): Defaults to false. If set to true, Pixi.js will not recalculate the world transform matrix before calculating the position. Use this only if you know the transforms are already up to date.

Practical Example

In a typical setup, a sprite is nested inside a container that has its own transformations (position, rotation, or scale). To find where the sprite appears on the user's screen:

import * as PIXI from 'pixi.js';

// Setup application
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Create a parent container and place it at (100, 100)
const parentContainer = new PIXI.Container();
parentContainer.position.set(100, 100);
app.stage.addChild(parentContainer);

// Create a child container nested inside the parent at (50, 50)
const childContainer = new PIXI.Container();
childContainer.position.set(50, 50);
parentContainer.addChild(childContainer);

// Calculate the global coordinates of the child container's origin
const globalPosition = childContainer.toGlobal(new PIXI.Point(0, 0));

console.log(globalPosition.x); // Outputs: 150
console.log(globalPosition.y); // Outputs: 150

Performance Best Practice

Creating a new PIXI.Point on every frame inside a render loop or ticker generates garbage collection pressure. To optimize performance, reuse an existing point:

// Pre-allocate points outside the loop
const localPoint = new PIXI.Point(0, 0);
const outputPoint = new PIXI.Point();

app.ticker.add(() => {
    // Reuses outputPoint instead of creating a new object each frame
    childContainer.toGlobal(localPoint, outputPoint);
});
