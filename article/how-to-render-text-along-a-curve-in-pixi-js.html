How to Render Text Along a Curve in Pixi.js

Rendering text along a curved path or circle in Pixi.js requires a programmatic approach, as the engine does not include a native curved text component. This guide demonstrates how to break a string into individual character sprites, calculate their coordinates and angles using trigonometry or Bézier curve mathematics, and group them inside a PIXI.Container for seamless manipulation and rendering.

The Underlying Mechanism

Because Pixi.js renders standard PIXI.Text objects inside rectangular bounding boxes, a single text object cannot be bent. Instead, you must:

  1. Deconstruct the string into individual characters.
  2. Create a separate text object for each character.
  3. Calculate the position \((x, y)\) and rotation angle for each character along the desired path.
  4. Add all characters to a parent PIXI.Container.

Method 1: Rendering Text Along a Circular Path

For a circular path, you can use basic polar-to-Cartesian trigonometry. Each character's position is derived from the radius of the circle and the angle increment.

import * as PIXI from 'pixi.js';

function createCurvedText(text, radius, startAngle, app) {
    const container = new PIXI.Container();
    const textStyle = new PIXI.TextStyle({
        fontFamily: 'Arial',
        fontSize: 24,
        fill: 0xffffff,
    });

    // Determine the angular spacing between characters
    // Larger radius requires smaller angular steps per character width
    const totalChars = text.length;
    const arcLength = 0.15; // Angle spread between characters in radians

    for (let i = 0; i < totalChars; i++) {
        const char = text[i];
        const charText = new PIXI.Text(char, textStyle);

        // Center the anchor to ensure smooth rotation
        charText.anchor.set(0.5, 0.5);

        // Calculate the angle for this character
        const charAngle = startAngle + i * arcLength;

        // Position on the circle
        charText.x = radius * Math.cos(charAngle);
        charText.y = radius * Math.sin(charAngle);

        // Rotate character so it aligns tangentially to the circle
        charText.rotation = charAngle + Math.PI / 2;

        container.addChild(charText);
    }

    return container;
}

// Usage
const circularText = createCurvedText("HELLO WORLD ON A CIRCLE", 150, -Math.PI / 2);
circularText.position.set(400, 300); // Center in the stage
app.stage.addChild(circularText);

Adjusting Alignment and Spacing

  • Text Spacing: Setting a fixed angle increment works well for monospaced fonts. For proportional fonts, measure each character using charText.width and calculate the individual angular step dynamically: \[\Delta \theta = \frac{\text{charWidth}}{\text{radius}}\]
  • Centering: To center the text arc at a specific point, set startAngle to: \[\text{targetAngle} - \frac{\text{totalArcLength}}{2}\]

Method 2: Rendering Text Along an Arbitrary Bézier Curve

To render text along non-circular curves (like an S-curve or an arch), calculate points and tangents along a cubic Bézier curve.

A cubic Bézier curve is defined by four points: start point (\(P_0\)), control points (\(P_1, P_2\)), and end point (\(P_3\)).

Bézier Calculation Formula

function getBezierPointAndTangent(t, p0, p1, p2, p3) {
    const u = 1 - t;
    const tt = t * t;
    const uu = u * u;
    const uuu = uu * u;
    const ttt = tt * t;

    // Calculate position
    const x = uuu * p0.x + 3 * uu * t * p1.x + 3 * u * tt * p2.x + ttt * p3.x;
    const y = uuu * p0.y + 3 * uu * t * p1.y + 3 * u * tt * p2.y + ttt * p3.y;

    // Calculate tangent vector (first derivative)
    const dx = 3 * uu * (p1.x - p0.x) + 6 * u * t * (p2.x - p1.x) + 3 * tt * (p3.x - p2.x);
    const dy = 3 * uu * (p1.y - p0.y) + 6 * u * t * (p2.y - p1.y) + 3 * tt * (p3.y - p2.y);

    // Calculate angle of tangent
    const angle = Math.atan2(dy, dx);

    return { x, y, angle };
}

Applying Characters to the Curve

function createPathText(text, p0, p1, p2, p3) {
    const container = new PIXI.Container();
    const textStyle = new PIXI.TextStyle({
        fontFamily: 'Arial',
        fontSize: 20,
        fill: 0xffffff,
    });

    const step = 1 / (text.length - 1);

    for (let i = 0; i < text.length; i++) {
        const t = i * step;
        const transform = getBezierPointAndTangent(t, p0, p1, p2, p3);

        const charText = new PIXI.Text(text[i], textStyle);
        charText.anchor.set(0.5, 0.5);
        charText.position.set(transform.x, transform.y);
        charText.rotation = transform.angle;

        container.addChild(charText);
    }

    return container;
}

Optimization: Use BitmapText for Performance

Generating multiple individual standard PIXI.Text objects creates separate canvas contexts for each letter, which can quickly degrade performance and consume video memory.

When rendering long text strings or updating curved text frequently:

  1. Replace PIXI.Text with PIXI.BitmapText.
  2. Generate a single bitmap font atlas.
  3. Apply the same positional and rotational logic to the individual character glyphs or instanced BitmapText nodes.

Using PIXI.BitmapText batches all character draws into a single draw call, maintaining a high frame rate even with numerous curved labels on screen.
