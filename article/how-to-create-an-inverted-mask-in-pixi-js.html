How to Create an Inverted Mask in Pixi.js

This article explains how to implement an inverted mask in Pixi.js so that content renders exclusively outside of a designated shape. You will learn how to configure MaskData to flip the default masking behavior, along with a complete code example demonstrating the implementation in modern Pixi.js versions.

By default, a standard mask in Pixi.js hides everything outside the mask boundary and shows only what is inside it. To achieve the reverse effect—creating a "hole" through which objects disappear or showing objects only in the surrounding space—you utilize Pixi.js's built-in MaskData class with its inverse property enabled.

Step 1: Create the Target and Mask Shapes

First, create the display object you want to mask and the graphic object that defines the cutout shape:

// Target container or sprite to be masked
const background = new PIXI.Graphics()
    .rect(0, 0, 800, 600)
    .fill(0x3498db);

app.stage.addChild(background);

// The mask shape (the area where the target will NOT render)
const holeShape = new PIXI.Graphics()
    .circle(400, 300, 100)
    .fill(0xffffff);

app.stage.addChild(holeShape);

Step 2: Wrap the Shape in MaskData and Enable inverse

Instead of assigning the graphics object directly to the mask property, wrap it inside an instance of PIXI.MaskData. Set the inverse property to true to invert the rendering rule:

// Create a MaskData instance wrapping the graphic
const maskData = new PIXI.MaskData(holeShape);

// Invert the mask
maskData.inverse = true;

// Apply the mask data to the target
background.mask = maskData;

Complete Working Example

Here is a full integration script compatible with modern Pixi.js:

import * as PIXI from 'pixi.js';

const app = new PIXI.Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

// 1. Create content to be masked
const container = new PIXI.Container();

const rect = new PIXI.Graphics()
    .rect(0, 0, 800, 600)
    .fill(0xe74c3c);

container.addChild(rect);
app.stage.addChild(container);

// 2. Define the cutout shape
const cutout = new PIXI.Graphics()
    .circle(400, 300, 150)
    .fill(0xffffff);

app.stage.addChild(cutout);

// 3. Create the inverted mask
const invertedMask = new PIXI.MaskData(cutout);
invertedMask.inverse = true;

// 4. Apply to container
container.mask = invertedMask;

Important Considerations

  • Render Pipeline Support: Inverted masks rely on stencil buffers or custom shader operations. Ensure your WebGL context is functioning normally, as fallback Canvas renderers do not support hardware-accelerated inverted stencil masks.
  • Scene Graph Placement: The mask object should generally remain on the stage to allow Pixi.js to properly calculate world transforms and render boundaries accurately during the stencil pass.
