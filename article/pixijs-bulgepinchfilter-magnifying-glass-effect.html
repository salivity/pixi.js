PixiJS BulgePinchFilter Magnifying Glass Effect

Creating a magnifying lens effect in PixiJS is straightforward using the BulgePinchFilter from the PixiJS community filters package. This guide explains how to install the filter, configure its core properties (radius, strength, and center) to replicate optical magnification, and bind it to pointer events for interactive cursor-based magnification.

1. Installation

The BulgePinchFilter is not part of the core PixiJS bundle. Install the standalone package via npm:

npm install @pixi/filter-bulge-pinch

Or import the entire filter collection:

npm install pixi-filters

2. Core Properties for Magnification

To create a magnifying lens rather than an indentation or pinch, configure these three parameters:

  • strength: Controls the intensity and direction of the distortion. Values range from -1 to 1. A positive value (e.g., 0.3 to 0.8) creates a bulge effect that enlarges content, simulating a convex lens. Negative values pinch pixels inward.
  • radius: Defines the pixel radius of the magnifying circle. This determines the physical size of your lens on the canvas.
  • center: An array or PIXI.Point representing normalized coordinates [x, y] between 0 and 1 relative to the target object's dimensions, defining where the center of the lens rests.

3. Implementation Example

Here is how to apply the filter to a container or sprite and map it dynamically to mouse or touch movements:

import * as PIXI from 'pixi.js';
import { BulgePinchFilter } from '@pixi/filter-bulge-pinch';

// Initialize the Pixi application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    antialias: true
});
document.body.appendChild(app.view);

// Create a display object (e.g., a background sprite)
const background = PIXI.Sprite.from('path/to/image.jpg');
background.width = app.screen.width;
background.height = app.screen.height;
app.stage.addChild(background);

// Configure the BulgePinchFilter
const magnifier = new BulgePinchFilter({
    center: [0.5, 0.5], // Center of the screen initially
    radius: 150,        // Radius of the lens in pixels
    strength: 0.5       // Positive value for magnification
});

// Apply filter to the target
background.filters = [magnifier];

// Enable interaction
app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;

// Update lens center on pointer move
app.stage.on('pointermove', (event) => {
    const { x, y } = event.global;
    
    // Normalize coordinates to [0, 1] for the filter
    magnifier.center[0] = x / app.screen.width;
    magnifier.center[1] = y / app.screen.height;
});

4. Fine-Tuning the Effect

  • Tuning Strength: Values between 0.3 and 0.6 provide a natural glass-like expansion. Setting strength closer to 1.0 produces extreme fisheye distortion that can heavily blur textures at the center.
  • Aspect Ratios: If the target container is not square, the magnification area may appear elliptical. Adjust the container dimensions or map normalized coordinates accounting for aspect ratio if uniform circular magnification is strictly required.
  • Hardware Acceleration: Running multiple complex filters can impact performance. Applying the filter to a specific container rather than the entire stage ensures better frame rates.
