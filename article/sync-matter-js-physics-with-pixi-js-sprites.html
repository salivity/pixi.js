Sync Matter.js Physics with Pixi.js Sprites

Synchronizing Matter.js rigid bodies with Pixi.js sprites allows you to decouple complex 2D physics simulations from high-performance WebGL rendering. Because Matter.js operates strictly as a physics engine without built-in visuals and Pixi.js functions purely as a renderer, synchronization is achieved by reading the translation coordinates (x, y) and rotation (angle) from a Matter.js body and assigning them directly to the corresponding Pixi.js sprite within a continuous update loop.

1. Aligning the Pivot and Anchor Points

The most common issue when pairing Matter.js with Pixi.js is mismatched origin points. By default, Matter.js calculates a rigid body's position from its center of mass. Conversely, Pixi.js positions sprites from their top-left corner (anchor.set(0, 0)).

To ensure rotation and positional transforms match precisely, set the Pixi.js sprite's anchor to its center:

sprite.anchor.set(0.5, 0.5);

2. Associating Sprites with Bodies

You need a reference between the physical entity and the visual entity. The most straightforward pattern is attaching the Pixi.js sprite directly to the Matter.js body via a custom property or maintaining an array of paired references.

import * as PIXI from 'pixi.js';
import Matter from 'matter-js';

// Create Pixi Sprite
const texture = PIXI.Texture.from('box.png');
const sprite = new PIXI.Sprite(texture);
sprite.anchor.set(0.5, 0.5);
app.stage.addChild(sprite);

// Create Matter.js Body
const body = Matter.Bodies.rectangle(400, 200, 80, 80);
Matter.Composite.add(engine.world, body);

// Link references
body.plugin = { sprite }; // or directly: body.sprite = sprite;

3. Updating Transforms in the Render Loop

Synchronization must happen continuously after the physics engine updates. You can use Pixi.js's built-in Ticker or a standard requestAnimationFrame loop.

In the loop, step the Matter.js engine first, then iterate over all synchronized bodies to copy their updated properties to the sprites:

app.ticker.add((delta) => {
    // 1. Advance the physics engine
    Matter.Engine.update(engine, delta * (1000 / 60));

    // 2. Synchronize transforms
    bodiesWithSprites.forEach(body => {
        const sprite = body.plugin.sprite;
        if (sprite) {
            sprite.position.set(body.position.x, body.position.y);
            sprite.rotation = body.angle;
        }
    });
});

Key Considerations

  • Compound and Custom Bodies: If a Matter.js body has an offset center of mass or consists of multiple sub-parts, the geometric center and the physics origin will differ. Adjust the Pixi sprite's pivot property rather than its anchor property to account for any offsets.
  • Removal and Cleanup: When removing an object from the simulation, ensure you remove the rigid body from Matter.Composite and destroy or remove the sprite from the Pixi container (app.stage.removeChild(sprite)) to prevent memory leaks and orphaned rendering calls.
