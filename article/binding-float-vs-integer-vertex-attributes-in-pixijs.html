Binding Float vs Integer Vertex Attributes in PixiJS

This guide explains how to define and bind floating-point and integer vertex attributes using PixiJS. Custom shaders frequently require diverse data inputs, from position vectors and UV coordinates to discrete texture indices and state flags. Understanding the configuration differences between standard floating-point buffers and non-normalized integer buffers in PixiJS ensures that the GPU correctly decodes your data without data corruption or shader compilation issues.

Floating-Point Vertex Attributes

Floating-point attributes are the standard attribute type in WebGL and PixiJS. They are read into shaders as float, vec2, vec3, or vec4 types and use standard floating-point vertex pointers under the hood.

1. Buffer Setup

Create a buffer populated with a typed array of floating-point values:

const floatData = new Float32Array([
    0.0,  0.5,
   -0.5, -0.5,
    0.5, -0.5,
]);

const positionBuffer = new PIXI.Buffer(floatData);

2. Attribute Binding

Add the attribute to a PIXI.Geometry instance using PIXI.TYPES.FLOAT:

const geometry = new PIXI.Geometry();

geometry.addAttribute(
    'aPosition',           // Attribute name matching the shader variable
    positionBuffer,        // The source buffer
    2,                     // Size: number of components (vec2)
    false,                 // Normalized: false (values are raw floats)
    PIXI.TYPES.FLOAT       // Type: explicitly declared as float
);

3. Vertex Shader Implementation

In the vertex shader, declare the input as a floating-point vector:

// WebGL 1 (GLSL ES 1.0)
attribute vec2 aPosition;

// WebGL 2 (GLSL ES 3.0)
in vec2 aPosition;

Integer Vertex Attributes

When using integer values, such as an object ID, texture array index, or bitmask, attributes must be handled based on whether the shader expects true integers (int, uint, ivec, uvec) or floats derived from integers.

In WebGL 2, true integer attributes must be bound via gl.vertexAttribIPointer rather than gl.vertexAttribPointer. PixiJS selects the appropriate WebGL binding method based on the type and normalized parameters assigned to the attribute.

1. Buffer Setup

Populate an integer typed array (Int32Array, Uint32Array, Int16Array, or Uint16Array):

const idData = new Uint32Array([
    0,
    1,
    2,
]);

const idBuffer = new PIXI.Buffer(idData);

2. Attribute Binding for True Integers (WebGL 2)

To pass discrete integers to a WebGL 2 integer shader input:

geometry.addAttribute(
    'aIndex',                  // Attribute name matching the shader
    idBuffer,                  // The integer buffer
    1,                         // Size: 1 component (scalar int/uint)
    false,                     // Normalized: MUST be false for integer inputs
    PIXI.TYPES.UNSIGNED_INT    // Type: PIXI.TYPES.INT or PIXI.TYPES.UNSIGNED_INT
);

3. Vertex Shader Implementation (WebGL 2)

Because this uses integer pointer routing, the shader must declare the variable using an integer type under GLSL ES 3.0:

#version 300 es

in vec2 aPosition;
in uint aIndex; // Declared as an integer, not a float

void main() {
    // aIndex is preserved as a discrete uint
    gl_Position = vec4(aPosition, 0.0, 1.0);
}

Integer Data Converted to Floats (Normalized Integers)

If you are packing color or coordinate data using bytes or shorts to save memory, but your shader expects them as standard floats (such as vec4(1.0, 0.0, 0.0, 1.0) for RGBA), configure the integer type with normalized: true.

const colorData = new Uint8Array([
    255, 0, 0, 255,
    0, 255, 0, 255,
    0, 0, 255, 255,
]);

geometry.addAttribute(
    'aColor',
    new PIXI.Buffer(colorData),
    4,
    true,                      // Normalized: converts [0, 255] to [0.0, 1.0]
    PIXI.TYPES.UNSIGNED_BYTE   // Byte storage
);

In the shader, read this attribute as a floating-point vec4:

attribute vec4 aColor; // Receives normalized floating-point values

Summary of Differences

Feature Floating-Point Attribute True Integer Attribute Normalized Integer Attribute
Typed Array Float32Array Int32Array / Uint32Array Uint8Array / Int16Array
PixiJS Type PIXI.TYPES.FLOAT PIXI.TYPES.INT or UNSIGNED_INT PIXI.TYPES.UNSIGNED_BYTE
Normalized Flag false false true
GL Pointer Call vertexAttribPointer vertexAttribIPointer vertexAttribPointer
Shader Type float, vec2, vec4 int, uint, ivec*, uvec* float, vec2, vec4
WebGL Context WebGL 1 & WebGL 2 WebGL 2 only WebGL 1 & WebGL 2
