Handling GLSL Precision Specifiers in Pixi.js

Precision specifiers in WebGL—namely highp, mediump, and lowp—dictate the bit-depth and accuracy of floating-point calculations within your graphics pipeline. In Pixi.js, managing these specifiers properly is vital for balancing visual accuracy against rendering performance, especially on mobile GPUs where floating-point math can be a major bottleneck. This guide explains how Pixi.js resolves precision defaults, how you can manually override them in your custom filters and shaders, and how to avoid common artifacts like texture banding and vertex jitter.

Understanding the Precision Levels

  • highp (32-bit float): Provides the highest numeric range and precision. It is required for accurate position calculations, deep matrix transformations, and large world coordinates to prevent vertex snapping or jitter.
  • mediump (16-bit float): Typically suitable for texture coordinates (UVs), normals, and light computations. It offers a significant performance and memory bandwidth improvement on mobile hardware.
  • lowp (8- to 10-bit fixed-point equivalent): Historically used for simple color vectors (RGBA ranges from 0.0 to 1.0). In modern WebGL development, it is rarely used directly because mediump offers vastly better accuracy with negligible performance cost on modern mobile chips.

How Pixi.js Injects Precision

By default, WebGL vertex shaders require precision declarations, while fragment shaders do not have an implicit default float precision. To simplify development, Pixi.js automatically injects precision statements at the top of your custom GLSL code if you do not specify them manually.

Pixi.js typically defaults to:

  • precision highp float; in vertex shaders.
  • precision mediump float; in fragment shaders (or highp depending on your global configuration and device support).

Configuring Global Precision Settings

You can alter the global precision defaults across all newly created shaders and filters by configuring Pixi’s settings prior to initializing your application or custom shaders.

In Pixi.js v7 and earlier:

import * as PIXI from 'pixi.js';

// Set fragment shader default precision to highp
PIXI.settings.PRECISION_FRAGMENT = PIXI.PRECISION.HIGH;

// Alternatively, set to medium precision for mobile performance
PIXI.settings.PRECISION_FRAGMENT = PIXI.PRECISION.MEDIUM;

In Pixi.js v8, precision can be controlled through pipe configurations or by defining it explicitly in your GlProgram or Shader templates to ensure consistent behavior across both WebGL and WebGPU pipelines.

Explicitly Declaring Precision in Custom Shaders

To eliminate ambiguity across different platforms, the best practice is to declare global precision directly at the top of your fragment and vertex shaders. Pixi.js will detect your explicit declaration and bypass its automatic injection.

Example Fragment Shader

precision highp float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;

void main(void) {
    vec4 color = texture2D(uSampler, vTextureCoord);
    gl_FragColor = color;
}

Variable-Level Precision Overrides

You are not restricted to a single precision setting for an entire shader. You can declare a general precision rule and override it for specific variables that demand extra accuracy or lower resource usage.

// Default all floats to medium precision for performance
precision mediump float;

// Explicitly use highp for UV coordinates to prevent texture distortion
varying highp vec2 vTextureCoord;

// Explicitly use mediump for color blending calculations
uniform mediump vec4 uTintColor;

uniform sampler2D uSampler;

void main(void) {
    // High-precision coordinate lookup
    vec4 baseColor = texture2D(uSampler, vTextureCoord);
    
    // Medium-precision blend
    gl_FragColor = baseColor * uTintColor;
}

Best Practices and Common Pitfalls

  • Avoid mediump for Texture Coordinates in Large Canvases: If your sprite sheets, tilemaps, or render targets are large, mediump UVs can cause visible stepping or texture shimmering on mobile devices. Always set varying highp vec2 vTextureCoord; when visual precision is critical.
  • Mobile Fragment highp Support: While nearly all modern mobile devices support highp in fragment shaders via WebGL2 or the OES_fragment_precision_high extension, older or low-tier hardware may fall back to mediump. Use feature detection if supporting legacy devices.
  • Prevent Banding: Gradients generated procedurally in fragment shaders often exhibit severe color banding when rendered under mediump. Force highp specifically on the float variables managing the gradient interpolation.
