How to Enable and Generate Mipmaps in Pixi.js

Mipmaps are pre-calculated, progressively downscaled sequences of an image texture that optimize rendering performance and eliminate aliasing or shimmering when textures are scaled down on screen. This guide explains how to enable and configure mipmap generation for high-resolution textures in Pixi.js, covering both texture creation settings and filtering modes to ensure smooth rendering.

Understanding Mipmap Requirements

Before enabling mipmaps, consider the dimensions of your texture. In standard WebGL 1 environments, mipmaps generally require power-of-two (POT) dimensions (such as 512x512, 1024x1024, or 2048x2048). While modern WebGL 2 contexts support non-power-of-two (NPOT) mipmaps natively, adhering to power-of-two dimensions ensures maximum compatibility across all devices and avoids unexpected fallback behaviors. Mipmapping also increases GPU memory usage by approximately 33%, which is a standard trade-off for reduced aliasing artifacts.

Enabling Mipmaps in Pixi.js v7

In Pixi.js v7, mipmap behavior is controlled via the MIPMAP_MODES enum attached to a BaseTexture. By default, Pixi.js sets the mipmap mode to MIPMAP_MODES.POW2, which automatically generates mipmaps only if the image has power-of-two dimensions.

To explicitly force mipmap generation for a texture:

import * as PIXI from 'pixi.js';

// Loading a texture using Assets with custom mipmap settings
const texture = await PIXI.Assets.load({
    src: 'path/to/high-res-texture.png',
    data: {
        mipmap: PIXI.MIPMAP_MODES.ON
    }
});

// Or modifying an existing BaseTexture directly
const baseTexture = PIXI.BaseTexture.from('path/to/high-res-texture.png');
baseTexture.mipmap = PIXI.MIPMAP_MODES.ON;

Pixi.js provides three main mipmap options:

  • PIXI.MIPMAP_MODES.OFF: Disables mipmap generation entirely.
  • PIXI.MIPMAP_MODES.POW2: Generates mipmaps only if dimensions are a power of two (default).
  • PIXI.MIPMAP_MODES.ON: Forces WebGL to generate mipmaps regardless of dimensions.

Enabling Mipmaps in Pixi.js v8

Pixi.js v8 overhauled the texture pipeline by introducing TextureSource. In this version, mipmap handling is specified directly on the source options or via Assets.load.

To generate mipmaps when loading an asset in v8:

import { Assets } from 'pixi.js';

const texture = await Assets.load({
    src: 'path/to/high-res-texture.png',
    data: {
        autoGenerateMipmaps: true,
    }
});

If you are instantiating a custom ImageSource or TextureSource:

import { ImageSource, Texture } from 'pixi.js';

const source = new ImageSource({
    resource: imageElement,
    autoGenerateMipmaps: true,
});

const texture = new Texture({ source });

Configuring Trilinear Filtering

To achieve the highest visual quality and seamless transitions between different mipmap levels, ensure the texture is configured to use linear filtering instead of nearest-neighbor filtering.

In Pixi.js v7:

baseTexture.scaleMode = PIXI.SCALE_MODES.LINEAR;

In Pixi.js v8:

texture.source.scaleMode = 'linear';

Linear scaling combined with active mipmaps enables trilinear filtering in the GPU shader pipeline, eliminating harsh transitions between mip levels as objects move closer to or further from the camera.
