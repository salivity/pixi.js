How to Count Draw Calls in Pixi.js

Optimizing rendering performance in Pixi.js requires monitoring how many WebGL draw calls are executed per frame to avoid CPU-to-GPU bottlenecks. This guide covers how to retrieve the exact count of draw calls per frame by intercepting native WebGL context methods, utilizing the official PixiJS Devtools browser extension, and profiling via Spector.js.

Method 1: Intercepting WebGL Draw Calls via JavaScript

The most reliable, version-independent way to capture the exact number of draw calls programmatically is to wrap the underlying WebGL context methods: drawElements and drawArrays.

You can attach an interceptor directly to the WebGL rendering context provided by your Pixi Application instance:

const app = new PIXI.Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

// Access the WebGL context
const gl = app.renderer.gl;

let drawCallCount = 0;
let currentFrameDrawCalls = 0;

// Store original WebGL draw functions
const originalDrawElements = gl.drawElements;
const originalDrawArrays = gl.drawArrays;

// Hook drawElements
gl.drawElements = function (...args) {
    drawCallCount++;
    return originalDrawElements.apply(this, args);
};

// Hook drawArrays
gl.drawArrays = function (...args) {
    drawCallCount++;
    return originalDrawArrays.apply(this, args);
};

// Reset and read count each frame
app.ticker.add(() => {
    currentFrameDrawCalls = drawCallCount;
    drawCallCount = 0;

    console.log(`Draw Calls Per Frame: ${currentFrameDrawCalls}`);
});

This approach works across Pixi.js v5, v6, v7, and v8 because it intercepts calls at the driver layer rather than relying on internal Pixi renderer states, which frequently change between major versions.

Method 2: PixiJS Devtools Extension

For quick inspections during development without modifying your codebase, use the PixiJS Devtools extension available for Chrome and Firefox.

  1. Install the PixiJS Devtools extension from your browser's extension store.
  2. Expose your application globally if using Pixi modules: 
    window.__PIXI_APP__ = app;
  3. Open your browser Developer Tools (F12) and switch to the PixiJS tab.
  4. The panel displays real-time statistics, including the active scene graph structure and the number of draw calls per frame.

Method 3: Spector.js

For an in-depth WebGL audit, Spector.js captures an entire frame and displays every command sent to the GPU.

  1. Install the Spector.js Chrome/Firefox extension or load the library via a script tag in your HTML.
  2. Click the red record circle in your browser toolbar to capture a frame.
  3. Spector.js opens a visual timeline of the frame, listing every drawElements and drawArrays call, along with the bound textures, uniforms, and shaders associated with each call.

How to Reduce High Draw Call Counts

If the count exceeds expectations:

  • Use Texture Atlases (Spritesheets): Pixi.js batches adjacent sprites automatically if they share the same base texture. Combining separate image files into a single spritesheet via tools like TexturePacker keeps draw calls near 1.
  • Avoid Interleaving Containers: Alternating between different spritesheet textures, graphics objects, and text forces Pixi.js to break its batch and issue a new draw call for each swap.
  • Check Filters and Masks: Every filter or complex mask requires its own offscreen render pass, adding at least 1 to 2 draw calls per affected container.
