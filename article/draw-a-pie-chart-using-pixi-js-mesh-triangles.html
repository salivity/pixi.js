Draw a Pie Chart Using Pixi.js Mesh Triangles

Rendering a circular pie chart in Pixi.js using custom mesh triangles provides high rendering performance and complete control over geometry. This technique relies on constructing a triangle fan, where every slice is built by connecting a shared central vertex to consecutive points along the circle's perimeter using basic trigonometry. By feeding calculated vertex positions and triangle index buffers directly into a PIXI.Mesh, you can dynamically draw and texture individual slices or an entire pie chart with minimal GPU overhead.

Understanding Triangle Fan Geometry

A circle or pie slice can be decomposed into small triangular segments originating from a central anchor point \((x_c, y_c)\). For each pie slice defined by a start angle \(\theta_{\text{start}}\) and an end angle \(\theta_{\text{end}}\):

  1. Center Vertex: Position \((x_c, y_c)\) acts as the base vertex shared by all triangles.
  2. Perimeter Vertices: The boundary arc is sampled at regular angular intervals. A point at angle \(\theta\) with radius \(r\) is calculated as: \[x = x_c + r \cdot \cos(\theta)\] \[y = y_c + r \cdot \sin(\theta)\]
  3. Indices: Triangles are formed by connecting the center vertex to two adjacent points along the arc.

Step-by-Step Implementation

To build this in Pixi.js, use PIXI.Mesh with a custom PIXI.Geometry or the higher-level PIXI.SimpleMesh.

1. Calculate Vertices and Indices

Each slice requires an array of 2D vertex coordinates and an index array mapping those vertices into triangles.

function createPieSliceData(cx, cy, radius, startAngle, endAngle, segments = 32) {
    const vertices = [cx, cy]; // Center vertex at index 0
    const uvs = [0.5, 0.5];    // Center UV mapped to texture midpoint
    const indices = [];

    const angleStep = (endAngle - startAngle) / segments;

    // Generate perimeter vertices
    for (let i = 0; i <= segments; i++) {
        const angle = startAngle + i * angleStep;
        const x = cx + radius * Math.cos(angle);
        const y = cy + radius * Math.sin(angle);

        vertices.push(x, y);

        // Normalized UV coordinates mapped to a [0, 1] square
        const u = 0.5 + 0.5 * Math.cos(angle);
        const v = 0.5 + 0.5 * Math.sin(angle);
        uvs.push(u, v);
    }

    // Generate triangle indices (connecting center to adjacent arc points)
    for (let i = 1; i <= segments; i++) {
        indices.push(0, i, i + 1);
    }

    return {
        vertices: new Float32Array(vertices),
        uvs: new Float32Array(uvs),
        indices: new Uint16Array(indices)
    };
}

2. Instantiate the Pixi.js Mesh

Once the geometry buffers are constructed, instantiate a PIXI.Mesh using a PIXI.Geometry object and a default material or texture.

import * as PIXI from 'pixi.js';

function createPieSliceMesh(cx, cy, radius, startAngle, endAngle, color) {
    const data = createPieSliceData(cx, cy, radius, startAngle, endAngle);

    const geometry = new PIXI.Geometry()
        .addAttribute('aVertexPosition', data.vertices, 2)
        .addAttribute('aTextureCoord', data.uvs, 2)
        .addIndex(data.indices);

    // Use a blank white texture so mesh tinting works correctly
    const mesh = new PIXI.Mesh(geometry, PIXI.Shader.fromDefault());
    mesh.tint = color;

    return mesh;
}

3. Assemble the Full Pie Chart

To build a complete pie chart, calculate the relative angles for each dataset value, assign unique colors, and append each slice mesh to a parent PIXI.Container.

const app = new PIXI.Application({ width: 800, height: 600, antialias: true });
document.body.appendChild(app.view);

const chartData = [
    { value: 40, color: 0xff5733 },
    { value: 25, color: 0x33ff57 },
    { value: 20, color: 0x3357ff },
    { value: 15, color: 0xf3ff33 }
];

const total = chartData.reduce((acc, item) => acc + item.value, 0);
const chartContainer = new PIXI.Container();

let currentAngle = -Math.PI / 2; // Start from top (12 o'clock)
const radius = 150;
const centerX = 400;
const centerY = 300;

chartData.forEach(slice => {
    const sliceAngle = (slice.value / total) * (Math.PI * 2);
    const nextAngle = currentAngle + sliceAngle;

    const sliceMesh = createPieSliceMesh(
        centerX,
        centerY,
        radius,
        currentAngle,
        nextAngle,
        slice.color
    );

    chartContainer.addChild(sliceMesh);
    currentAngle = nextAngle;
});

app.stage.addChild(chartContainer);

Texture and Shader Mapping

Because the UV coordinates are mapped from (0, 0) at the top-left to (1, 1) at the bottom-right relative to the circle's bounding box, you can replace standard solid color tints with radial gradients or custom textures. Passing a loaded PIXI.Texture into a PIXI.MeshMaterial maps the texture directly over the pie geometry using the calculated UV attributes.
