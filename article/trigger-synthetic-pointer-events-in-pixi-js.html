Trigger Synthetic Pointer Events in Pixi.js

This article explains how to programmatically trigger synthetic pointer events on a Pixi.js display object. Depending on your use case—such as automated testing, custom input integration, or remote control systems—you can trigger events either directly through Pixi's internal event emitter, by dispatching native DOM events to the canvas, or by leveraging Pixi's modern EventBoundary system.

Method 1: Direct Emission via emit()

The simplest and fastest way to trigger a synthetic event is by using the display object's built-in .emit() method. Pixi.js display objects inherit from an event emitter, allowing you to invoke listeners attached via .on() or .addEventListener().

import { Sprite, Texture, FederatedPointerEvent } from 'pixi.js';

const sprite = new Sprite(Texture.WHITE);
sprite.eventMode = 'static'; // Or 'dynamic'

sprite.on('pointerdown', (event) => {
    console.log('Pointer down triggered!', event);
});

// Create a synthetic event object or mock data
const mockEvent = {
    type: 'pointerdown',
    target: sprite,
    currentTarget: sprite,
    global: { x: sprite.x, y: sprite.y }
};

// Emit the event directly
sprite.emit('pointerdown', mockEvent);

Note: Direct emission executes the listener callbacks immediately, but it bypasses hit-testing, coordinate mapping, and event bubbling up the display hierarchy.

Method 2: Dispatching Native DOM Events to the Canvas

To test the entire input pipeline—including hit-testing, cursor interaction, and bubbling—dispatch a native browser PointerEvent directly to the renderer's canvas. Pixi.js will process the synthetic DOM event identically to real user input.

// Ensure the display object is interactive
sprite.eventMode = 'static';
sprite.cursor = 'pointer';

// Calculate the global screen position of the display object
const globalPosition = sprite.toGlobal({ x: 0, y: 0 });

// Find the canvas bounding rect to get client coordinates
const canvas = app.canvas ?? app.view; // app.canvas in v8, app.view in v7
const rect = canvas.getBoundingClientRect();

// Construct a synthetic native PointerEvent
const nativePointerEvent = new PointerEvent('pointerdown', {
    clientX: rect.left + globalPosition.x + sprite.width / 2,
    clientY: rect.top + globalPosition.y + sprite.height / 2,
    bubbles: true,
    cancelable: true,
    pointerType: 'mouse',
    button: 0 // Left click
});

// Dispatch to the canvas element
canvas.dispatchEvent(nativePointerEvent);

This method tests the exact visual location of the display object and verifies whether masking, hit areas, or overlapping display objects affect event delivery.

Method 3: Using the Pixi.js EventBoundary (Pixi v7 & v8)

Pixi.js versions 7 and 8 manage input using the EventSystem and an EventBoundary. You can use the renderer's EventBoundary to dispatch a fully structured FederatedPointerEvent through Pixi's event tree.

import { FederatedPointerEvent } from 'pixi.js';

// Access the EventBoundary from the renderer
const eventBoundary = app.renderer.events.rootBoundary;

// Create a new synthetic FederatedPointerEvent
const syntheticEvent = new FederatedPointerEvent(eventBoundary);
syntheticEvent.type = 'pointerdown';
syntheticEvent.target = sprite;
syntheticEvent.global.set(sprite.x, sprite.y);

// Dispatch the event through the boundary to allow bubbling
eventBoundary.dispatchEvent(syntheticEvent, 'pointerdown');

By dispatching through EventBoundary, the event respects propagation rules (event.stopPropagation()), bubbles up to parent containers, and maintains consistency with Pixi's federated event lifecycle without requiring native DOM event intervention.
