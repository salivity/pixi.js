PixiJS ShockwaveFilter: How Shock Ripples Work

The ShockwaveFilter in PixiJS generates expanding ripple effects by utilizing a custom GLSL fragment shader to dynamically displace texture coordinates based on a radial wave equation. This article breaks down the internal mechanics of the filter, covering the uniform properties involved, the mathematical displacement applied per fragment, and the animation loop required to produce realistic shockwave visuals.

Post-Processing and Coordinate Distortion

The ShockwaveFilter is a post-processing filter. Instead of transforming mesh geometry, it operates on a flattened render texture of the display object to which it is applied.

For every pixel (fragment) rendered on the screen, the shader determines a normalized coordinate space (UV coordinates, spanning from (0, 0) to (1, 1)). To create the illusion of a shockwave traveling through the medium, the shader alters these coordinates before sampling the source texture. If a fragment falls within the active wave boundary, its UV coordinates are shifted inward or outward radially, pulling color data from a neighboring pixel to produce a refraction-like distortion.

Key Shader Uniforms

The wave's behavior is driven by uniforms passed from JavaScript to the fragment shader:

  • center: The origin point [x, y] of the shockwave in pixel coordinates.
  • time: The elapsed time or phase of the wave, driving its outward expansion.
  • speed: The rate at which the wave expands over time.
  • wavelength: The thickness of the ripple ring.
  • amplitude: The strength of the refraction/displacement.
  • radius: The maximum reach of the shockwave before it dissipates.

The Shader Algorithm Step-by-Step

The internal fragment shader executes the following steps for each pixel:

  1. Calculate Distance from Center:
    The shader computes the Euclidean distance between the current fragment coordinate and the center uniform:

    vec2 coord = vTextureCoord;
vec2 dir = coord - center;
float dist = length(dir);

  2. Compute Current Wave Position:
    The shockwave's current expansion distance is calculated using time and speed. This represents the leading edge of the ripple.

  3. Check the Active Wave Region:
    The shader determines whether dist falls inside the ripple zone (between the current wave position and the wave position minus the wavelength). Pixels outside this zone are ignored, maintaining their original texture coordinates.

  4. Calculate Displacement Factor:
    For pixels inside the active zone, the shader applies a sine function across the width of the wave band. This creates a smooth rise-and-fall distortion profile:

    float wavePosition = dist - currentWaveRadius;
float factor = sin(wavePosition * (PI / wavelength));

  5. Apply Radial Offset and Attenuation:
    The displacement direction is calculated as the normalized vector pointing from the center to the fragment. The offset is scaled by amplitude and attenuated over distance or time, so the shockwave gradually flattens and vanishes as it moves farther from the origin:

    vec2 offset = normalize(dir) * (factor * amplitude * decay);
vec2 displacedCoord = coord + offset;

  6. Sample the Source Texture:
    Finally, the shader samples the display object's original texture using the altered coordinate displacedCoord, producing the distorted output pixel.

Driving the Animation

Because shaders are stateless, animation relies on the JavaScript runtime. In PixiJS, the filter is typically animated by updating its time property inside an update ticker:

import { ShockwaveFilter } from 'pixi-filters';

const shockwave = new ShockwaveFilter([app.screen.width / 2, app.screen.height / 2], {
    amplitude: 30,
    wavelength: 160,
    speed: 500,
    radius: 400,
});

container.filters = [shockwave];

app.ticker.add((ticker) => {
    shockwave.time += ticker.deltaTime / 60;

    // Reset or remove filter once it passes its max radius
    if (shockwave.time * shockwave.speed > shockwave.radius) {
        shockwave.time = 0;
    }
});

As time increments, the shader recalculates the expanding wave boundary on each frame, causing the displaced ring of pixels to propagate outward from the designated center point.
