Get Mesh Vertex World Coordinates in Pixi.js

This guide explains how to extract the transformed world coordinates of a specific mesh vertex in Pixi.js. To get the global position of a vertex, you must retrieve its local coordinates from the mesh's geometry buffer and transform them using the mesh’s global transformation matrix. Below, you will find the exact steps and code required to read the raw vertex data, ensure world transforms are up to date, and calculate the final world coordinates accurately.

1. Access the Local Vertex Data

In Pixi.js, mesh vertices are stored as a flat array of numbers representing alternating \((x, y)\) coordinates in local space. You can access this array via the mesh's geometry attributes or directly through the vertex buffer:

// Access the raw vertex buffer
const vertexData = mesh.geometry.getBuffer('aVertexPosition').data;

// Or via the geometry attribute (depending on the Pixi.js version)
// const vertexData = mesh.geometry.getAttribute('aVertexPosition').data;

For a specific vertex index i, its local coordinates are:

const localX = vertexData[i * 2];
const localY = vertexData[i * 2 + 1];

2. Update the Transform Matrix

Pixi.js recalculates transformation matrices during the render pass. If you read transforms outside of the render loop or immediately after moving a parent container, call updateTransform() on the mesh to ensure its matrix matches its current state:

mesh.updateTransform();

3. Transform Local Coordinates to World Space

There are two primary methods to map the local \((x, y)\) coordinate to the world coordinate system:

Method A: Using worldTransform.apply() (Fastest)

The mesh.worldTransform is a PIXI.Matrix object. Its apply method multiplies a local vector by the transformation matrix without allocating a new object, which is ideal for performance-sensitive applications:

import * as PIXI from 'pixi.js';

const localPoint = new PIXI.Point(localX, localY);
const worldPoint = new PIXI.Point();

// Apply the transform
mesh.worldTransform.apply(localPoint, worldPoint);

console.log(`World X: ${worldPoint.x}, World Y: ${worldPoint.y}`);

You can also bypass PIXI.Point entirely by using the matrix equation directly:

const wt = mesh.worldTransform;
const worldX = wt.a * localX + wt.c * localY + wt.tx;
const worldY = wt.b * localX + wt.d * localY + wt.ty;

Method B: Using toGlobal()

The toGlobal() method converts a point from the display object’s local coordinate system directly to world space:

const localPoint = new PIXI.Point(localX, localY);
const worldPoint = mesh.toGlobal(localPoint);

Complete Example Function

Here is a reusable function that returns the world coordinates for any vertex index in a given mesh:

import * as PIXI from 'pixi.js';

function getMeshVertexWorldPosition(mesh, vertexIndex) {
    // 1. Ensure transform hierarchy is calculated
    mesh.updateTransform();

    // 2. Fetch the vertex data buffer
    const vertexData = mesh.geometry.getBuffer('aVertexPosition').data;
    const localX = vertexData[vertexIndex * 2];
    const localY = vertexData[vertexIndex * 2 + 1];

    // 3. Transform local coordinates using the world matrix
    const wt = mesh.worldTransform;
    const worldX = wt.a * localX + wt.c * localY + wt.tx;
    const worldY = wt.b * localX + wt.d * localY + wt.ty;

    return new PIXI.Point(worldX, worldY);
}
