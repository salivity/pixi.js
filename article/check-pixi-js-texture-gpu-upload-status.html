Check Pixi.js Texture GPU Upload Status

In Pixi.js, textures are lazily uploaded to the GPU during their first render pass, which can cause noticeable frame drops or stuttering. This article covers how to force textures to upload ahead of time and how to reliably detect when the GPU upload is complete using the built-in Prepare plugin and low-level renderer texture checks.

Using the Prepare Plugin (Recommended)

The most reliable and idiomatic method to ensure a texture is fully uploaded to the GPU is using Pixi.js's prepare system. The prepare plugin handles asynchronous uploads of textures, base textures, or entire display trees without freezing the main thread.

You can trigger and confirm the upload using a callback:

// Pixi.js v7 / v8
app.renderer.prepare.upload(myTexture, () => {
    console.log("Texture has finished uploading to the GPU.");
});

To use async/await, wrap the prepare.upload method inside a Promise:

function uploadTextureToGPU(renderer, texture) {
    return new Promise((resolve) => {
        renderer.prepare.upload(texture, resolve);
    });
}

// Usage
await uploadTextureToGPU(app.renderer, myTexture);
console.log("Texture GPU upload complete.");

Checking the Internal GPU Binding State

If you need to synchronously query whether a texture already resides in GPU memory without forcing a new upload, you can inspect the internal renderer resources assigned to the texture's source.

Pixi.js v7 (WebGL)

In Pixi.js v7, a base texture retains a map of its WebGL representations keyed by the renderer's CONTEXT_UID. If an entry exists for the active renderer, the texture has been bound and uploaded to that GPU context:

function isTextureUploadedV7(renderer, texture) {
    const baseTexture = texture.baseTexture;
    const glTexture = baseTexture._glTextures[renderer.CONTEXT_UID];

    return Boolean(glTexture && glTexture.texture);
}

Pixi.js v8 (WebGL & WebGPU)

Pixi.js v8 redesigned the resource pipeline around TextureSource. To verify if the underlying GPU resource has been created and initialized:

function isTextureUploadedV8(renderer, texture) {
    const source = texture.source;
    
    // Check if the renderer has allocated a GPU texture for this source
    const gpuTexture = renderer.texture.getGlSource ? 
        renderer.texture.getGlSource(source) : 
        renderer.texture.getGpuSource(source);

    return Boolean(gpuTexture);
}

Forcing Immediate Synchronous Upload

If your application requires the texture to be present on the GPU immediately without waiting for the next render loop or an asynchronous callback, call the texture manager's bind method directly:

// Forces the texture to bind and generate GPU memory immediately
app.renderer.texture.bind(myTexture);

Once renderer.texture.bind() executes, the texture data has been transmitted to the GPU context, making it safe to render in the immediate frame without incurring an upload hitch.
