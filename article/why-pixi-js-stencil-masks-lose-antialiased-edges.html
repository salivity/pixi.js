Why Pixi.js Stencil Masks Lose Antialiased Edges

When using basic stencil masks in Pixi.js, previously smooth, antialiased edges frequently turn jagged and pixelated. This article explains the technical reasons behind this behavior, focusing on how the WebGL stencil buffer functions compared to alpha blending, and highlights the standard workarounds to achieve smooth, masked edges in your renders.

How Basic Stencil Masks Work in WebGL

Pixi.js applies basic masks—such as when assigning a PIXI.Graphics object directly to a display object's mask property—using the underlying WebGL stencil buffer.

The stencil buffer functions as a per-pixel integer scratchpad. When a stencil mask is rendered:

  1. Pixi.js draws the mask geometry exclusively into the stencil buffer rather than the color buffer.
  2. For each pixel covered by the geometry, WebGL writes an integer value (typically 1).
  3. When the masked object is subsequently drawn, WebGL runs a stencil test. If a pixel's stencil value meets the condition (e.g., equals 1), the pixel renders to the screen. If it fails, the pixel is discarded entirely.

The Problem: Binary Pass/Fail vs. Fractional Alpha

Antialiasing relies on partial transparency. To create the visual illusion of a smooth curve or diagonal line on a pixel grid, the edges of a shape are drawn with fractional alpha values between 0.0 (fully transparent) and 1.0 (fully opaque). These semi-transparent edge pixels blend with the background colors underneath them.

The stencil buffer cannot process this fractional data:

  • No Fractional Values: The stencil buffer stores discrete integers, not floating-point alpha values. A pixel either passes the stencil test or fails it.
  • Strict Thresholds: During rasterization of the mask, Pixi.js applies a strict cutoff. WebGL determines whether a pixel center is inside or outside the polygon primitive. Edge pixels that would normally be blended at 25%, 50%, or 75% opacity are forced into a binary outcome: completely visible or completely culled.
  • Overriding Multisampling: Even if hardware antialiasing (MSAA) is enabled on the WebGL canvas, the 1-bit nature of the stencil pass/fail operation discards the intermediate color blending stages of the masked content, producing sharp, aliased "staircase" artifacts along the boundary.

How to Get Smooth Masked Edges in Pixi.js

If your visual design requires smooth, curved, or feathered boundaries, you must bypass the WebGL stencil buffer in favor of alpha-based masking techniques.

1. Use Alpha Masks (Sprite Masks)

Instead of assigning a vector Graphics object directly as a stencil mask, convert it into an alpha mask using a sprite or texture. Alpha masking utilizes the SpriteMaskFilter, which evaluates the red or alpha channel of a texture via a fragment shader. Because shaders compute fractional values from 0.0 to 1.0, the partial transparency of the mask's edges is preserved and smoothly multiplied against the masked object.

2. Custom Fragment Shaders

For procedural shapes (like rounded rectangles or circles), you can write a custom filter or shader that calculates distances using signed distance fields (SDF) and smoothly interpolates the edges using the GLSL smoothstep() function.

3. Render-to-Texture with Downsampling

You can render your content and mask to an intermediate RenderTexture at double resolution (resolution: 2) and scale it down when displayed. Downsampling inherently softens harsh pixel edges, reducing the visual impact of stencil aliasing.
