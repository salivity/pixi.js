Single-Pass Outline and Glow Shaders in PixiJS

This article provides a direct guide on building an outline and glow effect in PixiJS using a single-pass custom fragment shader. You will learn the GLSL logic needed to sample adjacent pixels in a single execution, how to calculate distances for crisp outlines or smooth glows, and how to properly configure the PIXI.Filter in your application without clipping the edges of your display objects.

The Single-Pass Concept

A single-pass outline or glow inspects the alpha channel of pixels surrounding the current fragment (vTextureCoord). If the target pixel has an alpha value lower than the neighboring pixels, the shader determines that the pixel lies on the outer boundary of the sprite.

By taking multiple directional samples at a specific radius:

  • Crisp Outline: Check if any surrounding sample has an alpha above a certain threshold, then render a solid color where the source alpha is low.
  • Glow: Accumulate the alpha values of samples over multiple radii or angles and blend them with an attenuation factor to create a soft falloff.

Because the effect extends outside the original texture's dimensions, you must increase the filter's padding property to prevent the glow or outline from being cut off at the bounding box.

The GLSL Fragment Shader

Below is the GLSL fragment shader code designed for PixiJS. It supports adjustable thickness, color, and a toggle between a hard outline and a smooth glow.

varying vec2 vTextureCoord;
uniform sampler2D uSampler;

uniform vec2 uDimensions; // Width and height of the input texture
uniform vec4 uColor;      // Color of the outline or glow (RGBA)
uniform float uThickness; // Thickness/radius in pixels
uniform int uQuality;     // Number of sample directions (e.g., 8 to 16)
uniform bool uGlow;       // Set true for soft glow, false for hard outline

void main(void) {
    vec4 currentColor = texture2D(uSampler, vTextureCoord);
    vec2 step = (1.0 / uDimensions) * uThickness;
    
    float totalAlpha = 0.0;
    float maxAlpha = 0.0;
    float angleStep = 6.28318530718 / float(uQuality); // Tau / Quality

    for (int i = 0; i < 32; i++) {
        if (i >= uQuality) break;
        
        float angle = float(i) * angleStep;
        vec2 offset = vec2(cos(angle), sin(angle)) * step;
        float sampleAlpha = texture2D(uSampler, vTextureCoord + offset).a;
        
        totalAlpha += sampleAlpha;
        maxAlpha = max(maxAlpha, sampleAlpha);
    }

    if (uGlow) {
        // Soft Glow: Average neighbor alpha and subtract the original alpha to keep inside clean
        float glowFactor = (totalAlpha / float(uQuality)) * (1.0 - currentColor.a);
        vec4 glow = vec4(uColor.rgb * glowFactor, glowFactor * uColor.a);
        gl_FragColor = currentColor + glow;
    } else {
        // Hard Outline: Check if boundary pixel detects opacity
        float outlineFactor = clamp(maxAlpha - currentColor.a, 0.0, 1.0);
        gl_FragColor = mix(currentColor, uColor, outlineFactor);
    }
}

Implementing the Filter in PixiJS

To use this shader, pass it into a PIXI.Filter instance and supply the uniform values.

import * as PIXI from 'pixi.js';

// Fragment shader string from the section above
const fragmentShaderSrc = `...`; 

const outlineFilter = new PIXI.Filter(null, fragmentShaderSrc, {
    uDimensions: new Float32Array([sprite.width, sprite.height]),
    uColor: new Float32Array([1.0, 0.84, 0.0, 1.0]), // Gold outline
    uThickness: 4.0,                                  // 4-pixel radius
    uQuality: 16,                                     // 16 sampling angles
    uGlow: false                                      // False for outline, true for glow
});

// Crucial: Increase padding so the effect doesn't get clipped at sprite boundaries
outlineFilter.padding = 8;

// Apply to a sprite or container
sprite.filters = [outlineFilter];

Handling Texture Dynamic Dimensions and Padding

When working with dynamic bounds, such as an animated sprite or varying container sizes:

  1. Update Dimensions Uniform: Listen to updates or set the uDimensions uniform inside your render loop or resize handler: 
    outlineFilter.uniforms.uDimensions[0] = sprite.texture.orig.width;
outlineFilter.uniforms.uDimensions[1] = sprite.texture.orig.height;
  2. Padding Proportionality: The filter.padding value should always be set to at least the same value as uThickness (and slightly higher if using soft glow falloff) to allow the GPU enough blank space to render the expanded outline pixels.
