Apply Sound Filters with Pixi Sound in PixiJS

This guide explains how to implement and manipulate real-time audio filters—such as low-pass filters and distortion—using the @pixi/sound package in PixiJS. You will learn how to use the built-in filter classes, integrate native Web Audio API nodes for custom filtering, assign filters to individual sounds or the global audio context, and dynamically tweak parameters during runtime to respond to in-game events.

Installing and Importing the Library

To use sound filters, ensure @pixi/sound is installed in your project:

npm install @pixi/sound pixi.js

Import sound and the filters namespace into your project:

import { sound, filters } from '@pixi/sound';

Applying a Built-In Distortion Filter

@pixi/sound includes built-in filter implementations, such as DistortionFilter. This effect adds a wave-shaping distortion effect to audio.

You can apply it directly to a specific sound instance:

// Load a sound asset
sound.add('engine', 'assets/engine.mp3');

// Create the distortion filter (intensity ranges typically from 0 to 1)
const distortion = new filters.DistortionFilter(0.5);

// Apply the filter to the specific sound
const engineSound = sound.find('engine');
engineSound.filters = [distortion];

// Play the sound
engineSound.play({ loop: true });

Creating a Real-Time Low-Pass Filter

@pixi/sound allows you to wrap native Web Audio API nodes using the base filters.Filter class. A low-pass filter cuts higher frequencies, which is commonly used to simulate sound muffled by walls, underwater environments, or paused menus.

Use the Web Audio API's BiquadFilterNode inside a @pixi/sound filter:

// Access the native AudioContext from @pixi/sound
const audioContext = sound.context.audioContext;

// Create a native BiquadFilterNode
const biquadNode = audioContext.createBiquadFilter();
biquadNode.type = 'lowpass';
biquadNode.frequency.setValueAtTime(1000, audioContext.currentTime); // Cutoff frequency in Hz
biquadNode.Q.setValueAtTime(1, audioContext.currentTime); // Quality factor

// Wrap the native node in a Pixi Sound Filter
const lowPassFilter = new filters.Filter(biquadNode);

// Apply to a sound
const backgroundMusic = sound.find('bgm');
backgroundMusic.filters = [lowPassFilter];

Applying Filters Globally

If you want an effect applied to every sound played across the entire game (for example, muffling everything when a pause menu is opened), assign the filter to sound.filtersAll:

// Apply the low-pass filter to all sounds globally
sound.filtersAll = [lowPassFilter];

// Clear global filters to restore normal audio
sound.filtersAll = [];

Modifying Filter Properties in Real Time

Filter parameters can be modified dynamically during the PixiJS render loop or in response to player actions.

Dynamically Modifying Low-Pass Cutoff

Adjusting the frequency parameter of a low-pass filter simulates transitioning between environments:

import { Ticker } from 'pixi.js';

let targetFrequency = 800;

// Update the filter cutoff smoothly inside the PixiJS Ticker
Ticker.shared.add(() => {
    const current = biquadNode.frequency.value;
    biquadNode.frequency.setValueAtTime(
        current + (targetFrequency - current) * 0.05,
        audioContext.currentTime
    );
});

// Example: Muffle the sound when paused
function setUnderwater(isUnderwater) {
    targetFrequency = isUnderwater ? 400 : 20000;
}

Dynamically Modifying Distortion Amount

The DistortionFilter allows direct mutation of its amount property:

// Increase distortion as a character takes damage or boosts speed
function updateEngineDistortion(rpmRatio) {
    distortion.amount = Math.min(Math.max(rpmRatio, 0), 1);
}

Combining Multiple Filters

Multiple filters can be chained together by adding them to the filters array. The audio signal passes sequentially through each filter node:

const distortion = new filters.DistortionFilter(0.2);
const lowPass = new filters.Filter(biquadNode);

// The sound passes through the low-pass filter, then the distortion filter
sound.find('laser').filters = [lowPass, distortion];

To remove active filters and restore raw audio playback, assign an empty array:

sound.find('laser').filters = [];
