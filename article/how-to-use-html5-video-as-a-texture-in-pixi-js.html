How to Use HTML5 Video as a Texture in Pixi.js

This article explains how to bind an HTML5 <video> element to a dynamic texture in Pixi.js. By integrating native video elements into the Pixi.js rendering pipeline, you can project video content onto sprites and meshes for interactive WebGL backgrounds, UI elements, or visual effects.

1. Create and Configure the HTML5 Video Element

Before binding to Pixi.js, instantiate and configure the standard HTML5 <video> element in JavaScript. Most modern browsers restrict unmuted autoplay, so the element should be muted and configured to play inline.

const video = document.createElement('video');

video.src = 'path/to/your-video.mp4';
video.crossOrigin = 'anonymous';
video.loop = true;
video.muted = true;
video.playsInline = true;

// Preload the video data
video.preload = 'auto';

2. Generate a Pixi.js Texture from the Video

Pixi.js provides a built-in mechanism to parse HTML media elements. Pass the video element directly into PIXI.Texture.from() to automatically generate a dynamic VideoResource.

// Create the texture from the video element
const videoTexture = PIXI.Texture.from(video);

// Create a sprite utilizing the video texture
const videoSprite = new PIXI.Sprite(videoTexture);

// Configure sprite dimensions and positioning
videoSprite.width = app.screen.width;
videoSprite.height = app.screen.height;

// Add the sprite to the Pixi stage
app.stage.addChild(videoSprite);

Pixi.js automatically attaches a ticker listener to the underlying VideoResource. Whenever the native video advances a frame, Pixi.js uploads the new frame data directly to the WebGL texture buffer.

3. Controlling Playback

Control the video using standard HTMLMediaElement methods on the original DOM node, or via the source property of the texture's base resource.

// Start playback
video.play().catch((error) => {
    console.error("Autoplay was prevented:", error);
});

// Pause playback
video.pause();

If browser autoplay restrictions prevent the video from playing immediately, trigger video.play() inside a user interaction event listener, such as a pointer click:

window.addEventListener('pointerdown', () => {
    if (video.paused) {
        video.play();
    }
}, { once: true });

4. Resource Cleanup

When the video is no longer required, destroy both the Pixi.js texture and the DOM element to prevent memory leaks in the WebGL context:

// Pause and clear the DOM element source
video.pause();
video.removeAttribute('src');
video.load();

// Destroy the Pixi texture and underlying WebGL resources
videoTexture.destroy(true);
videoSprite.destroy();
