PixiJS Damage Flash: ColorOverlayFilter and Tint

In Pixi.js, visual damage feedback significantly improves combat feel, but relying solely on a sprite's native tint property limits visual impact because tinting operates multiplicatively and cannot turn dark pixels pure white. This article covers how to combine the native tint property with the ColorOverlayFilter from the pixi-filters package to create an immediate, high-contrast hit flash followed by a lingering colored tint.

Why Combine Tint and ColorOverlayFilter?

Pixi.js handles colors using two distinct mechanisms:

  1. Sprite Tint (sprite.tint): Multiplies the underlying texture colors. It works well for persistent status effects (such as poison or burning), but it cannot brighten a sprite beyond its base texture or produce a solid pure white impact flash on colored textures.
  2. ColorOverlayFilter (pixi-filters): Replaces the target’s visible pixels with a solid flat color while preserving the sprite's alpha channel. It excels at instantaneous, bright hit flashes (such as solid white or bright yellow).

By layering them, you can trigger a 100% solid overlay flash on the exact frame of impact, rapidly fade that overlay out, and leave behind a temporary tinted shade (like red) that fades back to normal.

Setting Up ColorOverlayFilter

To use ColorOverlayFilter, install the community filters library or import the specific filter module:

npm install pixi-filters

Then, initialize and attach the filter to your sprite alongside the default tint:

import { Application, Sprite, Assets } from 'pixi.js';
import { ColorOverlayFilter } from 'pixi-filters';

// Initialize filter with color (pure white) and 0 alpha (inactive)
const damageFilter = new ColorOverlayFilter(0xffffff, 0);

// Assign the filter to the target sprite
characterSprite.filters = [damageFilter];

Implementing the Damage Flash Sequence

To achieve a natural hit reaction, structure the flash into three distinct phases:

  1. Impact (Frame 0): Set the ColorOverlayFilter color to pure white (0xffffff) and its alpha to 1.0. Simultaneously change sprite.tint to damage red (0xff4444).
  2. Overlay Dissolve (approx. 50–100ms): Fade the filter's alpha from 1.0 down to 0.0. The solid white disappears, revealing the red-tinted sprite underneath.
  3. Tint Recovery (approx. 100–250ms): Transition the sprite’s tint back from 0xff4444 to default white (0xffffff), returning the character to its normal state.

Code Example

Below is a reusable function using a basic delta-time update loop to control both the filter and the tint:

import { ColorOverlayFilter } from 'pixi-filters';

export function applyDamageEffect(sprite, app) {
  // Ensure the filter exists on the sprite
  let overlay = sprite.filters?.find(f => f instanceof ColorOverlayFilter);
  if (!overlay) {
    overlay = new ColorOverlayFilter(0xffffff, 0);
    sprite.filters = sprite.filters ? [...sprite.filters, overlay] : [overlay];
  }

  // Set initial impact state
  overlay.color = 0xffffff;
  overlay.alpha = 1.0;
  sprite.tint = 0xff3333;

  let elapsed = 0;
  const flashDuration = 0.08; // Duration of solid white in seconds
  const totalDuration = 0.25; // Total duration of the effect

  const updateFlash = (ticker) => {
    const delta = ticker.deltaTime / 60;
    elapsed += delta;

    // Phase 1: Rapidly drop the white overlay
    if (elapsed < flashDuration) {
      overlay.alpha = 1.0 - (elapsed / flashDuration);
    } else {
      overlay.alpha = 0;
    }

    // Phase 2: Fade the tint back to normal (0xffffff)
    if (elapsed >= totalDuration) {
      sprite.tint = 0xffffff;
      overlay.alpha = 0;
      app.ticker.remove(updateFlash);
    }
  };

  app.ticker.add(updateFlash);
}

Performance Considerations

Applying filters incurs an off-screen render pass (FBO switch). To keep your game performant:

  • Do not instantiate a new ColorOverlayFilter on every hit. Create it once and reuse it by modifying its alpha property.
  • If a sprite is not actively flashing, consider setting sprite.filters = [] or removing the filter to bypass unnecessary GPU render passes. Set the filter array only when damage is actively taken.
