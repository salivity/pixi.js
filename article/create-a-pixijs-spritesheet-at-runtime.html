Create a PixiJS Spritesheet at Runtime

Creating a Pixi.js spritesheet dynamically at runtime from an array of images is entirely possible and often necessary when dealing with user-generated content, dynamic skins, or procedurally loaded assets. This process involves drawing loaded source images onto an offscreen HTML5 canvas to pack them into a single texture, defining the corresponding atlas metadata programmatically, and passing both to the Pixi.js Spritesheet class to parse into usable textures.

1. Load the Source Images

Before assembling the spritesheet, the individual images must be fully loaded as HTML image elements.

async function loadImages(urls) {
  const promises = urls.map(url => {
    return new Promise((resolve, reject) => {
      const img = new Image();
      img.crossOrigin = 'anonymous';
      img.onload = () => resolve({ img, id: url });
      img.onerror = reject;
      img.src = url;
    });
  });
  return Promise.all(promises);
}

2. Draw Images to an Offscreen Canvas

Create an offscreen <canvas> element and draw each loaded image onto it. You must calculate the positioning of each frame to pack them cleanly and avoid overlap. Simple horizontal, vertical, or grid placement works well, though dynamic rectangle-packing algorithms can be used for optimal space utilization.

function packImagesToCanvas(loadedImages) {
  let totalWidth = 0;
  let maxHeight = 0;

  // Simple horizontal layout calculation
  loadedImages.forEach(({ img }) => {
    totalWidth += img.width;
    maxHeight = Math.max(maxHeight, img.height);
  });

  const canvas = document.createElement('canvas');
  canvas.width = totalWidth;
  canvas.height = maxHeight;
  const ctx = canvas.getContext('2d');

  const frames = {};
  let currentX = 0;

  loadedImages.forEach(({ img, id }) => {
    ctx.drawImage(img, currentX, 0);

    frames[id] = {
      frame: { x: currentX, y: 0, w: img.width, h: img.height },
      sourceSize: { w: img.width, h: img.height },
      spriteSourceSize: { x: 0, y: 0, w: img.width, h: img.height }
    };

    currentX += img.width;
  });

  return { canvas, frames, width: totalWidth, height: maxHeight };
}

3. Generate the Atlas Metadata

The PIXI.Spritesheet class expects an atlas configuration object describing the frames and general texture metadata. Match the generated canvas dimensions to the metadata:

function generateAtlasData(frames, width, height) {
  return {
    frames: frames,
    meta: {
      scale: '1',
      format: 'RGBA8888',
      size: { w: width, h: height }
    }
  };
}

4. Instantiate and Parse the Spritesheet

Convert the offscreen canvas into a Pixi.js texture, supply it to a new PIXI.Spritesheet alongside your metadata, and parse it asynchronously.

async function createRuntimeSpritesheet(imageUrls) {
  // 1. Load image elements
  const loadedImages = await loadImages(imageUrls);

  // 2. Pack onto a dynamic canvas
  const { canvas, frames, width, height } = packImagesToCanvas(loadedImages);

  // 3. Create atlas metadata
  const atlasData = generateAtlasData(frames, width, height);

  // 4. Create base texture from canvas
  const baseTexture = PIXI.BaseTexture.from(canvas);

  // 5. Initialize and parse the spritesheet
  const spritesheet = new PIXI.Spritesheet(baseTexture, atlasData);
  await spritesheet.parse();

  return spritesheet;
}

5. Using the Dynamic Spritesheet

Once parsed, individual frames can be accessed through the textures property of the created spritesheet instance:

const imageUrls = ['hero.png', 'enemy.png', 'coin.png'];

createRuntimeSpritesheet(imageUrls).then(spritesheet => {
  // Access an individual frame using its identifier
  const heroTexture = spritesheet.textures['hero.png'];
  const sprite = new PIXI.Sprite(heroTexture);
  
  app.stage.addChild(sprite);
});

Key Considerations

  • GPU Texture Limits: Ensure the resulting canvas dimensions do not exceed the WebGL maximum texture size supported by the client device (typically 4096×4096 or 8192×8192 pixels).
  • CORS Settings: If images originate from an external domain, ensure the server returns appropriate Cross-Origin Resource Sharing (CORS) headers, and set crossOrigin = 'anonymous' on the image elements to avoid canvas tainting.
  • Memory Management: When discarding dynamically generated spritesheets, call spritesheet.destroy(true) to release both the frame textures and the underlying canvas texture from GPU memory.
