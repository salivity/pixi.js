How to Mask Text with an Image in Pixi.js

Masking text with an image texture in Pixi.js is an effective way to create visually striking typography filled with photographs, patterns, or gradients. This guide provides a straightforward walkthrough on creating a text object, loading an image texture onto a sprite, and using the text as an alpha mask so the image only shows through the letterforms.

Understanding the Concept

In Pixi.js, any display object can serve as a mask for another display object. To fill text with an image:

  1. Create a Sprite containing the image texture (the fill).
  2. Create a Text object defining the typography (the mask).
  3. Assign the text object to the sprite's .mask property.
  4. Add both elements to the display list.

Step-by-Step Implementation

1. Set Up the Application and Load Assets

First, initialize your Pixi.js application and load the image texture using the Assets manager.

import * as PIXI from 'pixi.js';

const app = new PIXI.Application();
await app.init({ width: 800, height: 600, backgroundColor: 0x1099bb });
document.body.appendChild(app.canvas);

// Load the texture fill
const texture = await PIXI.Assets.load('path/to/your/image.jpg');

2. Create the Image Sprite

Create the sprite using the loaded texture. This sprite acts as the background fill for your letters. Ensure the sprite is large enough to cover the bounds of the text you plan to render.

const fillSprite = new PIXI.Sprite(texture);
fillSprite.width = 800;
fillSprite.height = 600;

3. Create the Text Mask

Instantiate a Text object. The color of the text fill does not matter because Pixi.js utilizes the text's alpha channel to mask the sprite, but setting a solid fill ensures the mask is fully opaque. Use bold or heavy fonts to maximize the visibility of the underlying texture.

const textMask = new PIXI.Text({
    text: 'TEXTURE',
    style: {
        fontFamily: 'Arial',
        fontSize: 120,
        fontWeight: 'bold',
        fill: 0xffffff,
        align: 'center',
    },
});

// Center the text on the screen
textMask.anchor.set(0.5);
textMask.x = app.screen.width / 2;
textMask.y = app.screen.height / 2;

4. Apply the Mask and Add to the Stage

Assign the text object directly to the mask property of your sprite. Finally, add both the sprite and the text mask to the stage.

// Assign the text as the mask
fillSprite.mask = textMask;

// Add elements to the stage
app.stage.addChild(fillSprite);
app.stage.addChild(textMask);

Important Considerations

  • Coordinate Space: Both the sprite and the text mask operate within the coordinate space of their parent container. If you move or animate the sprite, the texture shifts under the text. If you move the text mask, the visible cutout moves across the texture.
  • Adding to Stage: In Pixi.js, the masking object must typically be added to the display tree alongside the masked object to be updated and rendered accurately.
  • Complex Textures: You can also group multiple sprites or animated sprites inside a PIXI.Container and apply the text mask directly to the container (container.mask = textMask) to achieve moving or multi-layered fills.
