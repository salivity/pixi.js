How to Set Anchor Point on a PixiJS Container

In PixiJS, PIXI.Sprite includes an anchor property that normalizes origin points between 0 and 1, but PIXI.Container lacks this feature by default. This guide explains how to achieve anchor point functionality on a standard Container using the native pivot property, and demonstrates how to implement a custom, normalized anchor property directly onto your container instances or via an extended class.

The Difference Between Anchor and Pivot

To simulate an anchor point on a container, you must use the pivot property.

  • Anchor: Uses normalized coordinates between 0.0 (top/left) and 1.0 (bottom/right).
  • Pivot: Uses absolute pixel values to set the origin point around which position, rotation, and scaling occur.

Because pivot operates in pixels, you can calculate the pivot values by multiplying the normalized anchor coordinate by the container's width and height.

Method 1: Manual Calculation Using Pivot

The simplest approach is calculating the pivot coordinates directly from the container's dimensions once all children have been added:

const container = new PIXI.Container();

// Add your children first so the container has dimensions
container.addChild(child1, child2);

// Target anchor values (0.5 represents the center)
const anchorX = 0.5;
const anchorY = 0.5;

// Set pivot using pixel values
container.pivot.x = container.width * anchorX;
container.pivot.y = container.height * anchorY;

// Reposition the container to compensate for the shifted origin
container.position.set(400, 300);

Method 2: Creating an Extensible Container Class

If you need the behavior across multiple containers or want to set normalized values dynamically, extend PIXI.Container with a custom getter and setter:

class AnchoredContainer extends PIXI.Container {
    constructor() {
        super();
        this._anchor = { x: 0, y: 0 };
    }

    get anchor() {
        return this._anchor;
    }

    setAnchor(x, y = x) {
        this._anchor.x = x;
        this._anchor.y = y;
        this.updateAnchor();
    }

    updateAnchor() {
        // Calculate bounds to ensure accurate dimensions
        const bounds = this.getLocalBounds();
        
        this.pivot.x = bounds.x + bounds.width * this._anchor.x;
        this.pivot.y = bounds.y + bounds.height * this._anchor.y;
    }
}

Usage:

const panel = new AnchoredContainer();

panel.addChild(backgroundGraphic);
panel.addChild(buttonGraphic);

// Centers the container's transform point
panel.setAnchor(0.5, 0.5);

panel.position.set(app.screen.width / 2, app.screen.height / 2);
app.stage.addChild(panel);

Important Considerations

  1. Calculate After Adding Children: A PIXI.Container has a width and height of 0 until it contains at least one display object with physical dimensions. Setting pivot values before adding children will result in a pivot point of (0, 0).
  2. Dynamic Content Updates: Unlike a sprite's fixed texture size, a container's dimensions change when children are added, removed, or repositioned. Whenever the bounds of your container change, you must re-calculate the pivot values using the latest dimensions to maintain the relative anchor position.
  3. Use getLocalBounds(): Instead of relying strictly on container.width and container.height, using container.getLocalBounds() accounts for negative coordinate offsets of child objects within the container, preventing misalignment issues.
