How to Use Custom CSS Cursors in Pixi.js

This guide explains what the cursor property is in Pixi.js and demonstrates how to implement both standard and custom CSS cursor styles on interactive display objects. You will learn how the Pixi.js event system manages cursor states, how to assign built-in CSS cursor values, and how to register bespoke cursor definitions using images or custom CSS properties across your canvas application.

The cursor Property in Pixi.js

In Pixi.js, the cursor property is a string-based attribute available on any display object, such as a Container, Sprite, or Graphics. It dictates what the mouse cursor should look like when a user hovers over that specific object.

For the cursor property to take effect, the object must be interactive. In modern Pixi.js (v7 and v8), you enable interactivity by setting the object's eventMode property to 'static' or 'dynamic'. Once interactivity is active, Pixi's event system automatically reads the object's cursor value upon pointer entry and applies the corresponding CSS style to the canvas element.

import { Application, Sprite, Assets } from 'pixi.js';

const app = new Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

const texture = await Assets.load('button.png');
const button = new Sprite(texture);

// Enable interaction
button.eventMode = 'static';

// Set standard CSS cursor
button.cursor = 'pointer';

app.stage.addChild(button);

Using Standard CSS Cursors

Pixi.js natively supports standard CSS cursor strings out of the box. Any valid CSS cursor keyword—such as 'pointer', 'grab', 'grabbing', 'crosshair', 'text', 'not-allowed', or 'wait'—can be assigned directly to the cursor property without additional configuration:

sprite.eventMode = 'static';
sprite.cursor = 'crosshair';

Registering Custom CSS Cursor Styles

To use custom graphics (like PNG or SVG files) as cursors, or to define unique CSS cursor behaviors, you must register them in the Pixi.js event system using the cursorStyles dictionary.

In Pixi.js, cursor mappings are managed via app.renderer.events.cursorStyles. You can add your own key to this object, mapping a custom name to any valid CSS cursor rule, including the url() syntax with fallback options and coordinates.

Step 1: Define the Custom Cursor Style

Map a custom cursor identifier to a CSS cursor declaration:

// Register a custom image cursor with an offset hotspot (x: 0, y: 0) and fallback to 'auto'
app.renderer.events.cursorStyles['sword'] = 'url("assets/sword-cursor.png") 0 0, auto';

// Register another custom cursor using standard CSS fallback
app.renderer.events.cursorStyles['target'] = 'url("assets/crosshair.cur"), crosshair';

Step 2: Assign the Custom Style to an Object

After registering the identifier in cursorStyles, set your display object's cursor property to match the custom key:

const enemy = new Sprite(enemyTexture);

enemy.eventMode = 'static';
enemy.cursor = 'sword';

app.stage.addChild(enemy);

When the user hovers over the enemy sprite, Pixi.js resolves 'sword' in cursorStyles and updates the canvas element's style attribute to cursor: url("assets/sword-cursor.png") 0 0, auto;. When the pointer leaves the object, the canvas cursor automatically reverts to the default style.
