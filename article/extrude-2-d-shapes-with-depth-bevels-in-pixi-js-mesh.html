Extrude 2D Shapes with Depth Bevels in Pixi.js Mesh

This article explores whether you can render extruded 2D shapes with depth bevels using the Pixi.js Mesh class, detailing how Pixi's low-level geometry pipeline can handle 3D extruded data, what limitations exist natively within the engine, and the steps required to generate the necessary geometry and shaders.

While Pixi.js is primarily a 2D rendering engine, you can render extruded 2D shapes with depth and bevels using the Mesh class. However, Pixi.js does not provide a built-in extrusion or beveling generator out of the box like dedicated 3D engines such as Three.js. Achieving this effect requires programmatic geometry generation and custom rendering logic.

1. Generating Extruded and Beveled Geometry

The Pixi.js Mesh class relies on a Geometry object comprised of vertex buffers (positions, UVs, normals, and indices). To create an extruded shape with bevels, you must construct these buffers manually:

  • Front and Back Caps: Define a 2D polygon path, inset it slightly for the bevel start, and triangulate the interior using a triangulation algorithm like Earcut.
  • Beveled Edges: Generate transitional quad strips between the flat front face and the outer edge. This is achieved by offsetting the 2D contour points inward/outward while stepping the Z-coordinate depth.
  • Extrusion Walls: Connect the perimeter vertices of the front bevel to the corresponding back bevel using quad strips (two triangles per segment) along the Z-axis.
  • Normals Calculation: Calculate surface normals for each vertex, particularly across the bevel transitions, to ensure proper light reflection.

2. Handling 3D Coordinates in Pixi.js

Standard Pixi.js meshes use 2D positions ([x, y]). Because an extruded beveled shape requires depth, your vertex buffer must either supply 3D positions ([x, y, z]) or encode depth information into a custom vertex attribute.

To use 3D coordinates, construct a custom PIXI.Geometry instance:

  • Add an attribute for vertex positions containing three floats per vertex (x, y, z).
  • Add a normal attribute (nx, ny, nz) to calculate lighting across the bevel angles.
  • Supply an index buffer that defines how the vertices form triangles.

3. Shading and Lighting

Default Pixi.js materials and shaders discard the Z-axis and lack lighting calculations. To make the bevels visually apparent, you must assign a custom PIXI.Shader to your mesh:

  • Vertex Shader: Multiply the 3D vertex positions by a custom Model-View-Projection (MVP) matrix to provide perspective or isometric projection. Pass calculated normals and light direction vectors to the fragment shader.
  • Fragment Shader: Implement a basic lighting model, such as Phong or Blinn-Phong, to shade the beveled edges distinctly from the flat caps. Without lighting or baked vertex colors, the bevels will appear flat regardless of the geometry.

Conclusion

Using the Pixi.js Mesh class to render extruded, beveled shapes is fully viable, but Pixi.js only acts as the GPU interface for rendering the buffers. You must handle the algorithmic extrusion, triangulation, normal generation, and 3D projection shaders yourself, or pre-compute the geometry using an external 3D utility before passing it to Pixi.js.
