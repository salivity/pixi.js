Masking ParticleContainer with Graphics in PixiJS

You cannot directly assign a Graphics mask to a ParticleContainer in PixiJS, but you can achieve this effect by wrapping the ParticleContainer inside a standard Container. This article explains why this limitation exists and provides a straightforward code solution to successfully mask high-performance particle systems using a Graphics object.

Why ParticleContainer Cannot Be Masked Directly

The ParticleContainer in PixiJS is a specialized, lightweight container built for maximum rendering performance. To render thousands of sprites at 60 FPS, it bypasses many standard PixiJS display pipeline features, including filters, complex hierarchies, and stencil masks. Because of these low-level WebGL optimizations, assigning a mask directly to particleContainer.mask will fail to render properly or have no effect.

The Solution: The Wrapper Container Pattern

The standard and most efficient workaround is to place the ParticleContainer inside a regular PIXI.Container and apply your PIXI.Graphics mask to that parent container.

A regular container uses the full PixiJS scene graph capabilities, allowing it to utilize WebGL stencil buffers or scissor masks properly while still batch-rendering all particles inside.

Implementation Example

Here is a practical implementation in JavaScript:

// 1. Create your application
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// 2. Create the parent container
const parentContainer = new PIXI.Container();
app.stage.addChild(parentContainer);

// 3. Create the ParticleContainer and add it to the parent
const particleContainer = new PIXI.ParticleContainer(10000, {
    scale: true,
    position: true,
    rotation: true,
    uvs: true,
    alpha: true
});
parentContainer.addChild(particleContainer);

// 4. Populate the ParticleContainer with sprites
const texture = PIXI.Texture.from('path/to/particle.png');
for (let i = 0; i < 1000; i++) {
    const sprite = new PIXI.Sprite(texture);
    sprite.x = Math.random() * app.screen.width;
    sprite.y = Math.random() * app.screen.height;
    particleContainer.addChild(sprite);
}

// 5. Create the Graphics shape to act as the mask
const maskShape = new PIXI.Graphics();
maskShape.beginFill(0xffffff);
maskShape.drawCircle(400, 300, 150);
maskShape.endFill();

// 6. Add the mask shape to the stage and assign it to the parent container
app.stage.addChild(maskShape);
parentContainer.mask = maskShape;

Performance Considerations

While wrapping the ParticleContainer solves the masking issue, keep these factors in mind:

  • Stencil Overhead: Using a Graphics mask activates the WebGL stencil buffer, which incurs a slight performance penalty compared to unmasked rendering.
  • Rectangular Bounds Optimization: If your mask is a simple rectangle, consider using parentContainer.filterArea or a rectangular scissor mask rather than a complex vector shape to improve rendering efficiency.
  • Dynamic Masks: If the mask moves or updates shape frequently, animate the Graphics object directly without needing to rebuild or re-mask the particle structure.
