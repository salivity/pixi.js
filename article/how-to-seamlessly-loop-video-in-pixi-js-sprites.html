How to Seamlessly Loop Video in Pixi.js Sprites

Seamlessly looping a video texture in Pixi.js requires proper configuration of the underlying HTML5 video element and optimal video encoding. This guide demonstrates how to configure an HTML5 video for background playback, import it as a PIXI.Texture, map it to a PIXI.Sprite, and eliminate visual stutters during loop resets.

1. Configure the HTML5 Video Element

Pixi.js creates video textures from native HTML5 <video> elements. To achieve a smooth loop without permission or buffering delays, configure the video element programmatically before passing it to Pixi.js:

const video = document.createElement('video');
video.src = 'path/to/your-video.mp4';
video.crossOrigin = 'anonymous';
video.loop = true;
video.muted = true;
video.playsInline = true;
video.preload = 'auto';

// Ensure playback begins when data is ready
video.play();

Setting muted = true and playsInline = true is required by modern browsers to allow autoplay without user interaction.

2. Create the Pixi.js Video Texture and Sprite

Once the video element is initialized, convert it into a Pixi.js texture using PIXI.Texture.from() and assign it to a sprite:

import * as PIXI from 'pixi.js';

const app = new PIXI.Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

// Create the texture from the video element
const videoTexture = PIXI.Texture.from(video);

// Create the sprite and add it to the stage
const videoSprite = new PIXI.Sprite(videoTexture);
videoSprite.width = app.screen.width;
videoSprite.height = app.screen.height;

app.stage.addChild(videoSprite);

Pixi.js automatically hooks into the video's render loop and updates the WebGL texture on every frame.

3. Eliminate Loop Stutters

If a noticeable freeze or black frame occurs when the video loops, apply the following adjustments:

  • Video Encoding: Ensure the video's first and last frames match. Encode the video with keyframes placed at both the very beginning and the very end of the file. Use short GOP (Group of Pictures) sizes in your encoder (e.g., Handbrake or FFmpeg) to minimize seek latency when the player returns to time zero.
  • Remove Unused Audio Tracks: Even if muted, a video containing an audio track can cause a micro-stutter while audio and video sync clocks align. Strip the audio stream completely during encoding if the video is purely visual.
  • Listen for the Ready State: Wait until the browser has buffered enough data before displaying the sprite:
video.addEventListener('canplaythrough', () => {
    video.play();
});

4. Advanced: Crossfading Two Videos

For high-resolution videos where browser hardware decoding still causes a dropped frame at loop boundaries, use two identical video elements on two separate sprites and alternate playback:

  1. Start Sprite A.
  2. Shortly before Sprite A ends, start Sprite B at time zero.
  3. Fade out Sprite A while fading in Sprite B using Pixi's sprite.alpha.
  4. Swap their roles when Sprite B nears its end.
