Pass 3D Textures in Pixi.js WebGPU Pipeline

Rendering volumetric data with Pixi.js requires leveraging the modern WebGPU backend introduced in Pixi.js v8. This guide explains how to allocate a 3D texture, populate it with scalar voxel data, bind the texture to a custom WebGPU shader pipeline, and sample it using raymarching in WGSL. By interfacing Pixi.js with the underlying WebGPU device, you can bypass standard 2D sprite limitations to render dense volumetric clouds, medical scans, or procedural fog.

1. Initialize Pixi.js with WebGPU Support

Ensure Pixi.js uses WebGPU as its active rendering context. Set the preference property to 'webgpu' during application initialization.

import { Application, Mesh, Geometry, Shader } from 'pixi.js';

const app = new Application();
await app.init({
    width: 800,
    height: 600,
    preference: 'webgpu',
});
document.body.appendChild(app.canvas);

2. Allocate and Write the 3D Texture

Pixi.js manages 2D textures natively, but WebGPU 3D textures (dimension: '3d') often require direct access to the underlying GPUDevice. Access the device via app.renderer.gpu.device to create the texture and upload volumetric byte arrays.

const device = app.renderer.gpu.device;

const width = 64;
const height = 64;
const depth = 64;

// Generate raw 3D density data (e.g., a sphere inside a 64x64x64 grid)
const rawData = new Uint8Array(width * height * depth);
for (let z = 0; z < depth; z++) {
    for (let y = 0; y < height; y++) {
        for (let x = 0; x < width; x++) {
            const dx = (x / width) - 0.5;
            const dy = (y / height) - 0.5;
            const dz = (z / depth) - 0.5;
            const dist = Math.sqrt(dx * dx + dy * dy + dz * dz);
            const index = x + y * width + z * width * height;
            rawData[index] = dist < 0.35 ? 255 : 0;
        }
    }
}

// Create the WebGPU 3D Texture
const gpuTexture3D = device.createTexture({
    size: [width, height, depth],
    dimension: '3d',
    format: 'r8unorm',
    usage: GPUTextureUsage.TEXTURE_BINDING | GPUTextureUsage.COPY_DST,
});

// Upload the raw volumetric buffer
device.queue.writeTexture(
    { texture: gpuTexture3D },
    rawData,
    { bytesPerRow: width, rowsPerImage: height },
    { width, height, depth }
);

const texture3DView = gpuTexture3D.createView({ dimension: '3d' });

3. Construct the WGSL Volumetric Raymarching Shader

Write a WGSL shader that defines a texture_3d<f32> resource and an associated sampler. The fragment shader casts rays through the normalized bounding volume ([0, 1] range) and accumulates density samples.

const wgslSource = `
struct VertexOutput {
    @builtin(position) position: vec4<f32>,
    @location(0) uv: vec2<f32>,
};

@vertex
fn mainVs(@location(0) aPosition: vec2<f32>, @location(1) aUV: vec2<f32>) -> VertexOutput {
    var output: VertexOutput;
    output.position = vec4<f32>(aPosition, 0.0, 1.0);
    output.uv = aUV;
    return output;
}

@group(0) @binding(0) var volumeTexture: texture_3d<f32>;
@group(0) @binding(1) var volumeSampler: sampler;

@fragment
fn mainFs(@location(0) uv: vec2<f32>) -> @location(0) vec4<f32> {
    var rayOrigin = vec3<f32>(uv.x, uv.y, 0.0);
    var rayDir = vec3<f32>(0.0, 0.0, 1.0);
    var accumulatedColor = vec4<f32>(0.0);
    var stepSize = 0.01;

    for (var i: i32 = 0; i < 100; i = i + 1) {
        var samplePos = rayOrigin + rayDir * (f32(i) * stepSize);
        if (any(samplePos < vec3<f32>(0.0)) || any(samplePos > vec3<f32>(1.0))) {
            break;
        }

        var density = textureSample(volumeTexture, volumeSampler, samplePos).r;
        var sampleColor = vec4<f32>(density, density, density, density * 0.1);
        accumulatedColor = accumulatedColor + sampleColor * (1.0 - accumulatedColor.a);

        if (accumulatedColor.a >= 0.95) {
            break;
        }
    }

    return accumulatedColor;
}
`;

4. Create the Custom Bindings and Mesh

Create a sampler using the WebGPU device, build the custom Pixi.js Shader, and render a screen-aligned quad.

const sampler = device.createSampler({
    magFilter: 'linear',
    minFilter: 'linear',
    mipmapFilter: 'linear',
});

// Define a full-screen quad geometry
const geometry = new Geometry({
    attributes: {
        aPosition: [-1, -1, 1, -1, 1, 1, -1, 1],
        aUV: [0, 0, 1, 0, 1, 1, 0, 1],
    },
    indexBuffer: [0, 1, 2, 0, 2, 3],
});

// Configure the Pixi.js WebGPU Shader
const shader = Shader.from({
    gpu: {
        vertex: {
            source: wgslSource,
            entryPoint: 'mainVs',
        },
        fragment: {
            source: wgslSource,
            entryPoint: 'mainFs',
        },
    },
    resources: {
        volumeTexture: texture3DView,
        volumeSampler: sampler,
    },
});

const volumeMesh = new Mesh({ geometry, shader });
app.stage.addChild(volumeMesh);

5. Memory Management and Updates

When updating the volume, call device.queue.writeTexture with the modified slice offsets or updated volumetric buffers. If the texture dimensions change, call gpuTexture3D.destroy() and regenerate both the 3D texture and its GPUTextureView before updating the shader's resource bindings.
