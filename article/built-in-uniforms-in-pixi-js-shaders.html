Built-in Uniforms in Pixi.js Shaders

When writing custom shaders in Pixi.js, the rendering engine automatically provides several built-in uniforms to streamline rendering without requiring manual binding. This article outlines the default uniforms injected into both standard mesh shaders and filter shaders, detailing their types, purposes, and how Pixi.js handles them behind the scenes.

Standard Mesh and Material Uniforms

When using custom shaders with Mesh, SimpleMesh, or a standard Shader program, Pixi.js provides core transformation and projection matrices to transform 2D vertices into WebGL clip space.

uniform mat3 uProjectionMatrix

The projection matrix maps 2D coordinates to WebGL normalized device coordinates (NDC) spanning from -1 to 1. It accounts for screen resolution, render targets, and whether coordinates need to be flipped vertically depending on the render destination (framebuffer vs. screen).

uniform mat3 uTranslationMatrix

Also referred to as the world transform matrix in different pipeline versions, this matrix represents the combined transformation (position, rotation, scale, and skew) of the display object. Vertex positions in local space are multiplied by this matrix to position them correctly in world space.

uniform sampler2D uSampler

The primary texture sampler bound to the mesh or sprite. Pixi.js automatically associates the active texture unit with this sampler when drawing textured geometry.

uniform vec4 uColor / uniform float uAlpha

Depending on the material configuration, Pixi.js injects tint and transparency data. uColor typically holds premultiplied RGBA values, while uAlpha passes the combined alpha value derived from parent containers.

Filter Shader Built-In Uniforms

Pixi.js features an advanced post-processing filter system. When creating custom shaders via the Filter class, the engine automatically calculates and binds several uniforms tailored to screen-space operations.

uniform sampler2D uSampler

The input texture passed into the filter. This represents the off-screen render target containing the rendered visual output of the target display object before the filter is applied.

uniform mat3 uProjectionMatrix

A specialized projection matrix mapped specifically to the filter's target bounds and render texture dimensions.

uniform vec4 filterArea

Contains the position and dimensions of the filter area in canvas coordinate space:

  • filterArea.xy: The top-left offset coordinates (x, y) of the filtered region.
  • filterArea.zw: The dimensions (width, height) of the filtered region.

uniform vec4 filterClamp

Used to prevent texture bleeding and sampling artifacts when reading from pooled framebuffers. It specifies the safe sampling bounds:

  • filterClamp.xy: Minimum normalized UV coordinates (minU, minV).
  • filterClamp.zw: Maximum normalized UV coordinates (maxU, maxV).

uniform vec4 inputSize

Provides the dimensions and inverse dimensions of the input render texture:

  • inputSize.xy: Total pixel width and height of the input texture.
  • inputSize.zw: Inverse dimensions (1.0 / width, 1.0 / height), useful for calculating single-pixel offsets in fragment shaders without runtime division.

uniform vec4 outputFrame

Represents the screen-space rectangle where the filtered output is drawn:

  • outputFrame.xy: The top-left destination position.
  • outputFrame.zw: The destination width and height.

uniform vec4 uGlobalFrame

Provides the global screen dimensions and offset of the main renderer viewport, allowing screen-locked effects such as vignettes or CRT scanlines to align consistently regardless of object transformations.

Automatic Injection Mechanics

Pixi.js injects these uniforms through its internal UniformGroup and shader template preprocessors. When a shader is compiled, default vertex shaders automatically declare matrices like uProjectionMatrix and uTranslationMatrix. If a custom vertex shader is supplied, these declarations must be included in the code so Pixi.js can successfully locate and populate the WebGL uniform locations during draw calls.
