How CRTFilter Simulates Retro Scanlines in PixiJS

The CRTFilter in the pixi-filters library provides developers with an easy-to-use shader effect to replicate the distinct aesthetic of vintage cathode-ray tube displays within a PixiJS application. This article covers what the CRTFilter is, how its underlying fragment shader algorithmically generates realistic scanlines, and the additional visual properties it uses to create an authentic retro television screen.

What is the CRTFilter?

pixi-filters is an official collection of specialized WebGL post-processing filters for PixiJS, extending the library's built-in filtering capabilities. Within this collection, CRTFilter is a dedicated post-processing filter designed to mimic the physical characteristics and artifacts of legacy analog CRT monitors and television sets.

When applied to a PixiJS Container or Sprite, the filter renders the source texture through a custom WebGL fragment shader before drawing it to the screen. This allows developers to introduce stylized visual degradation—such as scanlines, curvature, static noise, and color bleed—without altering the underlying game or application assets.

How the CRTFilter Simulates Scanlines

In physical CRT monitors, an electron beam scans across the inside of a phosphor-coated glass screen line by line. The spaces between these active beam sweeps appear as subtle, dark horizontal bands commonly referred to as scanlines.

The CRTFilter simulates this phenomenon purely through mathematical operations inside its fragment shader:

  1. Coordinate Mapping: The shader samples the vertical coordinate (\(y\)) of the current pixel relative to the resolution of the screen or targeted display area.
  2. Periodic Intensity Modulation: By passing the vertical coordinate into a periodic trigonometric function (such as a sine wave) or a modulo function, the shader calculates an alternating intensity factor.
  3. Color Darkening: The fragment shader multiplies the target pixel's RGB color values by this calculated intensity factor. Peaks in the wave retain full brightness, while troughs are dimmed according to a contrast ratio. This produces evenly spaced, alternating bright and dark horizontal strips.

The filter provides configurable parameters to control this effect:

  • lineWidth: Determines the thickness of the individual scanlines.
  • lineContrast: Dictates the contrast or darkness of the gaps between scanlines, ranging from faint lines to sharp, high-contrast bands.
  • verticalScanline: A boolean property that allows scanlines to run vertically instead of horizontally, simulating specialized arcade monitors.

Supporting CRT Visual Artifacts

While scanlines are the primary component of the retro look, the CRTFilter combines several other optical and hardware quirks to achieve complete realism:

  • Screen Curvature: CRT monitors featured curved glass faces. The filter uses barrel distortion to warp the texture coordinates outward from the center, bending straight lines near the screen edges.
  • Vignetting: Real CRTs suffer from uneven brightness distribution, where the corners and edges appear darker than the center. The filter applies a radial gradient that darkens pixel values as their distance from the screen center increases.
  • Noise and Grain: Analog signals inherently carry electrical interference. The filter can introduce animated, pseudo-random noise across the frame using a continuous time input.
  • Chromatic Aberration: Electron beams in color CRTs often fail to align perfectly at the outer edges of the screen. The filter offsets the red, green, and blue color channels slightly from one another to replicate this color-fringing effect.

Implementing the Filter

To use the filter, developers install the pixi-filters package and assign an instance of CRTFilter to the filters array of any PixiJS display object:

import { Application, Container } from 'pixi.js';
import { CRTFilter } from 'pixi-filters';

const app = new Application();
await app.init({ width: 800, height: 600 });

const crt = new CRTFilter({
    lineWidth: 1.0,
    lineContrast: 0.25,
    curvature: 2.0,
    noise: 0.1,
    vignetting: 0.3,
    time: 0
});

app.stage.filters = [crt];

// Animate noise and scanline jitter
app.ticker.add((ticker) => {
    crt.time += ticker.deltaTime;
});

By adjusting these properties, developers can range their aesthetic from subtle nostalgic warmth to heavily distorted, broken arcade displays.
