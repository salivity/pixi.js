Custom Circle and Polygon hitArea in Pixi.js

PixiJS defaults to rectangular bounding boxes for input interactions, which can cause unwanted pointer events when dealing with irregular or circular graphics. By assigning a PIXI.Circle or PIXI.Polygon instance to a display object's hitArea property, you can restrict pointer events strictly to specific geometric boundaries. This guide demonstrates how to configure circular and polygonal hit areas to improve interaction accuracy in your PixiJS projects.

Enabling Interactivity

Before defining a custom hitArea, ensure the target display object is configured to listen for pointer events. In PixiJS v7 and later, set eventMode to 'static' (or 'dynamic'). In older versions, set interactive = true.

const sprite = PIXI.Sprite.from('target.png');
sprite.eventMode = 'static';
sprite.cursor = 'pointer';

Using PIXI.Circle as a hitArea

A circular hit area is ideal for round sprites, buttons, or radial UI elements. The PIXI.Circle constructor accepts three parameters: the local x-coordinate of the center, the local y-coordinate of the center, and the radius.

// Syntax: new PIXI.Circle(x, y, radius)
const circleRadius = 50;

// Center the hit area relative to the object's origin (0, 0)
sprite.hitArea = new PIXI.Circle(circleRadius, circleRadius, circleRadius);

sprite.on('pointerdown', () => {
    console.log('Clicked inside the circular hitArea');
});

If the sprite's anchor is set to (0.5, 0.5), the local origin is at the visual center of the sprite. In this scenario, define the center of the circle at (0, 0):

sprite.anchor.set(0.5);
sprite.hitArea = new PIXI.Circle(0, 0, circleRadius);

Using PIXI.Polygon as a hitArea

For complex, irregular, or non-axis-aligned shapes (such as triangles, stars, or isometric tiles), use PIXI.Polygon. The constructor accepts coordinates as a flat array of numbers ([x1, y1, x2, y2, ...]), individual numeric arguments, or an array of PIXI.Point objects.

Flat Array of Coordinates

// Defines a triangular hit area
const trianglePoints = [
    50, 0,   // Top vertex
    100, 100, // Bottom-right vertex
    0, 100    // Bottom-left vertex
];

sprite.hitArea = new PIXI.Polygon(trianglePoints);

sprite.on('pointerdown', () => {
    console.log('Clicked inside the polygon hitArea');
});

Array of PIXI.Point Objects

const points = [
    new PIXI.Point(50, 0),
    new PIXI.Point(100, 100),
    new PIXI.Point(0, 100)
];

sprite.hitArea = new PIXI.Polygon(points);

The polygon automatically closes itself by connecting the final point back to the first point.

Important Considerations

  • Local Coordinates: The coordinates passed to PIXI.Circle and PIXI.Polygon are strictly in the local coordinate space of the display object, not the global stage coordinates.
  • Hit Area Isolation: When a hitArea is assigned, PixiJS bypasses texture transparency checks and child display objects when performing hit testing on that object. Hit detection is evaluated entirely within the defined geometric shape.
  • Debugging: To visually verify the location and scale of your hitArea, render an identical shape using PIXI.Graphics with a semi-transparent fill and add it as a child to the display object.
