Orthogonal vs Isometric Tilemap Math in Pixi.js

This article explains the fundamental differences between orthogonal and isometric tilemap rendering mathematics in Pixi.js. You will learn the coordinate transformation formulas used to convert grid coordinates into screen coordinates, the inverse formulas required for mouse picking, and how depth sorting (z-indexing) differs between both projection models when building 2D grid-based engines.

Coordinate Spaces

Both rendering techniques rely on two primary coordinate spaces:

  • Grid/Map Coordinates \((x, y)\): Integer values representing the discrete row and column positions of a tile.
  • Screen/World Coordinates \((px, py)\): Floating-point values representing the actual pixel position of a PIXI.Sprite or vertex in the Pixi.js scene graph.

The math dictates how vectors map between these two spaces.

Orthogonal Tilemap Math

Orthogonal tilemaps use a standard Cartesian 2D projection. The axes are perpendicular (\(90^\circ\)), making calculations direct linear multiplications.

Grid to Screen Projection

To place a tile at grid index \((x, y)\) with dimensions \(W\) (tile width) and \(H\) (tile height):

\[px = x \times W\] \[py = y \times H\]

In Pixi.js, you directly assign these values to the sprite:

sprite.x = tileX * tileWidth;
sprite.y = tileY * tileHeight;

Screen to Grid (Hit-Testing)

To determine which tile a user clicked on based on mouse coordinates \((px, py)\):

\[x = \lfloor px / W \rfloor\] \[y = \lfloor py / H \rfloor\]

In JavaScript:

const tileX = Math.floor(mouseX / tileWidth);
const tileY = Math.floor(mouseY / tileHeight);

Isometric Tilemap Math

Isometric tilemaps simulate a 3D perspective by rotating the grid \(45^\circ\) and compressing the vertical axis, typically using a 2:1 width-to-height ratio (dimetric projection).

Grid to Screen Projection

Because the \(x\) and \(y\) grid axes are rotated relative to the screen axes, both grid coordinates contribute to both screen dimensions:

\[px = (x - y) \times \frac{W}{2}\] \[py = (x + y) \times \frac{H}{2}\]

In Pixi.js:

const halfWidth = tileWidth / 2;
const halfHeight = tileHeight / 2;

sprite.x = (tileX - tileY) * halfWidth;
sprite.y = (tileX + tileY) * halfHeight;

Screen to Grid (Hit-Testing)

Converting screen coordinates back to an isometric grid requires solving a system of linear equations:

\[x = \frac{\frac{px}{W / 2} + \frac{py}{H / 2}}{2}\] \[y = \frac{\frac{py}{H / 2} - \frac{px}{W / 2}}{2}\]

In JavaScript:

const halfWidth = tileWidth / 2;
const halfHeight = tileHeight / 2;

const tileX = Math.floor((mouseX / halfWidth + mouseY / halfHeight) / 2);
const tileY = Math.floor((mouseY / halfHeight - mouseX / halfWidth) / 2);

Depth Sorting and Z-Index

Orthogonal Rendering

In orthogonal maps, flat ground tiles rarely overlap. Rendering can occur linearly from left-to-right and top-to-bottom. If layers exist (e.g., ground vs. objects), separating them into distinct PIXI.Container instances is usually sufficient.

Isometric Rendering

Because isometric tiles overlap diagonally, incorrect rendering order causes near tiles to be occluded by far tiles.

To resolve this in Pixi.js, enable sortableChildren = true on the parent container and calculate the zIndex dynamically:

// A higher sum of (tileX + tileY) indicates the tile is closer to the viewer
sprite.zIndex = tileX + tileY;

For entities with variable height or dimensions occupying multiple grid spaces, you must factor in the base elevation and current height:

sprite.zIndex = tileX + tileY + elevation;

Summary of Differences

Feature Orthogonal Math Isometric Math
Projection Angle \(90^\circ\) (standard Cartesian) \(45^\circ\) diamond (commonly 2:1 aspect ratio)
Grid to Screen \(x \times W\), \(y \times H\) \((x - y) \times \frac{W}{2}\), \((x + y) \times \frac{H}{2}\)
Axis Independence \(x\) affects only \(px\); \(y\) affects only \(py\) Both \(x\) and \(y\) affect both \(px\) and \(py\)
Depth Sorting Simple layer separation Distance-based sorting using \(x + y\)
Mouse Picking Direct bounding box division Transformed diamond-grid equation
