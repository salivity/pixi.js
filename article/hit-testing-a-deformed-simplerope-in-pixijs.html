Hit Testing a Deformed SimpleRope in PixiJS

This article explains how to implement accurate, pixel-level hit testing on a deformed PIXI.SimpleRope in PixiJS. By default, PixiJS uses axis-aligned bounding boxes (AABBs) for basic interaction checks, which causes false-positive hits when a rope bends or twists. To achieve precise interaction, you must test whether an interaction point falls within any of the deformed triangle meshes generated by the rope's geometry.

The Problem with Default Hit Testing

A SimpleRope generates dynamic mesh vertices along a set of control points. While the visual representation curves and deforms, the display object's native containsPoint or bounding-box calculations do not check individual triangles. Clicking anywhere inside the rectangular area encompassing the outer bounds of the entire curve triggers interaction events, even if the user clicks on empty space between bends.

The Solution: Triangle Hit Testing

To accurately hit-test a deformed rope, override the containsPoint method on your SimpleRope instance. The algorithm requires three steps:

  1. Transform the global interaction point into the local coordinate space of the rope mesh.
  2. Read the current vertex positions and triangle index list directly from the rope's geometry.
  3. Perform a 2D point-in-triangle test across all triangle faces until a match is found.

Implementation

Below is a complete, reusable implementation for assigning accurate hit-testing to a SimpleRope:

import * as PIXI from 'pixi.js';

// Helper function to check if a point (px, py) is inside a triangle (ax, ay), (bx, by), (cx, cy)
function isPointInTriangle(px, py, ax, ay, bx, by, cx, cy) {
    const v0x = cx - ax;
    const v0y = cy - ay;
    const v1x = bx - ax;
    const v1y = by - ay;
    const v2x = px - ax;
    const v2y = py - ay;

    const dot00 = v0x * v0x + v0y * v0y;
    const dot01 = v0x * v1x + v0y * v1y;
    const dot02 = v0x * v2x + v0y * v2y;
    const dot11 = v1x * v1x + v1y * v1y;
    const dot12 = v1x * v2x + v1y * v2y;

    const invDenom = 1 / (dot00 * dot11 - dot01 * dot01);
    const u = (dot11 * dot02 - dot01 * dot12) * invDenom;
    const v = (dot00 * dot12 - dot01 * dot02) * invDenom;

    return (u >= 0) && (v >= 0) && (u + v <= 1);
}

// Attach the hit test logic to your SimpleRope instance
export function enableRopeHitTesting(rope) {
    rope.interactive = true;

    rope.containsPoint = function(globalPoint) {
        // Step 1: Quick bounding box check to reject distant clicks early
        const bounds = this.getBounds();
        if (!bounds.contains(globalPoint.x, globalPoint.y)) {
            return false;
        }

        // Step 2: Convert world coordinate to local mesh space
        const localPoint = new PIXI.Point();
        this.worldTransform.applyInverse(globalPoint, localPoint);

        // Step 3: Extract mesh data
        const geometry = this.geometry;
        const positionBuffer = geometry.getAttribute('aVertexPosition').data;
        const indexBuffer = geometry.getIndex().data;

        // Step 4: Iterate through all triangle indices
        for (let i = 0; i < indexBuffer.length; i += 3) {
            const i0 = indexBuffer[i] * 2;
            const i1 = indexBuffer[i + 1] * 2;
            const i2 = indexBuffer[i + 2] * 2;

            const ax = positionBuffer[i0];
            const ay = positionBuffer[i0 + 1];
            const bx = positionBuffer[i1];
            const by = positionBuffer[i1 + 1];
            const cx = positionBuffer[i2];
            const cy = positionBuffer[i2 + 1];

            if (isPointInTriangle(localPoint.x, localPoint.y, ax, ay, bx, by, cx, cy)) {
                return true;
            }
        }

        return false;
    };
}

Usage

Create the rope as usual, then apply the helper function:

const points = [
    new PIXI.Point(0, 0),
    new PIXI.Point(100, 50),
    new PIXI.Point(200, 0)
];

const rope = new PIXI.SimpleRope(PIXI.Texture.from('rope.png'), points);
enableRopeHitTesting(rope);

rope.on('pointerdown', () => {
    console.log('Clicked directly on the deformed rope body!');
});

app.stage.addChild(rope);

Performance Considerations

  • Early Bounding Exit: Calling this.getBounds().contains(...) at the beginning prevents expensive triangle iterations whenever the cursor is outside the overall bounding region.
  • Segment Density: The iteration cost scales linearly with the number of segments along the rope. Keep segment counts balanced to maintain smooth performance during interactive pointer movement.
