How to Create a Rainbow Cycling Filter in PixiJS

This guide demonstrates how to build and animate a rainbow color cycling filter in Pixi.js using a custom GLSL fragment shader. By converting a display object’s RGB pixel values into the HSV color space, altering the hue value based on elapsed time and texture coordinates, and converting the values back to RGB, you can produce a dynamic, continuous rainbow spectrum effect across any Pixi.js sprite or container.

1. Write the Fragment Shader

The core of the effect is a custom fragment shader. Pixi.js provides standard vertex coordinates, so you only need to define a custom fragment shader with a uniform variable for time (uTime) and functions to convert between RGB and HSV color spaces.

precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;
uniform float uTime;

// Convert RGB to HSV
vec3 rgb2hsv(vec3 c) {
    vec4 K = vec4(0.0, -1.0 / 3.0, 2.0 / 3.0, -1.0);
    vec4 p = mix(vec4(c.bg, K.wz), vec4(c.gb, K.xy), step(c.b, c.g));
    vec4 q = mix(vec4(p.xyw, c.r), vec4(c.r, p.yzx), step(p.x, c.r));
    float d = q.x - min(q.w, q.y);
    float e = 1.0e-10;
    return vec3(abs(q.z + (q.w - q.y) / (6.0 * d + e)), d / (q.x + e), q.x);
}

// Convert HSV back to RGB
vec3 hsv2rgb(vec3 c) {
    vec4 K = vec4(1.0, 2.0 / 3.0, 1.0 / 3.0, 3.0);
    vec3 p = abs(fract(c.xxx + K.xyz) * 6.0 - K.www);
    return c.z * mix(K.xxx, clamp(p - K.xxx, 0.0, 1.0), c.y);
}

void main(void) {
    vec4 color = texture2D(uSampler, vTextureCoord);

    // Skip transparent pixels
    if (color.a == 0.0) {
        gl_FragColor = color;
        return;
    }

    vec3 hsv = rgb2hsv(color.rgb);

    // Shift hue using uTime and the horizontal texture coordinate (vTextureCoord.x)
    hsv.x = fract(hsv.x + uTime + vTextureCoord.x);

    // Maintain original saturation and brightness, or maximize saturation for vividness
    hsv.y = max(hsv.y, 0.8);

    gl_FragColor = vec4(hsv2rgb(hsv), color.a);
}

2. Instantiate the Pixi.js Filter

Use PIXI.Filter to bind your fragment shader and initialize the uniforms object. You can pass undefined as the first argument to let Pixi.js use its default vertex shader.

const fragmentShader = `...`; // Insert the GLSL shader code here

const rainbowUniforms = {
    uTime: 0.0
};

const rainbowFilter = new PIXI.Filter(undefined, fragmentShader, rainbowUniforms);

3. Apply the Filter to a Display Object

Assign the newly created filter to the filters array of any Pixi.js Sprite, Graphics, or Container instance.

const sprite = PIXI.Sprite.from('path/to/texture.png');
app.stage.addChild(sprite);

// Apply the filter
sprite.filters = [rainbowFilter];

4. Animate the Filter with the Pixi.js Ticker

To create continuous animation, increment the uTime uniform on every tick using PIXI.Ticker.

app.ticker.add((delta) => {
    // Increase uTime each frame; adjust the multiplier to change cycle speed
    rainbowFilter.uniforms.uTime += 0.01 * delta;

    // Reset value periodically to prevent numerical overflow
    if (rainbowFilter.uniforms.uTime > 1.0) {
        rainbowFilter.uniforms.uTime -= 1.0;
    }
});

Performance Considerations

  • Uniform updates: Updating a single scalar uniform like uTime has minimal CPU overhead.
  • Shader branches: The shader checks color.a == 0.0 to avoid running color conversions on fully transparent background pixels, which helps maintain frame rates when applied to large sprites with empty space.
