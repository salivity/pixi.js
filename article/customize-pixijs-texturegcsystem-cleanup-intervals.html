Customize PixiJS TextureGCSystem Cleanup Intervals

Managing GPU memory effectively in PixiJS requires fine-tuning how and when unused textures are purged from the system. The TextureGCSystem handles garbage collection by automatically unloading textures that have not been rendered for a set period. This guide explains how to customize the threshold intervals, idle times, and operational modes of the TextureGCSystem to prevent performance hitches and memory leaks in your application.

Accessing the TextureGCSystem

The garbage collector is managed by the renderer. Once your Application or Renderer is initialized, you can access the system through the renderer's textureGC property:

const app = new PIXI.Application();
await app.init({ width: 800, height: 600 });

// Access the TextureGCSystem
const textureGC = app.renderer.textureGC;

Key Configuration Properties

You can customize the cleanup threshold intervals using three primary properties on app.renderer.textureGC:

  1. maxIdle: Determines how long a texture can remain unused before becoming eligible for removal. In PixiJS, this value is measured in frames (or render counts). Textures that are not rendered within this frame count threshold are unmanaged and purged from the GPU.
  2. checkCountMax: Controls the frequency of garbage collection cycles. This defines how many frames must pass before the TextureGCSystem runs its cleanup check.
  3. mode: Dictates whether garbage collection runs automatically or manually. PixiJS provides modes via the GC_MODES enumeration (e.g., GC_MODES.AUTO and GC_MODES.MANUAL).

Customizing the Intervals

To adjust how aggressively or conservatively PixiJS manages texture memory, update the threshold properties directly:

import { GC_MODES } from 'pixi.js';

// Run cleanup checks every 300 frames (roughly every 5 seconds at 60 FPS)
app.renderer.textureGC.checkCountMax = 300;

// Textures must be idle for at least 1800 frames (~30 seconds) before removal
app.renderer.textureGC.maxIdle = 1800;

// Ensure automatic collection is enabled
app.renderer.textureGC.mode = GC_MODES.AUTO;

Manual Cleanup Control

In performance-critical scenarios, automatic checks during gameplay can cause frame drops. You can disable automatic collection and trigger cleanup thresholds manually during transitional moments, such as scene changes or loading screens:

import { GC_MODES } from 'pixi.js';

// Switch to manual mode
app.renderer.textureGC.mode = GC_MODES.MANUAL;

// Manually trigger garbage collection at a safe time
function onSceneChange() {
    app.renderer.textureGC.run();
}

Best Practices

  • High-Churn Scenes: If your application frequently loads and discards unique textures (such as a multi-page UI or procedural assets), decrease both checkCountMax and maxIdle to avoid VRAM bloat.
  • Stable Scenes: If assets are reused frequently throughout a session, increase maxIdle to prevent textures from constantly being evicted and re-uploaded to the GPU, which can introduce noticeable stutter.
