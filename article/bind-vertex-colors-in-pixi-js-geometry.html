Bind Vertex Colors in Pixi.js Geometry

Binding custom color attributes per vertex in Pixi.js allows you to pass unique RGB or RGBA values directly into your shaders to create gradients, debug geometry, or produce complex visual effects without multiple draw calls. This guide explains how to define a custom color buffer, attach it as an attribute to a PIXI.Geometry instance, pass it through a vertex shader, and output the interpolated color in the fragment shader.

1. Prepare Vertex Position and Color Buffers

To bind colors per vertex, the color array must contain a matching number of entries for the vertices defined in your position array. For example, if you define a 2D triangle with three vertices, you will need three sets of RGBA values.

// 3 vertices with (x, y) coordinates
const positions = new Float32Array([
    0,   0,   // Vertex 0 (Top)
    100, 200, // Vertex 1 (Bottom Right)
   -100, 200  // Vertex 2 (Bottom Left)
]);

// Matching RGBA color values for each vertex (0.0 to 1.0 range)
const colors = new Float32Array([
    1.0, 0.0, 0.0, 1.0, // Red for Vertex 0
    0.0, 1.0, 0.0, 1.0, // Green for Vertex 1
    0.0, 0.0, 1.0, 1.0  // Blue for Vertex 2
]);

// Triangle indices
const indices = new Uint16Array([0, 1, 2]);

2. Attach the Attribute to PIXI.Geometry

Create a PIXI.Geometry instance and use addAttribute() to register both the positions and your custom color buffer.

const geometry = new PIXI.Geometry();

// Add position attribute: name, buffer, size (2 components: x, y)
geometry.addAttribute('aVertexPosition', positions, 2);

// Add custom color attribute: name, buffer, size (4 components: r, g, b, a)
geometry.addAttribute('aColor', colors, 4);

// Set the index buffer
geometry.addIndex(indices);

The string 'aColor' must match the attribute variable name declared in your vertex shader.

3. Write the Vertex and Fragment Shaders

The vertex shader accepts aColor as an attribute and passes it to a varying variable (vColor) so that the GPU interpolates the colors across the surface of the geometry.

Vertex Shader

precision mediump float;

attribute vec2 aVertexPosition;
attribute vec4 aColor;

uniform mat3 translationMatrix;
uniform mat3 projectionMatrix;

varying vec4 vColor;

void main() {
    vColor = aColor;
    gl_Position = vec4((projectionMatrix * translationMatrix * vec3(aVertexPosition, 1.0)).xy, 0.0, 1.0);
}

Fragment Shader

precision mediump float;

varying vec4 vColor;

void main() {
    gl_FragColor = vColor;
}

4. Assemble the Mesh

Combine the custom geometry and shader into a PIXI.Mesh and add it to the display list.

const vertexSrc = `...`; // Vertex shader string from above
const fragmentSrc = `...`; // Fragment shader string from above

const shader = PIXI.Shader.from(vertexSrc, fragmentSrc);
const mesh = new PIXI.Mesh(geometry, shader);

// Position and add to stage
mesh.position.set(400, 200);
app.stage.addChild(mesh);

Memory Optimization: Using Normalized 8-bit Colors

Using Float32Array for colors allocates 16 bytes per vertex (4 floats × 4 bytes). To reduce memory consumption by 75%, use an 8-bit unsigned integer buffer (Uint8Array) and enable normalization.

const colorsUint8 = new Uint8Array([
    255, 0,   0,   255, // Red
    0,   255, 0,   255, // Green
    0,   0,   255, 255  // Blue
]);

// geometry.addAttribute(id, buffer, size, normalized, type)
geometry.addAttribute(
    'aColor',
    colorsUint8,
    4,
    true,
    PIXI.TYPES.UNSIGNED_BYTE
);

When normalized is set to true, Pixi.js instructs WebGL to automatically map integer values from 0–255 to the 0.0–1.0 range within the shader.
