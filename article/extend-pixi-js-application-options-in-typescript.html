Extend Pixi.js Application Options in TypeScript

Extending Pixi.js Application options allows you to pass custom configuration properties directly into your application constructor or init() method without triggering TypeScript compilation errors. This guide demonstrates how to use TypeScript's declaration merging feature to augment the default options interface cleanly and maintain type safety throughout your project.

Understanding the Target Interface

In modern versions of Pixi.js (v7 and v8), initialization settings are defined by the ApplicationOptions interface (or IApplicationOptions in v6 and earlier). By default, this interface only recognizes built-in properties such as width, height, backgroundColor, and antialias. When you supply custom parameters, TypeScript flags them as unknown properties.

Declaration merging solves this by letting you reopen the interface in a custom declaration file and append your own property definitions.

Step 1: Create a Custom Ambient Declaration File

Create a declaration file in your TypeScript source directory, such as src/types/pixi-extend.d.ts. Ensure this file is included within the include array of your tsconfig.json.

Add the following declaration merging block to add your custom properties:

import 'pixi.js';

declare module 'pixi.js' {
    interface ApplicationOptions {
        /** Custom identifier for analytics tracking */
        trackingId?: string;
        /** Flag to determine if the game operates in debug mode */
        debugMode?: boolean;
        /** Custom game-specific scale factor */
        pixelRatio?: number;
    }
}

Note for Pixi.js v6 and older: Replace ApplicationOptions with IApplicationOptions inside the declare module 'pixi.js' block.

Step 2: Ensure the Type Definition Is Recognized

For TypeScript to merge the declarations properly, the file must be treated as a module. Adding import 'pixi.js'; at the top ensures the file augments the existing module rather than overriding it entirely.

Verify your tsconfig.json includes the declaration file:

{
  "compilerOptions": {
    "target": "ES2022",
    "moduleResolution": "node"
  },
  "include": [
    "src/**/*"
  ]
}

Step 3: Use the Extended Options

Once defined, your custom properties can be passed directly to the Application instance without type assertions (as any).

In Pixi.js v8:

import { Application } from 'pixi.js';

async function setupGame() {
    const app = new Application();

    await app.init({
        width: 800,
        height: 600,
        backgroundColor: 0x1099bb,
        // Custom properties defined in pixi-extend.d.ts
        trackingId: 'GAME-PROD-01',
        debugMode: true,
        pixelRatio: 2
    });
}

In Pixi.js v7:

import { Application } from 'pixi.js';

const app = new Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1099bb,
    // Custom properties defined in pixi-extend.d.ts
    trackingId: 'GAME-PROD-01',
    debugMode: true
});

TypeScript will now validate your custom options alongside native Pixi.js properties, providing autocompletion and compiler safety.
