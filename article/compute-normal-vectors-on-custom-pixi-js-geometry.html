Compute Normal Vectors on Custom Pixi.js Geometry

Computing normal vectors on custom geometry in Pixi.js is essential for dynamic lighting, displacement effects, and realistic 3D surface shading. This guide demonstrates how to calculate vertex normals mathematically using the cross product of triangle edges and how to bind these vectors as custom attributes to a PIXI.Geometry instance for use in vertex and fragment shaders.

Mathematical Principle of Surface Normals

A normal vector is a vector perpendicular to a surface at a given point. For a triangle mesh defined by positions and indices:

  1. Each triangle consists of three vertices: \(A\), \(B\), and \(C\).
  2. Two direction vectors along the triangle's edges are determined: \[E_1 = B - A\] \[E_2 = C - A\]
  3. The surface (face) normal is obtained via the cross product: \[N_{face} = E_1 \times E_2\]
  4. For smooth shading, vertex normals are computed by summing the face normals of all triangles sharing that vertex, followed by vector normalization: \[\hat{N} = \frac{N}{\|N\|}\]

Step-by-Step Implementation

1. The Normal Calculation Function

The following function takes a flat array of vertex positions [x0, y0, z0, x1, y1, z1, ...] (or 2D positions assuming \(Z=0\)) and an index array, returning a Float32Array containing the calculated \((x, y, z)\) normal components for each vertex.

function computeVertexNormals(positions, indices) {
    const normals = new Float32Array(positions.length);

    // Loop through each triangle defined by indices
    for (let i = 0; i < indices.length; i += 3) {
        const i0 = indices[i] * 3;
        const i1 = indices[i + 1] * 3;
        const i2 = indices[i + 2] * 3;

        // Vertices A, B, C
        const ax = positions[i0],     ay = positions[i0 + 1],     az = positions[i0 + 2] || 0;
        const bx = positions[i1],     by = positions[i1 + 1],     bz = positions[i1 + 2] || 0;
        const cx = positions[i2],     cy = positions[i2 + 1],     cz = positions[i2 + 2] || 0;

        // Edge vectors: E1 = B - A, E2 = C - A
        const e1x = bx - ax, e1y = by - ay, e1z = bz - az;
        const e2x = cx - ax, e2y = cy - ay, e2z = cz - az;

        // Cross product: E1 x E2
        const nx = e1y * e2z - e1z * e2y;
        const ny = e1z * e2x - e1x * e2z;
        const nz = e1x * e2y - e1y * e2x;

        // Accumulate face normal into each vertex of this triangle
        normals[i0]     += nx;
        normals[i0 + 1] += ny;
        normals[i0 + 2] += nz;

        normals[i1]     += nx;
        normals[i1 + 1] += ny;
        normals[i1 + 2] += nz;

        normals[i2]     += nx;
        normals[i2 + 1] += ny;
        normals[i2 + 2] += nz;
    }

    // Normalize each accumulated vertex normal
    for (let i = 0; i < normals.length; i += 3) {
        const x = normals[i];
        const y = normals[i + 1];
        const z = normals[i + 2];

        const len = Math.hypot(x, y, z);
        if (len > 0.00001) {
            normals[i]     = x / len;
            normals[i + 1] = y / len;
            normals[i + 2] = z / len;
        } else {
            // Default pointing upward if degenerate
            normals[i]     = 0;
            normals[i + 1] = 0;
            normals[i + 2] = 1;
        }
    }

    return normals;
}

2. Binding Normals to PIXI.Geometry

Once the normal vectors are calculated, attach them to your Pixi.js Geometry alongside vertex positions, UVs, and indices.

import * as PIXI from 'pixi.js';

// Custom 3D plane or surface data
const positions = new Float32Array([
    -50, -50,  0,
     50, -50,  0,
     50,  50, 10,
    -50,  50,  0
]);

const uvs = new Float32Array([
    0, 0,
    1, 0,
    1, 1,
    0, 1
]);

const indices = new Uint16Array([
    0, 1, 2,
    0, 2, 3
]);

// Compute the normals
const normals = computeVertexNormals(positions, indices);

// Construct the Pixi Geometry
const geometry = new PIXI.Geometry()
    .addAttribute('aPosition', positions, 3)
    .addAttribute('aUvs', uvs, 2)
    .addAttribute('aNormal', normals, 3)
    .addIndex(indices);

3. Consuming Normals in Custom Shaders

To utilize the calculated normals for surface shading or lighting calculations, pass the attribute through your vertex shader to the fragment shader.

Vertex Shader

attribute vec3 aPosition;
attribute vec2 aUvs;
attribute vec3 aNormal;

uniform mat3 translationMatrix;
uniform mat3 projectionMatrix;

varying vec2 vUvs;
varying vec3 vNormal;

void main() {
    vUvs = aUvs;
    vNormal = aNormal;
    gl_Position = vec4((projectionMatrix * translationMatrix * vec3(aPosition.xy, 1.0)).xy, aPosition.z, 1.0);
}

Fragment Shader

precision mediump float;

varying vec2 vUvs;
varying vec3 vNormal;

uniform vec3 uLightDirection;

void main() {
    vec3 normal = normalize(vNormal);
    vec3 lightDir = normalize(uLightDirection);

    // Simple Lambertian diffuse reflection
    float diffuse = max(dot(normal, lightDir), 0.0);
    vec3 ambient = vec3(0.2);
    vec3 color = vec3(0.8, 0.4, 0.2) * (diffuse + ambient);

    gl_FragColor = vec4(color, 1.0);
}

Assign this geometry and shader setup to a PIXI.Mesh instance to render the dynamically shaded surface onto your Pixi.js canvas.
