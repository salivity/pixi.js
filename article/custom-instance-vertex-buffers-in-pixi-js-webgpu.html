Custom Instance Vertex Buffers in Pixi.js WebGPU

This article explains how to configure custom vertex buffer layouts with instanced step modes in Pixi.js when targeting the WebGPU renderer. You will learn how Pixi.js maps custom geometry attributes to WebGPU vertex buffer layouts, how to set the buffer attribute to step per instance instead of per vertex, and how to construct the corresponding pipeline with custom WGSL shaders.

WebGPU Instancing in Pixi.js

In standard WebGPU pipelines, vertex buffers advance their data pointers either per vertex or per instance using the stepMode property of a GPUVertexBufferLayout. In Pixi.js (v8+), the WebGPU renderer abstracts low-level pipeline layouts through the Geometry and Buffer classes.

To set stepMode: 'instance' in the underlying WebGPU vertex buffer layout, you flag specific attributes in your Geometry definition with instance: true. Pixi.js automatically groups attributes sharing the same buffer into a single WebGPU vertex buffer layout and marks that buffer's stepMode as 'instance'.

Defining the Buffers and Geometry

To implement custom instancing, separate your static per-vertex geometry (such as quad positions) from your dynamic per-instance data (such as position offsets, scales, or colors).

import { Buffer, BufferUsage, Geometry, Mesh, Shader } from 'pixi.js';

// 1. Static vertex data for a basic quad (advances per vertex)
const vertexPositions = new Float32Array([
    -0.5, -0.5,
     0.5, -0.5,
     0.5,  0.5,
    -0.5,  0.5,
]);

const indices = new Uint32Array([0, 1, 2, 0, 2, 3]);

// 2. Per-instance data: 1000 instances, each with an (x, y) offset and an RGBA color
const instanceCount = 1000;
const instanceOffsets = new Float32Array(instanceCount * 2);
const instanceColors = new Float32Array(instanceCount * 4);

// Populate instance offsets and colors
for (let i = 0; i < instanceCount; i++) {
    instanceOffsets[i * 2 + 0] = (Math.random() - 0.5) * 800;
    instanceOffsets[i * 2 + 1] = (Math.random() - 0.5) * 600;

    instanceColors[i * 4 + 0] = Math.random();
    instanceColors[i * 4 + 1] = Math.random();
    instanceColors[i * 4 + 2] = Math.random();
    instanceColors[i * 4 + 3] = 1.0;
}

// 3. Create Pixi Buffers
const vertexBuffer = new Buffer({
    data: vertexPositions,
    usage: BufferUsage.VERTEX | BufferUsage.COPY_DST,
});

const offsetBuffer = new Buffer({
    data: instanceOffsets,
    usage: BufferUsage.VERTEX | BufferUsage.COPY_DST,
});

const colorBuffer = new Buffer({
    data: instanceColors,
    usage: BufferUsage.VERTEX | BufferUsage.COPY_DST,
});

const indexBuffer = new Buffer({
    data: indices,
    usage: BufferUsage.INDEX | BufferUsage.COPY_DST,
});

// 4. Configure Geometry with instance: true
const geometry = new Geometry({
    attributes: {
        aPosition: {
            buffer: vertexBuffer,
            format: 'float32x2',
            instance: false, // stepMode: 'vertex'
        },
        aInstanceOffset: {
            buffer: offsetBuffer,
            format: 'float32x2',
            instance: true,  // stepMode: 'instance'
        },
        aInstanceColor: {
            buffer: colorBuffer,
            format: 'float32x4',
            instance: true,  // stepMode: 'instance'
        },
    },
    indexBuffer,
    instanceCount,
});

Interleaved Instance Buffers

If you combine per-instance attributes into a single interleaved array, assign the same Buffer instance to both attributes and specify explicit offsets and strides. Pixi.js detects the shared buffer and applies stepMode: 'instance' across all associated attributes.

// Interleaved: 2 floats for offset, 4 floats for color (6 floats = 24 bytes stride)
const interleavedData = new Float32Array(instanceCount * 6);
const interleavedBuffer = new Buffer({
    data: interleavedData,
    usage: BufferUsage.VERTEX | BufferUsage.COPY_DST,
});

const interleavedGeometry = new Geometry({
    attributes: {
        aPosition: {
            buffer: vertexBuffer,
            format: 'float32x2',
            instance: false,
        },
        aInstanceOffset: {
            buffer: interleavedBuffer,
            format: 'float32x2',
            stride: 24,
            offset: 0,
            instance: true,
        },
        aInstanceColor: {
            buffer: interleavedBuffer,
            format: 'float32x4',
            stride: 24,
            offset: 8,
            instance: true,
        },
    },
    indexBuffer,
    instanceCount,
});

Writing the WebGPU WGSL Shader

In your WebGPU shader code, map the input attributes to matching location indices. The GPU fetches one set of vertex coordinates per index, but only advances aInstanceOffset and aInstanceColor when moving to the next instance.

struct VertexInput {
    @location(0) position: vec2<f32>,
    @location(1) instanceOffset: vec2<f32>,
    @location(2) instanceColor: vec4<f32>,
};

struct VertexOutput {
    @builtin(position) position: vec4<f32>,
    @location(0) color: vec4<f32>,
};

@vertex
fn mainVertex(input: VertexInput) -> VertexOutput {
    var output: VertexOutput;
    
    // Apply per-instance translation to vertex position
    let worldPos = input.position * 20.0 + input.instanceOffset;
    
    // Convert to normalized device coordinates (assuming 800x600 viewport)
    let ndcPos = (worldPos / vec2<f32>(400.0, 300.0));

    output.position = vec4<f32>(ndcPos, 0.0, 1.0);
    output.color = input.instanceColor;
    return output;
}

@fragment
fn mainFragment(@location(0) color: vec4<f32>) -> @location(0) vec4<f32> {
    return color;
}

Creating the Pipeline with Mesh

Assign the custom shader and instanced geometry to a Mesh object. When rendered, Pixi.js sets up the underlying GPURenderPipeline where buffers with instance: true are assigned stepMode: 'instance' in the vertex.buffers array, and the draw call executes using drawIndexed(indexCount, instanceCount).

import { GpuProgram, Shader } from 'pixi.js';

const gpuProgram = GpuProgram.from({
    vertex: {
        source: wgslSource,
        entryPoint: 'mainVertex',
    },
    fragment: {
        source: wgslSource,
        entryPoint: 'mainFragment',
    },
});

const shader = new Shader({ gpuProgram });
const instancedMesh = new Mesh({ geometry, shader });

app.stage.addChild(instancedMesh);
