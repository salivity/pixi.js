How to Track Drag Velocity in Pixi.js

Tracking the global movement velocity of a dragged sprite in Pixi.js requires monitoring the change in global pointer coordinates over time across drag events. By recording the pointer's previous and current global positions alongside timestamps, you can calculate the exact directional speed (velocity vector) in pixels per millisecond or pixels per frame. This data can then be used for mechanics such as throwing, flicking, or applying inertial physics after release.

Understanding the Velocity Formula

Velocity is defined as the change in position divided by the elapsed time:

\[\text{Velocity}_x = \frac{x_{\text{current}} - x_{\text{previous}}}{\Delta t}\]

\[\text{Velocity}_y = \frac{y_{\text{current}} - y_{\text{previous}}}{\Delta t}\]

In Pixi.js, interaction events provide pointer positions in global screen space via event.global.x and event.global.y, making calculation independent of parent container nesting or scale transformations.

Step-by-Step Implementation

1. Configure the Sprite for Dragging

Set the sprite's eventMode to 'static' (or interactive = true in older Pixi.js versions) and attach listeners for pointer events:

const sprite = new PIXI.Sprite(texture);
sprite.eventMode = 'static';
sprite.cursor = 'pointer';

let isDragging = false;
let dragData = null;

// Tracking state
let lastPosition = { x: 0, y: 0 };
let lastTime = 0;
let velocity = { x: 0, y: 0 };

sprite.on('pointerdown', onDragStart);
sprite.on('globalpointermove', onDragMove);
sprite.on('pointerup', onDragEnd);
sprite.on('pointerupoutside', onDragEnd);

2. Initialize Tracking on Pointer Down

When the drag begins, record the starting global position and the initial timestamp:

function onDragStart(event) {
    isDragging = true;
    dragData = event;

    // Record initial global position and timestamp
    lastPosition.x = event.global.x;
    lastPosition.y = event.global.y;
    lastTime = performance.now();

    // Reset velocity
    velocity.x = 0;
    velocity.y = 0;
}

3. Calculate Velocity on Move

On movement, determine the elapsed time (\(\Delta t\)) and the delta movement (\(\Delta x, \Delta y\)). To prevent division-by-zero errors or erratic spikes, only update velocity when sufficient time has elapsed:

function onDragMove(event) {
    if (!isDragging) return;

    const currentTime = performance.now();
    const deltaTime = currentTime - lastTime;

    // Only calculate if at least 1ms has passed
    if (deltaTime > 0) {
        const currentPosition = {
            x: event.global.x,
            y: event.global.y
        };

        // Velocity in pixels per millisecond
        const instantaneousVx = (currentPosition.x - lastPosition.x) / deltaTime;
        const instantaneousVy = (currentPosition.y - lastPosition.y) / deltaTime;

        // Apply a moving average filter to smooth out sensor jitter
        const smoothingFactor = 0.2;
        velocity.x = velocity.x * (1 - smoothingFactor) + instantaneousVx * smoothingFactor;
        velocity.y = velocity.y * (1 - smoothingFactor) + instantaneousVy * smoothingFactor;

        // Update sprite position to follow pointer
        sprite.parent.toLocal(event.global, null, sprite.position);

        // Update tracking references
        lastPosition.x = currentPosition.x;
        lastPosition.y = currentPosition.y;
        lastTime = currentTime;
    }
}

4. Handle Drag Release

When the drag ends, check the elapsed time since the last move event. If the user stops moving the pointer before releasing, reset velocity to zero to avoid an unintended launch:

function onDragEnd() {
    if (!isDragging) return;
    isDragging = false;

    const currentTime = performance.now();
    // If the pointer was stationary for more than 50ms before release, zero the velocity
    if (currentTime - lastTime > 50) {
        velocity.x = 0;
        velocity.y = 0;
    }

    // `velocity.x` and `velocity.y` now contain the release velocity (px/ms)
    console.log(`Release Velocity: X: ${velocity.x}, Y: ${velocity.y}`);

    dragData = null;
}

Frame-Based Tracking via Pixi Ticker

If your project requires velocity in pixels per frame rather than pixels per millisecond, track the sprite’s global position inside the PIXI.Ticker loop:

let prevGlobalX = 0;
let prevGlobalY = 0;

app.ticker.add((ticker) => {
    if (isDragging) {
        const currentGlobal = sprite.toGlobal(new PIXI.Point(0, 0));

        velocity.x = (currentGlobal.x - prevGlobalX) / ticker.deltaTime;
        velocity.y = (currentGlobal.y - prevGlobalY) / ticker.deltaTime;

        prevGlobalX = currentGlobal.x;
        prevGlobalY = currentGlobal.y;
    }
});

Using sprite.toGlobal() accounts for any transformations applied to parent containers while providing continuous, frame-synced velocity values.
