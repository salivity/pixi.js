Wireframe Custom Polygons in Pixi.js Geometry

Rendering a wireframe representation of a custom polygon in Pixi.js requires building a custom PIXI.Geometry and rendering it through a PIXI.Mesh configured with a line-based draw mode. This guide outlines how to extract polygon vertices, build vertex and index buffers for the wireframe structure, and render the resulting geometry using Pixi.js's built-in draw modes.

1. Define Polygon Vertices

A custom polygon is typically defined as a flat array of 2D coordinates [x0, y0, x1, y1, ...]. Pixi.js expects vertex data packed into a typed array:

const polygonPoints = [
    100, 100,
    250, 50,
    350, 150,
    300, 300,
    150, 250
];

const positions = new Float32Array(polygonPoints);

2. Determine Edge Indices

To render a wireframe, you must tell the GPU which vertices connect to form lines. Depending on your needs, you can either outline the polygon perimeter or render an entire triangulated mesh in wireframe mode.

Option A: Polygon Outline (Perimeter Wireframe)

For a simple polygon perimeter, connect each point to the next, with the final point connecting back to the start:

const indices = [];
const vertexCount = polygonPoints.length / 2;

for (let i = 0; i < vertexCount; i++) {
    indices.push(i);
    indices.push((i + 1) % vertexCount);
}

const indexBuffer = new Uint16Array(indices);

Option B: Triangulated Mesh Wireframe

If your polygon is triangulated (e.g., via Earcut) and you want to visualize the internal mesh structure, generate indices for all three edges of each triangle:

// Example: existing triangle indices from triangulation
const triangleIndices = [0, 1, 2, 0, 2, 3, 0, 3, 4];
const lineIndices = [];

for (let i = 0; i < triangleIndices.length; i += 3) {
    const a = triangleIndices[i];
    const b = triangleIndices[i + 1];
    const c = triangleIndices[i + 2];

    lineIndices.push(a, b, b, c, c, a);
}

const indexBuffer = new Uint16Array(lineIndices);

3. Construct PIXI.Geometry

Create a PIXI.Geometry instance, attach the position attribute, and assign the index buffer:

const geometry = new PIXI.Geometry();

geometry.addAttribute('aVertexPosition', positions, 2);
geometry.addIndex(indexBuffer);

4. Apply a Shader and Create the Mesh

Pixi.js meshes require a shader. For simple flat-colored wireframes, you can use PIXI.Shader.from() with basic vertex and fragment shaders:

const vertexSrc = `
    precision mediump float;
    attribute vec2 aVertexPosition;
    uniform mat3 translationMatrix;
    uniform mat3 projectionMatrix;

    void main() {
        gl_Position = vec4((projectionMatrix * translationMatrix * vec3(aVertexPosition, 1.0)).xy, 0.0, 1.0);
    }
`;

const fragmentSrc = `
    precision mediump float;
    uniform vec4 uColor;

    void main() {
        gl_FragColor = uColor;
    }
`;

const uniforms = {
    uColor: [0.0, 1.0, 0.0, 1.0] // Green wireframe
};

const shader = PIXI.Shader.from(vertexSrc, fragmentSrc, uniforms);

5. Render Using PIXI.DRAW_MODES.LINES

Instantiate a PIXI.Mesh using the constructed geometry and shader, setting the draw mode to PIXI.DRAW_MODES.LINES:

const wireframeMesh = new PIXI.Mesh(geometry, shader);
wireframeMesh.drawMode = PIXI.DRAW_MODES.LINES;

app.stage.addChild(wireframeMesh);

Alternative: Using LINE_LOOP

If you only need an un-indexed outline without internal edges, you can omit the index buffer entirely and configure the mesh to use PIXI.DRAW_MODES.LINE_LOOP:

const simpleGeometry = new PIXI.Geometry();
simpleGeometry.addAttribute('aVertexPosition', positions, 2);

const loopMesh = new PIXI.Mesh(simpleGeometry, shader);
loopMesh.drawMode = PIXI.DRAW_MODES.LINE_LOOP;

app.stage.addChild(loopMesh);
