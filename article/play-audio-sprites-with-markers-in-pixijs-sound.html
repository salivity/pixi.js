Play Audio Sprites with Markers in PixiJS Sound

Audio sprites bundle multiple sound effects into a single audio file to reduce HTTP requests, optimize asset loading, and improve playback performance in web games. This guide explains how to define sound markers, load a composite audio file, and trigger individual sound effects using the @pixi/sound library in Pixi.js.

1. Install and Import the Library

Ensure you have @pixi/sound installed alongside Pixi.js:

npm install @pixi/sound

Import the sound manager into your script:

import { sound } from '@pixi/sound';

2. Define Sound Markers and Load the Sprite

An audio sprite configuration uses markers defined in seconds. Each marker requires a start time and an end time (or speed, loop, etc., if specific behaviors are needed).

Register the audio asset using sound.add(), passing the file path and the sprites configuration object:

sound.add('gameAudio', {
    url: 'assets/audio/game-sprite.mp3',
    sprites: {
        jump: {
            start: 0,
            end: 0.45
        },
        coin: {
            start: 1.0,
            end: 1.35
        },
        hit: {
            start: 2.0,
            end: 2.5
        },
        powerup: {
            start: 3.0,
            end: 4.2
        }
    },
    preload: true,
    loaded: (err, soundInstance) => {
        if (!err) {
            console.log('Audio sprite loaded successfully');
        }
    }
});

3. Play Specific Sound Markers

To play a marker from the registered audio sprite, call sound.play() and supply the sprite alias followed by the specific marker name as the second argument:

// Play the 'jump' sound effect
sound.play('gameAudio', 'jump');

// Play the 'coin' sound effect
sound.play('gameAudio', 'coin');

Alternatively, you can retrieve the sound instance directly using sound.find() and invoke play() directly with the marker name:

const gameSounds = sound.find('gameAudio');

// Play marker directly from instance
gameSounds.play('hit');

4. Overriding Playback Options per Marker

You can pass an options object to modify properties like volume, looping, or playback speed when triggering a marker:

sound.play('gameAudio', {
    marker: 'powerup',
    volume: 0.8,
    speed: 1.2,
    complete: () => {
        console.log('Powerup sound finished playing');
    }
});

Using this approach, all game sounds can be managed from a single audio file while maintaining control over individual triggers, playback speeds, and volume levels.
