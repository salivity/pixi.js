Animate a Twist Distortion Using PixiJS TwistFilter

Animating a twist or swirl distortion in Pixi.js involves applying the TwistFilter from the Pixi.js filter library to a display object and continuously updating its properties within the render loop. This guide provides a straightforward implementation showing how to set up the filter, configure its primary properties, and animate parameters like angle and radius using the Pixi.js ticker.

Installing and Importing the Filter

The TwistFilter is part of the community-maintained pixi-filters package. You must install the package or the individual filter module:

npm install pixi-filters
# or
npm install @pixi/filter-twist

Import TwistFilter alongside the core Pixi.js modules:

import * as PIXI from 'pixi.js';
import { TwistFilter } from 'pixi-filters';

Initializing the Filter

Create an instance of TwistFilter and assign it to an object's filters array. The filter primarily relies on three properties:

  • radius: The radius (in pixels) of the circular area affected by the twist.
  • angle: The strength and direction of the twist in radians.
  • offset: A PIXI.Point or [x, y] array indicating the center of the distortion.
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

const sprite = PIXI.Sprite.from('path/to/image.jpg');
sprite.anchor.set(0.5);
sprite.position.set(app.screen.width / 2, app.screen.height / 2);
app.stage.addChild(sprite);

// Create the TwistFilter centered on the sprite
const twistFilter = new TwistFilter({
    radius: 200,
    angle: 0,
    offset: new PIXI.Point(app.screen.width / 2, app.screen.height / 2)
});

sprite.filters = [twistFilter];

Animating via the Pixi.js Ticker

To create the animation, modify twistFilter.angle or twistFilter.radius inside app.ticker.

Continuous Swirl Rotation

Incrementing the angle creates a continuous spinning whirlpool effect:

app.ticker.add((delta) => {
    // Rotate the swirl smoothly
    twistFilter.angle += 0.05 * delta;
});

Pulsing or Oscillating Twist

Use trigonometric functions like Math.sin() to make the twist expand, contract, and reverse direction smoothly:

let count = 0;

app.ticker.add((delta) => {
    count += 0.02 * delta;
    
    // Oscillates between -4 and 4 radians
    twistFilter.angle = Math.sin(count) * 4;
    
    // Dynamically pulse the radius size
    twistFilter.radius = 200 + Math.cos(count) * 50;
});

Dynamic Center Following

You can move the center of the twist dynamically to follow user interaction by updating the offset property:

app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;

app.stage.on('pointermove', (event) => {
    twistFilter.offset.copyFrom(event.global);
});
