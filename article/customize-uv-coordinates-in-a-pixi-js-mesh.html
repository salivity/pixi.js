Customize UV Coordinates in a Pixi.js Mesh

Customizing the UV coordinates of individual vertices in a Pixi.js Mesh allows developers to achieve advanced texture mapping, custom sprite deformation, and selective texture wrapping. This article explains how to access a mesh's geometry attributes, alter specific UV values mapped to individual vertices, and properly flag the underlying buffers so Pixi.js uploads the updated coordinates to the GPU.

Understanding Pixi.js Mesh UV Structure

In Pixi.js, a Mesh relies on a MeshGeometry (or a generic Geometry object) to define vertices, texture coordinates, and triangle indices. Texture coordinates are stored in a flattened array (typically a Float32Array) associated with the aTextureCoord attribute.

Each vertex has two UV coordinates:

  • U (horizontal): Ranges from 0.0 (left) to 1.0 (right).
  • V (vertical): Ranges from 0.0 (top) to 1.0 (bottom).

Because the array is flattened, the coordinates for vertex i occupy indices i * 2 (for U) and i * 2 + 1 (for V).

Modifying Vertex UVs Step-by-Step

To update the UV coordinates for specific vertices, directly modify the geometry's UV buffer and notify the renderer of the change.

1. Retrieve the UV Buffer

Access the UV array directly from the geometry. In most standard mesh setups (such as SimpleMesh or custom meshes), you can access the array through the uvs property or the attribute buffer.

// Access the Float32Array containing the UV coordinates
const uvs = mesh.geometry.uvs;

If working with custom low-level geometries, access the buffer directly via the attribute list:

const uvBuffer = mesh.geometry.getAttribute('aTextureCoord').buffer;
const uvs = uvBuffer.data;

2. Update the Target Coordinates

Locate the index of the vertex you want to modify and assign new values between 0.0 and 1.0.

// Index of the vertex to modify
const vertexIndex = 2;

// Set new U and V coordinates
uvs[vertexIndex * 2] = 0.5;     // New U coordinate
uvs[vertexIndex * 2 + 1] = 0.8; // New V coordinate

3. Flag the Buffer for GPU Upload

Pixi.js buffers do not automatically re-upload to the GPU every frame for performance reasons. When buffer data changes, manually invoke update() on the buffer to mark it as dirty.

// Update using the geometry helper
mesh.geometry.getBuffer('aTextureCoord').update();

// Or update the buffer directly if referenced
mesh.geometry.buffers[1].update();

Complete Implementation Example

import * as PIXI from 'pixi.js';

// 1. Create a basic plane or mesh
const vertices = new Float32Array([
    0, 0,     // Vertex 0: Top-Left
    100, 0,   // Vertex 1: Top-Right
    100, 100, // Vertex 2: Bottom-Right
    0, 100    // Vertex 3: Bottom-Left
]);

const uvs = new Float32Array([
    0, 0, // Vertex 0
    1, 0, // Vertex 1
    1, 1, // Vertex 2
    0, 1  // Vertex 3
]);

const indices = new Uint16Array([0, 1, 2, 0, 2, 3]);

const geometry = new PIXI.MeshGeometry(vertices, uvs, indices);
const mesh = new PIXI.Mesh(geometry, new PIXI.MeshMaterial(PIXI.Texture.WHITE));

// 2. Custom function to update a specific vertex UV
function setVertexUV(meshInstance, vertexIndex, u, v) {
    const uvData = meshInstance.geometry.uvs;
    
    // Assign normalized coordinates
    uvData[vertexIndex * 2] = u;
    uvData[vertexIndex * 2 + 1] = v;
    
    // Inform the GPU that the buffer has changed
    meshInstance.geometry.getBuffer('aTextureCoord').update();
}

// 3. Customize the UV of Vertex 2 (Bottom-Right)
setVertexUV(mesh, 2, 0.5, 0.5);

Key Considerations

  • Normalized Values: Pixi.js expects UV values between 0.0 and 1.0. If you assign values outside this range, the behavior depends on the texture's wrapMode (such as CLAMP or REPEAT).
  • Texture Atlases: When using textures from a spritesheet or atlas, UV coordinates must be calculated relative to the frame rectangle within the base texture rather than the global 0.0 to 1.0 range.
  • Batching Impact: Frequently modifying buffer data marks the mesh as dynamic, which requires data transfer over the bus to the GPU. Keep updates confined only to frames where coordinates actually change.
