Disable Pixi.js Right-Click Context Menu

When building interactive applications or games with Pixi.js, the browser's default right-click context menu can interrupt custom pointer controls, preventing events like rightdown, rightclick, or secondary button detection from functioning correctly. This article explains how to disable the native context menu directly on the Pixi.js canvas and properly handle right-click pointer events within your application.

Disabling the Default Context Menu

The browser triggers a native contextmenu event whenever a user right-clicks an element on the webpage. To stop this menu from appearing over your Pixi.js canvas, you must attach an event listener to the canvas element and call event.preventDefault().

Depending on your Pixi.js version, reference the canvas element using app.canvas (Pixi.js v8) or app.view (Pixi.js v7 and earlier):

// For Pixi.js v8:
app.canvas.addEventListener('contextmenu', (event) => {
    event.preventDefault();
});

// For Pixi.js v7 and earlier:
app.view.addEventListener('contextmenu', (event) => {
    event.preventDefault();
});

If you prefer global suppression across the entire game container, attach the listener to the parent element or the window object directly:

window.addEventListener('contextmenu', (event) => {
    event.preventDefault();
});

Configuring Pixi.js Pointer Events

Once the browser context menu is suppressed, Pixi.js can cleanly capture secondary clicks. Pixi.js provides dedicated events for secondary mouse button actions as well as generic pointer events.

1. Enable Interactivity

Ensure your display object has interaction enabled:

  • Pixi.js v7 and v8: Set eventMode = 'static' (or 'dynamic').
  • Pixi.js v6 and earlier: Set interactive = true.

2. Listen for Right-Click Events

Pixi.js exposes built-in right-click events such as rightdown, rightup, and rightclick:

const sprite = PIXI.Sprite.from('asset.png');

// Enable interaction (v7/v8)
sprite.eventMode = 'static';
sprite.cursor = 'pointer';

// Listen specifically for right-click interactions
sprite.on('rightdown', (event) => {
    console.log('Right mouse button pressed down');
});

sprite.on('rightup', (event) => {
    console.log('Right mouse button released');
});

sprite.on('rightclick', (event) => {
    console.log('Right click completed');
});

3. Alternative: Using pointerdown

You can also use general pointerdown events and inspect the button property on the original event. The secondary button (right-click) is represented by the index 2:

sprite.on('pointerdown', (event) => {
    if (event.button === 2) {
        console.log('Right-click detected via pointerdown');
    } else if (event.button === 0) {
        console.log('Left-click detected via pointerdown');
    }
});

By calling event.preventDefault() on the canvas's contextmenu event and assigning static or dynamic eventMode to your display objects, you eliminate interference and gain full control over secondary mouse inputs in Pixi.js.
