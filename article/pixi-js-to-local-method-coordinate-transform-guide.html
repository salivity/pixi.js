Pixi.js toLocal Method Coordinate Transform Guide

The toLocal method in Pixi.js is an essential tool for converting coordinates between different reference frames within a hierarchical 2D scene graph. Because nested display containers inherit transformations such as translation, rotation, scaling, and skewing, their local coordinate systems diverge from the global screen coordinates. This guide explains the exact purpose of toLocal, how its parameters work, and how it resolves coordinate differences between nested display objects.

The Exact Purpose of toLocal

The primary purpose of the toLocal method is to take a coordinate point defined in one coordinate space (typically the global canvas space or another display object's space) and calculate its equivalent position relative to the local coordinate system of the target display object.

Internally, Pixi.js maintains a world transform matrix for every display object, which accumulates all parent translations, rotations, scale factors, and pivots. The toLocal method applies the inverse of these accumulated transformation matrices to determine where an external point lies relative to the target object’s origin (0, 0).

Syntax and Parameters

The standard signature for toLocal is:

displayObject.toLocal(position, from, point, skipUpdate);
  • position (IPointData): The coordinates to transform.
  • from (DisplayObject, optional): The display object representing the coordinate system that position is currently in. If omitted, null, or undefined, Pixi.js assumes position is in global (world/screen) coordinates.
  • point (Point, optional): A point instance to store the result. Providing an existing point prevents Pixi.js from instantiating a new PIXI.Point, which helps reduce garbage collection overhead in performance-critical loops.
  • skipUpdate (boolean, optional): If set to true, Pixi.js skips recalculating the world transforms before the calculation. This is useful for optimization if world transforms are already up to date.

Primary Use Cases

1. Converting Pointer and Mouse Coordinates

User inputs like mouse clicks, touches, and pointer events are provided in global screen coordinates. If you want to add an object inside a scaled, rotated, or shifted container at the exact location of a user click, you must convert the global event coordinates to the container's local space:

const globalClick = event.global;
const localClick = container.toLocal(globalClick);

const newSprite = PIXI.Sprite.from("item.png");
newSprite.position.set(localClick.x, localClick.y);
container.addChild(newSprite);

2. Transforming Across Different Containers

When two display objects belong to different parent containers with distinct transformations, their raw x and y properties cannot be compared directly. Passing the source object as the second argument (from) lets you translate coordinates directly between the two objects:

// Get containerB's position relative to containerA's coordinate space
const localPoint = containerA.toLocal({ x: 0, y: 0 }, containerB);

Summary

The toLocal method eliminates the need to manually compute inverse transformation matrices when handling nested containers in Pixi.js. Its exact purpose is to map external or global coordinates directly into a target object's local space, ensuring accurate placement, collision detection, and user interaction regardless of complex scene hierarchies.
