Detecting Clicks on Mesh Triangles in PixiJS

Detecting which individual triangle of a Mesh a user clicked in PixiJS requires converting screen coordinates into the mesh's local coordinate space, accessing the underlying vertex and index buffers, and testing the point against each triangle using a point-in-triangle algorithm such as barycentric coordinates. This guide explains how to read mesh geometry and efficiently determine the exact clicked polygon triangle.

1. Enable Interaction on the Mesh

First, ensure your Mesh instance is interactive and listen for pointer events:

const mesh = new PIXI.Mesh(geometry, shader);
mesh.eventMode = 'static';

mesh.on('pointerdown', (event) => {
    // Convert global screen coordinates to mesh local coordinates
    const localPoint = mesh.toLocal(event.global);
    
    const triangleIndex = getClickedTriangleIndex(mesh, localPoint);
    if (triangleIndex !== -1) {
        console.log(`Clicked triangle index: ${triangleIndex}`);
    }
});

2. Implement the Point-in-Triangle Check

A standard method for determining if a point P lies inside a 2D triangle defined by vertices A, B, and C is computing barycentric coordinates:

function isPointInTriangle(px, py, ax, ay, bx, by, cx, cy) {
    const v0x = cx - ax;
    const v0y = cy - ay;
    const v1x = bx - ax;
    const v1y = by - ay;
    const v2x = px - ax;
    const v2y = py - ay;

    const dot00 = v0x * v0x + v0y * v0y;
    const dot01 = v0x * v1x + v0y * v1y;
    const dot02 = v0x * v2x + v0y * v2y;
    const dot11 = v1x * v1x + v1y * v1y;
    const dot12 = v1x * v2x + v1y * v2y;

    const denom = dot00 * dot11 - dot01 * dot01;
    if (denom === 0) return false; // Degenerate triangle

    const invDenom = 1 / denom;
    const u = (dot11 * dot02 - dot01 * dot12) * invDenom;
    const v = (dot00 * dot12 - dot01 * dot02) * invDenom;

    return (u >= 0) && (v >= 0) && (u + v <= 1);
}

3. Iterate Through the Mesh Geometry

PixiJS stores mesh coordinates in the aVertexPosition attribute and face definitions in the index buffer. Iterate through the indices in steps of three to extract each triangle's coordinates:

function getClickedTriangleIndex(mesh, point) {
    const geometry = mesh.geometry;
    const positionAttr = geometry.getAttribute('aVertexPosition');
    const vertices = positionAttr.data;
    const indexAttr = geometry.getIndex();
    
    // Check if the mesh uses indexed geometry
    const indices = indexAttr ? indexAttr.data : null;
    const triangleCount = indices ? indices.length / 3 : vertices.length / 6;

    for (let i = 0; i < triangleCount; i++) {
        let i0, i1, i2;

        if (indices) {
            i0 = indices[i * 3];
            i1 = indices[i * 3 + 1];
            i2 = indices[i * 3 + 2];
        } else {
            i0 = i * 3;
            i1 = i * 3 + 1;
            i2 = i * 3 + 2;
        }

        const ax = vertices[i0 * 2];
        const ay = vertices[i0 * 2 + 1];
        const bx = vertices[i1 * 2];
        const by = vertices[i1 * 2 + 1];
        const cx = vertices[i2 * 2];
        const cy = vertices[i2 * 2 + 1];

        if (isPointInTriangle(point.x, point.y, ax, ay, bx, by, cx, cy)) {
            return i; // Returns the index of the intersected triangle
        }
    }

    return -1; // No triangle hit
}

Performance Optimization

For meshes with thousands of triangles, testing every triangle sequentially can impact frame rates. To optimize raycasting performance:

  • Test the point against the mesh's axis-aligned bounding box (mesh.getLocalBounds()) before looping through triangles.
  • Store static mesh triangles in a spatial partition structure, such as a quadtree or bounding volume hierarchy (BVH), to limit triangle tests to only nearby candidates.
