Using GPUExternalTexture in Pixi.js WebGPU Shaders

This guide explains how to bind external video frames to custom WGSL shaders using WebGPU's GPUExternalTexture within Pixi.js. Traditional video textures can introduce memory overhead and latency through CPU-to-GPU copying. By leveraging GPUExternalTexture, you can achieve zero-copy video playback and efficient color conversion directly inside Pixi.js rendering pipelines. You will learn how to configure the WGSL shader, import the video frame from an HTML video element, and maintain per-frame texture updates within Pixi.js's application loop.

Understanding GPUExternalTexture

WebGPU provides GPUExternalTexture as a dedicated primitive for importing frames from an HTMLVideoElement or VideoFrame. Unlike standard 2D textures, external textures:

  • Perform internal color space conversion (such as YUV to RGB) directly on the hardware.
  • Utilize zero-copy pathways where supported by the platform.
  • Are short-lived snapshots that expire after the current animation frame or microtask finishes, requiring a re-import on every frame render.

Writing the WGSL Shader

In WGSL, an external texture cannot be declared as texture_2d<f32>. It must be declared as texture_external and sampled using textureSampleBaseClampToEdge.

@group(0) @binding(0) var videoSampler: sampler;
@group(0) @binding(1) var videoTexture: texture_external;

struct VertexOutput {
    @builtin(position) position: vec4<f32>,
    @location(0) uv: vec2<f32>,
};

@vertex
fn mainVertex(
    @location(0) aPosition: vec2<f32>,
    @location(1) aUV: vec2<f32>
) -> VertexOutput {
    var output: VertexOutput;
    output.position = vec4<f32>(aPosition, 0.0, 1.0);
    output.uv = aUV;
    return output;
}

@fragment
fn mainFragment(@location(0) uv: vec2<f32>) -> @location(0) vec4<f32> {
    return textureSampleBaseClampToEdge(videoTexture, videoSampler, uv);
}

Initializing the HTML Video Element

Ensure your video source is playing and configured for WebGPU access:

const video = document.createElement('video');
video.src = 'path/to/video.mp4';
video.loop = true;
video.muted = true;
video.playsInline = true;
await video.play();

Accessing the WebGPU Device in Pixi.js

Pixi.js v8 operates natively on WebGPU when configured. You must access the underlying GPUDevice to call the importExternalTexture API:

import { Application } from 'pixi.js';

const app = new Application();
await app.init({
    preference: 'webgpu',
    width: 800,
    height: 600,
});

const gpuDevice = app.renderer.gpu.device;

Implementing Per-Frame Texture Binding

Because a GPUExternalTexture expires at the end of each frame task, you must import the texture on every tick of the render loop and update your shader's resource bindings before Pixi.js draws the frame.

import { Geometry, Mesh, Shader } from 'pixi.js';

// Define quad geometry
const geometry = new Geometry({
    attributes: {
        aPosition: [-1, -1, 1, -1, 1, 1, -1, 1],
        aUV: [0, 1, 1, 1, 1, 0, 0, 0],
    },
    indexBuffer: [0, 1, 2, 0, 2, 3],
});

// Configure sampler
const sampler = gpuDevice.createSampler({
    magFilter: 'linear',
    minFilter: 'linear',
});

// Set up the custom shader
const shader = Shader.from({
    gpu: {
        vertex: {
            code: vertexShaderSource,
            entryPoint: 'mainVertex',
        },
        fragment: {
            code: fragmentShaderSource,
            entryPoint: 'mainFragment',
        },
    },
    resources: {
        videoSampler: sampler,
        videoTexture: gpuDevice.importExternalTexture({ source: video }),
    },
});

const videoMesh = new Mesh(geometry, shader);
app.stage.addChild(videoMesh);

// Update external texture snapshot each frame
app.ticker.add(() => {
    if (video.readyState >= HTMLMediaElement.HAVE_CURRENT_DATA) {
        shader.resources.videoTexture = gpuDevice.importExternalTexture({
            source: video,
        });
    }
});

Considerations

  • Color Handling: textureSampleBaseClampToEdge automatically maps colors to the destination space, eliminating the need to write custom YUV-to-RGB matrix conversions in the fragment shader.
  • Lifecycle Management: Do not attempt to cache or store GPUExternalTexture instances across frames. Attempting to sample an expired texture results in WebGPU validation errors and blank rendering.
