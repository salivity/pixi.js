How to Create Motion Trails in PixiJS Using Filters

Creating motion trails in Pixi.js involves persisting past visual data and blending it with the current frame using a custom shader. This article explains how to achieve this effect using a technique called "ping-pong" buffering with two render textures, passing the previous frame's texture as a uniform into a custom Pixi.js filter, and applying an alpha fade factor each frame to generate smooth, decaying trails.

The Ping-Pong Buffering Concept

A GPU cannot safely read from and write to the same texture simultaneously. To feed the previous frame into the current frame's filter, you must alternate between two RenderTexture instances:

  1. Frame A: Draw the current scene along with the contents of Texture 1 into Texture 2, applying a fade-out filter.
  2. Frame B: Draw the new scene along with the contents of Texture 2 into Texture 1.
  3. Display the active target texture on the screen.

Step 1: Write the Custom Fragment Shader

The filter requires a fragment shader that takes two textures: the current frame (uSampler) and the previous frame (uPrevTexture). It also uses a decay rate (uFade) to determine how quickly the trail vanishes.

precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;      // Current frame
uniform sampler2D uPrevTexture;  // Previous frame
uniform float uFade;             // Trail persistence (e.g., 0.95)

void main(void) {
    vec4 current = texture2D(uSampler, vTextureCoord);
    vec4 previous = texture2D(uPrevTexture, vTextureCoord) * uFade;

    // Combine current frame with faded previous frame
    gl_FragColor = max(current, previous);
}

Step 2: Initialize Textures and the Filter

Set up your Pixi application, the two swap textures, and the custom filter in JavaScript:

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// 1. Create two render textures of equal size
let renderTextureA = PIXI.RenderTexture.create({ width: 800, height: 600 });
let renderTextureB = PIXI.RenderTexture.create({ width: 800, height: 600 });

// 2. Define uniforms for the filter
const uniforms = {
    uPrevTexture: renderTextureA,
    uFade: 0.92 // Values between 0.85 and 0.98 work best
};

// 3. Create the custom filter
const motionTrailFilter = new PIXI.Filter(null, fragmentShaderSource, uniforms);

// 4. Create an output sprite that covers the screen to display the result
const outputSprite = new PIXI.Sprite(renderTextureB);
app.stage.addChild(outputSprite);

// 5. Create a separate container for your moving elements
const sceneContainer = new PIXI.Container();

// Add any animated object to sceneContainer
const movingDot = new PIXI.Graphics().beginFill(0x00ffcc).drawCircle(0, 0, 15).endFill();
sceneContainer.addChild(movingDot);

Step 3: Implement the Ticker Loop

Within the ticker, render the scene to a temporary target, apply the filter using the previous texture as an input uniform, swap the references, and present the final texture on the screen.

app.ticker.add(() => {
    // Animate your objects inside sceneContainer
    movingDot.x = 400 + Math.cos(app.ticker.lastTime * 0.003) * 200;
    movingDot.y = 300 + Math.sin(app.ticker.lastTime * 0.005) * 150;

    // Point the uniform to the previous frame's texture
    motionTrailFilter.uniforms.uPrevTexture = renderTextureA;

    // Apply the filter to the scene and draw onto the target texture
    sceneContainer.filters = [motionTrailFilter];
    app.renderer.render(sceneContainer, { renderTexture: renderTextureB, clear: false });
    sceneContainer.filters = null;

    // Update display sprite to show the latest result
    outputSprite.texture = renderTextureB;

    // Swap (ping-pong) buffers for the next frame
    const temp = renderTextureA;
    renderTextureA = renderTextureB;
    renderTextureB = temp;
});

Key Considerations

  • Clear Flags: Ensure clear: false is set during rendering to prevent the target texture from being wiped before sampling.
  • Trail Duration: Adjust uFade. Values closer to 1.0 create longer-lasting trails, while lower values cause trails to dissipate faster.
  • Alpha Premultiplication: If your trail colors look dark or discolored, ensure that alpha values in the shader match the premultiplied alpha settings of your Pixi renderer.
