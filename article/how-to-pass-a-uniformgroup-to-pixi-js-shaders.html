How to Pass a UniformGroup to Pixi.js Shaders

In Pixi.js, a UniformGroup allows you to bundle related shader uniforms into a single reusable object, enabling more efficient GPU uploads and easier state management across multiple shaders. This article explains how to instantiate a UniformGroup, bind it to a custom Shader or MeshMaterial, write corresponding GLSL code, and update values dynamically at runtime.

1. Creating a UniformGroup

To define a uniform group, instantiate UniformGroup from pixi.js and provide an object containing your uniform key-value pairs. You can pass raw values or specify explicit types.

import { UniformGroup } from 'pixi.js';

const lightingUniforms = new UniformGroup({
    uLightColor: [1.0, 0.8, 0.6],
    uIntensity: 1.5,
    uLightPosition: [200.0, 150.0]
});

By default, Pixi.js infers the uniform types from the values:

  • Numbers are treated as float (f32).
  • Arrays of length 2, 3, or 4 are treated as vec2, vec3, or vec4.
  • Float32Array can also be used for matrices and vectors.

To mark a group as static or dynamic, you can pass a boolean as the second argument:

// Second argument `true` marks the group as static (rarely updated)
const staticUniforms = new UniformGroup({ uAmbientColor: [0.1, 0.1, 0.2] }, true);

2. Passing the UniformGroup to a Custom Shader

When creating a Shader or MeshMaterial, assign the UniformGroup directly to a key in the shader's uniform dictionary.

import { Shader, Mesh, Geometry } from 'pixi.js';

const vertexShader = `
    attribute vec2 aVertexPosition;
    uniform mat3 translationMatrix;
    uniform mat3 projectionMatrix;

    void main() {
        gl_Position = vec4((projectionMatrix * translationMatrix * vec3(aVertexPosition, 1.0)).xy, 0.0, 1.0);
    }
`;

const fragmentShader = `
    precision mediump float;
    
    uniform vec3 uLightColor;
    uniform float uIntensity;
    uniform vec2 uLightPosition;

    void main() {
        gl_FragColor = vec4(uLightColor * uIntensity, 1.0);
    }
`;

const shader = Shader.from(vertexShader, fragmentShader, {
    // Inject the uniform group here
    lighting: lightingUniforms
});

3. Writing the GLSL Shader Code

Inside your GLSL fragment or vertex shader, declare the uniforms individually matching the keys provided within the UniformGroup. Pixi.js unpacks the group members to match their uniform declarations.

precision mediump float;

// Uniforms defined in the UniformGroup
uniform vec3 uLightColor;
uniform float uIntensity;
uniform vec2 uLightPosition;

void main() {
    gl_FragColor = vec4(uLightColor * uIntensity, 1.0);
}

4. Updating Uniform Values at Runtime

To update values, modify the properties via the .uniforms object on the UniformGroup instance. Pixi.js will automatically detect changes and sync them with the GPU on the next render pass.

// Update individual uniform values directly
lightingUniforms.uniforms.uIntensity = 2.0;
lightingUniforms.uniforms.uLightColor[0] = 0.5;

// If you replace arrays directly or modify static groups, trigger an update manually:
lightingUniforms.uniforms.uLightPosition = [300.0, 400.0];
lightingUniforms.update();

5. Sharing Groups Across Multiple Shaders

A primary benefit of UniformGroup is sharing common state across different shaders without redundant data updates.

const sharedSceneData = new UniformGroup({
    uTime: 0.0,
    uResolution: [window.innerWidth, window.innerHeight]
});

// Pass the same group to multiple materials
const backgroundShader = Shader.from(bgVert, bgFrag, { scene: sharedSceneData });
const foregroundShader = Shader.from(fgVert, fgFrag, { scene: sharedSceneData });

// Updating this once updates the values for both shaders
app.ticker.add((ticker) => {
    sharedSceneData.uniforms.uTime += ticker.deltaTime;
});
