PixiJS: SCALE_MODES.LINEAR vs SCALE_MODES.NEAREST

This article provides a concise comparison between SCALE_MODES.LINEAR and SCALE_MODES.NEAREST in PixiJS, examining how each texture filtering method works, how they alter the visual presentation of scaled sprites, and when to choose one over the other for your game or application.

Understanding Scale Modes in PixiJS

When a sprite or texture is rendered at a different size than its source image, the rendering engine must decide how to display the missing or extra pixels. In PixiJS, texture scale modes dictate the GPU texture filtering algorithm used during texture upscaling (magnification) or downscaling (minification). The two primary options available are SCALE_MODES.LINEAR and SCALE_MODES.NEAREST.

SCALE_MODES.LINEAR

SCALE_MODES.LINEAR uses bilinear interpolation. When a texture is resized, the GPU samples the four nearest pixels to a given point and calculates a weighted average of their colors.

  • Visual Output: Smooth and blended. Edges appear softened rather than jagged.
  • Drawbacks: When scaled significantly above the native resolution, assets can appear blurry or washed out.
  • Best Used For:
    • High-resolution graphics and vector-style art.
    • Photographic or realistically shaded textures.
    • Modern UI elements where smooth gradients and anti-aliased edges are required.

Linear filtering is the default setting in PixiJS because it produces natural, smooth results for standard digital illustrations and user interfaces.

SCALE_MODES.NEAREST

SCALE_MODES.NEAREST uses nearest-neighbor interpolation. Instead of blending adjacent pixel colors, the GPU selects the single pixel whose center is closest to the sample point and copies its color directly.

  • Visual Output: Hard, sharp, and blocky. Pixels retain their distinct square boundaries without color bleeding.
  • Drawbacks: Diagonal lines and curves can appear jagged ("aliased"), and subtle gradients may show harsh banding.
  • Best Used For:
    • Retro, 8-bit, and 16-bit pixel art.
    • Low-resolution textures intended to be magnified cleanly.
    • Fonts or HUD elements designed specifically with pixel precision in mind.

Nearest-neighbor filtering is essential for retro games, as bilinear filtering destroys the deliberate, crisp aesthetic of pixel art by introducing unwanted blur.

Key Differences Summary

Feature SCALE_MODES.LINEAR SCALE_MODES.NEAREST

How to Apply Scale Modes in PixiJS

Scale modes can be set globally for all newly loaded textures or applied individually to specific textures.

Global Configuration

To set the default scale mode across your entire project, update the global setting before loading any assets:

import { BaseTexture, SCALE_MODES } from 'pixi.js';

// Set nearest-neighbor as default (ideal for pixel art games)
BaseTexture.defaultOptions.scaleMode = SCALE_MODES.NEAREST;

Individual Texture Configuration

To apply a scale mode to a specific texture without affecting the rest of the application:

import { Texture, SCALE_MODES } from 'pixi.js';

const texture = Texture.from('path/to/sprite.png');
texture.baseTexture.scaleMode = SCALE_MODES.NEAREST;

Choosing between SCALE_MODES.LINEAR and SCALE_MODES.NEAREST depends entirely on your visual direction. Use LINEAR to maintain smooth edges on modern high-resolution artwork, and switch to NEAREST whenever pixel-perfect sharpness is required.
