Nearest-Neighbor Scaling for Pixel Art in Pixi.js

Rendering pixel art in Pixi.js requires disabling default bilinear filtering so scaled sprites retain their crisp, sharp edges instead of becoming blurry. This article demonstrates how to configure nearest-neighbor filtering using Pixi.js's scaleMode settings, covering both global configurations and per-texture overrides across modern Pixi.js versions, as well as necessary canvas-level CSS adjustments.

Setting Global Scale Mode

Setting the scale mode globally ensures that all textures loaded or created afterward automatically use nearest-neighbor interpolation. This configuration should be executed before any assets are loaded.

Pixi.js v8

In Pixi.js v8, string literals are used to define scale modes, and defaults are applied via the texture source options:

import { TextureSource } from 'pixi.js';

// Set global default to nearest-neighbor
TextureSource.defaultOptions.scaleMode = 'nearest';

Pixi.js v7 and Earlier

In version 7 and earlier, the setting relies on the SCALE_MODES enumeration applied to the base texture defaults:

import * as PIXI from 'pixi.js';

// Pixi.js v7
PIXI.BaseTexture.defaultOptions.scaleMode = PIXI.SCALE_MODES.NEAREST;

// Pixi.js v6 and older
PIXI.settings.SCALE_MODE = PIXI.SCALE_MODES.NEAREST;

Applying Scale Mode to Individual Textures

If a project combines high-resolution assets with pixel art, set the scale mode directly on the specific texture instead of changing the global setting.

Pixi.js v8

Modify the underlying source of the texture:

import { Assets } from 'pixi.js';

const texture = await Assets.load('character.png');
texture.source.scaleMode = 'nearest';

Pixi.js v7 and Earlier

Modify the baseTexture object:

const texture = PIXI.Texture.from('character.png');
texture.baseTexture.scaleMode = PIXI.SCALE_MODES.NEAREST;

// If the texture was already rendered to the screen, trigger an update
texture.baseTexture.update();

Canvas CSS Scaling

If the entire game canvas is rendered at a low base resolution and scaled up to fit the window or display via CSS, the browser may apply its own smoothing. To preserve pixelation at the HTML canvas level, apply the following CSS rules to the Pixi view element:

canvas {
    image-rendering: -moz-crisp-edges;
    image-rendering: -webkit-crisp-edges;
    image-rendering: pixelated;
    image-rendering: crisp-edges;
}

Combining the WebGL texture scaleMode with CSS image-rendering guarantees completely sharp pixel art across all scaling layers in Pixi.js.
