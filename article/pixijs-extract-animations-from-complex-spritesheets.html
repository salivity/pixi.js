PixiJS: Extract Animations from Complex Spritesheets

Extracting individual animated sequences from a complex spritesheet in Pixi.js involves slicing a master texture into specific frame coordinates and assigning those frames to an AnimatedSprite. This guide covers how to achieve this using both JSON-based texture atlases—the standard, efficient approach—and programmatic frame extraction using manual cropping rectangles for raw image files.

Method 1: Using a JSON Texture Atlas (Recommended)

When working with complex spritesheets, the cleanest workflow is exporting a single image alongside a JSON atlas using tools like TexturePacker. The JSON file maps out frame positions, dimensions, and named animation sequences.

1. Load the Spritesheet

Use Pixi.js's modern Assets API to load the JSON file. Pixi automatically parses the JSON and loads the corresponding image.

import * as PIXI from 'pixi.js';

// Load the JSON atlas (which references the spritesheet image)
const sheet = await PIXI.Assets.load('assets/character.json');

2. Access and Play Named Sequences

If your JSON atlas defines animations, Pixi.js groups them automatically inside the sheet.animations object.

// Access the pre-defined 'walk' animation sequence
const walkFrames = sheet.animations['walk'];

// Create the AnimatedSprite
const character = new PIXI.AnimatedSprite(walkFrames);

// Configure animation settings
character.animationSpeed = 0.16; // Speed multiplier (default is 1)
character.loop = true;
character.play();

// Add to stage
app.stage.addChild(character);

Method 2: Manual Frame Extraction from a Raw Spritesheet

If you only have an image file without a JSON descriptor, you can manually define coordinates using PIXI.Rectangle and slice the base texture.

1. Load the Base Texture

Load your image using the Assets manager:

const texture = await PIXI.Assets.load('assets/spritesheet.png');

2. Crop Frames Programmatically

Extract each frame by instantiating new PIXI.Texture objects bound to specific sub-regions of the base texture.

function extractAnimationSequence(baseTexture, frameCoords) {
    return frameCoords.map(coord => {
        const rect = new PIXI.Rectangle(coord.x, coord.y, coord.w, coord.h);
        return new PIXI.Texture({
            source: baseTexture.source,
            frame: rect
        });
    });
}

// Define the exact coordinates of the frames for an animation sequence (e.g., 'attack')
const attackFrameData = [
    { x: 0,   y: 128, w: 64, h: 64 },
    { x: 64,  y: 128, w: 64, h: 64 },
    { x: 128, y: 128, w: 64, h: 64 },
    { x: 192, y: 128, w: 64, h: 64 }
];

const attackTextures = extractAnimationSequence(texture, attackFrameData);

3. Loop-Based Grid Extraction

If your complex spritesheet uses a consistent grid layout for an animation row:

function extractGridRow(baseTexture, row, frameWidth, frameHeight, totalFrames) {
    const frames = [];
    for (let i = 0; i < totalFrames; i++) {
        const rect = new PIXI.Rectangle(i * frameWidth, row * frameHeight, frameWidth, frameHeight);
        frames.push(new PIXI.Texture({
            source: baseTexture.source,
            frame: rect
        }));
    }
    return frames;
}

// Extract 6 frames from row index 2, where each frame is 32x32 pixels
const runFrames = extractGridRow(texture, 2, 32, 32, 6);

4. Create and Control the AnimatedSprite

Pass the extracted texture array directly into an AnimatedSprite.

const animatedCharacter = new PIXI.AnimatedSprite(attackTextures);

animatedCharacter.x = 100;
animatedCharacter.y = 100;
animatedCharacter.animationSpeed = 0.2;
animatedCharacter.loop = false;

// Handle animation completion
animatedCharacter.onComplete = () => {
    console.log('Attack animation finished');
};

animatedCharacter.play();
app.stage.addChild(animatedCharacter);

Switching Sequences on the Same Sprite

To alternate between animations (such as switching from "idle" to "run"), update the sprite's textures property directly:

function switchAnimation(sprite, newTextures, speed = 0.15) {
    sprite.stop();
    sprite.textures = newTextures;
    sprite.animationSpeed = speed;
    sprite.gotoAndPlay(0);
}

// Usage
switchAnimation(character, sheet.animations['run'], 0.2);
