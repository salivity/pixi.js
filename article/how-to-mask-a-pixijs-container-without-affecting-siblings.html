How to Mask a PixiJS Container Without Affecting Siblings

This article explains how to apply a mask to a single PIXI.Container in Pixi.js so that only its contents are clipped, leaving adjacent sibling containers completely untouched. By properly isolating the mask assignment to the target container's .mask property and managing display list positioning, you can prevent visual clipping from bleeding across your scene hierarchy.

Understanding Container-Level Masking

In Pixi.js, the .mask property applies exclusively to the display object it is assigned to and that object's descendant children. Siblings within the same parent will never be clipped by that mask as long as the mask is applied directly to the specific child container rather than their shared parent.

Step-by-Step Implementation

To isolate a mask to a single container:

  1. Create the parent and sibling containers.
  2. Create the masking geometry (typically a PIXI.Graphics object).
  3. Add the mask object to the display list (usually inside the target container or alongside it so it inherits the correct coordinate space).
  4. Assign the mask directly to the target container's .mask property.
import * as PIXI from 'pixi.js';

// 1. Set up the parent container
const parentContainer = new PIXI.Container();

// 2. Create the target container that needs masking
const maskedContainer = new PIXI.Container();

// Add some content to be masked
const spriteA = PIXI.Sprite.from('texture1.png');
maskedContainer.addChild(spriteA);

// 3. Create the sibling container that must remain unaffected
const siblingContainer = new PIXI.Container();
siblingContainer.x = 300;

// Add content to the sibling
const spriteB = PIXI.Sprite.from('texture2.png');
siblingContainer.addChild(spriteB);

// 4. Create the mask shape
const maskGraphic = new PIXI.Graphics();
maskGraphic.beginFill(0xffffff);
maskGraphic.drawCircle(100, 100, 75);
maskGraphic.endFill();

// 5. Add the mask to the display tree and apply it
// Adding the mask as a child of the container keeps their coordinates aligned
maskedContainer.addChild(maskGraphic);
maskedContainer.mask = maskGraphic;

// 6. Add both siblings to the main parent
parentContainer.addChild(maskedContainer);
parentContainer.addChild(siblingContainer);

Critical Details to Prevent Leaking and Coordinate Issues

  • Coordinate Alignment: If you add the mask graphic as a child of the maskedContainer, moving maskedContainer automatically moves the mask with it. If you add maskGraphic to parentContainer instead, the mask stays fixed in world coordinates while maskedContainer moves independently.
  • Never Assign to the Parent: Ensure you write maskedContainer.mask = maskGraphic and never parentContainer.mask = maskGraphic. Assigning a mask to the parent automatically restricts every sibling inside that parent.
  • Disabling the Mask: If you need to clear the mask dynamically later in execution, set maskedContainer.mask = null;. The sibling container will continue rendering without interruption.
