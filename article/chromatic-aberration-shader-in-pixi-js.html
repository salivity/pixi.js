Chromatic Aberration Shader in Pixi.js

Chromatic aberration is a popular optical distortion effect that mimics lens imperfection by separating a visual's red, green, and blue color channels. In Pixi.js, you can achieve this post-processing effect using a custom fragment shader wrapped within a PIXI.Filter. This guide demonstrates how to write the GLSL fragment code, define the filter in JavaScript, and apply it to your render pipeline.

1. The Fragment Shader (GLSL)

The chromatic aberration effect works by sampling the texture multiple times at slight spatial offsets for each primary color channel. Below is the GLSL fragment shader code:

precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;

uniform vec2 uRedOffset;
uniform vec2 uGreenOffset;
uniform vec2 uBlueOffset;

void main(void) {
    // Sample each channel with a distinct coordinate offset
    float r = texture2D(uSampler, vTextureCoord + uRedOffset).r;
    float g = texture2D(uSampler, vTextureCoord + uGreenOffset).g;
    float b = texture2D(uSampler, vTextureCoord + uBlueOffset).b;
    
    // Sample original alpha to preserve transparency
    float a = texture2D(uSampler, vTextureCoord).a;

    gl_FragColor = vec4(r, g, b, a);
}

2. Creating the Custom Filter in JavaScript

Pixi.js provides the PIXI.Filter class to encapsulate custom shaders and pass uniform values from JavaScript to the GPU.

import * as PIXI from 'pixi.js';

// Define the fragment shader string
const fragmentShader = `
precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;

uniform vec2 uRedOffset;
uniform vec2 uGreenOffset;
uniform vec2 uBlueOffset;

void main(void) {
    float r = texture2D(uSampler, vTextureCoord + uRedOffset).r;
    float g = texture2D(uSampler, vTextureCoord + uGreenOffset).g;
    float b = texture2D(uSampler, vTextureCoord + uBlueOffset).b;
    float a = texture2D(uSampler, vTextureCoord).a;

    gl_FragColor = vec4(r, g, b, a);
}
`;

// Define the uniform values (offsets are in normalized texture space)
const uniforms = {
    uRedOffset: new Float32Array([0.005, 0.0]),
    uGreenOffset: new Float32Array([0.0, 0.0]),
    uBlueOffset: new Float32Array([-0.005, 0.0]),
};

// Create the filter instance (null vertex shader uses Pixi's default quad shader)
const chromaticAberrationFilter = new PIXI.Filter(null, fragmentShader, uniforms);

3. Applying the Filter to the Stage

Assign the filter to any PIXI.Container or PIXI.Sprite via the filters array property:

// Initialize Pixi application
const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Create a container or load a sprite
const container = new PIXI.Container();
app.stage.addChild(container);

// Add your display objects to the container
const sprite = PIXI.Sprite.from('path/to/image.png');
container.addChild(sprite);

// Apply the filter
container.filters = [chromaticAberrationFilter];

4. Animating the Effect

You can dynamically modify the uniform values inside Pixi's ticker loop to create pulsing, glitching, or motion-reactive distortions:

let time = 0;

app.ticker.add((delta) => {
    time += delta * 0.05;
    
    // Oscillate the red and blue offsets over time
    const intensity = Math.sin(time) * 0.008;
    chromaticAberrationFilter.uniforms.uRedOffset[0] = intensity;
    chromaticAberrationFilter.uniforms.uBlueOffset[0] = -intensity;
});
