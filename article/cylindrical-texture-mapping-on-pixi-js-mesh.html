Cylindrical Texture Mapping on Pixi.js Mesh

Mapping panoramic cylindrical textures onto a curved surface in Pixi.js requires building a custom PIXI.Mesh with geometry that mimics cylindrical curvature. By subdividing a rectangular plane into multiple vertical slices and applying trigonometric functions to the vertex positions, you can simulate 3D cylinder perspective in Pixi's 2D WebGL environment while keeping UV coordinates mapped linearly to project the panoramic image without distortion.

1. The Core Components of a Pixi.js Mesh

A custom PIXI.Mesh uses PIXI.Geometry to define the shape and mapping of a texture. To create a curved cylindrical surface, you must construct three typed arrays:

  • Vertices (Float32Array): Defines the 2D screen coordinates \((x, y)\) for each point on the curved grid.
  • UVs (Float32Array): Maps the panoramic texture coordinates \((u, v)\) from 0.0 to 1.0 corresponding to each vertex.
  • Indices (Uint16Array): Connects the vertices into triangles to render the surface geometry.

2. Mathematical Projection for Cylindrical Curvature

To simulate a cylinder, divide the mesh into horizontal segments (\(S\)). Each segment represents a step along a radial arc:

  1. Angular Distribution: Define an arc angle (Field of View), such as \(\theta_{fov} = \pi / 2\) (\(90^\circ\)). The angle for each horizontal step \(i\) is: \[\theta_i = -\frac{\theta_{fov}}{2} + \left(\frac{i}{S}\right) \times \theta_{fov}\]
  2. Curvature and Perspective:
    • \(X\) position: \(x_i = \text{center}_x + R \times \sin(\theta_i)\)
    • Depth (\(Z\)): \(z_i = R \times \cos(\theta_i)\)
    • Perspective Scale: Scale factor \(k_i = \frac{d}{d + (R - z_i)}\), where \(d\) is the simulated camera distance and \(R\) is the cylinder radius.
    • Final Screen Coordinates: \[X_{screen} = \text{center}_x + (R \times \sin(\theta_i)) \times k_i\] \[Y_{top} = \text{center}_y - \left(\frac{\text{height}}{2}\right) \times k_i\] \[Y_{bottom} = \text{center}_y + \left(\frac{\text{height}}{2}\right) \times k_i\]

3. Implementation Example

The following script constructs a curved cylindrical mesh and maps a panoramic texture onto it:

import * as PIXI from 'pixi.js';

function createCylindricalMesh(texture, segments = 32, radius = 400, fov = Math.PI / 2, height = 300) {
    const cols = segments;
    const rows = 1;
    const totalVertices = (cols + 1) * (rows + 1);

    const vertices = new Float32Array(totalVertices * 2);
    const uvs = new Float32Array(totalVertices * 2);
    const indices = new Uint16Array(cols * rows * 6);

    const cameraDistance = 500;
    let vIndex = 0;
    let uvIndex = 0;

    // Generate Vertices and UVs
    for (let r = 0; r <= rows; r++) {
        const v = r / rows;
        const baseOffsetY = (v - 0.5) * height;

        for (let c = 0; c <= cols; c++) {
            const u = c / cols;
            const angle = -fov / 2 + u * fov;

            const sin = Math.sin(angle);
            const cos = Math.cos(angle);

            // Calculate depth and perspective scale
            const z = radius * (1 - cos);
            const scale = cameraDistance / (cameraDistance + z);

            const x = radius * sin * scale;
            const y = baseOffsetY * scale;

            vertices[vIndex++] = x;
            vertices[vIndex++] = y;

            uvs[uvIndex++] = u;
            uvs[uvIndex++] = v;
        }
    }

    // Generate Triangle Indices
    let iIndex = 0;
    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            const current = r * (cols + 1) + c;
            const next = current + (cols + 1);

            indices[iIndex++] = current;
            indices[iIndex++] = next;
            indices[iIndex++] = current + 1;

            indices[iIndex++] = current + 1;
            indices[iIndex++] = next;
            indices[iIndex++] = next + 1;
        }
    }

    const geometry = new PIXI.Geometry()
        .addAttribute('aVertexPosition', vertices, 2)
        .addAttribute('aTextureCoord', uvs, 2)
        .addIndex(indices);

    return new PIXI.Mesh(geometry, new PIXI.MeshMaterial(texture));
}

4. Animating and Panning the Panorama

To rotate the panoramic view around the cylinder without recalculating mesh geometry, continuously offset the horizontal texture coordinates:

app.ticker.add((delta) => {
    const uvBuffer = mesh.geometry.getBuffer('aTextureCoord');
    const uvArray = uvBuffer.data;
    const speed = 0.002 * delta;

    for (let i = 0; i < uvArray.length; i += 2) {
        uvArray[i] = (uvArray[i] + speed) % 1.0;
    }
    uvBuffer.update();
});

Ensure the source texture's wrap mode is set to PIXI.WRAP_MODES.REPEAT to prevent seams when wrapping the UV coordinates across edges.
