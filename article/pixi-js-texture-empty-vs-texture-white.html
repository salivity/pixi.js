Pixi.js Texture.EMPTY vs Texture.WHITE

In Pixi.js, Texture.EMPTY and Texture.WHITE are built-in static textures designed for different utility roles within a rendering pipeline. While Texture.EMPTY acts as a transparent, non-rendering placeholder to represent the absence of visual data, Texture.WHITE provides a solid, single-color white pixel surface designed for tinting and drawing procedural colored rectangles without loading external image assets.

Texture.EMPTY

Texture.EMPTY is a shared empty texture with no visual content and an effective size of zero. When rendered via a Sprite, it does not draw any visible pixels to the screen.

  • Primary Purpose: It serves as a safe default or placeholder when a display object requires a texture reference, but no image should be displayed.
  • Common Use Cases:
    • Initializing a Sprite before an asset has finished loading asynchronously, avoiding null or undefined runtime exceptions.
    • Creating invisible interactive regions (hit areas) or structural container nodes when you do not want to load a blank transparent PNG.
  • Rendering Behavior: Pixi.js recognizes that it has no underlying resource to draw, so it contributes no visible geometry to the render batch.

Texture.WHITE

Texture.WHITE is a pre-generated, solid white texture (typically a 16x16 canvas or single-pixel texture internally). Because it is completely opaque and pure white (#FFFFFF), it interacts predictably with Pixi.js's color multiplication engine.

  • Primary Purpose: It functions as a lightweight base for solid-color primitives that can be dynamically tinted and scaled.
  • Common Use Cases:
    • Creating flat-color UI elements, bounding boxes, health bars, or solid backgrounds without using PIXI.Graphics.
    • Achieving higher rendering performance than PIXI.Graphics by taking advantage of the standard Sprite batch renderer.
  • Tinting Capability: Setting sprite.tint = 0xFF0000 on a sprite using Texture.WHITE produces a crisp, solid red rectangle.

Key Differences

Feature Texture.EMPTY Texture.WHITE
Visual Appearance Completely transparent / none Solid white
Dimensions 0 × 0 pixels Solid block (commonly 16 × 16)
Tinting Support No effect (remains invisible) Multiplies directly with the tint color
Performance Impact Bypasses standard drawing operations Batches as standard textured quads
Best Used For Fallbacks, invisible anchors, load placeholders Fast colored shapes, UI panels, health bars

Summary

Use Texture.EMPTY when you need a safe Sprite reference that displays nothing. Use Texture.WHITE combined with width, height, and tint properties when you need to draw colored boxes and UI panels efficiently using the sprite batcher.
