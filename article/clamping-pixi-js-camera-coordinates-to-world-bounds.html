Clamping Pixi.js Camera Coordinates to World Bounds

This guide explains how to restrict camera movement in Pixi.js to prevent the viewport from showing empty space beyond the edges of your game world. By calculating boundaries based on the world dimensions and screen resolution, you can clamp the position of your main world container using standard mathematical limits or third-party camera plugins.

Understanding Camera Movement in Pixi.js

Pixi.js does not have a built-in dedicated camera object. Instead, camera movement is simulated by moving a parent Container that holds all world elements. When the target (such as a player character) moves right, the world container moves left by the same amount:

worldContainer.x = (app.screen.width / 2) - player.x;
worldContainer.y = (app.screen.height / 2) - player.y;

Without boundary constraints, moving near the edges of the map causes the background to slide into the center of the screen, revealing an empty canvas.

The Clamping Formula

To stop the viewport at the edge of the world, clamp the container's coordinates between a minimum and a maximum boundary.

Assuming the top-left corner of your world is at (0, 0):

  • The maximum position of the container is 0 (the left/top edge aligned with the screen's left/top edge).
  • The minimum position is screenDimension - worldDimension (the right/bottom edge aligned with the screen's right/bottom edge).
function updateCamera(player, worldContainer, app, worldWidth, worldHeight) {
    // 1. Center the camera on the target
    let targetX = (app.screen.width / 2) - player.x;
    let targetY = (app.screen.height / 2) - player.y;

    // 2. Define boundaries
    const minX = app.screen.width - worldWidth;
    const maxX = 0;
    const minY = app.screen.height - worldHeight;
    const maxY = 0;

    // 3. Clamp values
    worldContainer.x = Math.max(minX, Math.min(maxX, targetX));
    worldContainer.y = Math.max(minY, Math.min(maxY, targetY));
}

Handling Worlds Smaller Than the Screen

If the world size is smaller than the viewport, app.screen.width - worldWidth produces a positive number, causing the boundaries to invert. To prevent erratic snapping, ensure your world size is greater than or equal to the viewport size, or center the world container when the condition occurs:

if (worldWidth < app.screen.width) {
    worldContainer.x = (app.screen.width - worldWidth) / 2;
} else {
    worldContainer.x = Math.max(minX, Math.min(maxX, targetX));
}

Clamping with pixi-viewport

If you are using the popular pixi-viewport library, boundary clamping is built into its plugin pipeline via the .clamp() method:

import { Viewport } from 'pixi-viewport';

const viewport = new Viewport({
    screenWidth: window.innerWidth,
    screenHeight: window.innerHeight,
    worldWidth: 2000,
    worldHeight: 2000,
    events: app.renderer.events
});

app.stage.addChild(viewport);

viewport
    .follow(player)
    .clamp({
        left: 0,
        right: 2000,
        top: 0,
        bottom: 2000,
        direction: 'all',
        underflow: 'center'
    });

Using .clamp() automatically prevents the viewport from showing out-of-bounds space while also centering any dimension where the world is smaller than the screen (underflow: 'center').
