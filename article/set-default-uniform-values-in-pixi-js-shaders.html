Set Default Uniform Values in Pixi.js Shaders

In Pixi.js, setting default uniform values for a custom shader is accomplished during the shader's instantiation by passing a uniforms object or a UniformGroup. This article demonstrates how to define default uniforms directly within PIXI.Shader.from(), structure them using PIXI.UniformGroup, and ensure default states align with custom GLSL code.

1. Defining Uniforms with PIXI.Shader.from()

The most common way to create a shader is using the static PIXI.Shader.from() method. You define default values by passing a JavaScript object as the third argument. The keys must match the uniform names in your GLSL fragment or vertex source code.

import * as PIXI from 'pixi.js';

const vertexSrc = `
    attribute vec2 aVertexPosition;
    attribute vec2 aTextureCoord;
    uniform mat3 translationMatrix;
    uniform mat3 projectionMatrix;
    varying vec2 vTextureCoord;

    void main() {
        vTextureCoord = aTextureCoord;
        gl_Position = vec4((projectionMatrix * translationMatrix * vec3(aVertexPosition, 1.0)).xy, 0.0, 1.0);
    }
`;

const fragmentSrc = `
    varying vec2 vTextureCoord;
    uniform vec3 uColor;
    uniform float uAlpha;

    void main() {
        gl_FragColor = vec4(uColor, uAlpha);
    }
`;

// Define default uniform values
const defaultUniforms = {
    uColor: [1.0, 0.5, 0.0], // Default orange tint (RGB)
    uAlpha: 1.0              // Default fully opaque
};

// Create the shader with the defaults
const customShader = PIXI.Shader.from(vertexSrc, fragmentSrc, defaultUniforms);

2. Using PIXI.UniformGroup

For advanced use cases—such as sharing uniform buffers, syncing uniforms across multiple materials, or handling static flags—wrap your default values inside a PIXI.UniformGroup.

import * as PIXI from 'pixi.js';

const uniformGroup = new PIXI.UniformGroup({
    uColor: new Float32Array([0.2, 0.8, 0.4]),
    uAlpha: 0.75,
    uTime: 0.0
});

const shader = PIXI.Shader.from(vertexSrc, fragmentSrc, uniformGroup);

3. Setting Defaults in Custom Filters

If you are using PIXI.Filter instead of a standalone PIXI.Shader, default uniforms are passed similarly through the constructor.

import * as PIXI from 'pixi.js';

class CustomFilter extends PIXI.Filter {
    constructor() {
        const defaultUniforms = {
            uBrightness: 1.2,
            uContrast: 1.0
        };

        super(vertexSrc, fragmentSrc, defaultUniforms);
    }

    // Optional: Getters and setters for convenience
    get brightness() {
        return this.uniforms.uBrightness;
    }

    set brightness(value) {
        this.uniforms.uBrightness = value;
    }
}

4. Updating Uniforms at Runtime

Any default value passed during creation is directly accessible and mutable through the shader.uniforms object:

// Overwrite the initial default uniform value
customShader.uniforms.uAlpha = 0.5;

// Vector uniforms can be assigned as arrays or typed arrays
customShader.uniforms.uColor = [0.0, 0.0, 1.0];
