Pass a Dynamic LUT Texture to Pixi.js Fragment Shader

This guide explains how to supply and dynamically update a lookup table (LUT) texture within a Pixi.js fragment shader. You will learn how to generate data-driven color maps using typed arrays and raw buffer resources, bind them to a custom filter as a texture uniform, and trigger real-time updates to achieve dynamic color grading, heatmaps, or palette cycling.

1. Generating the Dynamic LUT Data

A lookup table can be represented as a 1D or 2D array of pixel data. To make it dynamic and performant, store the color values in a Uint8Array (for 8-bit RGBA) or a Float32Array (for floating-point data) and wrap it inside a Pixi.js BufferResource.

// Define dimensions for a 256x1 gradient LUT
const lutWidth = 256;
const lutHeight = 1;
const lutData = new Uint8Array(lutWidth * lutHeight * 4);

// Populate with initial color data (e.g., black-to-red gradient)
function updateLutData(time = 0) {
  for (let i = 0; i < lutWidth; i++) {
    const index = i * 4;
    lutData[index]     = (i + time) % 256; // Red
    lutData[index + 1] = 0;                // Green
    lutData[index + 2] = 255 - ((i + time) % 256); // Blue
    lutData[index + 3] = 255;              // Alpha
  }
}
updateLutData();

2. Creating the Dynamic Pixi.js Texture

Instantiate a PIXI.BufferResource backed by your typed array, then attach it to a PIXI.BaseTexture and PIXI.Texture. Ensure that texture filtering matches your intended look (PIXI.SCALE_MODES.LINEAR for smooth transitions or NEAREST for stepped palettes).

import * as PIXI from 'pixi.js';

const lutResource = new PIXI.BufferResource(lutData, {
  width: lutWidth,
  height: lutHeight,
});

const lutBaseTexture = new PIXI.BaseTexture(lutResource, {
  scaleMode: PIXI.SCALE_MODES.LINEAR,
  wrapMode: PIXI.WRAP_MODES.CLAMP,
  format: PIXI.FORMATS.RGBA,
  type: PIXI.TYPES.UNSIGNED_BYTE,
});

const lutTexture = new PIXI.Texture(lutBaseTexture);

3. Writing the Fragment Shader

The fragment shader receives two textures: the original rendered scene (uSampler) and your dynamic LUT (uLut). For a 1D gradient mapping, calculate the luminance of the source fragment and use it as the X-coordinate to sample the LUT texture.

precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;
uniform sampler2D uLut;

void main(void) {
    vec4 color = texture2D(uSampler, vTextureCoord);

    // Calculate perceived brightness (luminance)
    float luminance = dot(color.rgb, vec3(0.299, 0.587, 0.114));

    // Sample the LUT using luminance on the X axis
    vec4 lutColor = texture2D(uLut, vec2(luminance, 0.5));

    // Preserve the original alpha channel
    gl_FragColor = vec4(lutColor.rgb, color.a);
}

4. Creating and Applying the Filter

Pass the custom fragment shader and your LUT texture into a new PIXI.Filter.

const fragmentSrc = `...`; // Shader code from Step 3

const uniforms = {
  uLut: lutTexture,
};

const lutFilter = new PIXI.Filter(undefined, fragmentSrc, uniforms);

// Apply the filter to a container or sprite
app.stage.filters = [lutFilter];

5. Modifying the LUT at Runtime

To update the dynamic LUT during runtime:

  1. Mutate the values directly inside your existing Uint8Array.
  2. Call lutBaseTexture.update() to inform WebGL that the pixel data has changed.
app.ticker.add((delta) => {
  // Update the array data
  updateLutData(performance.now() * 0.1);

  // Upload the updated array buffer to the GPU
  lutBaseTexture.update();
});

Using BufferResource avoids reallocating memory on each frame, ensuring efficient GPU texture uploads for dynamic color manipulation in Pixi.js.
