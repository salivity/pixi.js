How to Project Isometric Coordinates in Pixi.js

Projecting 3D isometric coordinates into 2D screen coordinates is essential for building isometric tilemaps, strategy games, and virtual worlds. This guide explains the core mathematical formula behind isometric projection, demonstrates how to implement the conversion in JavaScript, and shows how to position Pixi.js display objects like sprites and containers accurately on the screen while handling depth sorting.

The Isometric Projection Formula

In standard isometric projection (often using a 2:1 ratio where the tile width is twice its height), world coordinates \((x, y, z)\) map to 2D screen coordinates \((X, Y)\) using linear transformations:

  • Screen X: \((x - y) \times (\text{tileWidth} / 2)\)
  • Screen Y: \((x + y) \times (\text{tileHeight} / 2) - (z \times \text{tileHeight})\)

Here, \(x\) and \(y\) represent the horizontal grid positions, while \(z\) represents elevation or height above the ground plane.

Coordinate Conversion Function

You can encapsulate this logic into a reusable helper function that outputs standard Pixi.js Point coordinates:

import * as PIXI from 'pixi.js';

const TILE_WIDTH = 64;
const TILE_HEIGHT = 32;

/**
 * Converts isometric grid coordinates into 2D screen coordinates.
 * @param {number} x - Grid X position.
 * @param {number} y - Grid Y position.
 * @param {number} [z=0] - Elevation/Height.
 * @returns {PIXI.Point} The corresponding 2D screen position.
 */
function isoToScreen(x, y, z = 0) {
    const screenX = (x - y) * (TILE_WIDTH / 2);
    const screenY = (x + y) * (TILE_HEIGHT / 2) - (z * TILE_HEIGHT);
    
    return new PIXI.Point(screenX, screenY);
}

Applying Coordinates to Pixi.js Display Objects

To place a PIXI.Sprite on your isometric map, compute the target position and assign it directly to the sprite's x and y properties.

When positioning isometric sprites, set their anchor to the bottom-center (0.5, 1.0) so that the base of the sprite aligns with the center of the isometric tile floor.

const sprite = PIXI.Sprite.from('assets/building.png');

// Align sprite base with the tile footprint
sprite.anchor.set(0.5, 1.0);

// Target coordinates in the grid: x = 3, y = 5, elevation = 0
const gridX = 3;
const gridY = 5;
const gridZ = 0;

const screenPos = isoToScreen(gridX, gridY, gridZ);

// Offset by map center or camera view if needed
const mapOffsetX = app.screen.width / 2;
const mapOffsetY = 100;

sprite.position.set(screenPos.x + mapOffsetX, screenPos.y + mapOffsetY);

container.addChild(sprite);

Depth Sorting and Z-Indexing

Isometric rendering requires objects closer to the camera to render in front of objects further away. In a 2:1 isometric grid, depth is determined by the sum of the \(x\) and \(y\) coordinates, with \(z\) applied as an offset.

Enable sortableChildren on the parent container and assign each sprite a zIndex:

const worldContainer = new PIXI.Container();
worldContainer.sortableChildren = true;

// Set zIndex based on depth
sprite.zIndex = gridX + gridY + gridZ;
worldContainer.addChild(sprite);

Whenever positions change dynamically, updating the zIndex ensures Pixi.js renders the visual layers in the correct isometric perspective.
