Pixi.js accessibleTitle and accessibleHint Guide

Pixi.js renders graphics directly inside an HTML <canvas> element, making visual content inherently invisible to screen readers without an underlying accessibility layer. To bridge this gap, Pixi.js provides built-in accessibility tools that generate invisible HTML DOM elements mirroring the canvas display objects. This article explains the purpose of the accessibleTitle and accessibleHint properties on interactive Pixi.js objects, detailing how they function, how they communicate with assistive technologies, and how to implement them effectively.

The Pixi.js Accessibility System

When you set an object's accessible property to true, the Pixi.js AccessibilityManager creates an invisible HTML element (typically a <button> or <div>) positioned directly over the canvas object. This enables screen readers to detect, focus on, and interact with the canvas object just like standard web elements.

The accessibleTitle and accessibleHint properties are attributes assigned to these generated DOM elements to convey meaning and context to users who rely on assistive technologies.

Understanding accessibleTitle

The accessibleTitle property serves as the primary accessible name or label for an interactive display object.

  • Primary Purpose: It identifies what the object is or what immediate action it performs.
  • DOM Implementation: Pixi.js typically maps accessibleTitle to the accessible label or text content of the generated HTML overlay element, which screen readers announce when the element gains focus.
  • Example Use Cases: Setting accessibleTitle = "Start Game" on a play button, or accessibleTitle = "Settings" on a gear icon.

If accessibleTitle is omitted on an accessible object, a screen reader may only announce the element as an unlabeled button, leaving the user with no context regarding its function.

Understanding accessibleHint

The accessibleHint property provides additional context, instructions, or secondary information about interacting with the object.

  • Primary Purpose: It describes how to interact with the object or what will happen as a consequence of the interaction.
  • DOM Implementation: Pixi.js uses this property to provide descriptive metadata, often mapping to accessible description attributes (such as the HTML title or description semantics) that screen readers read following the primary label.
  • Example Use Cases: Setting accessibleHint = "Opens the audio configuration menu" on a settings button, or accessibleHint = "Double-click to equip this item" on an inventory icon.

Implementation Example

To use these properties, ensure the display object is interactive and accessible:

import { Application, Sprite, Texture } from 'pixi.js';

const app = new Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

// Create an interactive sprite
const button = new Sprite(Texture.WHITE);
button.width = 150;
button.height = 50;

// Enable interaction and accessibility
button.eventMode = 'static';
button.accessible = true;

// Define accessibility labels
button.accessibleTitle = "Save Progress";
button.accessibleHint = "Saves your current game state to the cloud";

// Attach standard click/pointer events
button.on('pointertap', () => {
    console.log("Game saved.");
});

app.stage.addChild(button);

Best Practices

  • Keep Titles Concise: Use short, action-oriented phrases for accessibleTitle (e.g., "Mute Audio", "Close Window").
  • Use Hints for Non-Obvious Behavior: Only populate accessibleHint when the action requires further explanation or produces a non-standard outcome. If the title is completely self-explanatory, a hint may be redundant.
  • Always Enable Accessibility Explicitly: Neither accessibleTitle nor accessibleHint will function unless the object has accessible = true and eventMode (or interactive in older Pixi versions) enabled.
