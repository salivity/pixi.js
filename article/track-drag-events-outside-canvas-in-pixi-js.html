Track Drag Events Outside Canvas in Pixi.js

Tracking pointer events beyond the boundaries of a <canvas> element is essential for creating smooth drag-and-drop interactions in Pixi.js. By default, moving the cursor outside the canvas halts event dispatching, causing dragged elements to stick or stutter. This guide explains how to use the HTML5 Pointer Capture API alongside Pixi.js's modern Federated Events system to maintain continuous pointer tracking anywhere on the screen.

The Problem with Canvas Boundaries

When a user drags an object in Pixi.js, the event system relies on DOM events dispatched by the canvas element. If the user moves the pointer too quickly or drags an object near the edge of the viewport, the pointer leaves the canvas. Once outside, the canvas stops receiving standard mouse or touch events, preventing pointermove updates and often missing the terminating pointerup event.

The Solution: setPointerCapture

The native DOM Element.setPointerCapture() method redirects all subsequent pointer events for a specific pointerId to the target DOM element, even if the cursor moves outside the browser window or over other DOM elements. Integrating this with the Pixi.js canvas ensures uninterrupted event delivery.

Implementation

To implement pointer capture in Pixi.js (v7 and v8):

  1. Set the target display object's eventMode to 'static'.
  2. Access the pointerId from the Pixi event on pointerdown.
  3. Call setPointerCapture(event.pointerId) on the Pixi canvas (app.canvas in v8 or app.view in v7).
  4. Listen for movement and handle cleanup by calling releasePointerCapture when the drag ends.
import { Application, Graphics } from 'pixi.js';

const app = new Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

// Create a draggable object
const box = new Graphics()
    .rect(0, 0, 100, 100)
    .fill(0x3498db);

box.eventMode = 'static';
box.cursor = 'grab';

let isDragging = false;
let dragOffset = { x: 0, y: 0 };

box.on('pointerdown', (event) => {
    isDragging = true;
    box.cursor = 'grabbing';

    // Calculate local offset so the object doesn't jump to the cursor
    dragOffset.x = event.global.x - box.x;
    dragOffset.y = event.global.y - box.y;

    // Capture the pointer on the canvas element
    const canvas = app.canvas || app.view;
    canvas.setPointerCapture(event.pointerId);
});

box.on('globalpointermove', (event) => {
    if (!isDragging) return;

    box.x = event.global.x - dragOffset.x;
    box.y = event.global.y - dragOffset.y;
});

const onDragEnd = (event) => {
    if (!isDragging) return;

    isDragging = false;
    box.cursor = 'grab';

    // Release the captured pointer
    const canvas = app.canvas || app.view;
    if (canvas.hasPointerCapture(event.pointerId)) {
        canvas.releasePointerCapture(event.pointerId);
    }
};

box.on('pointerup', onDragEnd);
box.on('pointerupoutside', onDragEnd);

app.stage.addChild(box);

Key Considerations

  • Global Movement: Use the globalpointermove event on the dragged object or attach a pointermove listener to app.stage. This ensures coordinate updates continue processing as long as pointer capture is active.
  • Handling Interrupted Drags: Always listen to pointerupoutside and native lostpointercapture events to reset drag states if the browser cancels tracking (such as when switching applications or handling multi-touch gestures).
  • DOM Canvas Access: Pixi.js v8 references the canvas via app.canvas, whereas v7 and earlier use app.view. Checking app.canvas || app.view guarantees compatibility across versions.
