Feathered Cutouts Using Blur Filter in PixiJS

Creating a feathered cutout in PixiJS allows you to smoothly blend edges rather than using sharp geometric cuts. This article covers how to pair a BlurFilter with an alpha mask by applying the filter to a Graphics shape or sprite, adding it to the display tree, and assigning it as a mask to achieve soft, faded cutouts.

Understanding Alpha Masks vs. Stencil Masks

By default, PixiJS uses a stencil buffer for simple geometric masks created with PIXI.Graphics. Stencil masks are binary: a pixel is either completely visible or completely hidden, which prevents soft or feathered edges.

To create a feathered edge, PixiJS must use an alpha mask (texture-based mask). When you attach a filter like PIXI.BlurFilter to your mask object, PixiJS automatically switches the masking technique from stencil-based rendering to an alpha-channel mask pass, letting partial opacity create a smooth gradient.

Step-by-Step Implementation

  1. Prepare the Target Object: Create the display object or container you want to mask.
  2. Create the Mask Shape: Draw a shape using PIXI.Graphics.
  3. Attach the BlurFilter: Add a PIXI.BlurFilter to the mask object's filters array.
  4. Add the Mask to the Display Tree: The mask must exist in the stage hierarchy for PixiJS to render its filtered texture properly.
  5. Assign the Mask: Set the target's .mask property to the blurred mask object.

Implementation Example

import * as PIXI from 'pixi.js';

// 1. Initialize the PixiJS Application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1099bb,
});
document.body.appendChild(app.view);

// 2. Create the target content to be masked
const targetContainer = new PIXI.Container();
app.stage.addChild(targetContainer);

const backgroundSprite = PIXI.Sprite.from('path/to/image.jpg');
backgroundSprite.width = 800;
backgroundSprite.height = 600;
targetContainer.addChild(backgroundSprite);

// 3. Create the mask shape
const maskGraphic = new PIXI.Graphics();
maskGraphic.beginFill(0xffffff);
maskGraphic.drawCircle(400, 300, 150);
maskGraphic.endFill();

// 4. Configure and apply the BlurFilter
const blurFilter = new PIXI.BlurFilter();
blurFilter.strength = 16;
blurFilter.quality = 4;
blurFilter.padding = 30; // Prevents the blur from clipping at the bounding box

maskGraphic.filters = [blurFilter];

// 5. Add the mask to the stage and link it to the target
app.stage.addChild(maskGraphic);
targetContainer.mask = maskGraphic;

Key Considerations

  • Padding: When applying heavy blur, PixiJS might clip the soft edges at the original bounding box of the graphic. Increase blurFilter.padding to accommodate the blurred dispersion radius.
  • Display Tree Requirement: Always call app.stage.addChild(maskGraphic). If the filtered mask is not part of the active scene graph, PixiJS cannot render the blurred texture required for alpha masking.
  • Performance: Alpha masks with blur filters involve an offscreen render pass and multiple blur passes every frame. If the mask is static, set maskGraphic.cacheAsBitmap = true or render the blurred mask into a PIXI.RenderTexture once to maintain high frame rates.
