Add Dynamic Frames to a Pixi.js Spritesheet

This article explains how to dynamically inject additional sprite frames into an existing Pixi.js spritesheet at runtime. By creating new sub-textures from the spritesheet’s underlying base texture and registering them directly into the spritesheet instance and texture cache, developers can expand atlas definitions on the fly without re-downloading or re-parsing the original assets.

Understanding the Pixi.js Spritesheet Architecture

A Pixi.js Spritesheet consists of two primary components:

  1. baseTexture: The single, shared image asset loaded on the GPU.
  2. textures: An object containing individual PIXI.Texture instances, each mapping to specific pixel boundaries (frame, trim, orig) inside that baseTexture.

To inject a new frame, you instantiate a new PIXI.Texture referencing the existing baseTexture and define its sub-rectangle, then register it into the spritesheet's texture dictionary.

Step-by-Step Implementation

1. Define the Injection Function

The following function creates a new PIXI.Texture referencing the base texture of an existing spritesheet and registers it under a custom identifier:

import * as PIXI from 'pixi.js';

/**
 * Dynamically adds a new frame to an existing spritesheet.
 * 
 * @param {PIXI.Spritesheet} sheet - The target spritesheet.
 * @param {string} frameId - The unique name for the new frame.
 * @param {object} frameRect - Coordinates and dimensions { x, y, width, height }.
 * @param {object} [trimRect] - Optional trim data { x, y, width, height }.
 * @returns {PIXI.Texture} The newly created texture.
 */
function injectFrame(sheet, frameId, frameRect, trimRect = null) {
    if (sheet.textures[frameId]) {
        console.warn(`Frame "${frameId}" already exists in the spritesheet.`);
        return sheet.textures[frameId];
    }

    // Define the frame area on the BaseTexture
    const frame = new PIXI.Rectangle(
        frameRect.x,
        frameRect.y,
        frameRect.width,
        frameRect.height
    );

    // Handle orig/trim rectangles if the frame is trimmed
    const orig = trimRect 
        ? new PIXI.Rectangle(0, 0, trimRect.width, trimRect.height)
        : new PIXI.Rectangle(0, 0, frameRect.width, frameRect.height);

    const trim = trimRect 
        ? new PIXI.Rectangle(trimRect.x, trimRect.y, frameRect.width, frameRect.height)
        : undefined;

    // Create the new sub-texture from the spritesheet's base texture
    const newTexture = new PIXI.Texture(
        sheet.baseTexture,
        frame,
        orig,
        trim
    );

    // Register into the spritesheet's internal texture map
    sheet.textures[frameId] = newTexture;

    // Optional: Add to the global texture cache for global access
    PIXI.Texture.addToCache(newTexture, frameId);

    return newTexture;
}

2. Usage Example

After loading your spritesheet using PIXI.Assets, you can target it and slice out an previously unregistered region:

async function setup() {
    const app = new PIXI.Application();
    await app.init({ width: 800, height: 600 });
    document.body.appendChild(app.canvas);

    // Load an existing spritesheet
    const sheet = await PIXI.Assets.load('assets/character.json');

    // Inject a frame from an unused or newly defined region
    injectFrame(sheet, 'extra_pose', {
        x: 128,
        y: 64,
        width: 32,
        height: 32
    });

    // Use the injected frame directly via the spritesheet
    const sprite = new PIXI.Sprite(sheet.textures['extra_pose']);
    sprite.position.set(100, 100);
    app.stage.addChild(sprite);

    // Or instantiate using PIXI.Sprite.from if cached
    const spriteFromCache = PIXI.Sprite.from('extra_pose');
    spriteFromCache.position.set(150, 100);
    app.stage.addChild(spriteFromCache);
}

setup();

Adding Injected Frames to Animations

If you need the newly injected frames to function within an animated sequence (PIXI.AnimatedSprite), push the textures directly to the sheet.animations object:

function addFrameToAnimation(sheet, animName, frameId) {
    if (!sheet.animations[animName]) {
        sheet.animations[animName] = [];
    }

    const texture = sheet.textures[frameId];
    if (texture) {
        sheet.animations[animName].push(texture);
    }
}

// Example:
injectFrame(sheet, 'run_03', { x: 64, y: 0, width: 32, height: 32 });
addFrameToAnimation(sheet, 'run', 'run_03');

const animatedSprite = new PIXI.AnimatedSprite(sheet.animations['run']);
animatedSprite.play();

Memory Considerations

When injecting frames dynamically:

  • Dynamic textures share the underlying GPU allocation of the baseTexture, meaning injection creates minimal memory overhead.
  • Destroying the spritesheet with sheet.destroy(true) will also destroy the baseTexture and all injected frames referencing it.
  • If frames are added to the global cache via PIXI.Texture.addToCache(), remove them with PIXI.Texture.removeFromCache(frameId) before destroying the textures to avoid memory leaks.
