Parse XML and JSON Bitmap Fonts in Pixi.js

Bitmap fonts provide an optimized way to render text in Pixi.js by utilizing pre-rendered glyph textures rather than dynamically rasterizing vector typefaces at runtime. This guide explains how to parse both XML and JSON bitmap font descriptor files and register them with Pixi.js using the BitmapFont system. Whether you are letting Pixi.js load assets automatically or parsing raw strings manually at runtime, the following steps will help you properly bind font metrics to textures for rendering.

Automatic Loading via Pixi.js Assets

The simplest way to parse and register bitmap fonts is through the Pixi.js Assets pipeline. When provided with a .fnt or .json file that references a sibling image file, Pixi.js parses the metadata and registers the font automatically.

import { Assets, BitmapText } from 'pixi.js';

// Pixi automatically parses the XML/JSON and loads the associated texture
const font = await Assets.load('path/to/font.fnt'); 

// The font is now registered globally under the name defined in the file
const text = new BitmapText('Hello World', {
    fontName: 'YourFontName',
    fontSize: 32,
});

If your file uses a custom extension or you are loading from an API response without clear file extensions, specify the format explicitly:

await Assets.load({
    src: 'https://example.com/api/font-definition',
    loadParser: 'loadBitmapFont',
});

Manually Parsing and Registering XML Fonts

When working with an XML .fnt file loaded as raw text or embedded in your bundle, you must convert the XML string into an XML Document using the browser's native DOMParser and bind it to a pre-loaded Texture.

import { BitmapFont, Texture } from 'pixi.js';

// 1. Obtain your raw XML string and font sprite texture
const xmlString = `
<font>
  <info face="CustomXMLFont" size="32" />
  <common lineHeight="36" base="28" />
  <pages>
    <page id="0" file="font.png" />
  </pages>
  <chars count="1">
    <char id="65" x="0" y="0" width="20" height="28" xoffset="0" yoffset="0" xadvance="22" page="0" />
  </chars>
</font>
`;
const texture = Texture.from('path/to/font.png');

// 2. Parse the string into an XML Document
const parser = new DOMParser();
const xmlDoc = parser.parseFromString(xmlString, 'text/xml');

// 3. Register the font with BitmapFont
const registeredFont = BitmapFont.install(xmlDoc, texture);

console.log(`Registered font: ${registeredFont.font}`);

If your bitmap font spans across multiple texture pages, pass an array of textures or an object mapping page IDs/filenames to corresponding textures as the second argument:

BitmapFont.install(xmlDoc, [texturePage0, texturePage1]);

Manually Parsing and Registering JSON Fonts

Modern font generation tools (such as BMFont or msdf-bmfont-xml) can export definitions in JSON format. Pixi.js accepts parsed JSON objects directly into BitmapFont.install.

import { BitmapFont, Texture } from 'pixi.js';

// 1. Raw JSON font definition
const jsonString = `{
  "font": {
    "info": { "face": "CustomJSONFont", "size": 24 },
    "common": { "lineHeight": 28 },
    "pages": ["font.png"],
    "chars": [
      { "id": 65, "x": 0, "y": 0, "width": 16, "height": 24, "xoffset": 0, "yoffset": 0, "xadvance": 18, "page": 0 }
    ]
  }
}`;

const texture = Texture.from('path/to/font.png');

// 2. Parse into a standard JavaScript object
const fontData = JSON.parse(jsonString);

// 3. Register using the parsed object and base texture
BitmapFont.install(fontData, texture);

Rendering Text with the Registered Font

Once a font is installed—either through Assets.load or BitmapFont.install—it is stored in the global BitmapFont.available registry under the face identifier declared in the file metadata.

import { Application, BitmapText } from 'pixi.js';

const app = new Application();
await app.init({ width: 800, height: 600 });
document.body.appendChild(app.canvas);

// Instantiate using the face name declared inside your XML or JSON
const label = new BitmapText({
    text: 'A',
    style: {
        fontName: 'CustomXMLFont', // Matches the "face" attribute
        fontSize: 32,
    },
});

app.stage.addChild(label);

Unregistering Fonts

To free up memory when a font is no longer needed, remove it using the uninstall method:

BitmapFont.uninstall('CustomXMLFont');
