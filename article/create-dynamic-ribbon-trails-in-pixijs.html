Create Dynamic Ribbon Trails in PixiJS

Creating dynamic ribbons or trail effects in PixiJS is fully achievable and performant by manipulating vertex buffer data inside a render loop. By recording a historical path of positions, computing perpendicular offsets to define thickness, and updating a PIXI.Geometry buffer on every tick, you can build smooth, reactive visual trails for cursors, projectiles, or characters.

How Dynamic Ribbon Meshes Work

A ribbon trail is essentially a strip of connected quads or a continuous triangle strip drawn along a path of moving points. Rather than instantiating new display objects every frame, you maintain a fixed-length array of path coordinates. Each frame, you:

  1. Push the newest position to the front of the array and discard the oldest.
  2. Iterate through these positions to calculate normal vectors (perpendicular lines) representing the ribbon's width.
  3. Write the computed left and right edge coordinates directly into a Float32Array.
  4. Flag the PIXI.Buffer as updated so the GPU receives the new geometry.

Implementing the Ribbon Geometry

Using PIXI.Mesh and PIXI.Geometry, you can bind custom vertex buffers and draw dynamic paths efficiently.

1. Initialize Points and Buffers

Pre-allocate your arrays to prevent garbage collection spikes during animation.

const maxPoints = 50;
const history = [];

// Initialize history with starting coordinates
for (let i = 0; i < maxPoints; i++) {
    history.push({ x: 0, y: 0 });
}

// Two vertices per point (left and right edges)
const vertexCount = maxPoints * 2;
const positions = new Float32Array(vertexCount * 2);
const uvs = new Float32Array(vertexCount * 2);
const indices = new Uint16Array((maxPoints - 1) * 6);

// Build static UVs and triangle indices
for (let i = 0; i < maxPoints; i++) {
    const t = i / (maxPoints - 1);
    
    // UV coordinates
    uvs[i * 4] = t;
    uvs[i * 4 + 1] = 0;
    uvs[i * 4 + 2] = t;
    uvs[i * 4 + 3] = 1;

    // Index buffer (quads as two triangles)
    if (i < maxPoints - 1) {
        const base = i * 2;
        const indexOffset = i * 6;

        indices[indexOffset] = base;
        indices[indexOffset + 1] = base + 1;
        indices[indexOffset + 2] = base + 2;

        indices[indexOffset + 3] = base + 1;
        indices[indexOffset + 4] = base + 3;
        indices[indexOffset + 5] = base + 2;
    }
}

2. Assemble the Geometry and Mesh

Pass the typed arrays into a PIXI.Geometry and attach a material or standard texture shader.

const geometry = new PIXI.Geometry()
    .addAttribute('aVertexPosition', positions, 2)
    .addAttribute('aTextureCoord', uvs, 2)
    .addIndex(indices);

const shader = PIXI.Shader.from(
    `
    precision mediump float;
    attribute vec2 aVertexPosition;
    attribute vec2 aTextureCoord;
    uniform mat3 translationMatrix;
    uniform mat3 projectionMatrix;
    varying vec2 vTextureCoord;

    void main() {
        vTextureCoord = aTextureCoord;
        gl_Position = vec4((projectionMatrix * translationMatrix * vec3(aVertexPosition, 1.0)).xy, 0.0, 1.0);
    }
    `,
    `
    precision mediump float;
    varying vec2 vTextureCoord;
    uniform sampler2D uSampler;

    void main() {
        gl_FragColor = vec4(1.0, 0.4, 0.1, 1.0 - vTextureCoord.x); // Fade out along trail
    }
    `
);

const ribbonMesh = new PIXI.Mesh(geometry, shader);
app.stage.addChild(ribbonMesh);

3. Shift Points and Update the Buffer Every Frame

Inside the PixiJS ticker, shift your point history by adding the latest target coordinate and recalculate the ribbon's outer vertices using 2D normal vectors.

const baseThickness = 20;

app.ticker.add(() => {
    // 1. Shift positions: pop the tail, push current mouse or target point to head
    history.pop();
    history.unshift({ x: app.renderer.events.pointer.global.x, y: app.renderer.events.pointer.global.y });

    // 2. Compute vertex geometry based on path direction
    for (let i = 0; i < maxPoints; i++) {
        const current = history[i];
        const next = history[i + 1] || current;
        const prev = history[i - 1] || current;

        // Tangent vector
        let dx = next.x - prev.x;
        let dy = next.y - prev.y;
        let len = Math.hypot(dx, dy) || 1.0;

        // Normal vector (perpendicular)
        let nx = -dy / len;
        let ny = dx / len;

        // Taper thickness toward the tail
        const progress = 1 - i / (maxPoints - 1);
        const halfWidth = (baseThickness * progress) / 2;

        const vertexIndex = i * 4;
        
        // Left vertex
        positions[vertexIndex] = current.x + nx * halfWidth;
        positions[vertexIndex + 1] = current.y + ny * halfWidth;

        // Right vertex
        positions[vertexIndex + 2] = current.x - nx * halfWidth;
        positions[vertexIndex + 3] = current.y - ny * halfWidth;
    }

    // 3. Mark the vertex buffer for upload to the GPU
    geometry.getBuffer('aVertexPosition').update();
});

Performance Best Practices

  • Avoid Reallocation: Always mutate the existing Float32Array rather than instantiating new arrays inside the ticker loop.
  • Tessellation Resolution: Keep point counts between 30 and 100. Higher values yield smoother curves at the cost of more CPU calculations per frame.
  • Alternative Shortcut: If dynamic width tapering or custom shaders are not strictly needed, PIXI.SimpleRope provides a built-in convenience wrapper that uses this identical underlying concept to bend a texture across a sequence of points.
