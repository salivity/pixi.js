Custom 2D Lighting and Shadows Shader in Pixi.js

Creating realistic 2D lighting and shadows in Pixi.js involves writing a custom fragment shader using the PIXI.Filter class. This article explains how to build a dynamic 2D point light system from scratch, complete with distance attenuation and raymarched 2D shadows. By passing light coordinates and scene occlusion data to GLSL uniforms, you can render smooth ambient lighting, falloff curves, and realistic occlusions over your game sprites in real time.

Understanding the Architecture

A 2D lighting system requires two primary components: an occlusion map (which defines where light-blocking obstacles exist) and a light shader. Pixi.js passes the scene as a standard texture (uSampler), while a custom fragment shader calculates the distance between each pixel and the light source. To generate shadows, the fragment shader steps along a ray from the current pixel toward the light source, testing the occlusion map for obstacles.

Step 1: Setting Up the Occlusion Map

Before writing the shader, you need a texture that tells the shader where obstacles are. Create a dedicated container for shadow-casting objects and render it to a PIXI.RenderTexture.

const app = new PIXI.Application({ width: 800, height: 600 });
document.body.appendChild(app.view);

// Container for obstacles that cast shadows
const shadowCasters = new PIXI.Container();

// Render texture used as the occlusion map
const occlusionTexture = PIXI.RenderTexture.create({
    width: app.screen.width,
    height: app.screen.height
});

Black or transparent pixels in this container represent open air, while white or opaque pixels represent walls and obstacles.

Step 2: Writing the GLSL Fragment Shader

The fragment shader evaluates light intensity based on distance falloff and traces a ray to ensure no opaque pixels sit between the light and the current fragment.

precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;          // Scene texture
uniform sampler2D uOcclusionMap;     // Obstacle texture
uniform vec2 uLightPosition;         // Light position in normalized coordinates (0.0 to 1.0)
uniform vec3 uLightColor;            // Light tint (R, G, B)
uniform float uLightRadius;          // Radius of the light in normalized units
uniform vec3 uAmbientColor;          // Base ambient light level

const int RAY_STEPS = 32;

void main(void) {
    vec4 sceneColor = texture2D(uSampler, vTextureCoord);
    
    // Calculate direction and distance to the light source
    vec2 lightDir = uLightPosition - vTextureCoord;
    float dist = length(lightDir);

    // If outside the radius, apply only ambient light
    if (dist > uLightRadius) {
        gl_FragColor = vec4(sceneColor.rgb * uAmbientColor, sceneColor.a);
        return;
    }

    // Trace a ray from the fragment to the light
    vec2 stepVector = lightDir / float(RAY_STEPS);
    vec2 currentPos = vTextureCoord;
    float shadow = 1.0;

    for (int i = 0; i < RAY_STEPS; i++) {
        currentPos += stepVector;
        
        // Stop if the ray passes the light position
        if (length(uLightPosition - currentPos) < length(stepVector)) {
            break;
        }

        // Check if an obstacle is hit (alpha or red threshold)
        vec4 occlusionSample = texture2D(uOcclusionMap, currentPos);
        if (occlusionSample.a > 0.5) {
            shadow = 0.0;
            break;
        }
    }

    // Calculate attenuation (smooth quadratic falloff)
    float attenuation = clamp(1.0 - (dist / uLightRadius), 0.0, 1.0);
    attenuation *= attenuation;

    // Combine light, shadows, and ambient illumination
    vec3 totalLight = uAmbientColor + (uLightColor * attenuation * shadow);
    gl_FragColor = vec4(sceneColor.rgb * totalLight, sceneColor.a);
}

Step 3: Instantiating the Pixi.js Filter

Create an instance of PIXI.Filter using your fragment shader. Map the uniforms so they can be modified dynamically from JavaScript.

const uniforms = {
    uOcclusionMap: occlusionTexture,
    uLightPosition: new Float32Array([0.5, 0.5]),
    uLightColor: new Float32Array([1.0, 0.9, 0.7]),
    uLightRadius: 0.4,
    uAmbientColor: new Float32Array([0.1, 0.1, 0.15])
};

const lightingFilter = new PIXI.Filter(null, fragmentShaderSource, uniforms);

// Apply the filter to your main game scene
const mainScene = new PIXI.Container();
app.stage.addChild(mainScene);
mainScene.filters = [lightingFilter];

Step 4: Updating Lights in the Render Loop

Normalize screen coordinates to the [0.0, 1.0] range required by the fragment shader and render the occlusion texture every frame.

app.ticker.add(() => {
    // Render shadow casters to the occlusion texture
    app.renderer.render(shadowCasters, {
        renderTexture: occlusionTexture,
        clear: true
    });

    // Update the light position to follow mouse or player
    const mousePos = app.renderer.events.pointer.global;
    lightingFilter.uniforms.uLightPosition[0] = mousePos.x / app.screen.width;
    lightingFilter.uniforms.uLightPosition[1] = mousePos.y / app.screen.height;
});

Optimizing Shader Performance

Raymarching within a 2D fragment shader is computationally intensive because every pixel samples the occlusion map multiple times. To maintain high framerates:

  1. Keep step counts reasonable: A step count of 16 to 32 is generally sufficient for 2D games.
  2. Downsample the occlusion map: Render the occlusion texture at half or quarter resolution to save memory bandwidth.
  3. Use early exits: Discard pixels outside uLightRadius immediately before executing the raymarching loop.
