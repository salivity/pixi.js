Pixi.js WebGPU Mesh Primitive Topologies

This article provides an overview of the WebGPU primitive topologies supported when defining custom mesh geometry in Pixi.js. With the introduction of Pixi.js v8 and its native WebGPU integration, geometry topology configuration now aligns directly with standard WebGPU specifications. Below, you will find the specific topologies available, how the GPU interprets vertex data for each, and how to define them within your Pixi.js application.

Supported WebGPU Primitive Topologies

When building custom meshes using Geometry in Pixi.js v8, you can specify the topology property. WebGPU does not support legacy drawing modes such as triangle fans; instead, it supports five specific primitive topologies:

1. triangle-list

  • Description: The default topology for meshes. Every group of three consecutive vertices (or indices, if using an index buffer) forms an independent triangle.
  • Use Cases: General 3D/2D models, sprites, and complex irregular polygonal shapes.
  • Vertex Requirement: Vertex or index counts must be a multiple of three.

2. triangle-strip

  • Description: Draws a connected series of triangles where each additional vertex after the first two forms a new triangle sharing two vertices with the preceding triangle.
  • Use Cases: Ribbons, paths with thickness, grids, and terrain meshes where vertex reuse reduces buffer sizes.
  • Vertex Requirement: Requires at least three vertices; \(N\) vertices produce \(N - 2\) triangles.

3. point-list

  • Description: Renders each vertex as an individual, disconnected point in space.
  • Use Cases: Particle engines, point clouds, and data visualization nodes.
  • Vertex Requirement: Every single vertex defines one point.

4. line-list

  • Description: Treats each pair of vertices as an independent, disconnected line segment.
  • Use Cases: Grids, coordinate axes, wireframe rendering, and non-continuous vector strokes.
  • Vertex Requirement: The total vertex count must be an even number; vertices \(2k\) and \(2k+1\) form segment \(k\).

5. line-strip

  • Description: Connects all vertices in a continuous sequence of line segments, where each vertex (after the first) creates a segment connecting back to the previous vertex.
  • Use Cases: Trajectories, continuous paths, graphs, and line charts.
  • Vertex Requirement: Requires at least two vertices; \(N\) vertices produce \(N - 1\) line segments.

Setting Topologies in Pixi.js

To use these topologies in Pixi.js, pass the topology string directly into your Geometry definition or set it after instantiation:

import { Geometry, Mesh, Shader } from 'pixi.js';

// Define a geometry with a specific WebGPU topology
const geometry = new Geometry({
    attributes: {
        aPosition: [
            0, 0,
            100, 0,
            50, 100,
        ],
    },
    topology: 'triangle-list', // Options: 'triangle-list', 'triangle-strip', 'point-list', 'line-list', 'line-strip'
});

const mesh = new Mesh({
    geometry,
    shader: customShader,
});

Pixi.js ensures that these topology keys translate directly to the WebGPU pipeline descriptor (primitive.topology), providing full control over how your custom vertex buffers are rasterized.
