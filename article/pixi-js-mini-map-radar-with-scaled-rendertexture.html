Pixi.js Mini-Map Radar with Scaled RenderTexture

Creating a mini-map radar in Pixi.js provides players with top-down situational awareness without requiring complex secondary rendering pipelines. This guide explains how to render an entire dynamic game world into a scaled RenderTexture and project it onto a lightweight HUD element. You will learn how to isolate scene layers, calculate scale transformations, and render the scene continuously within the Pixi.js application ticker.

1. Separate the World from the Interface

To avoid an infinite visual loop, your mini-map must never capture itself or other HUD elements. Organize your stage into at least two distinct Container instances:

  • worldContainer: Holds terrain, players, enemies, and interactive game objects.
  • uiContainer: Holds the HUD, controls, and the mini-map display itself.
const worldContainer = new PIXI.Container();
const uiContainer = new PIXI.Container();

app.stage.addChild(worldContainer);
app.stage.addChild(uiContainer);

2. Configure the RenderTexture and Mini-Map Sprite

Determine the dimensions of your mini-map and create a RenderTexture matching those bounds. Then, attach that texture to a Sprite placed inside your uiContainer.

const mapWidth = 200;
const mapHeight = 200;

// Create the target texture
const miniMapTexture = PIXI.RenderTexture.create({
    width: mapWidth,
    height: mapHeight,
});

// Create the HUD sprite to display the texture
const miniMapSprite = new PIXI.Sprite(miniMapTexture);
miniMapSprite.position.set(app.screen.width - mapWidth - 20, 20); // Top-right corner

// Optional: Add a border or background
const border = new PIXI.Graphics();
border.lineStyle(2, 0xffffff, 1);
border.drawRect(miniMapSprite.x, miniMapSprite.y, mapWidth, mapHeight);

uiContainer.addChild(border);
uiContainer.addChild(miniMapSprite);

3. Calculate the Transformation Matrix

To map the entire bounds of the game world into the smaller mini-map texture, scale the scene using a PIXI.Matrix. Calculate the scale factors by dividing the mini-map dimensions by the total world dimensions.

const worldWidth = 4000;
const worldHeight = 4000;

const scaleX = mapWidth / worldWidth;
const scaleY = mapHeight / worldHeight;

const matrix = new PIXI.Matrix();
matrix.scale(scaleX, scaleY);

4. Render the Mini-Map in the Ticker

In your main animation loop, invoke renderer.render to draw the worldContainer onto the miniMapTexture. Pass the transformation matrix in the render options so Pixi.js draws the world downscaled to fit the mini-map boundaries.

app.ticker.add(() => {
    // Render the world container to the mini-map texture using the scaling matrix
    app.renderer.render(worldContainer, {
        renderTexture: miniMapTexture,
        clear: true,
        transform: matrix,
    });
});

Performance Considerations

  • Render Throttling: Rendering an entire scene twice per frame can reduce performance on low-end hardware. Update the mini-map every 2 to 4 frames if 60 FPS is not strictly required for the radar.
  • Dedicated Radar Layers: If the full scene contains high-density visuals (such as lighting effects or fine particle systems), create a simplified radarContainer containing primitive dots for targets and positions rather than drawing the full worldContainer.
