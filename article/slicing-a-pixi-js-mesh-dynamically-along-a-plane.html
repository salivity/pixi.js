Slicing a Pixi.js Mesh Dynamically Along a Plane

Dynamically slicing a Pixi.js mesh involves intersecting the geometry's triangles with an arbitrary cutting line, interpolating vertex data along the cut, and rebuilding two separate PIXI.Mesh instances from the resulting polygons. This article explains the geometric algorithm needed to determine vertex positions relative to a cutting line, split intersecting triangles, linearly interpolate UV coordinates, and generate two new renderable meshes in Pixi.js.

1. Define the Cutting Line

In a 2D environment like Pixi.js, a cutting "plane" is defined as a directed line. You can represent this line using a point \(\mathbf{P_0} = (x_0, y_0)\) on the line and a normalized normal vector \(\mathbf{N} = (n_x, n_y)\).

To determine which side of the cutting line a vertex \(\mathbf{V} = (x, y)\) falls on, compute the signed distance:

\[d = (\mathbf{V} - \mathbf{P_0}) \cdot \mathbf{N} = (x - x_0)n_x + (y - y_0)n_y\]

  • If \(d > 0\), the vertex lies on the positive side (Mesh A).
  • If \(d < 0\), the vertex lies on the negative side (Mesh B).
  • If \(d = 0\), the vertex lies directly on the cutting line.

2. Triangle Classification and Intersection

Access the geometry of the source PIXI.Mesh. Extract the position buffer (usually float pairs for \(x, y\)), the UV buffer, and the index buffer.

Iterate through the index buffer three vertices at a time (\(V_0, V_1, V_2\)). Calculate the signed distance for all three points:

  1. All vertices positive (\(d \ge 0\)): Add the triangle directly to Mesh A.
  2. All vertices negative (\(d < 0\)): Add the triangle directly to Mesh B.
  3. Intersected: Two vertices reside on one side, and one vertex resides on the other. This triangle must be split into three smaller triangles (one triangle on one side, and a quadrilateral divided into two triangles on the other side).

3. Calculating Edge Intersections and Interpolating UVs

When an edge connecting vertex \(A\) and vertex \(B\) crosses the line, find the exact intersection point \(I\) using the linear interpolation factor \(t\):

\[t = \frac{d_A}{d_A - d_B}\]

Using \(t\), interpolate both the 2D position and UV coordinates:

\[\mathbf{Pos}_I = \mathbf{Pos}_A + t \cdot (\mathbf{Pos}_B - \mathbf{Pos}_A)\] \[\mathbf{UV}_I = \mathbf{UV}_A + t \cdot (\mathbf{UV}_B - \mathbf{UV}_A)\]

4. Implementation Example

The following function demonstrates how to partition the geometry buffers into two separate vertex arrays and construct two new PIXI.Mesh objects:

import * as PIXI from 'pixi.js';

function sliceMesh(sourceMesh, linePoint, lineNormal) {
    const geom = sourceMesh.geometry;
    const positions = geom.getAttribute('aVertexPosition').data;
    const uvs = geom.getAttribute('aTextureCoord').data;
    const indices = geom.getIndex().data;

    // Output data containers for side A and side B
    const partA = { positions: [], uvs: [], indices: [] };
    const partB = { positions: [], uvs: [], indices: [] };

    function getDistance(x, y) {
        return (x - linePoint.x) * lineNormal.x + (y - linePoint.y) * lineNormal.y;
    }

    function addVertex(target, x, y, u, v) {
        const index = target.positions.length / 2;
        target.positions.push(x, y);
        target.uvs.push(u, v);
        return index;
    }

    function interpolate(v1, v2, d1, d2) {
        const t = d1 / (d1 - d2);
        return {
            x: v1.x + t * (v2.x - v1.x),
            y: v1.y + t * (v2.y - v1.y),
            u: v1.u + t * (v2.u - v1.u),
            v: v1.v + t * (v2.v - v1.v)
        };
    }

    for (let i = 0; i < indices.length; i += 3) {
        const idx = [indices[i], indices[i + 1], indices[i + 2]];
        const triVerts = idx.map(j => ({
            x: positions[j * 2],
            y: positions[j * 2 + 1],
            u: uvs[j * 2],
            v: uvs[j * 2 + 1]
        }));

        const dists = triVerts.map(v => getDistance(v.x, v.y));

        const sideA = [];
        const sideB = [];

        triVerts.forEach((v, index) => {
            if (dists[index] >= 0) sideA.push({ vert: v, dist: dists[index] });
            else sideB.push({ vert: v, dist: dists[index] });
        });

        if (sideA.length === 3) {
            // Entire triangle on side A
            const i0 = addVertex(partA, triVerts[0].x, triVerts[0].y, triVerts[0].u, triVerts[0].v);
            const i1 = addVertex(partA, triVerts[1].x, triVerts[1].y, triVerts[1].u, triVerts[1].v);
            const i2 = addVertex(partA, triVerts[2].x, triVerts[2].y, triVerts[2].u, triVerts[2].v);
            partA.indices.push(i0, i1, i2);
        } else if (sideB.length === 3) {
            // Entire triangle on side B
            const i0 = addVertex(partB, triVerts[0].x, triVerts[0].y, triVerts[0].u, triVerts[0].v);
            const i1 = addVertex(partB, triVerts[1].x, triVerts[1].y, triVerts[1].u, triVerts[1].v);
            const i2 = addVertex(partB, triVerts[2].x, triVerts[2].y, triVerts[2].u, triVerts[2].v);
            partB.indices.push(i0, i1, i2);
        } else {
            // Triangle is sliced
            const single = sideA.length === 1 ? sideA[0] : sideB[0];
            const pair = sideA.length === 2 ? sideA : sideB;
            const singleTarget = sideA.length === 1 ? partA : partB;
            const pairTarget = sideA.length === 2 ? partA : partB;

            const int1 = interpolate(single.vert, pair[0].vert, single.dist, pair[0].dist);
            const int2 = interpolate(single.vert, pair[1].vert, single.dist, pair[1].dist);

            // Reconstruct the single-vertex side as 1 triangle
            const s0 = addVertex(singleTarget, single.vert.x, single.vert.y, single.vert.u, single.vert.v);
            const s1 = addVertex(singleTarget, int1.x, int1.y, int1.u, int1.v);
            const s2 = addVertex(singleTarget, int2.x, int2.y, int2.u, int2.v);
            singleTarget.indices.push(s0, s1, s2);

            // Reconstruct the two-vertex side as a quad (2 triangles)
            const p0 = addVertex(pairTarget, pair[0].vert.x, pair[0].vert.y, pair[0].vert.u, pair[0].vert.v);
            const p1 = addVertex(pairTarget, pair[1].vert.x, pair[1].vert.y, pair[1].vert.u, pair[1].vert.v);
            const p2 = addVertex(pairTarget, int1.x, int1.y, int1.u, int1.v);
            const p3 = addVertex(pairTarget, int2.x, int2.y, int2.u, int2.v);

            pairTarget.indices.push(p0, p1, p2);
            pairTarget.indices.push(p1, p3, p2);
        }
    }

    return [
        createMeshFromData(partA, sourceMesh.texture),
        createMeshFromData(partB, sourceMesh.texture)
    ];
}

function createMeshFromData(data, texture) {
    const geometry = new PIXI.Geometry()
        .addAttribute('aVertexPosition', data.positions, 2)
        .addAttribute('aTextureCoord', data.uvs, 2)
        .addIndex(data.indices);

    return new PIXI.Mesh(geometry, new PIXI.MeshMaterial(texture));
}

5. Integrating the Sliced Meshes

After generating the two resulting meshes, copy the transform properties (position, rotation, scale, pivot) of the original mesh to both halves. Add both new meshes to the scene hierarchy and remove the original mesh:

const [meshA, meshB] = sliceMesh(originalMesh, { x: 100, y: 100 }, { x: 0, y: 1 });

meshA.transform.copyFrom(originalMesh.transform);
meshB.transform.copyFrom(originalMesh.transform);

parentContainer.addChild(meshA);
parentContainer.addChild(meshB);
parentContainer.removeChild(originalMesh);
originalMesh.destroy({ children: true, texture: false });

This ensures both halves maintain proper visual alignment at the cut line while allowing independent transformation and physics simulation on each half.
