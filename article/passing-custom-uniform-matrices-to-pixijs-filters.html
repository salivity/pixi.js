Passing Custom Uniform Matrices to PixiJS Filters

This article provides a direct guide on how to pass custom uniform matrices, such as 3x3 and 4x4 matrices, into a custom filter in Pixi.js. You will learn how to declare the matrix inside your GLSL shader code, initialize the filter with the matrix uniform using standard JavaScript arrays or Pixi.js objects, and update matrix data dynamically during your render loop.

Declaring the Uniform in GLSL

In your vertex or fragment shader, define the uniform matrix using standard GLSL syntax. A 2D transformation or color matrix typically uses mat3, while 3D transformations use mat4:

// fragment.glsl
precision mediump float;

varying vec2 vTextureCoord;
uniform sampler2D uSampler;

// Custom 3x3 matrix uniform
uniform mat3 uCustomMatrix;

void main(void) {
    vec4 color = texture2D(uSampler, vTextureCoord);
    // Apply matrix transformation to RGB channels
    vec3 transformed = uCustomMatrix * color.rgb;
    gl_FragColor = vec4(transformed, color.a);
}

Passing Matrices in Pixi.js

Pixi.js accepts matrices defined as flattened arrays (Float32Array or standard JavaScript arrays) or as instances of PIXI.Matrix.

Method 1: Using Float32Array (Column-Major Order)

OpenGL expects matrices in column-major format. When creating a mat3, pass a 9-element array; for a mat4, pass a 16-element array.

import * as PIXI from 'pixi.js';

// Define a 3x3 matrix in column-major order
const matrixData = new Float32Array([
    1.0, 0.0, 0.0, // Column 1
    0.0, 1.0, 0.0, // Column 2
    0.0, 0.0, 1.0  // Column 3
]);

const customFilter = new PIXI.Filter(vertexShader, fragmentShader, {
    uCustomMatrix: matrixData
});

// Apply to a sprite or container
sprite.filters = [customFilter];

Method 2: Using PIXI.Matrix

For 2D affine transformations, Pixi.js provides the PIXI.Matrix class. Pixi.js automatically converts PIXI.Matrix into a column-major 3x3 matrix for the shader:

const matrix = new PIXI.Matrix();

// Apply transformations
matrix.identity();
matrix.scale(1.5, 1.5);
matrix.rotate(Math.PI / 4);

const customFilter = new PIXI.Filter(vertexShader, fragmentShader, {
    uCustomMatrix: matrix
});

Updating Uniform Matrices at Runtime

You can update the matrix per frame within your application's ticker. Modify the uniform values directly on the filter instance:

app.ticker.add((delta) => {
    // If using Float32Array
    customFilter.uniforms.uCustomMatrix[0] = Math.sin(Date.now() * 0.001);

    // If using PIXI.Matrix
    const mat = customFilter.uniforms.uCustomMatrix;
    mat.identity();
    mat.rotate(delta * 0.05);
});

When you mutate a Float32Array in place, Pixi.js's internal uniform system detects updates automatically during the render phase and uploads the fresh matrix data to the GPU.
