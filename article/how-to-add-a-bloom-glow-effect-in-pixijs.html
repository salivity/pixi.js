How to Add a Bloom Glow Effect in PixiJS

This guide provides a direct walkthrough on creating a luminous bloom glow effect in PixiJS using the external pixi-filters library. You will learn how to install the required packages, set up a basic PixiJS stage, instantiate the bloom filter, and fine-tune its properties to achieve the desired glowing visual effect on your display objects.

1. Install PixiJS and Pixi-Filters

To get started, install both PixiJS and the PixiJS community filters collection via npm:

npm install pixi.js pixi-filters

If you are working in a browser environment without a bundler, you can load them via CDN script tags:

<script src="https://cdnjs.cloudflare.com/ajax/libs/pixi.js/7.3.2/pixi.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/pixi-filters@latest/dist/pixi-filters.js"></script>

2. Initialize the PixiJS Application

Set up your PixiJS application canvas and add it to the DOM:

import * as PIXI from 'pixi.js';
import { AdvancedBloomFilter } from 'pixi-filters';

const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x050510, // Dark background to enhance the glow
});

document.body.appendChild(app.view);

3. Create Visual Elements

Create a bright graphic or sprite. The bloom effect functions best on objects with bright or saturated colors contrasted against a dark background:

// Create a glowing neon circle
const circle = new PIXI.Graphics();
circle.beginFill(0x00ffff); // Cyan
circle.drawCircle(400, 300, 60);
circle.endFill();

app.stage.addChild(circle);

4. Configure and Apply the Bloom Filter

The pixi-filters package provides two options: BloomFilter (a fast, standard bloom) and AdvancedBloomFilter (offering granular controls such as thresholds and brightness adjustments).

To achieve a modern glow effect, use AdvancedBloomFilter:

const bloomFilter = new AdvancedBloomFilter({
    threshold: 0.5,     // Luminance threshold required to trigger the glow (0 to 1)
    bloomScale: 1.5,    // Intensity/scale of the bloom effect
    brightness: 1.0,    // Brightness adjustment for the bloomed pixels
    blur: 8,            // Spread of the blur causing the glow
    quality: 4          // Blur quality (higher increases GPU workload)
});

// Apply the filter directly to an object or the entire stage
circle.filters = [bloomFilter];

5. Adjusting Properties at Runtime

You can modify the bloom properties dynamically within the ticker to create pulsing or animated effects:

let count = 0;

app.ticker.add(() => {
    count += 0.05;
    // Oscillate the bloom scale between 1.0 and 2.0
    bloomFilter.bloomScale = 1.5 + Math.sin(count) * 0.5;
});
