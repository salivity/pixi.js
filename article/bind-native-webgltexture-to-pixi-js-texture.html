Bind Native WebGLTexture to Pixi.js Texture

Integrating externally generated WebGL textures into Pixi.js allows you to render content from raw WebGL pipelines, external frameworks, or video decoders directly inside the Pixi scene graph without costly CPU readbacks. This guide explains how to wrap a native WebGLTexture inside a Pixi.js Texture instance by leveraging Pixi's internal GLTexture wrapper and BaseTexture system.

Understanding the Architecture

Pixi.js decouples display objects from GPU memory through an abstraction pipeline:

  1. PIXI.Texture: Defines the sub-region (frame) and UV coordinates displayed by sprites.
  2. PIXI.BaseTexture: Manages the underlying source dimensions, resolution, scale modes, and hardware-specific texture bindings.
  3. PIXI.GLTexture: Wraps the native WebGLTexture object per WebGL context.

To bind a native texture directly, you instantiate a PIXI.BaseTexture, manually inject a PIXI.GLTexture into its context map, and wrap the result in a PIXI.Texture.

Step-by-Step Implementation

1. Direct Context Injection (PixiJS v6 / v7)

This approach manually registers the native texture directly into the renderer's texture cache for the active context.

import * as PIXI from 'pixi.js';

function createPixiTextureFromWebGL(renderer, glTextureSource, width, height) {
    // 1. Create a BaseTexture with known dimensions
    const baseTexture = new PIXI.BaseTexture();
    baseTexture.width = width;
    baseTexture.height = height;
    baseTexture.valid = true;

    // 2. Wrap the native WebGLTexture inside a PIXI.GLTexture
    const glTexture = new PIXI.GLTexture(glTextureSource);
    glTexture.type = renderer.gl.UNSIGNED_BYTE;
    glTexture.format = renderer.gl.RGBA;

    // 3. Bind the GLTexture to Pixi's context tracking system
    // renderer.CONTEXT_UID uniquely identifies the WebGL rendering context
    baseTexture._glTextures[renderer.CONTEXT_UID] = glTexture;

    // 4. Return a usable PIXI.Texture
    return new PIXI.Texture(baseTexture);
}

// Usage:
const nativeTexture = gl.createTexture();
// ... (populate nativeTexture via gl.texImage2D, framebuffer, etc.)

const pixiTexture = createPixiTextureFromWebGL(app.renderer, nativeTexture, 512, 512);
const sprite = new PIXI.Sprite(pixiTexture);
app.stage.addChild(sprite);

2. Using a Custom Resource (Recommended for Lifecycle Safety)

Manually manipulating _glTextures bypasses Pixi's texture management pipeline. A cleaner and safer alternative is extending PIXI.Resource. This ensures proper binding state handling and avoids unexpected overwrites when Pixi updates textures.

import * as PIXI from 'pixi.js';

class NativeTextureResource extends PIXI.Resource {
    constructor(sourceTexture, width, height) {
        super(width, height);
        this.sourceTexture = sourceTexture;
    }

    upload(renderer, baseTexture, glTexture) {
        // Swap Pixi's allocated texture handle with the native instance
        const gl = renderer.gl;

        // If Pixi already generated a glTexture, delete it to avoid memory leaks
        if (glTexture.texture && glTexture.texture !== this.sourceTexture) {
            gl.deleteTexture(glTexture.texture);
        }

        glTexture.texture = this.sourceTexture;
        return true;
    }
}

// Usage:
const resource = new NativeTextureResource(nativeTexture, 800, 600);
const baseTexture = new PIXI.BaseTexture(resource);
const texture = new PIXI.Texture(baseTexture);

const sprite = new PIXI.Sprite(texture);
app.stage.addChild(sprite);

Important Considerations

  • Texture Filtering and Wrapping: Ensure standard texture sampling parameters (GL_TEXTURE_MIN_FILTER, GL_TEXTURE_MAG_FILTER, GL_TEXTURE_WRAP_S, GL_TEXTURE_WRAP_T) are configured on the native texture before rendering, especially if the texture dimensions are not powers of two.
  • Context Consistency: The native WebGLTexture must belong to the exact same WebGLRenderingContext used by renderer.gl. Cross-context texture sharing requires shared contexts via extensions, which are not universally supported in WebGL.
  • Premultiplied Alpha: Ensure the alpha handling mode of your native texture matches baseTexture.alphaMode. Mismatches can produce dark outlines or overbright blending in the Pixi.js pipeline.
