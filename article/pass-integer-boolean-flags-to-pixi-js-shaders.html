Pass Integer Boolean Flags to Pixi.js Shaders

Passing multiple individual boolean uniforms to GPU shaders leads to redundant draw-call overhead and wastes precious uniform register space. This article explains how to efficiently pack multiple boolean states into a single integer uniform using bitmasking in Pixi.js, how to configure the shader uniform, and how to decode the individual flags directly inside WebGL 1 and WebGL 2 fragment shaders.

Packing Booleans Using Bitmasks in JavaScript

Instead of defining separate uniforms for every toggle, assign each boolean flag a specific bit position within a 32-bit integer. You can toggle these bits using JavaScript's bitwise operators (| for enabling, & ~ for disabling, and ^ for toggling).

// Define bit positions
const FLAG_GRAYSCALE = 1 << 0; // 1 (0001)
const FLAG_INVERT    = 1 << 1; // 2 (0010)
const FLAG_SEPIA     = 1 << 2; // 4 (0100)
const FLAG_OUTLINE   = 1 << 3; // 8 (1000)

// Combine flags
let activeFlags = 0;
activeFlags |= FLAG_GRAYSCALE;
activeFlags |= FLAG_OUTLINE;

Passing the Uniform in Pixi.js

In Pixi.js, you can supply this combined integer to a custom Filter or Shader. Pixi.js automatically handles integer uniform uploads (gl.uniform1i) when initialized with an integer value.

import { Filter } from 'pixi.js';

const vertexShader = `...`; // Standard vertex shader
const fragmentShader = `...`; // Fragment shader containing decoding logic

const myFilter = new Filter(vertexShader, fragmentShader, {
    uFlags: activeFlags
});

// Update dynamic flags on the fly
function updateFlags(newFlags) {
    myFilter.uniforms.uFlags = newFlags;
}

Unpacking Flags in GLSL (WebGL 2 / GLSL 300 es)

If your Pixi.js application targets WebGL 2 (default in modern Pixi.js setups), GLSL ES 3.00 supports native integer bitwise operations. Declare the uniform as flat in or uniform int.

#version 300 es
precision mediump float;

uniform sampler2D uSampler;
uniform int uFlags;

in vec2 vTextureCoord;
out vec4 fragColor;

void main(void) {
    vec4 color = texture(uSampler, vTextureCoord);

    // Extract flags using bitwise AND
    bool isGrayscale = (uFlags & 1) != 0;
    bool isInvert    = (uFlags & 2) != 0;
    bool isSepia     = (uFlags & 4) != 0;
    bool isOutline   = (uFlags & 8) != 0;

    if (isGrayscale) {
        float gray = dot(color.rgb, vec3(0.299, 0.587, 0.114));
        color.rgb = vec3(gray);
    }

    if (isInvert) {
        color.rgb = 1.0 - color.rgb;
    }

    fragColor = color;
}

Unpacking Flags in GLSL (WebGL 1 / GLSL 100 Fallback)

If targeting WebGL 1, bitwise operators (&, |, ^) are not available. Pass the uniform as an integer or float, and use modulo arithmetic and division to read individual bits:

precision mediump float;

uniform sampler2D uSampler;
uniform float uFlags; // Accept the packed flags as a float

varying vec2 vTextureCoord;

bool getFlag(float packedFlags, float bitIndex) {
    // Shift the bit to the ones place and check if it's odd
    return mod(floor(packedFlags / pow(2.0, bitIndex)), 2.0) == 1.0;
}

void main(void) {
    vec4 color = texture2D(uSampler, vTextureCoord);

    bool isGrayscale = getFlag(uFlags, 0.0);
    bool isInvert    = getFlag(uFlags, 1.0);
    bool isSepia     = getFlag(uFlags, 2.0);
    bool isOutline   = getFlag(uFlags, 3.0);

    if (isInvert) {
        color.rgb = vec3(1.0) - color.rgb;
    }

    gl_FragColor = color;
}

Performance Advantages

  1. Reduced Uniform Overhead: Uploading a single 32-bit integer reduces WebGL uniform binding calls compared to passing dozens of individual uniforms.
  2. Unified State Management: All render-state conditions reside inside a single variable, making state caching and snapshotting cleaner in CPU-side code.
  3. Cache Coherency: Compacting flags preserves GPU register capacity for vector and matrix calculations.
