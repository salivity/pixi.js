Smooth Camera Follow with Lerp in Pixi.js

This article explains how to implement a smooth camera follow system in Pixi.js using linear interpolation (lerp). By continuously shifting a parent world container toward the player's coordinates by a fractional amount each frame, you can create fluid, professional viewport movement that centers on a moving target without jarring transitions.

Understanding the "Camera" in Pixi.js

Pixi.js does not have a native 2D camera object. Instead, the standard approach is to place all game entities (the player, background, enemies, obstacles) inside a single container, commonly called the world container.

To simulate a camera moving toward the player, you move the world container in the opposite direction. Centering the player on the screen requires calculating the target position as:

targetX = (screenWidth / 2) - player.x
targetY = (screenHeight / 2) - player.y

The Lerp Formula

Linear interpolation calculates a value between two points based on a factor \(t\) (a value between 0 and 1):

function lerp(start, end, t) {
    return start + (end - start) * t;
}

A lower \(t\) value (like 0.05) results in a slower, smoother camera lag, while a higher value (like 0.2) creates a snappier response.

Complete Implementation

Below is a complete implementation using PIXI.Ticker to smoothly update the container position.

import * as PIXI from 'pixi.js';

// 1. Initialize Pixi Application
const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1099bb,
});
document.body.appendChild(app.view);

// 2. Create the World Container
const world = new PIXI.Container();
app.stage.addChild(world);

// 3. Create a Target (Player)
const player = new PIXI.Graphics();
player.beginFill(0xff0000);
player.drawRect(-16, -16, 32, 32); // Centered anchor
player.endFill();
player.x = 400;
player.y = 300;
world.addChild(player);

// Linear interpolation helper
const lerp = (start, end, alpha) => start + (end - start) * alpha;

// Smoothness factor (0.05 = soft, 0.2 = fast)
const CAMERA_SMOOTHING = 0.08;

// 4. Update Camera on Every Frame
app.ticker.add((delta) => {
    // Example player movement (replace with real controls)
    player.x += 2; 

    // Determine where the world should ideally be to center the player
    const targetWorldX = (app.screen.width / 2) - player.x;
    const targetWorldY = (app.screen.height / 2) - player.y;

    // Apply lerp smoothly toward the target position
    // Adjust smoothing with delta for frame-rate independence
    const adjustedSmoothing = 1 - Math.pow(1 - CAMERA_SMOOTHING, delta);

    world.x = lerp(world.x, targetWorldX, adjustedSmoothing);
    world.y = lerp(world.y, targetWorldY, adjustedSmoothing);
});

Frame-Rate Independence

Using a fixed multiplier with variable frame rates can cause visual jitter on monitors with different refresh rates (e.g., 60Hz vs. 144Hz).

Using the formula 1 - Math.pow(1 - factor, delta) guarantees that the interpolation rate remains consistent regardless of drops or spikes in frame rate. Pass app.ticker.deltaTime to this calculation to maintain identical movement speeds across all display setups.
