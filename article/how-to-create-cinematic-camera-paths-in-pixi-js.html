How to Create Cinematic Camera Paths in Pixi.js

This guide explains how to implement smooth, follow-path cinematic camera tracks across a 2D world using Pixi.js. By anchoring your game scene within a parent container, defining curved trajectories with splines, and interpolating camera properties like position, scale, and rotation along normalized time, you can create dynamic cutscenes and panoramic sweeping views across any 2D environment.

1. Conceptualizing the 2D Camera

Pixi.js does not provide a native camera primitive. Instead, a camera effect is achieved by manipulating a root Container (often called the world or stageContainer).

To focus on a specific world coordinate \((X, Y)\):

  • Set the world container's pivot to \((X, Y)\).
  • Set the world container's position to the center of the screen \((screenWidth / 2, screenHeight / 2)\).
  • Adjust the world container's scale to control zoom.
  • Adjust the world container's rotation to tilt the camera.

2. Defining the Path with Splines

Cinematic movement requires smooth curves rather than abrupt linear transitions between points. A Catmull-Rom spline is ideal because it passes directly through all defined control points while maintaining continuous curvature.

Below is a lightweight Catmull-Rom interpolation function:

function catmullRom(p0, p1, p2, p3, t) {
    const v0 = (p2 - p0) * 0.5;
    const v1 = (p3 - p1) * 0.5;
    const t2 = t * t;
    const t3 = t * t2;

    return (2 * p1 - 2 * p2 + v0 + v1) * t3 +
           (-3 * p1 + 3 * p2 - 2 * v0 - v1) * t2 +
           v0 * t +
           p1;
}

function getSplinePoint(points, progress) {
    // progress ranges from 0 to 1
    const p = (points.length - 1) * progress;
    const index = Math.floor(p);
    const t = p - index;

    const p0 = points[Math.max(index - 1, 0)];
    const p1 = points[index];
    const p2 = points[Math.min(index + 1, points.length - 1)];
    const p3 = points[Math.min(index + 2, points.length - 1)];

    return {
        x: catmullRom(p0.x, p1.x, p2.x, p3.x, t),
        y: catmullRom(p0.y, p1.y, p2.y, p3.y, t),
        zoom: catmullRom(p0.zoom ?? 1, p1.zoom ?? 1, p2.zoom ?? 1, p3.zoom ?? 1, t),
        rotation: catmullRom(p0.rotation ?? 0, p1.rotation ?? 0, p2.rotation ?? 0, p3.rotation ?? 0, t)
    };
}

3. Setting Up Waypoints

Define an array of keyframes representing the cinematic shot. Include position, zoom levels, and rotations at key moments:

const cameraTrack = [
    { x: 100,  y: 200,  zoom: 1.0, rotation: 0 },
    { x: 600,  y: 400,  zoom: 1.4, rotation: 0.05 },
    { x: 1200, y: 300,  zoom: 0.8, rotation: -0.05 },
    { x: 1800, y: 800,  zoom: 1.2, rotation: 0 }
];

4. Building the Cinematic Track Controller

Create a controller that manages track playback, timing, and updates the world container inside the Pixi.js render loop.

class CinematicCamera {
    constructor(worldContainer, app) {
        this.world = worldContainer;
        this.app = app;
        this.track = [];
        this.duration = 0;
        this.elapsedTime = 0;
        this.isPlaying = false;
        this.onComplete = null;

        // Position container center to the screen center
        this.world.position.set(this.app.screen.width / 2, this.app.screen.height / 2);
    }

    play(track, durationInSeconds, onComplete = null) {
        this.track = track;
        this.duration = durationInSeconds * 1000;
        this.elapsedTime = 0;
        this.isPlaying = true;
        this.onComplete = onComplete;
    }

    update(deltaMS) {
        if (!this.isPlaying || this.track.length < 2) return;

        this.elapsedTime += deltaMS;
        let progress = this.elapsedTime / this.duration;

        if (progress >= 1) {
            progress = 1;
            this.isPlaying = false;
        }

        // Apply easing for cinematic acceleration and deceleration
        const easedProgress = this.easeInOutCubic(progress);
        const cameraState = getSplinePoint(this.track, easedProgress);

        // Update container transform
        this.world.pivot.set(cameraState.x, cameraState.y);
        this.world.scale.set(cameraState.zoom);
        this.world.rotation = cameraState.rotation;

        if (!this.isPlaying && this.onComplete) {
            this.onComplete();
        }
    }

    easeInOutCubic(t) {
        return t < 0.5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2;
    }
}

5. Integrating with Pixi Application

Instantiate the camera controller and bind its update call to PIXI.Ticker:

import * as PIXI from 'pixi.js';

const app = new PIXI.Application({
    width: 800,
    height: 600,
    backgroundColor: 0x1099bb
});
document.body.appendChild(app.view);

const world = new PIXI.Container();
app.stage.addChild(world);

// Populate world with content (sprites, backgrounds, etc.)
populateWorld(world);

const camera = new CinematicCamera(world, app);

// Start camera animation: 8 seconds long
camera.play(cameraTrack, 8.0, () => {
    console.log("Cinematic shot finished.");
});

// Main Loop
app.ticker.add(() => {
    camera.update(app.ticker.deltaMS);
});

6. Dynamic Look-Ahead Trajectory

For active tracks where the camera follows a dynamic path or target, compute the forward tangent to align the camera rotation dynamically along the motion vector:

function getPathAngle(points, progress, delta = 0.01) {
    const nextProgress = Math.min(progress + delta, 1);
    const currentPoint = getSplinePoint(points, progress);
    const nextPoint = getSplinePoint(points, nextProgress);

    return Math.atan2(nextPoint.y - currentPoint.y, nextPoint.x - currentPoint.x);
}

Assigning the calculated angle to world.rotation (offset by your desired angle) keeps the camera aligned with the forward direction of movement along the track.
