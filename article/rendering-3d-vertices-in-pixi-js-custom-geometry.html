Rendering 3D Vertices in Pixi.js Custom Geometry

Pixi.js is engineered primarily as a 2D rendering engine, but it fully supports rendering 3D vertex positions \((X, Y, Z)\) using its low-level mesh API. By defining a custom PIXI.Geometry with a 3-component attribute buffer and attaching a custom PIXI.Shader configured with 3D projection matrices, developers can render and manipulate three-dimensional geometry directly within a standard Pixi.js scene.

Configuring the 3D Buffer in PIXI.Geometry

Pixi's PIXI.Geometry class allows you to define arbitrary vertex attributes. By default, 2D coordinates use a size of 2 (\(X\) and \(Y\)). To support 3D vertices, you must set the attribute size to 3 so the GPU reads three consecutive floating-point values (\(X, Y, Z\)) for each vertex.

import * as PIXI from 'pixi.js';

// Define vertices for a 3D triangle: [X, Y, Z, X, Y, Z, ...]
const vertices = new Float32Array([
  -50, -50,   0,
   50, -50,   0,
    0,  50, 100
]);

const geometry = new PIXI.Geometry();
geometry.addAttribute('aVertexPosition', vertices, 3);

Writing the Custom Shader

Because standard Pixi.js shaders expect two-dimensional positions, you must create a custom vertex shader that accepts a vec3 attribute. You then multiply this position by a projection or Model-View-Projection (MVP) matrix passed via uniforms.

const vertexSrc = `
  precision mediump float;

  attribute vec3 aVertexPosition;

  uniform mat4 uProjectionMatrix;
  uniform mat4 uWorldMatrix;

  void main() {
    gl_Position = uProjectionMatrix * uWorldMatrix * vec4(aVertexPosition, 1.0);
  }
`;

const fragmentSrc = `
  precision mediump float;

  void main() {
    gl_FragColor = vec4(1.0, 0.0, 0.0, 1.0); // Solid red
  }
`;

Constructing the Mesh and Matrices

Combine the geometry and shader using PIXI.Mesh. You must calculate and supply the perspective projection matrix and world transform matrix yourself, or use a matrix library such as gl-matrix.

const uniforms = {
  uProjectionMatrix: new Float32Array([ /* 4x4 perspective matrix */ ]),
  uWorldMatrix: new Float32Array([ /* 4x4 model-view matrix */ ]),
};

const shader = PIXI.Shader.from(vertexSrc, fragmentSrc, uniforms);
const mesh = new PIXI.Mesh(geometry, shader);

app.stage.addChild(mesh);

Handling the Depth Buffer

Pixi.js renders display objects sequentially using painter's algorithm sorting rather than depth testing by default. When working with overlapping 3D geometry, enable depth testing on the mesh state:

mesh.state.depthTest = true;

Enabling depth testing ensures that surfaces closer to the virtual camera correctly occlude surfaces located further along the Z-axis.
